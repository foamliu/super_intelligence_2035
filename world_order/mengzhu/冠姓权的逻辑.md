# 冠姓权的逻辑：从母系到父系，谁养跟谁姓

而我一直支持一件事情，就是冠父姓——除非你是自己来抚养他，除非母亲单独地抚养孩子，否则的话要让孩子冠父姓。

为什么这个样子？那就是为什么我们会从母系走向父系？最开始的姓，这个东西都是从母亲那里继承的，都是母姓。我们在母系时代的时候都是继承的母姓，所以你看我们最早期的几大姓，很多里面都是含一个“女”字的。包括嬴政的“嬴”里面也是有女的，姬周的“姬”也是有女的。为什么呀？因为都是从母系时代、从母亲那里继承的血缘关系、继承的姓。所以这些东西啊，原本就是从母亲那儿继承的。

那他为什么后来转进变成了从父亲那里继承的？因为从父亲那里继承了姓之后，他除了有一个爹，并不会失去他的妈，于是他就开始父母双全了，于是他就有了两个家族的扶持。于是这个孩子的成就更大，成长的可能性更大。就这样啊，发展的空间不一样啊。

所以你说为什么非得要从父亲？那难道不是我生的吗？那你让他从呗。你从了母姓之后，这个男人没有怀胎十月，然后他又没有这个姓氏的传承，他跟这个孩子之间的纽带窄得跟头发丝一样的。然后你又期待他用一生之力去托举这个孩子？割韭菜都不带这么割的——你这不是割韭菜，你是薅韭菜苗子。

这个姓从谁手上拿？孩子一定是母亲的孩子，但是姓不是这个男人的姓的时候，这个男人跟这个孩子之间就没有很明确的亲缘纽带、继承关系。你不想让人家托举，然后又不给冠姓权——咋啥事都让你想那么美好呢？

当然了，你要是自己养。母系社会为什么能够母姓传承？因为孩子都是娘家养，从来不找爹，你知道吗？所以你决定了说我要继承母姓，就是要继承——可以，我支持。自己养孩子，娘家养孩子，千万别找那个男人。什么爹是哪的不重要，你都不要让人家冠姓了，你找他干什么呀？跟他没有任何的关系。独立抚养，独立女性，自立自强——双手双脚赞成，没有任何问题。

入赘不就是这样吗？对啊，我们自古以来就允许从母姓的，没有说不从母姓这件事情。而是说姓氏传承是什么？姓氏传承是家庭继承权、家庭祭祀权的传承。这个传承的方式就是：你受了哪个姓，你就承担哪个姓，你承担哪个姓氏的财富继承，同时也承担这个姓氏的责任。就是这么回事。

所以你拿哪个姓是干嘛？我姓了李，就意味着李家的财产里头有我的一份，李家的责任里头有我的一份；我姓了张，那就是张家的财产有我一份，张家的责任有我一份。所以我们自古以来不是按照严格的性别关系来界定姓氏的传承的，是按照主导权——经济的主导权、能力的主导权以及财富的继承权——这个方面去考虑它的。

所以自古以来有赘婿，赘婿生下来的孩子就跟妈姓。为什么？因为娘养的。谁养、谁给孩子财富、谁给孩子托举，那个姓就是跟谁的。都是这样的。

你要是做不到——又要让别人出钱，又要让别人铺路，又要让别人出力气，然后又不给别人冠姓权——将来出了问题，自己兜着。
