他站起来，走到街边。手机没电了。他站在那里，想叫一辆车，但突然发现自己不知道要去哪里。

回实验室？那里有等待他签署的文件，有下午要开的会，有项目负责人的汇报。

回家？家里没人。妻子出差了，孩子在寄宿学校。

去公地的办公室？去那里做什么？人已经走了，服务器还在运行，但“那个”公地已经不存在了。不是物理上不存在，是结构上。就像一个人的骨架还在，但血液已经抽干了。

他站在那里，站了很久。

这不是“我决定”。这是“我没有选择”。

他想起1999年。符号AI被淘汰的那个春天。不是技术输了，是范式转移了。个人的道德选择在结构性力量面前毫无意义。

这一次，他不想再站在错误的一边。

他拦下一辆车。

“去哪？”司机问。

他想了想。“深智科技。”
```

事件报告已经写好，早上九点要提交。他靠在椅背上，没有开灯。窗外的深圳，灯火通明。数据中心的指示灯在远处闪烁，像某种静默的语言。

他伸出手，在黑暗中握了握拳头。然后松开。

他不知道自己在想什么。也许什么都不想。也许只是在确认，手还在，人还在。

# 第40.5章：哨声

北京，某会议室。

赵建军站在投影屏幕前，对面是五家头部AI平台的法务负责人。会议已经开了三个小时，核心议题只有一个：工作组模式的全国推广。

“为什么？”一个法务总监第三次问，“凭什么深智科技要进驻，我们也要？”

赵建军不能说出真正的理由。攻击事件的情报是机密，攻击手法的分析报告标记为“绝密”。他不能公开证明“你们已经被渗透了”，因为公开会暴露防御边界。

但他必须推动这个改变。因为证据告诉他，没有国家介入的制衡，下一次攻击可能不会只是72小时。

“因为这是必要的。”他说。

“必要”这个词太轻了。对面的人面面相觑。

会议结束后，赵建军站在走廊里。窗外的北京，灰蒙蒙的。

他想起陈思危早年在石林里做的那些事——在信息不对称中预警，在别人看不见威胁时吹哨。

现在他在做同样的事。

只是哨声不同。

陈思危吹给想听的人。他吹给不想听、但必须听的人。

他整理了一下领带，走进下一个会议室。
```

墨子：“我的设计告诉我，国家是人类创造的最复杂的系统之一。它也需要留白——被质疑的空间、被修改的接口、被推翻的可能。”

林薇看着窗外：“所以赵建军也需要被约束。”

墨子：“对。但不是由另一个赵建军。是由制度、由法律、由每一个愿意追问的普通人。”
