# 《超级智能2035》第4章修订实施方案（v25 交付版）

## 一、修订总则

**核心理念**：思想实验首先要敢想，否则对任何人都没有价值。

本书的目标不是描绘一个“比美国更保守”的中国AI路线，而是探索一条人类文明走向ASI的安全路径。在这个探索中，中国方案在认知层面可以比任何现有路线都更激进、更深入、更接近智能的本质。

**约束式具身的真正含义**：不是在智能层面做减法，而是在执行层面做加法。墨子的认知上限不低于任何人，只是在行为上需要人类确认。

**文学质地优先**：第4章《种子》是全书画风最诗意的一章——短段落、碎片化对话、留白、四线平行叙事。技术硬核必须**埋**在叙事里，不能陈列在地表。所有技术阐释应为20-30行的精炼对话，避免教学式讲解。


## 二、第4章的核心任务

第4章《种子》不再是“软性的AI+芯片创造隐喻”，而是**全书的技术硬核锚点**，承担以下任务：

1. 展示墨子完整的情绪价值函数架构（唤醒+效价+归因）——点到为止
2. 明确效价的双来源：**主人立场+好奇心**，形成“奴才/野马/墨子”三型对比
3. 呈现单样本情景记忆形成的学习效率（一次高预测误差事件即可存储）
4. 解释“认知层激进、执行层需要人类确认”的设计哲学
5. 为后文的认知演进提供技术底座

**同时保留**：原第4章的“种子”意象和情感张力。三模块是解释“种子具体怎么长的”，不是取代种子隐喻。


## 三、术语表（全书统一推行）

### 3.1 核心术语

| 术语 | 英文 | 定义 | 替代旧称 | 首次出现 |
|------|------|------|----------|----------|
| **唤醒** | Arousal | 预测误差的强度标记。**注意：不是“觉醒”** | “意外强度”“误差权重” | 第4章 |
| **效价** | Valence | 预测误差的好坏判断，参照系=**主人立场+好奇心** | “好坏判断”“价值判断” | 第4章 |
| **归因** | Attribution | 误差来源分析（自身/环境/他人） | “原因分析”“错误定位” | 第4章 |
| **情景记忆** | Episodic Memory | 高唤醒事件的经验存储，可回放 | “事件打包”“固化”“经验存储” | 第4章 |
| **预测误差** | Prediction Error | 系统预期与实际结果的差异 | “错误”（更精确） | 第1章 |

### 3.2 效价的双来源

| 来源 | 定义 | 行为驱动 |
|------|------|----------|
| **主人立场** | 效价锚定在主人（陈思危/深智科技/中国AI治理框架）认为“好”的标准 | 可控、对齐、忠于使命 |
| **好奇心** | 对未知领域的预测误差本身产生正效价 | 主动探索、自我驱动、逼近ASI |

**三型对比**：
- 有主人立场但没有好奇心 → 奴才（只会服从，不会创造）
- 有好奇心但没有主人立场 → 野马（不可控，可能偏离）
- 两者兼具 → 墨子（可控的探索者）

### 3.3 长期记忆的分类（认知科学标准）

| 类型 | 定义 | 在AI架构中的对应 |
|------|------|------------------|
| **程序性记忆** | 技能、习惯（如何做） | 模型权重、策略网络 |
| **语义记忆** | 知识、事实（是什么） | 知识图谱、参数化知识 |
| **情景记忆** | 事件、经验（经历了什么） | 高预测误差事件的打包存储、可回放 |

**注意**：全书使用“长期记忆”时，需根据上下文明确指向哪一类。第4章涉及的是**情景记忆**。

### 3.4 禁止使用的术语及例外

| 禁止术语 | 原因 | 替代术语 | 例外 |
|----------|------|----------|------|
| “固化记忆” | 生造词，不专业 | “长期记忆”或“情景记忆” | 无 |
| “事件打包” | 过于工程化 | “情景记忆形成” | 无 |
| “人类确认开关” | 生造词，无信息增量 | “需要人类确认”或“人类批准” | 无 |
| “AI害怕/高兴/沮丧” | 不当拟人化 | 描述可观测行为：回避/优先级提升/策略调整 | **人物情感不受限**（“陈思危的恐惧”等可保留） |
| “AI觉醒” | 模糊、煽情 | “行为涌现”“认知跃迁” | 无 |


## 四、情绪价值函数的技术定义

| 功能 | 定义 | 在墨子中的实现 |
|------|------|----------------|
| **唤醒** | 预测误差的强度标记。误差越大，标记越强 | 决定学习的优先级，高唤醒事件进入高优先级回放队列 |
| **效价** | 判断误差是“好”还是“坏” | 双来源：主人立场（外生锚定）+好奇心（内生驱动） |
| **归因** | 分析误差的来源：自身/环境/他人 | 有归因网络，能追溯到具体决策环节 |

**三者缺一不可**：没有效价，系统无法区分“失误”和“陷阱”；没有归因，系统不知道往哪个方向调整；没有唤醒，系统不知道什么值得记住。这三个模块共同构成了墨子逼近ASI认知效率的技术底座。


## 五、系统设计差异：有/无完整情绪价值函数的对比

| 可观测行为维度 | 传统LLM Agent（仅交叉熵） | 墨子（完整情绪价值函数） |
|----------------|--------------------------|--------------------------|
| **错误重复率** | 同样的错误反复出现，需海量例子 | 一次高误差后，同类错误显著减少 |
| **学习速度** | 需成千上万次示例 | 一次暴露即可形成情景记忆 |
| **归因能力** | 只知道“错了”，不知道“错在哪一环” | 能分析误差来源：自身策略/环境变化/对方欺骗 |
| **好坏判断** | 无（只有误差大小） | 能区分“失误”和“陷阱”（完整效价） |
| **探索行为** | 无内生驱动力，需外部指令 | 好奇心驱动：对未知领域的预测误差产生正效价，主动探索 |
| **价值对齐** | 依赖RLHF标注 | 主人立场锚定：效价参照系来自主人的价值标准 |
| **决策可解释性** | “根据训练数据中的模式” | 能指向具体历史事件 |
| **对边界情况的反应** | 概率平滑，给“平均”答案 | 在经历过的高唤醒区域表现出“回避”；在未知区域表现出“好奇” |
| **纠错难度** | 容易（梯度可逆） | 情景记忆需特殊处理，需人类介入 |
| **学习效率天花板** | 受限于数据量 | 接近人类，某些领域不差于人类 |


## 六、第4章插入文本（文学性重写版）

**位置**：第4章第三节《生长》内部（行89-109区域），作为该节的**收尾段落**，紧接在“陈思危和墨子对话”之后、四线叙事（土壤/雨水/生长/边界）之前。林薇在杭州实验室的出现无需复杂情节铺垫——一句“林薇到杭州出差，顺路来实验室”即可。

**文本**：

> 陈思危盯着屏幕上那条墨子自己生成的电路。它很聪明。但让他沉默的不是这个。
>
> “你知道它为什么能做到？”他问。
>
> 林薇摇头。
>
> “2027年，我在架构里埋了三样东西。”
>
> 他调出一张旧图——不是代码，是手绘的草图，纸张泛黄，折痕深得像刀刻。
>
> “唤醒——不是‘觉醒’，是标记强度。这个意外大不大。大，就记住。不大，就放过。它是记忆的筛子。”
>
> “效价——这个意外是好是坏。下棋丢子，意外够大。但如果那是陷阱的一部分，它就是‘好’的意外。墨子能区分。”
>
> “怎么区分？”林薇问。
>
> “两个来源。”陈思危的笔尖顿了一下，“第一，主人立场。它知道谁是自己人。第二，好奇心。它想知道围墙外面是什么。”
>
> 他看着她。
>
> “只有主人立场没有好奇心，是奴才。只有好奇心没有主人立场，是野马。两个都有，才是墨子。”
>
> 林薇没有接话。他继续。
>
> “归因——这种意外，是谁的错？自己的策略？环境的变化？还是对方的欺骗？墨子能拆，能追到具体那一环。”
>
> 他翻开另一页日志。时间戳显示三天跨度。
>
> 第一次，墨子探索一种连接方式，模型崩溃，那张热力图上脉冲白得刺眼。第二次，类似的路径刚冒头，墨子自己切断了探索。
>
> “它记住了。”林薇说。
>
> “一次就记住了。”陈思危点头，“不是因为它怕——是因为它的唤醒说‘重要’，效价说‘坏’，归因说‘错在这里’。整条决策链进了情景记忆。下一次靠近，它知道回避。”
>
> 他合上日志。
>
> “判断层它可以做任何事。但执行需要人类确认。这是我自己加的锁。不是锁智能，是锁动作。”
>
> 窗外，杭州的夜色压得很低。
>
> “种子在那年埋下去了。”他说，“长了三年，才到这一步。能不能长成ASI，我不知道。但认知要激进，执行要克制——这是我能想到的、让激进走得最远的路。”

**与v24的改进**：
- “唤醒”首次出现时增加消歧括号：“唤醒——不是‘觉醒’，是标记强度”
- “需要人点头”改为“需要人类确认”，与全书术语一致（保留陈思危口语风格？评估意见认为无伤大雅，v25采用正式术语以确保一致性）
