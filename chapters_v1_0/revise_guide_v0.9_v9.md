# 《超级智能2035》粗体字修订实施方案 v9.1

## 基于评估意见的调整说明

评估认为原方案（不超过10处）过于激进。本版调整为：

| 项目 | v9.0 | v9.1（修订后） |
|---|---|---|
| 全书粗体上限 | 10处 | **15-25处** |
| 结构性标题/文档标签 | 全部删除 | **保留** |
| 功能性视觉锚点 | 删除 | **保留或单独成行替代** |
| 修订轮次 | 一次性 | **三轮渐进** |


## 一、修订原则

### 1.1 核心原则

| 原则 | 说明 |
|---|---|
| **少即是多** | 粗体总量控制在15-25处 |
| **分层保留** | 主题句/核心概念/结构锚点/文档标签——不同层级不同标准 |
| **叙事优先** | 观点的重量应依赖上下文和句法，而非格式 |
| **功能第一** | 有实际导航功能的粗体（如结构标题）予以保留 |

### 1.2 分层保留标准

| 层级 | 类型 | 数量上限 | 处理方式 |
|---|---|---|---|
| **一级（必留）** | 全书主题句、核心哲学追问、核心概念首次定义 | 5-8处 | 保留粗体 |
| **二级（选留）** | 各章核心命题、人物成长标志性台词 | 10-15处 | 每章最多1处 |
| **三级（功能）** | 章节结构标题、技术文档标签、列表视觉锚点 | 不限 | 保留，或改为单独成行 |

## 四、实施路径（三轮渐进）

### 第一轮：删除明显过量的

- 同段出现3处以上粗体 → 删至最多1处
- 连续3个段落都有粗体 → 保留其中1处
- 删除操作性内容中的非必要粗体

**目标**：将粗体总量压缩至40处左右

### 第二轮：句法替代

将可用句法替代的粗体改为：

| 原格式 | 替代方案 |
|---|---|
| 粗体 | 破折号断句（“十五小时——不是剩余，是精华。”） |
| 粗体 | 独立短句成行（“AI做，人判断。”换行“AI执行，人定义。”） |
| 粗体 | 排比递进 |

**目标**：将粗体总量压缩至20-25处

### 第三轮：语感筛选

通读全文，凭阅读体验判断：

- 看到粗体时是否感到“这里确实重要”？
- 还是感到“这里又被加粗了”？

根据语感删减至15-20处。
