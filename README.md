# 《超级智能2035》

> 事缓则圆——在加速时代的生存哲学  
> 作者：刘杨（Foam）

---

## 项目简介

一本关于AI时代技术哲学的未来学著作。通过2035年的思想实验，追问智能时代的生存之道。

**核心问题**：
- 当算法可以优化一切，谁来决定什么值得被优化？
- 在效率至上的时代，"事缓则圆"的智慧还有什么价值？
- AI时代，人还有什么不可替代的价值？

**叙事特色**：用西方的分析框架解剖未来，用东方的思维结构作为潜台词。如盐入水，有味无痕。
