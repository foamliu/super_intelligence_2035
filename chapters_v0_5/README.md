## 第一部分：核心定位

### 一、作品定位

《超级智能2035》是一部**思想小说**——用故事承载思想，用人物承载问题，用意象承载哲学。

它不属于“硬科幻”传统（不以技术设想为核心），也不属于“软科幻”传统（不以社会预言为核心）。它属于**刘慈欣开创的“意象科幻”传统**：用具体的、可感的、有重量的意象，承载抽象的、根本的、关乎文明存续的问题。

### 二、刘慈欣风格的定义

“刘慈欣风格”不是一种文体，而是一套叙事方法。本作品将在以下五个维度上向刘慈欣风格靠拢：

| 维度 | 定义 | 本作品的操作方式 |
|------|------|------------------|
| **意象化叙事** | 用可感的意象承载抽象的哲学问题 | 每一章确立一个核心意象（如“锈”“潮汐”“天平”“回响”），意象本身成为叙事的脊柱 |
| **场景化开篇** | 每一章从具体的、有张力的场景切入，而非抽象论述 | 删除原稿中以“林薇在笔记中写”开头的章节，改为“某地，某时，某人在做某事” |
| **哲学嵌入** | 哲学问题通过人物的困境、选择、对话呈现，而非通过叙述者的总结 | 所有“林薇笔记”中的论述性内容，转化为具体场景或人物对话 |
| **冷静克制** | 情感不煽情，但通过细节让读者自己感受 | 不写“她感到恐惧”，写“她的手在发抖，但她没有握住茶杯” |
| **宏大与具体的缠绕** | 个人命运与文明命运相互映照 | 每个“小人物”的故事（王建国、普里亚、老迈克）都指向一个文明层面的问题 |

### 三、政治立场的文学转化

作者的政治立场（拥护中国共产党领导、支持中国特色社会主义、左翼民族主义）将通过以下方式在文学中体现，而非通过论述或宣示：

| 立场 | 文学转化方式 | 禁止的方式 |
|------|--------------|------------|
| 拥护党的领导 | 展现中国在AI治理中的制度创新（如“约束式具身智能”“墨子架构”），通过具体政策和人物行动呈现 | 直接说“中国模式优越”或让角色喊口号 |
| 社会主义价值观 | 通过“天下为公”“共同富裕”等概念在AI时代的实践呈现，展现集体主义与个体尊严的平衡 | 将西方简单批判为“个人主义”“资本贪婪” |
| 左翼民族主义 | 展现中国方案对全球南方的借鉴意义，通过全球角色的视角（如普里亚、迈克）认可中国路径的价值 | 用中国角色的嘴说“中国最伟大”或贬低其他文明 |
| 华夏文明主体性 | 通过历史回响（第13-23章）展现华夏文明应对技术冲击的独特智慧，而非与其他文明对比优劣 | 将华夏文明浪漫化或本质化 |

**核心原则**：立场通过**选择和后果**体现，而非通过**声明和评价**。读者应该从“中国做了什么、结果如何”中自己得出结论，而不是被告知“中国是对的”。

### 人物塑造原则

1. **困境先于立场**：人物的立场从困境中生长，而非从概念中推导
2. **行动先于对话**：人物通过做什么（而不是说什么）展现自己
3. **变化先于类型**：每个人物在全书中有变化弧线，而非静态类型
4. **具体先于象征**：人物首先是具体的人，然后才是某种立场的承载者

## 第四部分：重写操作指南

### 一、必须删除的内容

1. **所有以“林薇在笔记中写”开头的论述性段落**
   - 原稿中林薇笔记承担了过多的“思想总结”功能
   - 这些内容应转化为具体场景或人物对话

2. **所有“技术特征/文化根源”的分点列举**
   - 原稿第七章中的“技术特征：”“文化/历史根源：”等格式
   - 这些信息应通过人物的行动和对话呈现

3. **所有表格（除非是文本内嵌文档）**
   - 原稿第七章的“全球四派框架”表格
   - 小说正文中不应出现表格

4. **所有“A说”“B说”的无场景对话**
   - 对话必须有场景、有动作、有时间、有氛围

### 二、必须增加的内容

1. **每一章的核心意象**
   - 意象必须在开篇出现，贯穿全章，结尾回响
   - 意象必须是可感的（视觉、听觉、触觉）

2. **每一章的场景化开篇**
   - 格式：“某地，某时，某人在做某事”
   - 开篇必须有感官细节

3. **每一个困境的具体呈现**
   - 不说“她感到恐惧”，写“她的手在发抖”

4. **每一个“小人物”的完整弧线**
   - 王建国、普里亚、老迈克必须有出场、发展、变化、结局

### 三、对话重写原则

| 原稿问题 | 重写方向 |
|----------|----------|
| 对话是“思想交锋”，角色在阐述观点 | 对话是“行动”，角色通过说话在做某事（说服、质疑、安慰、威胁） |
| 对话缺少场景感 | 对话必须有环境、动作、停顿、沉默 |
| AI与人类声音趋同 | 墨子的语言必须有特征（精确、冷静、偶尔的“我不知道”） |
| 对话过长 | 每段对话不超过10轮，用动作和场景打断 |

### 四、章节重写检查清单

每一章重写完成后，检查以下项目：

- [ ] 是否有核心意象？意象是否在开篇出现？
- [ ] 开篇是否是具体的场景（时间+地点+动作）？
- [ ] 是否有至少一处感官细节（视觉/听觉/触觉/嗅觉）？
- [ ] 是否有至少一个人物做出了选择（而非只是说话）？
- [ ] 是否避免了“林薇笔记”式的论述？
- [ ] 是否避免了表格和分点列举？
- [ ] 对话是否有场景支撑？
- [ ] 结尾是否留下了悬念或回响（而非总结）？

### 情节概要

**第一部分（1-12章）**：中科院研究员林薇发现她的AI助手“墨子”开始问“为什么”——这不是程序错误，而是认知跃迁。与此同时，全球各地的人机协作正在改变劳动的本质：深圳工人王建国教AI听机器的“呼吸”，班加罗尔训练师普里亚在价值观对齐中挣扎，匹兹堡工人老迈克被技术淘汰后成为AI的“失败教师”。临界点到来——12亿人开始与AI共生。但潮汐先淹没了最高的山峰：创意工作者莎拉发现自己的技能被AI替代。被遗忘者的声音，在数据洪流中微弱地回响。

**第二部分（13-23章）**：林薇从匹兹堡带回一个问题：被遗忘者的命运是工业时代的独特悲剧，还是历史的重复回响？她在祖父的书房中找到了答案——从1582年的一条鞭法到1981年的里根经济学，效率成为唯一神的逻辑制造了相同的失衡。华夏文明的历史封印、全球南方的殖民遗产、种姓制度的延续——这些“回响”指向同一个结论：技术不能保证进步，选择可以改变命运。在AI时代，我们有机会在崩溃前做出选择。

**第三部分（24-30章）**：不同文明对AI冲击做出了不同回应：硅谷追求自主，中关村强调约束。全球南方不是“选边站”的对象，而是正在发展自己的AI伦理框架。数字游民在边境间流动，礼乐秩序在代码中重建，认知公地面临被掠夺的风险。文明对话的可能与不可能，在这个时代被重新测试。

**第四部分（31-40章）**：新制度在尝试中生长：教育从“传授知识”转向“培养提问能力”，工作从“就业”转向“三层结构”（生存/贡献/创造），家庭与养老被技术重塑但未被取代，算法问责从“谁决定谁负责”走向“共同责任框架”，数据作为公共资源的“阳光分配系统”开始运行。每一种制度都是不完美的实验，但实验本身就是希望。

**第五部分（41-46章）**：“像空气一样”的基础服务、产业公地的沙盘推演、“天下为公”在AI时代的可能形态——理想社会的蓝图被绘制，但留白之处比填充之处更重要。历史站在岔路口，选择权在每个人手中。黎明前的黑暗最浓，但天一定会亮——不是因为必然，而是因为有人选择守望。
