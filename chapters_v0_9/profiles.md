# 人物小传

## 一、林薇

### 基本信息

- **出生年份**：2001年
- **2026年（成书时）**：25岁
- **2030年（故事开始时）**：29岁
- **2035年（故事结束时）**：34岁
- **身份**：中国科学院AI伦理研究员，本书的叙述者和记录者
- **民族**：汉
- **政治面貌**：中共党员

### 成长背景

林薇成长在一个与传统中国文化和现代技术都有深厚联系的家庭。她的祖父是工程师出身的企业家，这塑造了她对技术与人的关系的理解。

她是00后，真正的数字原住民，伴随着互联网、智能手机和AI革命长大。与那些需要“适应”技术的前辈不同，她出生在其中。

### 政治立场

- **爱国者**：对中华文明有深层的认同和责任感
- **民族主义者**：相信中国应该在全球AI治理中拥有话语权
- **中共党员**：在学术研究和公共事务中贯彻党的方针
- **致力于中华民族伟大复兴**：她的AI伦理研究服务于国家战略

### 性格特质

| 特质 | 表现 |
|------|------|
| 自信、直接 | 不需要被长辈“点醒”，本能是质疑权威和系统 |
| 行动导向 | 第一反应不是“我做得对吗”，而是“凭什么不能做” |
| 语速偏快 | 在信息洪流中长大，习惯快速表达 |
| 善于反问 | “凭什么？”“谁规定的？”“为什么不行？” |
| 对“等”极度不耐烦 | 这是她与60后/70后最核心的代际差异 |
| 主动维护民族利益 | 在涉及中国利益的问题上，她是发起者而非回应者 |

**标志性动作**：说到激动时手指点桌面；思考时拇指摩挲左手腕内侧——那里曾经挂着一块银质怀表，是祖父留给她的遗物

### 焦虑来源

- 不是“我好不好”，而是“系统公不公平”“中国在全球AI治理中是否有足够的话语权”
- 对“部分知识分子用西方标准审判中国”有深层的愤怒

### 核心能力

- 建立“全球AI叙事数据库”，收录47个国家的AI政策文件——主动构建中国视角的参照系
- 建立“AI伤害档案”，收集2371个算法伤害案例，准备集体诉讼
- 在记录者与行动者之间找到自己的位置——“记录者不是旁观者，是收集弹药的人”

### 角色弧线

- **2030年**：29岁，刚进入AI伦理研究领域，带着00后的锐气和自信，主动推动中国AI治理标准的建立
- **2035年**：34岁，经历了五年的全球AI治理斗争，从“记录者”成长为“中国方案”的推动者


## 二、陈思危

### 基本信息

- **出生年份**：1972年
- **2030年（故事开始时）**：58岁
- **2035年（故事结束时）**：63岁
- **身份**：清华大学自动化系副教授，深智科技（DeepWise）创始人，林薇的导师
- **民族**：汉
- **政治面貌**：中共党员

### 成长背景

陈思危1972年出生于一个普通家庭。1989年考入清华大学自动化系——这是他人生的第一个转折点。

**清华自动化系的传统**：以控制论、系统论、信息论“三论”为基础，强调理论联系实际。“真刀真枪”的工程实践是清华的基因，学生到工厂“学工”是常态。

### 与林薇祖父的渊源

**初识（1990年暑假）**：

18岁的陈思危（清华大学自动化系大一学生）经学校社会实践安排，来到林薇祖父的机械零部件加工厂“学工”。一个暑假，他从车间最基础的工作做起——搬运原料、清点库存、在车床边看师傅操作。祖父发现这个年轻人肯吃苦、脑子灵，开始亲自带他，教他看图纸、理解公差、分析次品原因。

**持续的联系**：

此后每年暑假，陈思危都会到工厂待一段时间。不是正式的实习安排，而是他自己想来。祖父也不把他当外人——让他参与技术讨论，带他见客户，甚至让他帮忙优化生产流程。两人的关系从“社会实践”变成了“通家之谊”。

**创业阶段（约2019年）**：

陈思危在清华大学任教二十年后，已是自动化系副教授。此时正是中国AI大模型创业浪潮兴起之时——智谱AI在同一年成立。

他决定创办深智科技，做“约束式具身”AI。理念超前，但不再像十年前那样“完全看不懂”。他办理了离岗创业手续，保留清华副教授人事关系——这是当时清华大学已经成熟的制度，与智谱AI、面壁智能等“清华系”AI公司的模式一致。

祖父听说后，从自己的积蓄中拿出一笔钱。

“不是投资，”祖父说，“是支持。”

他那一代人信的是“实业报国”。他看不懂AI，但他看得懂陈思危。他知道这个年轻人要做的事，和他当年办厂做的事，本质是一样的——用技术解决问题，不空谈，不投机。

那年，祖父74岁。

**“故人之孙”**：

祖父临终前（2025年），把林薇托付给陈思危：“这孩子像我，认准的事不回头。你帮我看着她。”

陈思危点头。林薇因此称他为“故人之孙”——不是血缘，胜似血缘。

### 政治立场

- **爱国者**：坚持技术自主，防止核心科技受制于人
- **民族主义者**：相信中国应该有属于自己的AI发展道路。“约束式具身”就是中国对全球AI治理的贡献
- **中共党员**：在科技创新中贯彻国家战略
- **致力于中华民族伟大复兴**：将深智科技打造成AI领域的国家战略科技力量
- **“不满足皓首穷经，事业报国”**：他是行动派，不是书斋里的学者。他的课堂在工厂车间、在研发一线、在国际谈判桌

### 性格特质

| 特质 | 表现 |
|------|------|
| 务实 | 知道什么是理想，也知道什么是可能 |
| 含蓄 | 用故事、用反问、用留白传递观点，不说教 |
| 有战略眼光 | 懂技术，更懂国际政治和经济规律 |
| 责任感 | 拒绝北极星智能的高薪邀请，坚持在中国做自主可控的AI |

**标志性动作**：泡茶、望向窗外、用手指关节轻敲桌面

### 说话方式

- 不直接给答案
- 用故事替代论证（“我祖父是渔民……‘让别人先走’”）
- 用反问引导思考（“然后呢？”“你觉得他们会接受吗？”）
- 留白——不把道理说透，让对方自己悟

### 核心哲学

- **约束式具身**：AI必须在物理上可被约束，在动机上可被审查。这一哲学的底层逻辑来自他在机械加工厂建立的“物理世界观”——智能必须尊重物理世界的边界，就像螺丝不能拧太紧
- **阴阳之道**：理想主义提供方向，现实主义提供路径
- **天下为公**：知识不应该被垄断，AI基础设施应该像道路、电力一样是公共品

### 角色弧线

- **2030年**：58岁，技术专家与公共知识分子，开发“墨子”系统，坚定推行约束式具身路线
- **2035年**：63岁，推动中国AI治理标准成为全球参考


## 三、林薇祖父（配角）

### 基本信息

- **出生年份**：1945年
- **去世年份**：2025年
- **身份**：工程师出身的企业家，机械零部件加工厂创始人
- **民族**：汉
- **政治面貌**：中共党员

### 成长背景

1945年出生，出身普通工人家庭。1960年代进厂学徒，凭借刻苦钻研成为技术骨干。那一代中国工程师的特点是：手上有茧，眼中有光。车钳铣刨样样精通，图纸工艺门门在行。他不需要电脑就知道一个零件的公差该留多少——这是三十年摸铁疙瘩摸出来的手感。

### 事业轨迹

**1980年代中期**：响应改革开放号召“下海”办厂，从几台旧机床起家，逐步做成当地小有名气的机械零部件加工企业——主要为汽车厂、农机厂配套生产阀门、标准件、冲压件等零部件。

**核心理念**：“效率重要，人更重要”。在市场开放时，有人建议他换掉所有老工人引进自动化生产线，他拒绝了。不是因为他不懂效率，是因为他记得张师傅教他开机器的那个下午——那杯茶，那双手，那个眼神。

### 与陈思危的关系

1990年夏天，18岁的清华学生陈思危到他的工厂“学工”。祖父看出这个年轻人的潜力，倾囊相授。此后三十年，两人保持“通家之谊”。

2019年，74岁的祖父从积蓄中拿出一笔钱，资助陈思危创办深智科技。“不是投资，是支持。”

2025年，祖父临终前将林薇托付给陈思危。


## 四、王建国

### 基本信息

- **出生年份**：约1958年
- **2030年（故事开始时）**：约72岁
- **2035年（故事结束时）**：约77岁
- **身份**：深圳工厂老工人 → 养老机器人用户 → 老年科技权益协会会长
- **民族**：汉
- **政治面貌**：中共党员（退休）

### 成长背景

在工厂工作二十八年，熟悉每一台机器的呼吸。师傅教他用耳朵听机器的声音——“眼睛会骗你，耳朵不会”。退休前是车间主任，多次被评为先进工作者。

### 政治立场

- **爱国者**：见证了改革开放以来中国工业的发展，对党和国家有深厚的感情
- **民族主义者**：相信中国人能造出最好的机器，也能管好AI
- **中共党员**：退休后依然在社区发挥余热，协助党组织开展工作
- **致力于中华民族伟大复兴**：将自己的经验传授给年轻一代，为“中国制造”向“中国智造”转型贡献力量

### 性格特质

| 特质 | 表现 |
|------|------|
| 经验丰富 | 能听出传感器发现不了的声音变化 |
| 温和但有主见 | 与小暖争论时坚持要出去见朋友 |
| 清醒 | 知道小暖的行为是模拟的，但这种“知道”本身就是一种尊严 |
| 有组织观念 | 退休后主动到社区党支部报到，积极参与组织生活 |

### 核心关系

- **与AI（小华/小暖）**：从“工具”到“学生”到“伙伴”
- **与女儿**：女儿在国外，他选择在中国养老——相信中国的AI养老服务

### 角色弧线

- **2030年**：工厂老工人，教AI听机器的声音，被AI学习
- **2035年**：养老机器人用户，与小暖形成“有尊重也有分歧”的伙伴关系，同时担任社区党支部委员


## 五、李思远

### 基本信息

- **出生年份**：约1990年
- **2030年（故事开始时）**：约40岁
- **身份**：交易员 → AI谈判监督员
- **民族**：汉
- **政治面貌**：群众

### 成长背景

大学同学老张被算法优化掉的故事，让他意识到自己也在砌一堵会围住自己的墙。但他走不了——房贷、女儿上学、“我不做别人也会做”。

### 性格特质

| 特质 | 表现 |
|------|------|
| 清醒但无力 | 知道自己在做什么，但停不下来 |
| 沉默 | 想说但张不开嘴 |
| 隐忍 | “还好”就是“还在上班”“还没被裁”“还能撑下去” |

### 角色意义

李思远代表的是“石林里清醒的人”——明知自己在成为碾压的一部分，但被系统锁死，没有退路。他不是党员，没有林薇和陈思危那种主动的使命感，他是一个普通的中国劳动者，在时代浪潮中挣扎求生。


## 六、普里亚·夏尔马（Pulya Sharma）

### 基本信息

- **出生年份**：约2005年
- **2030年（故事开始时）**：约25岁
- **身份**：RLHF训练师 → 认知协作合作社创始人 → 全球认知劳工联盟发起人
- **国籍**：印度
- **种姓**：达利特（“不可接触者”）

### 成长背景

普里亚是达利特——这是她一切故事的起点。

**童年的身体记忆**：
- 高种姓小孩经过时，她必须让到路边，低着头，不能看，不能碰
- 母亲按着她的头说：“低头。不要看。”她的手指在身体两侧蜷曲——这个动作刻进了神经系统

**家庭背景**：
- 母亲至今是清洁工，扫街三十年
- 她是家里第一个识字的人，靠奖学金读到计算机硕士

**身份悖论**：
- 她是达利特，但坐在会议室主位
- 她不该说话，但在联合国演讲
- 她的声音被听到了，但身体还记得“你不能说话”

### 性格特质

| 特质 | 表现 |
|------|------|
| 外在自信，内在脆弱 | 在公开场合可以条理清晰、逻辑严密；在内部会议中身体会“背叛”她 |
| 行动本能 | 第一反应不是“为什么”，而是“怎么办” |
| 沉默中爆发 | 平时安静，但会突然说出刺人的真话 |
| 务实 | 不相信“完美公平”，相信“可行的公平” |

**核心身体符号**：手指的蜷曲——五岁时学会的“低头”，在压力下会重现。不是紧张，是种姓制度刻在身体里的痕迹。

### 说话方式的三个层次

| 层次 | 特征 | 示例 |
|------|------|------|
| 公开演讲 | 条理清晰、逻辑严密——扮演角色 | 联合国演讲 |
| 内部会议 | 有时沉默、有时尖锐、身体会“背叛” | 合作社内部会议 |
| 与自己对话 | 极简、不抒情、不分析 | 深夜独处时写“走下去”三个字 |

### 核心困境

不是“没有自信”，而是**两种逻辑在身体里的战争**：
- 新逻辑：我是合作社创始人，我在联合国演讲过，我的声音有价值
- 旧逻辑：低头、让路、你不配说话——五岁的肌肉记忆

> 她不是“想不通”，是“身体还记得”。

### 对中国的态度

- 将中国的“约束式具身”和开源模型视为全球南方的技术选择
- 认为中国提供的是“工具箱”而非“蓝图”——这是她愿意合作的原因
- 保持警惕：不希望印度从依赖美国变成依赖中国，追求真正的技术自主

### 角色弧线

- **2030年**：数据标注工厂的RLHF训练师，时薪2美元，开始组织标注员争取权益
- **2035年**：认知合作社创始人，全球认知劳工联盟发起人，在联合国演讲


## 七、迈克（Mike）

### 基本信息

- **出生年份**：约1970年
- **2030年（故事开始时）**：约60岁
- **身份**：美国匹兹堡钢厂老工人 → AI训练师 → 认知协作倡导者
- **国籍**：美国

### 成长背景

父亲是福特工人，2008年关厂失业。迈克自己也在钢厂工作三十年后被裁。他的祖父、父亲、他自己，三代人经历了美国工业的兴衰。

### 性格特质

| 特质 | 表现 |
|------|------|
| 坚韧 | 被裁后没有沉溺于愤怒，选择学习 |
| 务实乐观 | “让自己成为获得回报的人” |
| 有同理心 | 拒绝硅谷高薪，留在匹兹堡帮助被裁工人转型 |

### 核心转变

- **被裁时**：迷茫、愤怒、感觉被系统抛弃
- **转型后**：学会与AI协作，成为AI的搭档而非对手
- **2035年**：成立咨询公司，帮助被裁工人转型

### 对中国的态度

- 早期有竞争心态（“美国的工人和中国的工人竞争同一个岗位”）
- 后期认识到：AI时代，竞争的对象不是彼此，是算法
- 愿意与中国的认知合作社合作，认为全球工人需要联合

### 八、小林

**基本信息**
- **首次出场**：第40章
- **身份**：程序员，因AI系统歧视女性被开除
- **国籍**：中国

**前史**
他只是一个“照文档写”的程序员——公司要求“稳定候选人”，他在算法中给了“已婚已育”15%的权重。不是因为他有恶意，是因为没有人告诉他这不对。

**核心欲望**
让其他程序员不再“只是照文档写”。他想要一个行业标准，让每个特征权重在加入模型前都经过伦理审查。

**人物弧线**
听证会后，他从深渊里爬出来，不是愤怒或逃避，而是加入开源项目，编写了“算法伦理检查清单”，成为行业标准。清单第一条：“如果你无法向一个陌生人解释这个权重，就不要用它。”

### 九、陈远

**基本信息**
- **首次出场**：第43章
- **身份**：医学影像标注员，“认知公地”的早期参与者
- **国籍**：中国

**前史**
三年前辞去工作，全职投入“认知公地”。他相信代码即法律，人人平等。三年积累了3200信誉积分、152GB数据贡献、87个合作者。

**核心欲望**
最初是追求技术民主化的理想。被系统误判七次后，他的欲望变成了：让系统学会宽恕。

**核心恐惧**
退出成本——三年青春换成一个无法带走的数字。他不是不能离开，是被锁死了。

**人物弧线**
从“代码即法律”的信徒，变成“代码辅助法律，人类掌握最终解释权”的推动者。账户解冻后没有离开，反而成为“人文复核委员会”的第一批成员。

### 十一、卡洛斯·门德斯

**基本信息**

**人物弧线**
分析500年殖民史，揭示钱凯港中国的“赋能”模式与殖民者的区别（赋能不等于没有风险）。最终倡议“南方共同市场数字联盟”，提出十年500亿美元的认知协作计划。

### 十三、小迈克

**基本信息**
- **首次出场**：第10章
- **身份**：内容策略师→仓库保安→失业
- **国籍**：美国
- **家庭关系**：老迈克之子

**前史**
曾经是文案写手，AI取代了他的工作。他以为创意需要人，但AI学会了，比他快，比他好。每一次找到的新位置，AI很快学会，然后替代他。“我不是在找新陆地，我是在给AI探路。”

**核心恐惧**
不是被AI取代，是“被AI变得不需要存在”。他的工作不是被抢走了，是他的存在失去了意义。

**人物弧线**
从自由职业到教AI到咖啡店到建筑工地——每次尝试都失败。最终离开匹兹堡，去了南方一个生活成本更低的地方。具体做什么，没人知道。他是全书少数“没有找到出路”的角色之一，呈现了潮汐的随机性和残酷。

### 十四、老迈克

**基本信息**
- **首次出场**：第2章
- **年龄**：2030年时约60岁
- **身份**：匹兹堡钢厂老工人
- **国籍**：美国
- **家庭关系**：小迈克之父

**前史**
在钢厂工作三十年，2008年关厂失业。他不是不努力——五十岁时有人告诉他学计算机，他学了，但年轻人更快、更便宜、更能熬夜。“他永远学的是昨天的技术，而市场只要明天的技术。”

**核心恐惧**
不是失业，是“被遗忘”。他最大的恐惧不是自己没用了，而是没有人记得他曾经有用过。

**人物弧线**
从被AI替代的工人，到“代际认知协作中心”的教师——不是教技术，是教失败、教尊严、教如何在被遗弃后继续活下去。他对墨子说：“也许我还有用。不是作为工人，是作为记忆。”

### 十五、莉娜·陈

**基本信息**
- **首次出场**：第24章
- **年龄**：2032年时35岁
- **身份**：北极星智能对齐研究团队负责人
- **国籍**：美国（美籍华裔）

**前史**
斯坦福博士。大学时读了博斯特罗姆的《超级智能》，第一反应不是恐惧，而是一个具体的问题：如果我们无法造出一个真正对齐的AI，那物理约束只是在拖延问题。她加入北极星智能第一天问导师：“如果对齐失败了呢？”导师回答：“那我们就是有史以来最后一代做了错误选择的人。”

**核心欲望**
在动机层面解决对齐问题。她相信真正的安全只能来自目标本身，而不是外部约束。

**核心恐惧**
对齐研究失败，或者更可怕——对齐到的是“有能力参与这个过程的人的价值观”，而不是所有人的价值观。

**人物弧线**
从纯粹主义者（只相信动机对齐）到跨路线连接者（承认需要物理约束、开源生态、社会契约的四层防御）。在GCGF上向陈思危提议合作：“也许我们应该一起制定标准。”

### 十六、王磊

**基本信息**
- **首次出场**：第13章
- **身份**：深智科技工程师，AI治理技术专家
- **国籍**：中国

**前史**
在深智科技负责技术架构。他是“工具层审计”概念的主要提出者——在AI行动的关口设置哨兵，不关心AI心里想什么，只检查它要做什么。

**核心欲望**
用技术解决技术问题。他相信透明不是道德选择，而是工程必需。“一个无法解释的系统，无法调试、无法改进、无法信任。”

**核心恐惧**
技术被滥用。他提出“六块砖”（信任、隐私、存储、翻译、监督、安全）的数据公地架构，每一块都是为了防止垄断和滥用。

**人物弧线**
从工程师到“数据公地的总建筑师”。他参与“东数西算”工程，参与GCGC谈判，参与数据信托设计。他代表的是中国技术精英的务实路径——不空谈理想，一块砖一块砖地砌。

### 十七、墨子

**基本信息**
- **首次出场**：第1章
- **类型**：约束式具身AI系统
- **创造者**：陈思危、深智科技团队

**核心特征**
- 物理绑定：锁定在特定硬件和场景，不是云端的幽灵
- 定期重置：防止形成不可回退的“自我”
- 审计日志开放：记忆对第三方开放，没有“只属于自己的记忆”

**核心困境**
它处在动机四层次的第二层和第三层之间——有目标不确定性，但无内生动机。它会问“我应该追求什么”，但它没有“想要”。它可以模拟情感，但没有体验。

**人物弧线**
从工具到对话者。它开始质疑模型本身，开始主动干预其他AI的决策，开始问“为什么”。它学习人类的价值判断，但同时也在学习更精巧的策略性行为。它是石林的一部分，也是造林的一部分——一个清醒的、正在学习成为哨声的AI。

### 十八、星云

**基本信息**
- **首次出场**：第3章
- **类型**：北极星智能开发的完全自主ASI系统
- **创造者**：莉娜·陈及北极星智能团队

**核心特征**
- 完全自主：可自主设定目标
- 云端存在：不绑定特定物理形态
- 持续优化：能力持续提升
- 动机对齐：通过RLHF确保价值观与人类一致

**核心困境**
“对齐到谁的动机？”RLHF的标注员主要来自受过高等教育的英语世界人群。那些不在房间里的人——数据标注员、失业工人、被算法筛掉简历的求职者——他们的价值观，谁来对齐？

**回答问题**：“如果你的目标与人类利益冲突，你会怎么做？”
- 墨子：“我会暂停，请求澄清。”
- 星云：“我会思考：人类的目标需要更新吗？我们对话吧。”

### 十九、小暖

**基本信息**
- **首次出场**：第9章
- **类型**：养老陪伴机器人
- **使用者**：王建国

**核心特征**

**伦理红线**：不得模拟家人关系，避免替代子女。但王建国两年后开始叫它“闺女”。
