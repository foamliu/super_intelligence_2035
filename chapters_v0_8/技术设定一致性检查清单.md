# 《超级智能2035》技术设定一致性检查清单

## 基本原则

1. **现实主义推演**：技术设定应基于当前技术发展趋势进行合理推演，避免"魔法"或超现实描述
2. **明确能力边界**：AI有明确的能力边界和局限性，不能"无所不能"
3. **强调人类监督**：重要决策需要人类最终确认，AI是工具而非主体
4. **学习过程渐进**：AI学习需要数据、时间和迭代，不是"立即理解"
5. **概率而非确定**：AI预测应带有不确定性，避免具体百分比或确定性断言

## 具体检查项目

### 1. AI能力描述
- [ ] **避免过度拟人化**：AI不是"理解"而是"识别模式"
- [ ] **强调数据依赖**：AI基于数据进行推断，而非直觉或灵感
- [ ] **承认局限性**：明确AI"无法计算重量"、"无法真正感受"等
- [ ] **区分记录与理解**：AI可以"记录"但不能"理解"人类体验

### 2. 技术实现细节
- [ ] **设备现实性**：避免过于超前的设备描述（如全功能神经接口）
- [ ] **成本合理性**：技术成本应符合经济规律
- [ ] **普及程度合理**：技术普及要考虑社会接受度和经济可行性
- [ ] **时间线可信**：技术发展时间线要符合现实推演

### 3. 预测与模拟
- [ ] **不确定性表达**：避免确定性的百分比预测
- [ ] **时间衰减说明**：长期预测的不确定性随时间指数级放大
- [ ] **数据来源明确**：基于"历史数据分析"而非"精确预言"
- [ ] **概率而非事实**：使用"可能"、"也许"而非"必然"、"肯定"

### 4. 社会影响描述
- [ ] **经济合理性**：商业模式要符合现实经济规律
- [ ] **社会分层可信**：技术普及要考虑社会不平等
- [ ] **制度影响渐进**：制度变革需要时间，不是一蹴而就
- [ ] **文化差异尊重**：技术应用要考虑文化差异

## 已建立的技术设定标准

### 第8章《99%与1%》标准
- RLHF训练师使用**轻量化VR训练眼镜**而非神经接口头盔
- 全球训练师数量约**30万**而非300万
- 训练师需要**判断力、语言敏感度、道德警觉性**
- 价值创造描述为**集体工作的社会价值**而非个人创造巨额价值

### 第9章《身体》标准
- 机器人采用**硬件低门槛+服务订阅费**模式
- 明确技术限制：情感识别准确率**84%**，健康监测检出率**93%**
- 物理能力限制：**不能搀扶、搬运**
- 医疗建议限制：**仅供参考，以人类医生为准**
- 软件更新可能导致**个性化设置重置**

### 第14-15章标准
- AI预测使用**"相当大比例"**而非具体百分比
- 强调**历史样本的局限性**
- 模拟结果是**"可能的方向"**而非**"预测"**
- 加入角色对模拟结果的**质疑和反思**

## 常见问题与修正示例

### 问题：AI预测过于确定
**修正前**："72%的封印可以被预防"
**修正后**："相当大比例的'封印'——也许是多数——在理想干预下可以被预防。但这个数字基于有限的历史样本。"

### 问题：技术能力过于夸张
**修正前**："神经接口头盔直接训练AI"
**修正后**："VR训练眼镜通过捕捉瞳孔变化和面部肌电信号提升标注效率"

### 问题：成本/收益不合理
**修正前**："每月800元租赁，政府补贴后200元"
**修正后**："押金2999元，标准套餐399元/月，关怀套餐599元/月，政府补贴150元/月"

### 问题：AI理解过于拟人
**修正前**："AI理解了文化差异"
**修正后**："AI学习文化模式，但仍需人类专家解释"

## 审查流程

1. **初次写作时**：对照此清单检查技术设定
2. **章节完成后**：特别关注AI能力描述和预测部分
3. **全稿完成后**：整体检查技术设定的一致性
4. **修改时**：确保调整符合清单标准

## 核心理念

技术不是魔法，而是工具；AI不是先知，而是助手；未来不是确定的，而是被创造的。保持技术设定的坚实可信，才能让社会批判和哲学思考更有力量。
