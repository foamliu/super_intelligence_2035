# DeepResearch 项目 · 智谱合作需求



**一、术语说明**



1. **可信度（credibility）**：指命题为真的概率性判断，取值 0\.0–1\.0，须附置信说明；该判断为概率性评估，非事实认定。无相关信源时，输出先验值并明确标注为无信息先验，不得与基于信源的评估结果混同。

2. **命题（claim）**：指可拆解为若干可独立核实子断言的事实性陈述，例如"某主体在某时间实现某突破，关键指标为某值，采用某技术路线，关键参数为某组值"。整体评分须基于子断言的评分聚合得出。

3. **子断言（sub\-claim）**：指命题中可独立核实的最小事实单元，是评分与拆解的基本单位。

4. **多信源信息（multi\-source evidence）**：指围绕同一命题的多个独立来源的信息，包括但不限于新闻、论文、专利、官方公告、财报等；信源之间不一致时，须在输出中体现分歧，而非强行聚合为单一结论。

5. **维度拆解（claim decomposition / sub\-claim level scoring）**：指按子断言逐项给出评分及依据，而非按抽象维度（如"权威性""一致性"）笼统打分。

6. **增量更新（incremental update）**：指新信源加入时，在已有评分基础上做局部调整，而非重新执行完整评分流程。

7. **准确性（accuracy）/ 校准度（calibration）**：准确性指评分与真值之间的偏差程度；校准度指评分所声明的置信水平与实际正确率之间的一致性。两者须分别报告。

8. **恰当评分规则（proper scoring rule）**：指能促使预测者诚实报出真实信念的概率评价指标，如 Brier score、cross\-entropy 等。

9. **业界 SOTA（state\-of\-the\-art）**：指可信度评估或事实核查方向上当前公认的最强方法，或双方共同确认的强基线；不得以弱基线替代。

    

**二、需求**



1. **可信度打分机制**：输入关键命题 \+ 多信源信息，输出 0\.0–1\.0 可信度评分、置信说明、维度拆解、标签、解释。

2. **增量更新机制**：新信源加入时，在已有评分基础上增量调整，输出新分数及调整说明；调整的耗时与计算量应与新增信源数量相关，而非与历史信源总量相关。

3. **技术先进性保证**：合作期内共同申请发明专利至少一项，长鑫方为共同申请人，专利须获得授权；共同撰写学术论文并投稿 AI 领域顶级会议，长鑫方为共同作者，论文须被录用。

4. **可量化效果验证**：智谱提供本机制与业界 SOTA 方法的对比结果，经长鑫方确认在恰当评分规则（proper scoring rule，如 Brier score 或 cross\-entropy）上具有可量化优势，并附校准度分析。基线实现须采用公开可复现的实现，或由双方共同确认其实现方式。评测集由智谱方构建，总量不少于 200 条，全部 case 须经长鑫方逐条审核通过后方可纳入评测。



**三、检索与报告质量要求**



5. **检索信源完备性**：检索策略须保证子断言拆解的完整性，以及信源在类型、立场、时效上的多样性；须说明检索覆盖范围与可能的盲区，不得以单一来源或单一批次检索结果作为评估依据。

6. **报告生成质量**：基于检索信源生成的报告，须降低幻觉率，保证引用真实、相关；关键洞察须有可追溯的信源支撑，不得出现无来源的断言。报告质量须有可量化评估方式。
