5.4 阶段数据调研核心结论

  1. 领域退火：最后 10–30% 步切换高质量策展数据 + LR 衰减至峰值 1%；白泽拟用 PyAether API 语料（8463 个 API）+ 配比 Domain 30%/Web 50%/Code 12%/Math 8%，约 4000 步、8.4B tok。
  2. SFT agentic 轨迹：58pp 差距最大可回收来源。DeepSeek-V3 SFT 用 1.5M 条；AgentTrove 170 万条（219 源）；仅 10% 轨迹含"错误后恢复"决策——白泽需补的"缺信号→重试→修正"链。
  3. RLVR 难度筛选：对应 CPU GRPO advantage=0 无梯度问题。sGPO 用 8 样本 profiling 过滤全对/全错题，3x 效率。建议白泽 RL 用 pass@8 取 1/8~7/8 区间。
  4. 奖励设计：从二值 outcome → process reward + 工具惩罚演进；白泽四臂设计与前沿一致。
3 周窗口优先补 2 项：(a) PyAether API 语料合成 SFT 轨迹（~50–100K 条，回收 ~20pp M1→M2）； (b) RLVR 难度筛选（~2–5K 题，打磨 ~5–10pp M3）。
