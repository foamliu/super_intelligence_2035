9运维基础设施：零 token 的 ops relay（今天立了大功）

ops relay 是一条「纯 bash、零 token、~20s 轮询」的远程命令通道（Windows 侧 → git → 服务器执行 → 结果写回 run/ops/outbox.md）。 它今天的价值被彻底验证：18 轮探查 + 3 次修复动作，全部通过它完成，没有消耗一个 agent token、没有打扰任何正在干活的线。
  • 用法铁律（已记入记忆）：① 命令块必须放在文件最前面（中继只执行第一个 ```bash 块）② 旧块降级为 ```text ③ RUN_ID 每次 +1。
  • 安全检查已内建：本次全部命令只读优先；所有「写」动作（改 secrets / 改 loop / 改 rc）都先备份并在下一轮验证。
  • 教训：grep -c Forbidden 会数到 agent 的散文（假阳性）→ 精确探针是 grep -c 'error:.*Forbidden'；且 /proc/<pid>/environ 只反映 exec 时的初始环境，不能用来验证脚本里的 export。
