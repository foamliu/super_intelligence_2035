4Round 2 推翻的两个先前判断

这两条都是"我们先前以为已经解决、实际上没有"的问题——列出来是为了避免它们再次被当成已解决。
#先前判断R2 实证结果影响
1 tab:visres 六格 loss 全同（4.9962）只是 LR 坍缩伪影， 换成正确 LR 就能得到有区分度的表 伪影属实（Δ0.54），但修正 LR 后 loss 仍然平： 5 组 4.4556~4.4566，差 <0.001。 换言之 "loss 对分辨率不敏感"是一个真实结论，不是伪影 ——只是被伪影叠加放大成了"六格完全相同" 该表不会因为重跑而变得"有信息量"； 论文已改为如实报告零结果 + 吞吐作为有效信号
2 可以用 eval5k 的检索 R@K 作为可通约的下游代理指标 （我据此设计了 R2-2 的主指标） 不可行：R@1 = 0.0002，恰好等于 1/5000 随机水平， 对不同 LR 与分支零区分度 R2-2 的主指标作废；更严重的是—— 视觉编码器目前没有任何有效的下游指标（这条已写入论文 §6 与 README 风险清单）
