🚨 R3 结论：不是"训练不足"，是表征坍缩（representation collapse）

两个塔都退化成常量输出（same-tower 余弦 ≈ 1.0000），与输入无关 → 检索排序全随机 → 表现为"精确等于 1/5000 的 chance"。四个完全不同的架构坍缩到同一个均衡点 （学到的 scale≈5.6~5.7 / bias≈−9.0~−9.1 几乎同值）→ 问题在共享的 recipe，不在架构。

两条最硬的证据：

  • 控制实验：全新随机初始化喂同一批输入 → 特征发散（offdiag 0.1725）→ 证明输入与评测无 bug，坍缩是训练造成的
  • 损失恒等式（算术证明）：SigLIP loss = -logsigmoid(label·(sim·scale+bias))， 代入坍缩态 sim≈0.9956 / scale=5.6827 / bias=−9.0937 → loss = 4.459， 与实测 4.456 分毫不差。即 loss≈4.45 是坍缩均衡的算术值，不是学习结果。

影响：tab:visarch / tab:visres / tab:visobj 的 loss 类结论全部作废； 仅吞吐/延迟排序仍成立（结构属性，不受坍缩影响）。
并已下 R4：以"训练不收敛"为核心阻塞单线程解决 —— 含 6 条代码级怀疑、LLaVA vs Stanford GPIC 数据集对比、修复实验与路线裁定。

✅ R4 结论：坍缩根因已定位，修复通过全部四项判据

单变量四档实验把坍缩拆成 两个独立的来源——「随机初始化的 text 塔」与「SigLIP 的可坍缩均衡」， 二者叠加才造成 1.0000 的精确坍缩。修复 = 冻结的预训练 CLIP 文本塔 + CLIP InfoNCE。

关键归因（两条）

  • 换语义 text 塔（B）显著缓解但不根治：C1 1.00 → 0.90，说明随机 text 塔确实是坍缩燃料； 但 SigLIP 的可学 logit_bias 仍允许 vision 退化到「平均文本方向」这个近似常量解。
  • InfoNCE（D）是解药：softmax 归一化强制「正样本要打败所有负样本」， 常量特征无法降低 loss → 模型被迫学出区分性表征。300 步即 C1=0.19、cross 正间隙出现、loss 单调下降。

⚠️ 同时证伪了我先前的一个假设：「77-token 截断导致坍缩」（截断保留套话前缀、丢掉区分性内容）。 R4 的决定性实验把同一条长 caption 的「保留头部 75 token」与「被丢弃的尾部 75 token」分别用冻结 CLIP 文本塔嵌入： HEAD off-diag 0.2946 vs TAIL off-diag 0.3720 —— 被丢弃的尾部反而更相似。→ 截断没有丢掉区分性信息，问题在于整条 recaption 通篇公式化。 截断 100% 属实，但只是背景事实，不是坍缩的直接推手。

  • 200B → ≈ 25 天
  • ⚠️ 690B（真实全语料）→ ≈ 86 天，2027-02-01 前不可能，不要定这个档
