§2 BaiZe 复现差异表

2.1 核心差异：Qwen3-4B → Qwen3.5-4B

维度原版 (Qwen3-4B)BaiZe 复现 (Qwen3.5-4B)
模态纯文本 LLM⚠ 原生多模态 支持图文输入
上下文窗口32K tokens262K tokens（可扩展至 1M+）
发布日期2025 年2026-03-02（阿里千问开源）
许可需核实Apache 2.0
HF repoQwen/Qwen3-4BQwen/Qwen3.5-4B + Qwen/Qwen3.5-4B-Base
视觉编码器无（外接 RICE-ViT）⚠ 内置 已有多模态视觉模块
🔴 架构冲突分析：

原版 LLaVA-OV1.5 前提：纯文本 LLM + 外接 RICE-ViT。Qwen3.5-4B 已内置视觉编码器 → 双视觉编码器冲突。

三种解决方案：

  • 方案 A（推荐）：提取 Qwen3.5-4B 纯 LLM 解码器（剥离内置视觉模块）+ 外接 RICE-ViT。需核实 Qwen3.5-4B-Base 是否提供纯文本权重。
  • 方案 B：用 Qwen3.5-4B 全量多模态模型，跳过 RICE-ViT，用内置视觉编码器 + LLaVA connector。架构偏离原版。
  • 方案 C（降级回退）：降级回 Qwen3-4B（原版骨干），保证架构一致性。

⚠ 未核实：Qwen3.5-4B-Base 是否纯文本、视觉模块是否可禁用 —— 需上机拉取 config.json 核实。

4.2 ms-swift 命令模板

环境准备

pip install ms-swift  # v4.2.0+
swift --version       # 应 >= 4.2.0
swift sft --help | grep llava_onevision  # 验证支持

Stage 1: 对齐训练

NPROC_PER_NODE=8 swift sft \
  --model_type llava_onevision \
  --model Qwen/Qwen3.5-4B-Base \
  --train_type lora \
  --dataset /nas_train/app.e0031982/datasets/mvp-lab/LLaVA-558K-Webdataset \
  --torch_dtype bfloat16 \
  --per_device_train_batch_size 4 --gradient_accumulation_steps 32 \
  --learning_rate 1e-4 --warmup_steps 100 --lr_scheduler_type cosine \
  --max_length 4096 --gradient_checkpointing true --deepspeed zero2 \
  --save_steps 500 --logging_steps 10 --output_dir output/stage1_align \
  --seed 42 --use_flash_attn true

Stage 1.5: 中期训练（全参数）

NPROC_PER_NODE=8 swift pt \
  --model_type llava_onevision \
  --model output/stage1_align/checkpoint-xxx \
  --dataset .../LLaVA-OneVision-1.5-Mid-Training-85M-packed-webdataset \
  --torch_dtype bfloat16 \
  --per_device_train_batch_size 2 --gradient_accumulation_steps 128 \
  --learning_rate 1e-4 --warmup_steps 1000 --lr_scheduler_type cosine \
  --max_steps 20000 --max_length 4096 --gradient_checkpointing true \
  --deepspeed zero3 --save_steps 2000 --logging_steps 50 \
  --output_dir output/stage1.5_mid --seed 42 --use_flash_attn true

Stage 2: 指令微调

NPROC_PER_NODE=8 swift sft \
  --model_type llava_onevision \
  --model output/stage1.5_mid/checkpoint-xxx --train_type full \
  --dataset .../LLaVA-NeXT-780k-webdataset \
  --torch_dtype bfloat16 \
  --per_device_train_batch_size 4 --gradient_accumulation_steps 32 \
  --learning_rate 1e-5 --warmup_steps 100 --lr_scheduler_type cosine \
  --max_length 4096 --gradient_checkpointing true --deepspeed zero2 \
  --save_steps 500 --logging_steps 10 --output_dir output/stage2_sft \
  --seed 42 --use_flash_attn true
⚠ 命令说明：
  • --model_type llava_onevision 需 ms-swift ≥ 4.2.0
  • --model Qwen/Qwen3.5-4B-Base 假设存在纯文本基座 —— 需核实，否则降级 Qwen3-4B
  • Stage 1 LoRA 冻结 LLM+ViT 仅训 projector；Stage 1.5 用 swift pt 全参数

§5 H100×8 训练时间估算

5.1 估算方法论

  • 原版：128 A800 × 3.7 天 = 11,366 GPU·h
  • GPU 数量比：128 → 8 = 16× 减少
  • H100 vs A800 加速比：~1.5–2.0×（训练密集负载；峰值 FLOPS ~3.2× 但受带宽限制）
