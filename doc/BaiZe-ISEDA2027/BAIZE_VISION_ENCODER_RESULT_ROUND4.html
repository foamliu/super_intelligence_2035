🎯 R4 一句话结论

坍缩的根因是「随机初始化的 text 塔」与「SigLIP 目标的可坍缩均衡」这两个独立的风险源叠加；修复 = 把 text 塔换成冻结的预训练 CLIP 文本编码器 + 目标从 SigLIP 换成 CLIP InfoNCE（去掉可学习 logit_bias）。

  • 🔑 300 步即复现坍缩：现状配置（随机 text + SigLIP）C1 = 1.0000（精确坍缩，负对照成立）。
  • 🔑 两个坍缩源：① 随机 text 塔（off-diag 0.726，正负样本文本侧不可分）；② SigLIP 逐对 sigmoid + 可学习 bias（提供「常数坍缩」与「反平均坍缩」两个吸引子）。
  • 🔑 修复验证：冻结 CLIP 文本塔 + InfoNCE，300 步 C1=0.1909、cross gap +0.085；2000 步 C1=0.2819、eval5k R@1 = 0.0064（32× chance） → C1–C4 全过。
  • 📌 对论文：R1/R2 的 loss 与 R@K 仍作废为坍缩读数；新增可报告的发现「SigLIP 在小 batch 从零对比下有两类坍缩吸引子，InfoNCE 无」。计算侧结论（OpenVision2 双最优）不受影响。

  • B：换语义 text 缓解但不根治（C1 1.00→0.90），SigLIP 的可学习 bias 仍允许「平均文本方向」常量解。
  • C：固定 bias=0 反而翻出「反平均坍缩」——vision 全映射到平均文本的负方向，cross 分数一致 ≈ −0.436，SigLIP 逐对 sigmoid 仍能以「全判负」拿低 loss（n 个正样本 ≪ n²−n 个负样本）。
  • D：InfoNCE 的 softmax 强制「正样本打败所有负样本」，常量特征无法降 loss → 被迫学区分性特征。

🧭 路线裁定（C1–C4 已全过）

固定 recipe = 冻结预训练 CLIP 文本塔 + CLIP InfoNCE（学温度、无 logit_bias）+（推荐）GPIC-short caption。

  • 冻结文本塔：openai/clip-vit-large-patch14-336 text tower（768 维）。
  • 目标：open_clip.loss.ClipLoss（InfoNCE，无 logit_bias），学 logit_scale（温度）。
  • vision：OpenVision2 保持原架构，仅 readout head 改 embed_dim=768。
  • 数据：优先 GPIC short，medium 次选，LLaVA 长 recaption 不推荐。
  • 放大：4 架构 × 3000–10000 步、batch 64–128（跨卡 gather 到 512–1024 负样本），预算 ~6–12 GPU·h，作为 R5 输入。

6论文回填建议（§6 怎么写）

  • 「loss 4.45 架构不可区分」应如实改写为「从零 + SigLIP 配方下的坍缩均衡 loss」，不能当成「架构对 loss 无影响」的有效结论；R1/R2 的 loss 排名与 eval5k R@K 作废标注。
  • 可新增一条发现：小 batch 从零对比学习中，SigLIP（sigmoid 逐对）存在两类坍缩吸引子（常数坍缩 + 反平均坍缩），CLIP InfoNCE（softmax 批量归一化）无此问题。
  • 计算侧结论（OpenVision2 训练/推理吞吐、延迟双最优）不受坍缩影响，保留。
  • 修复 recipe 写进方法，作为后续 Stage(iii)/(iv) 的可复现配置。
  • 数据段注明：LLaVA recaption 100% 截断、通篇公式化；GPIC-short 是更适合对比学习的 caption 档位。
