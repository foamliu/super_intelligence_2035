2目标产物与 token 预算

2.1 约束分析：瓶颈是算力，不是数据

项值依据
每步 token≈ 32.7 KGBS 8 × seq 4094（Round 1 口径）
每步耗时≈ 350 ms/iterRound 1 实测（8×H100 TP1/DP8）
吞吐≈ 93 K tok/s推算
日产能≈ 8.0 B token24 h 连续
连续训练 30 天≈ 242 B token8.0 B × 30
Chinchilla 最优（2.2B）≈ 44 B token20 × params
已有通用文本1.8 T tokenUltra-FineWeb-L3

结论：30 天连续训练 ≈ 242 B token ≈ Chinchilla 最优的 5.5 倍，而可用语料是它的 7.4 倍以上。 数据量根本不是约束——约束是算力窗口。因此本阶段的成功标准不是"下载/切分了更多数据"， 而是质量、配比、格式可直接被训练消费、以及污染隔离。

4三条数据线

4.1 通用文本（已就绪）— 把 1.8T 变成"训练可直接消费"

  • 重点不是再下载，而是转格式 + 建配比。产出 mcore .bin/.idx，直接喂 pretrain_launcher.py。
  • 复用既有产物：BASE_DIR/data/ultrafineweb_l3_qa 已经跑通过一次（200k docs / 165M token）， 脚本与格式约定照抄，只改数据源与规模。
  • 必须产出：stable 主体（≈200 B token）+ 退火源（code / math）各自的 .bin/.idx， 且能按配比混合（训练侧需要按比例采样）。

4.2 通用多模态（下载中 >50%）— 等下载完再动，但预处理脚本可以先生成

  • 下载未完成前不要做重 I/O（会与下载抢带宽/抢盘，且可能读到半截文件）。
  • 可以先做的：写预处理脚本、定 shard 划分、复算 en500k 的 webdataset 打包参数。
  • 下载完成后：校验完整性 → 统计（图像数 / caption 类型 tag·short·medium·long / 语言分布） → 切统一子集 → webdataset 打包（复用 run/vision/prep_data.py）。
  • 必须另切 held-out 评估集，且与训练源不同源（Round 1 用的是 imagenet/EN 训练、laioncn/EN 评估，沿用该做法）。

4.3 EDA 领域语料（来源未落实）— 本方案最关键、也最不确定的一条

这条线是 Stage (ii)「领域模型」claim 的唯一支撑。当前 BaiZe 的预训练语料（web+code+math） 不含任何 EDA 数据，所以整个"领域模型"叙事目前是悬空的。
候选来源可得性用途备注
PyAether / SKILL API 参考文档 已有线索 领域退火 + SFT 语料 ZhuLong 的 eda_fastmcp 里已建有 API 知识库（检索索引）， 先去确认它能否导出为纯文本文档
EDA 工具文档 / 用户手册待确认授权退火语料注意版权与"能否入库"
开源 HDL（Verilog / SystemVerilog）公开可得退火语料与 PyAether 脚本语言不同，价值次要
内部培训材料 / 脱敏 CAD 案例未落实SFT 语料（高价值）需人工提供，agent 无法自行获取

行动：phase3_domain 的第一步是把"有哪些 EDA 语料、在哪、能不能用"这件事查清楚并汇报， 而不是硬造数据。来源未确认前，不要产出一个"看起来像 EDA"的合成语料——那会污染结论。

5🚨 污染隔离（红线）

EDA-Eval-PyAether 的 158 个任务内容（prompt / entry_point / canonical_solution / test 断言）绝对不能进入任何训练集。
一旦泄漏，全部下游结论作废，且事后无法补救。这不是"尽量做"，是红线。

5.1 允许与禁止

内容可否入训练集
允许PyAether / SKILL 的 API 参考文档（函数签名、参数说明、示例）✅ 可以——它是任务的"来源材料"
禁止评测任务的自然语言 prompt、函数名、参考解、断言代码❌ 绝对不可以
禁止由上述任务改写/ paraphrasing 得到的版本❌ 改写不洗白

5.2 隔离机制（必须实现并留证）

  1. 建黑名单：把 158 题逐条做规范化 + 指纹（n-gram / MinHash），落盘为可复用的黑名单文件。
  2. 训练集侧扫描：对每一份候选训练文档算指纹，与黑名单重合超阈值即剔除并记录。
  3. 阈值要写明：用多少 n-gram、多少重合度算命中，论文里要能复现。
  4. SFT 语料同闸：Stage (ii) 的 SFT 数据必须走同一套校验，不能只查预训练语料。
  5. 产出独立报告：CONTAMINATION_CHECK.md——列出规则、阈值、扫描量、命中数、处置结果。
同一条规则也适用于多模态侧的 held-out 评估集（如 eval5k）：评估集与训练集必须不同源， 且要做跨集去重比对。
