1. 任务定义：波形图分类与「看懂」的层次

1.1 为什么「波形图」是 EDA 领域 MLLM 的核心能力

在 IC 设计验证流程中，工程师需要频繁查看多种波形/曲线图来理解电路行为、定位故障、验证规格。 当前这些工作高度依赖人工读图——工程师需要打开 SPICE 仿真器、波形查看器、DRC/LVS 报告， 肉眼判读趋势、测量参数、定位异常、推理因果。一个能「看懂波形图」的 2B MLLM， 可以直接接入设计验证回路，实现：

  • 自动化参数提取：从 tran 曲线读出周期、幅度、上升/下降沿时间，省去人工光标测量；
  • 异常快速定位：识别眼图闭合、毛刺、振铃、过冲等异常，缩短 debug 周期；
  • 报告自动解读：把 DRC/LVS 截图中的违规条目和修复建议结构化输出；
  • 因果推理辅助：结合电路拓扑和仿真结果，推理「为什么这一段波形异常」。

1.3 「看懂」的四层能力梯度

四层能力从低到高，对应模型需要具备的不同认知能力：

  1. 趋势判读（L1 — 感知层）：识别图的整体走势——是单调递增/递减、振荡、饱和、还是发散？对应 MLLM 的全局视觉理解能力。
  2. 参数测量（L2 — 量化层）：从图上精确读出数值——周期、幅度、上升沿时间、眼高等。要求模型能OCR 轴刻度 + 几何量测，而非仅做定性描述。
  3. 异常定位（L3 — 检测层）：在正常波形中找到异常段——眼图闭合区域、非单调翻转、DRC 违规条目。要求局部注意力 + 区域级描述。
  4. 因果解释（L4 — 推理层）：将观察到的波形/违例与电路原理关联——「这段振荡是因为反馈环路相位裕量不足」。要求领域知识 + 链式推理，是最高层能力。
本项目现状定位：当前 BaiZe 2B MLLM（ArmE-R2, ViT-L/14 编码器, 224px 单块, 无 anyres）在 12 集 lmms-eval 评测中， ChartQA 12.16%、DocVQA 7.35%、OCRBench 1.6%（实测，来源：mllm_eval_results_armE_r2_20261022/consolidated_12benchmarks.json）。 这意味着模型当前连 L1 趋势判读和 L2 轴刻度 OCR 都很弱——图表数值提取和文档识别能力几乎在随机水平。 波形图理解需要的不只是通用 VQA 能力，而是专项数据 + 专项训练 + 专项评测的三位一体建设。

2. 能力拆解：从像素到语义的五层

要让 2B MLLM 真正「看懂」波形图，需要将能力拆解为五个可独立训练、可独立评测的子能力：

2.1 分辨率与 anyres 适配

表 2.1 分辨率对波形图理解的影响
配置token 数patch 网格波形图适用性

336px 单块57624×24⚠️ 改善但仍不足以读密集刻度，需 anyres

2.2 轴刻度 OCR

波形图的一切定量分析都始于轴刻度读取：x 轴标注时间（ns/μs）或频率（Hz/MHz），y 轴标注电压（mV/V）或增益（dB）。 当前模型 OCRBench 仅 1.6%（实测），无法可靠读取刻度标签 → 所有 L2 参数测量都无法进行。

  • 难点：刻度标签常为小字号、旋转 90°、部分被网格线遮挡、科学计数法（如 1e-6）；
  • 解决路径：① 在 OCR 合成数据（已交付 10M 样本，见 report_vision_ocr_synth10m_zh.html）中加入轴刻度专项子集（含旋转/科学计数法/密集小字）；② SFT 阶段加入「给定波形图，读出 x/y 轴范围和刻度」的 QA 对。
  • 验收指标：轴刻度数值识别相对误差 ≤10%（合成数据 ground truth 可控）。

2.3 几何量测（周期 / 幅度 / 上升沿 / 占空比）

在轴刻度已知的前提下，模型需要从像素坐标反推物理量。这要求模型具备几何推理能力：

表 2.2 几何量测子能力拆解
量测项视觉操作所需精度难点
周期 T识别相邻同相位点，量横向像素距离 × x 轴分辨率±5%振荡信号相位对齐；多周期取平均
幅度 V_pp识别波形最高/最低点，量纵向像素距离 × y 轴分辨率±5%噪声/振铃干扰极值判断
上升沿 t_r (10-90%)在跳变段定位 10% 和 90% 幅度点，量横向距离±10%需先确定稳态高低电平；10%/90% 判定依赖幅度参考
占空比 D量高电平持续时间 ÷ 周期±5%需准确判定高/低电平阈值
眼高/眼宽在眼图中央十字区域量纵向/横向张开度±10%眼图叠加导致边界模糊；需统计性判断而非单次测量
关键洞察：几何量测不是单纯的视觉感知，而是视觉感知 + 数值计算的复合能力。 模型需要先从图中读出轴刻度（OCR），再在像素空间定位关键点，最后做「像素 → 物理量」的换算。 这比通用 ChartQA（仅提取数值）更难——ChartQA 只需读出柱状图上方的数字标签，波形图量测需要从连续曲线上的点反推数值。

2.4 多子图对齐

实际仿真输出常以多子图形式呈现——同一时间轴上叠放多个信号（如时钟 CLK、数据 D、输出 Q）， 或 AC 分析的幅度图和相位图上下排列。模型需要：

  • 子图边界检测：区分多个 subplot 区域（颜色框、标题、坐标轴）；
  • 共享轴对齐：识别多个子图共享同一 x 轴（时间/频率），将不同 y 轴刻度独立处理；
  • 跨子图关联：「在 CLK 上升沿时刻，D 信号是高还是低？」——需要在时间轴上对齐两个子图的信号状态。

这与 BLINK（视觉语言跳变推理，本项目实测 38.88%）的能力有部分重叠，但 EDA 场景的子图对齐需要精确到时间点而非仅判断「是否变化」。

2.5 领域语义理解（器件 / 工艺 / EDA 术语）

波形图的因果解释（L4）需要EDA 领域知识。模型需要理解：

  • 器件术语：MOSFET（NMOS/PMOS）、BJT、传输门、运放等器件在波形上的典型行为；
  • 工艺参数：工艺节点（28nm/7nm）、阈值电压 Vth、迁移率等对波形特征的影响；
  • EDA 工具语义：SPICE 仿真类型（.tran/.ac/.dc/.noise）、DRC rule 编号体系、LVS 比对逻辑；
  • 设计规范：setup/hold time 的定义和违例含义、眼图 mask 的通过/失败判定标准。
2B 容量的限制：2B 参数量的 LLM 领域知识容量有限。通用预训练语料中 EDA 相关内容稀少， 模型很可能不知道「相位裕量 45°」是稳定性判据。解决方案：① 在 SFT 数据中嵌入领域知识 QA （如「什么是 setup time？如何从时序报告中读取 slack？」）；② 可选地用 EDA 文本语料做轻量 continued pretraining。

3. 数据方案：合成波形 + 真实截图

3.1 数据策略总览

采用「合成为主（参数可控、QA 自动生成）+ 真实为辅（领域覆盖、泛化验证）」的双轨策略：

  • 合成波形（A 级，~80% 数据量）：用 matplotlib 程序化生成参数可控的波形图，自动生成 QA 对。优势：ground truth 精确已知、可大规模生成、可覆盖参数空间。
  • 真实截图（B 级，~20% 数据量）：从 698 机 SSH 扫描得到的 EDA session 中深读取样。优势：领域真实分布、覆盖工具风格差异、检验泛化能力。

3.2.2 自动 QA 生成：三类问答

每张合成波形图自动生成三类 QA 对，分别对应 L2（量化）、L1+L3（比较/检测）、L4（因果）：

表 3.2 三类 QA 设计
QA 类型对应能力层示例问题答案格式评分方式
数值型 (Numeric) L2 参数测量 「图中信号的周期是多少？」「上升沿时间是多少？」「眼高是多少 mV？」 浮点数 + 单位（如 "2.5 ns"） 相对误差 ≤ 阈值则正确
比较型 (Comparative) L1 趋势 + L3 异常 「图中的信号是单调递增还是振荡？」「这个眼图是张开还是闭合？」「是否存在过冲？」 多选（A/B/C/D）+ 简短理由 选项 exact-match + 理由关键词匹配
因果型 (Causal) L4 推理 「为什么这段波形出现振铃？」「相位裕量是否足够？请解释。」「这条 DRC 违规应如何修复？」 开放式文本（2-5 句） 关键事实点核查（如提及「相位裕量不足」「反馈环路」等关键词）
自动 QA 的可信度保证：合成数据的 ground truth 来自生成参数本身（如周期 T=1/f 精确已知）， 因此数值型 QA 的答案无需人工标注，可大规模生成。 比较型 QA 的选项由规则模板生成（如「如果 SNR < 10dB 且信号类型=方波，则存在明显噪声」）。 因果型 QA 需要部分人工审核（~10% 抽检），确保推理链条合理。

3.2.3 合成数据的渲染多样性

为避免模型过拟合于单一渲染风格，合成时随机变化以下维度：

  • 图大小：400×300 ~ 1200×800 像素（5 档）
  • 配色方案：白底黑线 / 黑底绿线 / 白底多彩 / 论文灰度（4 种）
  • 网格密度：无网格 / 稀疏 / 密集（3 种）
  • 标签格式：科学计数法 / 工程计数法 / 普通小数（3 种）
  • 轴范围：紧凑范围 / 含余量 / 对数轴（3 种）
  • 字体大小：8pt / 10pt / 12pt（3 种，模拟截图清晰度差异）
  • 多信号叠加：单信号 / 2 信号 / 4 信号（3 种，模拟真实仿真输出）

3.3.3 标注协议

真实截图标注协议（因无法自动生成 ground truth，需人工标注）：

  1. 标注者资质：至少 1 名有 SPICE 仿真经验的 EDA 工程师 + 1 名标注质量审核员；
  2. 标注内容：图像元信息（来源工具、信号类型、分辨率）· 轴信息（x/y 轴物理量、范围、刻度）· 波形参数（周期/幅度/上升沿/占空比，人工测量）· 异常标注（过冲/振铃/眼图闭合/DRC 违规）· QA 对（每图 2-3 个数值型 + 1 个比较型 + 1 个因果型，人工撰写答案）
  3. 一致性抽检：20% 样本双标注（2 人独立标注），计算 Cohen's Kappa（目标 ≥ 0.7）；数值型参数双标注相对误差 ≤ 15% 视为一致；不一致样本由审核员仲裁
  4. 脱敏要求：移除所有用户名、IP 地址、项目代号；对截图中的敏感文本做马赛克处理

4. 训练策略：从对齐到专项 SFT

4.1 当前训练管线回顾

BaiZe vision 线当前 MLLM 训练管线为三阶段对齐（实测，来源：BAIZE_VISION_TASK.md §最佳实践）：

  • Stage-1（projector 训练）：冻结视觉编码器 + 冻结 LLM，仅训练 projector（MLP 连接器），将视觉特征映射到 LLM 的 token 空间；
  • Stage-1.5（LoRA 微调）：冻结视觉编码器，对 LLM 加 LoRA（rank=64），用图文对训练；
  • Stage-2（instruct SFT）：用原版 LLaVA-NeXT-780k 指令数据做全量 instruct 微调（step 3500）。

当前编码器：ViT-L/14（304M），AIMv2-style dense objective（InfoNCE 1.0 + masked-patch-MSE 1.0，mask-ratio 0.6），在 10.239.2.12 上训练 63400 步完成。ProtB lp 68.236%（本项目历史最高，实测）。但 MLLM 12 集 avg 26.10%，编码器优势未传递到下游（ProtB→MLLM 传递性证伪，见 report_vision_recent_work_zh.html）。

4.2 波形图能力训练方案：两阶段增量

4.2.1 Stage-1W：波形图对齐（Waveform Alignment）

目标：让 projector 和 LoRA 层学会「波形图 → 文本描述」的基础映射。

  • 输入：合成波形图 + 自动生成的数值型 QA 对（~48K pilot / ~105K 全量）
  • 训练对象：projector + LLM LoRA（rank=64），冻结视觉编码器
  • 学习率：1e-5（与现有 Stage-1.5 一致，避免灾难性遗忘）
  • 训练步数：pilot ~2000 步 / 全量 ~5000 步
  • 数据配比：波形 QA 70% + 原版 LLaVA-NeXT 通用 VQA 30%（防止通用能力退化）

4.2.2 Stage-2W：波形图专项 SFT（Waveform SFT）

目标：在 Stage-1W 基础上，加入比较型和因果型 QA，训练异常定位和因果推理能力。

  • 输入：合成波形图（全部三类 QA）+ 真实截图（人工标注 QA）
  • 训练对象：projector + LLM LoRA（rank=128，提升容量），冻结视觉编码器
  • 学习率：5e-6（更低 LR，精细调整）
  • 训练步数：pilot ~1000 步 / 全量 ~3000 步
  • 数据配比：波形 QA（数值 40% + 比较 25% + 因果 15%）+ 原版通用 VQA 20%
  • 真实数据权重：真实截图 QA 每条复制 3-5 倍（弥补数量不足，增强真实分布覆盖）

4.2.3 可选 Stage-3W：RL 微调（Reward-Based）

可选：如 Stage-2W 后数值量测仍不够精确，可用 RL 进一步优化。

  • 奖励函数：数值型 QA 用「相对误差越小奖励越高」（连续奖励，如 r = max(0, 1 - |pred - gt| / |gt|)）
  • 算法：GRPO 或 PPO（本项目 pretrain 线有相关经验可复用）
  • 前提：Stage-2W 已产出可用 ckpt；合成数据可自动计算奖励（无需人工标注）
  • 风险：RL 训练不稳定，2B 模型容量小可能 reward hacking；建议仅在 SFT 不够时尝试

4.4 灾难性遗忘防护

核心风险：专项 SFT 可能导致模型在通用 VQA 任务上退化。本项目已有教训——Stage-2 从 opt47 切到原版 780k 时， 数据分布变化导致下游评测波动（见 report_vision_recent_work_zh.html §3）。 防护措施：
  1. 混合训练：每个 batch 中保持 ≥20% 通用 VQA 数据（从 LLaVA-NeXT-780k 采样）；
  2. 学习率控制：Stage-1W 用 1e-5、Stage-2W 用 5e-6，远低于 Stage-2 的典型 LR；
  3. 回归评测：每 500 步在 MMStar/MMBench 上跑一次子集评测，监控掉幅；掉幅 >1pp 立即回退到上一个 ckpt；
  4. 早停：WaveQA 达标后即停，不过度训练。

5.1.2 评测指标

表 5.2 WaveQA 评测指标体系
QA 类型指标计算方式目标值
数值型 (150 题) 数值相对误差 (NRE) NRE = |pred - gt| / |gt|，按阈值（5%/10%/20%）分档统计准确率 ≤5% 误差率 ≥ 40%

开放型评分细节：Fact-Score 不依赖 LLM judge（本项目 MMVet/MathVista 因缺 OPENAI_API_KEY 阻塞的教训——见 report_vision_next_steps_protb_mllm_zh.html）， 而是用预设关键事实点 + 关键词/语义匹配的规则评分。例如：
  • 题：「为什么这段波形出现振铃？」
  • 预设关键事实点：① 提及「反馈环路 / ringing / 振荡」；② 提及「相位裕量不足 / phase margin」；③ 提及「阻尼不足 / underdamped」
  • 模型回答命中 2/3 → Fact-Score = 0.67

总结

本报告提出了一套完整的「2B MLLM 看懂波形图」能力建设与评测方案，核心要点：

  • 任务定义：四大类波形（SPICE tran/ac、眼图、时序/DRC/LVS 报告）× 四层看懂（趋势/参数/异常/因果）
  • 能力拆解：五层子能力（分辨率 anyres / 轴刻度 OCR / 几何量测 / 多子图对齐 / 领域语义）
  • 数据：合成 80%（matplotlib 参数可控 + 自动三类 QA）+ 真实 20%（698 机 368 waveform 命中深读取样）
  • 训练：Stage-1W 对齐 → Stage-2W 专项 SFT（可选 Stage-3W RL），2B 下取 224px 训练 + 推理高分辨率切换
  • 评测：自建 WaveQA（300 题，数值/多选/开放）+ ChartQA/DocVQA 迁移 + MMStar/MMBench 回归护栏（≤1pp 掉幅）
  • 成本：Pilot ~10 GPU·h / ~1.5 天 / 2 万题；全量 ~24 GPU·h / ~3 天 / 10.6 万题
