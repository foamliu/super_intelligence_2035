样例3: 高难度

import pyAether as pyScript
from typing import List, Any

def analyze_0430(design: 'pyScript.emyDesign', layer_name: str) -> List[Any]:
    """
    Complex EDA analysis using multiple APIs:
    - `etCss`: Use etCss
    - `aeAddSelectBox`: Use aeAddSelectBox
    - `aeIncreaseSel`: Use aeIncreaseSel
    Steps: 1) Query objects on layer 2) Process results 3) Collect analysis.
    Handle edge cases: empty design, missing layer, no matches.
    """

参考解:

    objs = pyScript.etCss(design, layer_name)
    if not objs: return []
    processed = []
    for obj in objs:
        r = pyScript.aeAddSelectBox(obj)
        processed.append(r)
    analysis = pyScript.aeIncreaseSel(processed)
    return list(analysis) if analysis else []

(5) 奖励设计对比(R1-R4)

奖励臂定义2B适用性优缺点
R1二值pass/fail不推荐2B大面积0,advantage全0无梯度。GRPO冷启动要求10-20%成功率
R2分层部分分(0.2/0.2-0.8/1.0)推荐起步保证非零梯度;与sGPO pass@8互补
R3R2+工具调用惩罚第二阶段防刷调用次数;需R2收敛后再加
R4R3+API合法性检查最终阶段防幻觉API调用;需白名单匹配器

推荐: 起步用R2,稳定后加R3/R4。同时报告cheat rate。预算按沙盒并发数x墙钟,不沿用GPU-hour。

(7) 与白泽的可迁移性分析

维度替身(MiniCPM5-2B)白泽(EDA专用)可迁移性
