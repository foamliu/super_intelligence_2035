R61: RL Rollout 吞吐量投影 + 发射补丁实现

2026-11-08 wake109 · 零 GPU · Python 3.8+ · BaiZe Stage(ii) Post-Training

核心发现：R60 推荐的 ctx=32768 在 non-hybrid 模式下不可行（KV cache 10.5GB/seq，每 GPU 仅放 1 序列，G=8 需 8 个）。 经吞吐量投影，ctx=16384 + hybrid engine 是 72h 窗口内唯一可行方案（3.45 steps/hr → ~248 步/72h）。 已应用 9 处补丁到 RL 配置和 SFT 脚本。

§1 背景

R60 分析了 103 条 DeepSeek 轨迹，发现平均 28,339 tokens/任务，推荐 ctx=32768。 但 R60 未评估吞吐量可行性——在 4×A40 48GB 上，500 步 GRPO 训练需要多久？ctx=32768 是否可行？

§2 KV Cache 内存约束

MiniCPM5-2B: 42 层, 32 KV heads, head_dim=64, bf16（2 bytes）

§7 11/9 发射建议更新

  1. Smoke：ctx=32768, bs=16, G=4, hybrid → 37min/10步 ✅
  2. 主 RL：ctx=16384, bs=128, G=8, hybrid → 200步/72h
