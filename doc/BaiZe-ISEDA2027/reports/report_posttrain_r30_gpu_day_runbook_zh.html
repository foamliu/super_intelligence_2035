3. 执行步骤详解

Step 0: cu124 Venv 设置（5-15 min）

状态：R27 已完成验证，venv 已就绪。此步通常跳过。
命令bash baize_posttrain_setup_cu124_venv.sh --yes
验收torch.cuda.is_available()=True + SGLang launch_server --help + verl import OK
回退若 torch CUDA False → 检查 nvidia-smi 驱动版本 ≥ 12.4

Step 1: Preflight Check（2 min）

命令bash baize_posttrain_preflight_check.sh
验收18 项全 PASS

Step 2: SGLang Serve + 36% 基线复测（30-60 min）

关键步骤：36% 基线是所有后续实验的锚点。
命令bash baize_posttrain_minicpm5_diag.sh --full --gpu-ids 0,1,2,3
做什么① SGLang serve MiniCPM5-2B ② 158 任务 5-run Pass@1 ③ 采集失败轨迹
验收5-run mean ≈ 36% ± 5pp（31%-41%）
回退SGLang 失败→nvidia-smi 确认 GPU 释放；基线偏离→检查 eval 协议

Step 3: D1-D6 失败轨迹提取（10-20 min）

命令bash baize_posttrain_minicpm5_diag.sh --extract-only --gpu-ids 0,1,2,3
验收六项数值提取，替换 §D「❌ 不在本节点」标注
回退字段缺失→如实标注，不编造

Step 4: 污染隔离闸门（1 min）

🛑 红线：闸门失败 = 禁止继续 RL。
命令bash baize_posttrain_contamination_gate.sh
验收CONTAMINATION OK + 0 命中

Step 5: RL Smoke Test（20-40 min）

替身预演：10 iter GRPO + R2 奖励臂。
命令bash baize_posttrain_rl_grpo.sh --smoke --reward-arm R2 --gpu-ids 0,1,2,3
验收① loss 有变化 ② reward > 0 ③ cheat rate < 5%
回退reward 全 0→检查 auto_fallback；OOM→降 GROUP_SIZE 到 4

4. 关键决策点

决策 1: 基线复测后

情况行动
mean 在 31%-41%继续 Step 3
mean < 31%暂停 排查 eval 协议差异
mean > 41%暂停 排查 task 子集 / 评分差异

决策 2: Smoke Test 后

情况行动
loss↓ + reward>0 + cheat<5%链路验证通过 写报告
reward 全 0排查 sandbox / auto_fallback / R0 梯度
cheat rate > 5%红线 重跑 contamination gate
OOM降配 GROUP_SIZE 8→4, ctx 8192→4096
