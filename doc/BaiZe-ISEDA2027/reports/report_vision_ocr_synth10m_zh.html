6.5 如何加载本数据集

本数据集格式与现有 GPIC 一致（<key>.jpg + <key>.json，json 含 caption 与 caption_type='short'），可直接用 run/vision/data.py 的两个加载器之一：

# 方式 A：GPIC 专用加载器（按 caption_type 过滤）
import glob
from data import build_gpic_loader
shards = sorted(glob.glob("/nas_train/.../ocr_synth_10m_full/shard-*.tar"))
loader = build_gpic_loader(shard_list=shards, batch_size=256,
                           tokenizer=open_clip.get_tokenizer("ViT-B-16"),
                           size=224, num_workers=6, caption_type="short")
for imgs, texts in loader:   # imgs:(B,3,224,224) texts:dict(input_ids,attention_mask)
    ...

# 方式 B：混合加载器（可与 GPIC / CC12M 同表混喂）
from data import build_mixed_loader
loader = build_mixed_loader(shard_list=shards, batch_size=256,
                            tokenizer=tok, size=224, gpic_caption_type='short')

训练时 resize/crop 到 224 或 336 均可；本数据集存储为 448 基线渲染，保留更高分辨率以便后续 336 实验复用，不必重新生成。

7. 已知偏差

  • 文本为合成模板（词表 + 语法模板），非真实维基/书/新闻；视觉多样性是 OCR 预训练的主要价值。
  • 生成器内联去重基于图像 sha1（文本 sha1 仅写入 index 供独立复检），故文本去重率由 postprocess_ocr_synth.py 独立复检得到（见 §5）。
  • 生成器内联泄漏护栏因路径错误为空操作；真实泄漏复检由 postprocess 完成，命中均为极短串巧合。
  • 手写用楷体 + 逐字抖动近似，非真实笔画模拟。
  • 数学用 matplotlib mathtext（LaTeX 子集），非完整 TeX 渲染。
  • 场景文本用合成背景 + 透视，非真实照片。

7.5 复现与验证命令

# 生成（固定 seed，可重放；--mode p0 冒烟 / --mode full 全量）
python3 vision/ocr_synth/gen_ocr_synth.py --mode full \
    --out /nas_train/.../ocr_synth_10m_full --workers 32

# 独立质量复检（文本去重 + 真实评测泄漏 + 统计聚合）
python3 vision/ocr_synth/postprocess_ocr_synth.py \
    --data-dir /nas_train/.../ocr_synth_10m_full

# 加载器兼容性验证（真 build_gpic_loader + open_clip tokenizer 前向 1 batch）
python3 vision/ocr_synth/verify_loader_compat.py --n-shards 8 --batch-size 16

# 预览（preview_200.html 自包含 + preview_10k.tar 抽样包）
python3 vision/ocr_synth/make_preview.py --data-dir <dir> --n-preview 200 --n-pack 10000

# 生成本报告
python3 vision/ocr_synth/generate_ocr_synth10m_report.py --data-dir <dir>

所有脚本 CPU-only；postprocess / verify / make_preview 均可在生成器运行时并行执行（轻 I/O、单进程、nice 友好）。生成器固定 seed=20261025 + 顶部参数块 ⇒ 相同参数重跑字节级可复现。
