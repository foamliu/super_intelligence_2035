关键发现：
  • eval Pass@1是RL终点最强正向预测因子(r=+0.5735)，但与RL提升负相关(r=-0.7208) → 边际递减
  • 过拟合分数是RL崩溃最强预测因子 → anti_overfit策略价值最高
  • 工具调用率同时正向预测RL终点和提升 → D1/D2修复是SFT首要目标
  • SFT loss与RL结果弱相关/负相关 → loss不是好的检查点选择指标

7. 综合建议

检查点选择

  1. 首选：balanced（eval40%+tool30%+api20%-overfit10%）
  2. 次选：anti_overfit
  3. 不推荐：latest和lowest_loss

就绪门阈值

  1. eval Pass@1 ≥ 36%（红线）
  2. 工具调用率 ≥ 80%
  3. 作弊率 < 5%（红线）
  4. 过拟合分数 < 0.05
  5. API知识 ≥ 60%
  6. loss斜率 |slope| < 0.0001

早停准则

  1. loss斜率连续3检查点 < 0.0001 → 可停
  2. eval连续2检查点下降 → 立即停
  3. 过拟合 > 0.05 → 立即停
  4. 预计最优停止：step 1200-2000（约23-39h）

RL热启动

  • RL LR = SFT LR × 0.1
  • KL初始0.05，SFT KL>0.3则提至0.08
  • 奖励臂首选R3
  • STRONG_GO → 直接进RL phase 2

8. 局限性

  • SFT动力学用经验公式，实际曲线可能不同
  • RL增益假设边际递减，实际可能有相变点
  • 过拟合分数是复合指标，需GPU实测校准
  • 替身模型结果不可迁移到白泽正式训练
