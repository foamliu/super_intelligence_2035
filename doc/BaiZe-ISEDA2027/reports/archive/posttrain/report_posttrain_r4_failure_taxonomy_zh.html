12. 局限性与诚实标注

  • MiniCPM5-2B 36% 侧轨迹不在本节点——所有"36% 侧预期占比"为外推假设，非实测。
  • "Unknown Failure"(18.9%)具体成因未深入——可能静默退出/无输出/C 层崩溃，需 GPU 后排查。
  • 始终失败 25 题中 8/25 是 Generation timeout——可能是输出过长被截断而非能力不足。
  • API 11-20 范围样本仅 12 个，置信区间宽。
  • 本分类法是框架性的——GPU 后可能发现 2B 特有新失败模式。
