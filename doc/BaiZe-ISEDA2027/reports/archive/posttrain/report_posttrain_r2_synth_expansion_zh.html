4. 自动可判定断言模板（5 种）

⚠️ 当前 500 题全部 test=pass，零自动判定。以下模板修复此致命缺陷。

T1_type_check（L1，~1500 题）

def check(candidate):
    result = candidate()
    assert result is not None, "Should return non-None"
    assert isinstance(result, ({ret_type_py}), f"Expected {ret_type}"

T2_value_invariant（L1/L2，~500 题）

def check(candidate):
    r1 = candidate(); r2 = candidate()
    assert r1 == r2, f"Non-deterministic: {r1} != {r2}"

T3_chain_type（L2/L3，~800 题）

def check(candidate):
    result = candidate({args})
    assert result is not None
    assert isinstance(result, (list, tuple)), "Should return collection"

T4_state_verify（L3/L4，~500 题）

def check(candidate):
    result = candidate({args})
    assert isinstance(result, dict), "Should return dict"
    assert "status" in result

T5_behavior（L4/L5，~200 题）

def check(candidate):
    result = candidate({args}); r2 = candidate({args})
    assert result == r2, "Should be idempotent"

Reward 映射：T1/T2→二值R1臂 | T3/T4→分档R2臂 | T5→过程+结果R3臂

5. pass@8 经验校准（GPU 后 · 11/9 起）

参考 sGPO (arXiv:2606.08854)：pass@8 profiling 过滤全对/全错题，3× 效率提升。
步骤：MiniCPM5-2B × 8 runs/题 → 保留 1/8≤p≤7/8 → 丢弃 0/8和8/8

12. 结论

  1. 现有500题是占位验证级别——污染隔离✅但零自动判定，不可直接用于RL训练。
  2. 扩展至4000题可行——6781白名单API远超需求，5层5模板覆盖全难度谱。
  3. 难度校准两步走——规则分层(零GPU,初始) + pass@8(GPU后,经验)，参考sGPO 3×效率提升。
  4. 核心RL区L3+L4——~1300题，预估pass@8保留~800题，GRPO advantage最大。
  5. E1(生成+断言+闸门)可在GPU前完成——11/8-11/9执行，GPU到位即可起pass@8校准。
