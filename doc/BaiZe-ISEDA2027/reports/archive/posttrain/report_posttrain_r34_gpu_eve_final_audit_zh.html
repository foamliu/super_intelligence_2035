§3 关键发现：flash_attn 缺失 + 根因

问题：RL 配置 attn_implementation: flash_attention_2 要求 flash_attn 包，但 venv 中未安装。预检 import flash_attn → ModuleNotFoundError。

根因：环境变量 CUDA_HOME=/usr/local/cuda-12.8（不存在），系统实际 CUDA 12.4 在 /usr/local/cuda-12.4。flash-attn 编译时通过 torch.utils.cpp_extension.CUDA_HOME 查找 nvcc → FileNotFoundError: /usr/local/cuda-12.8/bin/nvcc。

$ echo $CUDA_HOME    → /usr/local/cuda-12.8  # ← 不存在！
$ which nvcc         → /usr/local/cuda-12.4/bin/nvcc  # ← 实际路径
$ nvcc --version     → release 12.4, V12.4.131
>>> torch.version.cuda → '12.4'  # torch 编译时正确
>>> torch.utils.cpp_extension.CUDA_HOME → '/usr/local/cuda-12.8'  # 从环境继承，错误
