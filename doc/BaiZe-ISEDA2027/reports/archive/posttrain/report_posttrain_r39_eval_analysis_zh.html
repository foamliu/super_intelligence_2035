9. 方法学说明

Pass@1: 5 次独立运行（reshuffled, fresh context）的平均通过率。

Wilson CI: Wilson score interval（优于正态近似，尤其在小样本/极端比例时）。

McNemar 检验: 配对检验，n01 = A 失败 B 通过，n10 = A 通过 B 失败。连续性校正。p < 0.05 → 显著。

Paired Bootstrap: 10000 次有放回重采样，2.5%/97.5% 分位数作为 95% CI。CI 不含 0 → 显著。

预注册: M0-M4 先定后测，避免事后合理化。
