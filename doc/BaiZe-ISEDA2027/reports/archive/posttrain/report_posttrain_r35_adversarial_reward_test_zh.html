3. Bug 1（CRITICAL）：None solution_str 崩溃

现象：compute_score("t", None, ...) → TypeError: expected string or bytes-like object
根因：compute_score 入口未对 solution_str 做 None/类型守卫，regex 操作直接崩溃
影响：verl 在空生成或解码错误时可能传入 None → 训练崩溃
修复：入口添加 if solution_str is None: solution_str = "" + 类型守卫
验证：T1.2_none PASS（score=0.06，与空字符串一致）

4. Bug 2：R0 语法错误代码高分（Reward Hacking 向量）

现象：语法错误代码 def call_test_func( return pyScript.testFunc( → R0=0.86（过高）
根因：R0 的 API 名匹配(0.3) + entry_point(0.2) + structure(部分) + test_align(部分) + format(0.02) 在语法完全无效时仍给出高分。syntax_score=0 但其他组件不受语法影响
影响：模型可能学会「只提 API 名不写合法代码」获得高 R0 reward → GRPO 优化方向错误
修复：reward_r0_skeleton 增加 anti-gaming cap：if n_total > 0 and n_valid == 0: total = min(total, 0.3)
效果：语法错误代码 R0 从 0.86 降至 0.30（-65%）✅
