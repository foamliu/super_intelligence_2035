4. 影响分析

single_turn 不受

原因:When multi_turn.tool_config_path is None (line 427-428), _initialize_tools returns early. get_tool_call_parser_type() is never called. Single-turn RL uses reward function on output text.

配置:multi_turn.enable: False (or tool_config_path: null)

multi_turn 受影响

原因:When tool_config_path is set (line 465-471), get_tool_call_parser_type(tokenizer) iterates 4 parsers. None match MiniCPM5-2B -> ValueError. SGLang fails to start.

配置:multi_turn.enable: True + tool_config_path:

修复:import baize_posttrain_minicpm5_parser_patch before rollout init

smoke_test 受影响

原因:If smoke enables multi_turn, it hits ValueError. Recommend: smoke single-turn first, then apply patch for multi-turn.

✅单轮 RL 完全不受 F14 影响。
