3. Recovery Protocols

C01 GPU OOM during rollout [MEDIUM]

Recovery: 16min | Auto: YES

  1. 1. Kill verl workers (ray stop)
  2. 2. Reduce rollout batch_size or max_new_tokens
  3. 3. Clear CUDA cache (torch.cuda.empty_cache)
  4. 4. Restart from last checkpoint (no progress loss if within step)

C02 NFS stall / cold-start [MEDIUM]

Recovery: 32min | Auto: YES

  1. 1. Wait 60s for NFS to recover
  2. 2. If persists >5min: checkpoint to /tmp (local SSD)
  3. 3. Ray cluster restart if workers died
  4. 4. Resume from last successful checkpoint

C03 SGLang server crash [HIGH]

Recovery: 21min | Auto: NO

  1. 1. Kill stale SGLang process
  2. 2. Restart SGLang with same config (--port 30000)
  3. 3. Wait for model load (~3min on warm NFS)
  4. 4. Re-run failed rollout batch (no checkpoint needed)

C04 Ray worker death [HIGH]

Recovery: 26min | Auto: NO

  1. 1. ray.stop() + ray.start()
  2. 2. Reload checkpoint into new workers
  3. 3. Re-run failed rollout batch
  4. 4. If recurring: reduce num_workers or memory_per_worker

C05 Checkpoint corruption [CRITICAL]

Recovery: 350min | Auto: NO

  1. 1. Identify last valid checkpoint (verification step)
  2. 2. Delete corrupted checkpoint
  3. 3. Load previous valid checkpoint
  4. 4. Resume training (lose progress between corrupt and valid ckpt)
  5. 5. Enable dual-write (local + NFS) going forward

C06 GRPO collapse (R80 modes) [HIGH]

Recovery: 193min | Auto: NO

  1. 1. R81 DecisionEngine triggers STOP or ROLLBACK
  2. 2. Load pre-collapse checkpoint (R81: rollback P=0.90)
  3. 3. Adjust hyperparameters (R73: KL coef, clip, lr)
  4. 4. Switch reward arm if needed (R81: SWITCH_ARM P=0.85)
  5. 5. Resume with conservative settings

C07 Disk full (checkpoint storage) [HIGH]

Recovery: 21min | Auto: NO

  1. 1. Delete old checkpoints (keep last 3)
  2. 2. Move checkpoints to /nas_data (20TB available)
  3. 3. Adjust checkpoint retention policy
  4. 4. Resume from last checkpoint

C08 Power failure / node reboot [CRITICAL]

Recovery: 370min | Auto: NO

  1. 1. Wait for node to come back up
  2. 2. Verify GPU availability (nvidia-smi)
  3. 3. NFS warm-up (R62: 30min)
  4. 4. Restart SGLang + Ray cluster
  5. 5. Load last valid checkpoint
  6. 6. Resume training

C09 EDA sandbox timeout [LOW]

Recovery: 12min | Auto: YES

  1. 1. Mark rollout as failed (reward=0)
  2. 2. Continue with remaining rollouts in batch
  3. 3. If >50% rollouts timeout: switch to R0 (no-sandbox) arm

C10 Reward hacking detected [HIGH]

Recovery: 122min | Auto: NO

  1. 1. R81 DecisionEngine triggers SWITCH_ARM (P=0.85)
  2. 2. Switch from current arm to R4 (strict API legality)
  3. 3. If severe: ROLLBACK to pre-hack checkpoint
  4. 4. Log cheat rate in experiment tracker

C11 OOM in training (not rollout) [MEDIUM]

Recovery: 16min | Auto: YES

  1. 1. Reduce micro_batch_size
  2. 2. Enable gradient checkpointing
  3. 3. Restart from last checkpoint

C12 Human intervention / maintenance [LOW]

Recovery: 120min | Auto: NO

  1. 1. Save checkpoint before intervention
  2. 2. Stop training cleanly (graceful shutdown)
  3. 3. Perform maintenance
  4. 4. Resume from checkpoint

6. Checkpoint Verification

Dual-Write + Verify Checkpoint Protocol

  1. 1. BEFORE save: record step, optimizer.step(), RNG state to metadata.json
  2. 2. SAVE: write to /tmp (local SSD) first, then copy to /nas_data
  3. 3. VERIFY: load checkpoint metadata, verify SHA256 of model_state_dict
  4. 4. MARK: if verify passes, rename .tmp to .ckpt (atomic)
  5. 5. CLEANUP: delete checkpoints older than max_keep
  6. 6. ON RESUME: verify latest checkpoint; if corrupt, try previous

7. Shutdown & Resume

Resume Steps

  1. 1. Check GPU availability (nvidia-smi, need >=4 A40 free)
  2. 2. NFS warm-up (R62: touch model files, import torch, 30min)
  3. 3. Start SGLang server (--port 30000)
  4. 4. Wait for SGLang health check (max 5min)
  5. 5. Start Ray cluster (ray start --head)
  6. 6. Find latest valid checkpoint (verify SHA256)
  7. 7. Load checkpoint: model + optimizer + scheduler + RNG
  8. 8. Restore reward_arm and curriculum_stage from metadata
  9. 9. Resume training from checkpoint step
  10. 10. Log resume event
