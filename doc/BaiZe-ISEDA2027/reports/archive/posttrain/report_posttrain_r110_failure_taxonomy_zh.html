9. 自动分类规则(GPU后校正)

R-F1 -> F1_syntax
Check if model output is valid Python
R-F2 -> F2_api_misuse
Check if API exists in PyAether KB; sub-types: F2a_hallucination/F2b_wrong_args/F2c_wrong_attr
R-F3 -> F3_missing_dep
Environment issue
R-F4 -> F4_timeout
Check token count or loop
R-F5 -> F5_logic
Code runs but wrong result; sub-types: F5a_assertion/F5b_value/F5c_runtime
R-F6 -> F6_unknown
Manual review

10. 结论

核心发现:
  1. AssertionError最大(254/610=41.6%) -> F5逻辑错误 -> RL(GRPO)主战场
  2. API误用F2第二大(78) -> SFT首要目标
  3. 超时F4占12.5% -> RL长度惩罚
  4. Schematic/Layout占70%且偏低 -> SFT优先配比
  5. techlib依赖任务通过率低 -> 退火语料需覆盖
  6. LOC越多通过率越低 -> RL课程从短任务起步
