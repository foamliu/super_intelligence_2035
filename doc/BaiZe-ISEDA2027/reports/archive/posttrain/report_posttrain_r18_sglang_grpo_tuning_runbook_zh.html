2. GRPO 超参数深度分析

超参数当前值文献推荐评估建议
lr (actor)1.0e-62–5×10⁻⁶⚠️偏低smoke 后提到 3.0e-6
kl_loss_coef0.040.01–0.04✅上限full 可降到 0.02
clip_ratio0.20.2✅最优保持
group_size (G)88✅最优保持
ppo_epochs11–3✅保守full 可试 2
entropy_coeff0.00.0–0.01⚠️零full 加 0.001

关键逻辑：lr 1e-6→3e-6（防止误判 RL 无效）；KL 分阶段 0.04→0.02→0.01；entropy 0→0.001 防坍缩；ppo_epochs 1→2 提高利用率。

5. 残余风险

  1. SGLang 0.5.6.post3 + MiniCPM5 tokenizer 510 added tokens 映射可能有差异。缓解：V2 验证。
  2. verl v0.7 server mode 行为变化（移除 SPMD rollout）。缓解：pip show verl 看版本对照文档。
  3. chat_template + need_tools_kwargs 双重注入。缓解：V4 检查。
  4. thinking 模式消耗 response 预算。缓解：enable_thinking: false。
  5. flash-attn 编译失败。缓解：fallback sdpa。
