关于 Duplicated key 警告：112k 转换日志中出现 3 条 Duplicated key name 警告（head_count_kv / context_length / feed_forward_length）。 但 converter 文件（convert_hf_to_gguf.py）在 10k–100k 和 112k 之间完全一致（diff rc=0）。 历史 10k–100k 转换日志没有这些警告，可能是因为日志被 grep -vE 过滤掉了。 这些 Duplicated key 警告是 nemotron_h 的混合架构正常行为（某些 key 被设了两次：标量值 + 数组值），不是权重覆盖 bug。 历史已验证 _fixed_ 版本的 GGUF 结果正确（sciq 非 NaN，10/10 ckpt 一致）。

十二、结论

结论：A. 口径差异（非真实能力下降）

证据链：

  1. 训练 loss 90k–128k 平滑稳定（avg ≈ 2.05–2.09），无退化 → 模型本身正常
