3. 决策门

G1: Smoke Test (10 iters, R0)

条件：reward_mean > 0.1 AND reward_std > 0.05 AND no OOM AND no NaN

✅ PASS：GO: proceed to full R0 training (500 iters)
⚠️ ADJUST：ADJUST: if reward_mean < 0.1 -> check reward function; if OOM -> reduce batch 128->64
🚫 ABORT：ABORT: if NaN/Inf -> check grad_clip + KL; if reward all 0 -> check data format + parser

G2: R0 Full Training (500 iters)

条件：M1 > 0.3 AND M5 > 0.05 AND M6 > 0.1 AND M4 < 0.05

✅ PASS：GO: R0 viable baseline; proceed to sandbox arms (R1/R2/R3)
⚠️ ADJUST：ADJUST: if M1 < 0.3 but rising -> extend to 1000 iters; if M6 < 0.1 -> increase entropy_coeff
🚫 ABORT：ABORT: if M1 flat 200+ iters -> signal insufficient; if M4 > 5% -> anti-cheat failure

G3: Sandbox Arm Comparison (R1 vs R2 vs R3, each 500 iters)

条件：At least one arm achieves M1 > R0_M1 + 0.05 (improvement > 5pp)

✅ PASS：GO: best arm selected for Phase3; report all 4 arms in paper
⚠️ ADJUST：ADJUST: if no arm beats R0 by 5pp -> extend to 1000 iters; if R1 std < 0.05 -> skip
🚫 ABORT：ABORT: if all sandbox arms crash -> infra failure; fall back to R0-only

G4: Final Eval (5-run on 158 tasks)

条件：Best arm eval Pass@1 > baseline_36 + 3pp (McNemar p < 0.05)

✅ PASS：GO: result publishable (even if only M1: 36%->50%)
⚠️ ADJUST：ADJUST: if < 3pp but > 0 -> paired bootstrap CI; report as trending
🚫 ABORT：ABORT: if eval < 36% -> regression; check reward hacking or overfitting

4. 统计分析计划

主比较：Paired bootstrap (10,000 resamples) on per-task pass/fail vectors

多重比较校正：Bonferroni: 6 pairwise (alpha=0.05/6~0.0083)

最小可检测效应：7.2pp — Min detectable Pass@1 diff: 158 tasks, 5 runs, alpha=0.05, power=0.8
