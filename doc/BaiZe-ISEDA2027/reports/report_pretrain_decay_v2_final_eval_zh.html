关键观察（事实陈述，不归因）：
  • decay v2 final 用了 ~80B tokens（P-8 仅 44.4B，约 1.8×），但 CS8 反而低 4.24pp——在相同架构、相同参数量下，更多 tokens 未带来 CS8 提升。
  • CS8 降幅最大的三集：boolq（-10.09pp）、hellaswag（-9.31pp）、piqa（-7.78pp）；arc_challenge / sciq / winogrande 基本持平。
  • CX6 中 mmlu 反超 P-8 达 +7.94pp（32.22% vs 24.28%），但 bbh_zeroshot 大幅下降 -10.38pp（3.98% vs 14.36%），两者相互抵消。
  • 代码生成（humaneval/mbpp）两模型均接近 0，80B tokens 尚未涌现。

6. 小结

  • CS8 = 44.97%：8 集零样本常识推理均值。sciq（68%）为最高单项，arc_challenge（28.24%）最低。
  • CX6 = 6.21%：6 集复杂任务均值。mmlu（32.22%）为唯一有意义的单项，数学/代码任务尚未涌现。
  • 与 P-8（同架构 / 同参数量 / 44.4B tokens）对比：CS8 低 4.24pp、CX6 低 0.60pp。mmlu 反超 +7.94pp，bbh 大降 -10.38pp。
  • 与 Xmodel-2.5 step_6000（同 ~80B tokens / 1.3B Dense Transformer）对比：CS8 低 5.23pp。
  • 所有数字可溯源至 eval_decay_v2_final/eval_summary.txt 及 p8_eval_summary.json。
