5. 分析

5.1 ProtB 增益小但 zero-shot 增益大

ProtB 测线性可分性，zero-shot 测文本对齐质量。GPIC 短 caption (~20 token, 0% 截断) 提供密集 image-text 对 → C1 +0.0736 → zero-shot 大幅提升。但线性可分性受 trunk 表征能力限制。

5.2 大 batch + 高 LR

GBS 512→2048, LR 5e-4→2e-3（Goyal 线性缩放）。154,500 步 ≈ 2.85 epoch（vs ④-4ep 4 epoch），更少 epoch 取得更高指标。

5.3 多变量问题

同时变更数据组成(+GPIC)、GBS/MBS(×4)、LR(×4)，无法隔离单一因素贡献。后续可消融。

7. 结论

  1. ProtB 68.25±0.01%（Δ=+1.20pp）→ 严格判据 NULL，但 4 指标中 3 个显著提升
  2. 合并三数据集 + 大 batch 改善表征通用性（zs +5.53pp, ProtA +2.71pp）
  3. C1 +0.0736 表明对比对齐增强，GPIC 短 caption 有正向贡献
  4. 多变量变更无法隔离贡献 → 后续可消融
  5. k-NN k=20: 44.88%（Δ=+2.53pp vs ④-4ep 42.35%）— 4 指标全部提升
