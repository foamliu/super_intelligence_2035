一句话结论

158 任务 × 5 runs 配对设计对 M1–M4 成功阶梯（36→50→65→75→85%）均有充足统计功效（配对 t-test ≥ 99.2%）；5 runs 是最优配置（1 run 仅 71.4%）；非配对 CI 对所有 M 水平对均重叠 → 配对检验不可替代。预注册阈值：α=0.0125（Bonferroni），CI 排除 0，点估计 ≥ M−2.5pp。

1. 研究问题

任务书要求「预注册判定阈值：点估计 + 配对检验（McNemar / paired bootstrap）显著性 + 成本比 —— 必须先定后测」。本分析回答：158 任务 × 5 runs 能否统计区分 M1–M4？5 runs 够不够？哪种检验最有力？多重比较校正后是否仍显著？

2. 方法：蒙特卡洛模拟

采用 Rasch-like 模型：P(pass|d_i, θ) = σ(θ - d_i)。任务难度从 scenario 分布采样（Layout N(0.50,0.15), Schematic N(0.65,0.15), DesignMgmt N(0.35,0.15), Others N(0.30,0.15)）。模型能力 θ 校准使均值 Pass@1 = 目标率。500 次蒙特卡洛模拟，纯 Python 3.8，~60s。

8. 预注册阈值（先定后测）

  1. 主检验：配对 t-test（per-task pass rate，5 runs），单侧，α=0.0125
  2. 辅助检验：McNemar（3/5 majority），双侧，α=0.0125
  3. CI：95% paired bootstrap CI（B=10000），必须排除 0
  4. 成功阶梯（每级需同时满足三项）：
    • M1: p<0.0125 AND CI>0 AND ≥47.5%
    • M2: p<0.0125 AND CI>0 AND ≥62.5%
    • M3: p<0.0125 AND CI>0 AND ≥72.5%
    • M4: p<0.0125 AND CI>0 AND ≥82.5%
  5. 失败保护：未达显著但超阈值 → 报告「方向正确但未达统计显著」

9. 局限性

  1. Rasch-like 模型未建模多轮工具调用闭环效应
  2. 难度分布基于 D5 经验外推，非实测拟合（11/9 后可校准）
  3. 5 runs 独立性假设（fresh context 缓解）
  4. Bootstrap CI power 通过 t-test 间接推断（纯 Python 性能限制）

10. 对论文的意义

  • 5-run 协议有充分统计依据（1 run 71.4% → 5 runs 99.4%）
  • 配对检验必须（非配对 CI 全部重叠）
  • 配对 t-test > McNemar（尤其 10pp gap）
  • Bonferroni 不影响结论（校正后仍 98.6% power）
  • 预注册阈值已定：α=0.0125 + CI 排除 0 + 点估计 ≥ M−2.5pp
