修复: R548 (2026-10-28): HermesDriver.run() 的 env 字典设 PYTHONPATH=None → _run() 函数将 None 值的 key 从继承环境中删除(run_harness.py:96-99) → hermes 子进程不再看到 dsh_sdk 的影子 pydantic_core

修复位置: run/harness/run_harness.py:486-491 (HermesDriver.run env dict)

smoke 结果: PASS — rc=0, wall=314.8s, patch=1957B (django__django-10097 URLValidator regex fix)

deepseek-harness — ✅ 已修复

  • glm53 7x300=40.0% (2026-10-17): 证明 deepseek 适配器历史可用

修复: gw_proxy_dsh.py 新增 rewrite_sse_event() 函数: 逐事件修正网关 SSE 的非标字段 + _stream() 改为逐行缓冲 rewrite(避免跨 chunk 截断 JSON)
