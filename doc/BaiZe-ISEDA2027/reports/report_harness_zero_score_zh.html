  • gate v2首跑: logs/gate_predict_hermes.log — 10/10 patch=0B, wall=1.8-3.0s
  • hermes rerun: logs/gate_predict_hermes_rerun.log — sympy-11618 patch=1269B wall=578.7s
  • pilot20: 13/15 non-empty patch (11/20 resolved=55%)

修复: R548 (2026-10-28): HermesDriver.run() 的 env 字典设 PYTHONPATH=None → _run() 函数将 None 值的 key 从继承环境中删除(run_harness.py:96-99) → hermes 子进程不再看到 dsh_sdk 的影子 pydantic_core

修复位置: run/harness/run_harness.py:486-491 (HermesDriver.run env dict)

smoke 结果: PASS — rc=0, wall=314.8s, patch=1957B (django__django-10097 URLValidator regex fix)

deepseek-harness — ✅ 已修复

症状: gate v2 首跑 10/10 题 patch=0B, wall约0.9-6.3s退出(SDK启动但SSE解析失败)

证据:
  • deep_debug_run2.log(修复前): 'DeepSeek Messages SSE contains invalid JSON' (24.7s, turn 1 step 6 即崩)
  • smoke_v2.log(修复后): '== harness=deepseek-harness rc=0 timed_out=False wall=1649.4s ==' + 'model_patch: 1860 bytes'
  • smoke_v2_django-10097.patch: 3 files changed (validators.py URL正则 + invalid_urls.txt +4行 + valid_urls.txt), 正确修复 django-10097
  • glm53 7x300=40.0% (2026-10-17): 证明 deepseek 适配器历史可用

修复: gw_proxy_dsh.py 新增 rewrite_sse_event() 函数: 逐事件修正网关 SSE 的非标字段 + _stream() 改为逐行缓冲 rewrite(避免跨 chunk 截断 JSON)
