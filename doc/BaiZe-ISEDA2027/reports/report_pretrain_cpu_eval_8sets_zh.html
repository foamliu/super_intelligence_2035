结论：llama.cpp 路线 pilot=FAIL（保留 HF float32 路线）

  • 速度达标：f16 并行=1 时 707s/600 docs = 7.03× 加速（vs HF 估计 9864s），f32 为 5.88×。
  • 精度不达标：SciQ -18pp / PIQA -16pp，Avg Δacc = -17pp。f16 / f32 / newbin 三次测试结果完全一致 → 不是量化误差，而是 llama.cpp 的 Mamba2 SSM 层数值实现与 transformers reference 有系统性偏差。
  • 根因：GGUF 转换时 hybrid_override_pattern 中 Duplicated key 覆写了 Mamba2 层元数据，导致 llama.cpp 内核用错误的 conv_dt / ssm 参数计算 → logit 输出偏移。
  • 处置：CPU 评测保留 HF transformers float32 路径（数值可信），llama.cpp 提速路线搁置，待 llama.cpp 上游修复 Nemotron-H SSM 转换后再试。
