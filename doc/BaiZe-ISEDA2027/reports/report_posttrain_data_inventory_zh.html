§7领域退火语料组装方案

基于 P1-d 调研结果，设计领域退火（Stage ii 步骤 0）的语料配比与体量估算。退火从 pretrain ckpt resume，复用 WSD 机制，不重新学新知识而是"温和注入"领域分布。

退火 blend 配比（P2 方案书已定）

成分配比来源估算 tokens角色
domain（PyAether API 参考）30%P1-d 导出纯文本约0.6-0.8 B tok（上样量）领域分布注入主体
web（Ultra-FineWeb）50%pretrain 同源约1.0-1.3 B tok通用能力保持
code（UltraData-Code）12%pretrain 同源约0.25 B tok代码能力保持
math（UltraData-Math）8%pretrain 同源约0.17 B tok推理能力保持
合计100%-约2.0-2.5 B tok（上样量）退火总上样 约8.4B tok x 实际 epoch

关键参数

  • 退火步数：4000 步（WSD：warmup 200 + decay 400 + stable 3400）
  • 学习率：5e-4 到 1e-5（WSD decay）
  • 序列长度：4096（与 pretrain 一致）
  • domain 部分上样量：约 0.6-0.8B tok（占总 8.4B 的约30%，与 blend 一致）
  • 注意：PyAether API 参考（约4-5M tok）仅约 0.005B，远小于 0.6-0.8B domain 配额 需多轮 epoch（约120-160 epoch）或与其他领域文档混合填充 domain slot
