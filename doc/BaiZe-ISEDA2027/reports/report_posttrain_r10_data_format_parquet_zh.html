4. 多轮工具调用数据流

DataLoader → RLHFDataset(prompt=list[dict]) → SGLang Async Rollout
  模型生成 → 解析 tool_call (minicpm5 parser)
    PENDING → RUNNING → TOOL_CALLING
  工具执行 (EDASandboxTool.execute) → TOOL_CALLING → RUNNING
  结果追加到历史 → 再次生成 → (max_turns) COMPLETED
  → calc_reward (R2/R3/R4) → GRPO Advantage → FSDP Update
关键点：
  • prompt 必须是 list[dict]（return_raw_chat=True）
  • 工具调用由 SGLang tool_call_parser: minicpm5 解析 XML 格式
  • agent_name 决定每条样本用哪套工具
  • 奖励函数从 reward_model 获取 ground truth
