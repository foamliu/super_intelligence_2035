核心结论

Vision 线 GRPO 全部 4 轮失败。根因: std=0=78.7%（离散奖励+低base->全同档->零梯度）。 连续化未解决（v3 仍 loss~0）。

BaiZe 优势: 36% base >> 9.2% -> R1 P(signal)=97.2% vs vision 32.0% = 3.03x 更多信号。但 R1 仍有风险，必须从 R2 起步。

七、最终建议

  1. 从 R2 起步，不从 R1
  2. 监控 std=0: >60%x3步->Dr.GRPO; >70%->G=12
  3. Step 500: 无改善->per-scenario分析->排除0%/100%场景
  4. 不回退 RFT（vision v4 证明无效）->回退 SFT 增强
  5. 诚实报告: RL 无效=支持「规模非瓶颈」论
