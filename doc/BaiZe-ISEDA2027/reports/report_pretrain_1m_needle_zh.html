BaiZe-2B：1M 长上下文与 >95% 大海捞针技术报告

运维直令 2026-10-30 · 用户令：「如何实现 1M 长上下文，如果在 1M 上下文实现 >95% 的大海捞针正确率，该怎么办。」
一句话结论：BaiZe-2B Mamba2-hybrid 已具备 1M 推理能力（max_pos=1M、θ=1e6、ABF 外推、SGLang 1M prefill 14,989 tok/s），但 1M 检索能力尚未训练（B1 实测 passkey = 0%）。要达到 >95% 大海捞针，需走 路径 A：16K 主训练 → 32K→64K→128K 阶梯扩展（~37B token）→ ABF 外推 1M，同时注入 合成 needle 数据（单针/多针/多跳/变长），辅以 RULER 评测闭环。总附加成本约 ~56 GPU·h（16 卡 H100），不扩卡即可完成。

3. 怎么到 >95% 大海捞针

前置事实：B1 实测 passkey=0%（4K 训练 ckpt）。PPL 好看不等于能检索。不训练 needle 数据，95% 是不可能的。

3.1 Needle 合成协议

任务类型协议难度目标准确率
单针 NIAH在长度 L 的 haystack 中插入 1 个针（如 "The magic password is X7K2M."），末尾提问。深度 d ∈ {0%,10%,25%,50%,75%,90%,100%} 均匀采样。基础≥95%
多针 MK-NIAH插入 3–5 针（含干扰针），提问指定 1 个。全中才算对。中≥85%
多值 MV-NIAH1 key 对应多 value，检索全部 value。全中才算对。中≥80%
多跳 VT变量链赋值（X1=42…X2=X1+10…X3=X2×2），问 X3。模拟指代消解。难≥70%
变长针针长度从 1 句到 3 段不等；haystack 4K→1M 变化。中≥85%
改写/噪声针被同义改写；haystack 加入主题相关干扰段落。难≥75%

参考 NVIDIA RULER（Hsieh et al. 2024, arXiv:2404.06654）：13 类任务覆盖 retrieval / multi-hop tracing / aggregation / QA。

3.2 合成数据生成协议

def gen_needle_sample(ctx_len, needle_type, depth_ratio, num_needles=1):
    """生成单条 needle-in-haystack 训练样本"""
    filler = sample_filler(ctx_len - needle_len - query_len)
    insert_pos = int(len(filler) * depth_ratio)
    needles = [gen_needle(needle_type) for _ in range(num_needles)]
    sample = filler[:insert_pos]
    for n in needles:
        sample += n + filler_between
    sample += filler[insert_pos:] + query
    return {"input": sample, "target": needle_answer}

# 训练数据配比：
#   单针 NIAH: 40% (ctx ∈ {4K,16K,32K,64K,128K})
#   多针 MK:   25% (3-5针, ctx ∈ {32K,64K,128K})
#   多跳 VT:   15% (ctx ∈ {16K,32K,128K})
#   变长针:    10% (针长1句~3段)
#   改写/噪声: 10% (同义替换+主题干扰)

每 ctx × 每任务 ≥500 条 → 总计 ~15,000 条。阶梯训练中混入（占 ~20-40%）。每级阶梯后评测该级 ctx + 1M 外推 needle。

3.3 训练目标

  • 主目标：标准 next-token prediction（causal LM loss），needle 数据与自然文本混合。needle loss 权重 1.0–2.0。
  • 课程学习：rung1 训单针 NIAH；rung2 加多针 MK-NIAH；rung3 加多跳 VT + 改写/噪声。难度随 ctx 递增。
  • 短文本保持：每级混入 20% 原 7 源 blend 数据，防止遗忘（CS8 退化 ≤1pp）。
  • LR：阶梯阶段保持 1e-3，不衰减（衰减留最终 Decay）。WSD stable 段。

3.4 评测协议

维度内容门限
depth×position 网格单针 NIAH：ctx ∈ {4K,16K,32K,64K,128K,1M} × depth ∈ {0%,10%,25%,50%,75%,90%,100%} = 42 格，每格 20 条。1M 平均 ≥95%

5. 取舍建议

5.1 若只能做一件事

选 A2（128K 阶梯 + 强 needle 数据）。理由：
  • 成本最低：~46 GPU·h（~2 天），不扩卡。B1/B2 多 +12h 但 256K 吞吐仅 45K，性价比差。
  • 外推可控：128K→1M = 8×，θ=1e6 已实测 1M PPL 稳定。
  • needle 是必需项：A1 vs A2 唯一差别是 needle 量（20%→40%），B1 passkey=0% 说明不训 needle 不可能 95%。
  • 16 卡上限：rung3（CP8 DP2）已是舒适上限；rung4（CP16 DP1）DP=1 容错差。

5.2 短文本回退监控与护栏

关键技术差异

  • Qwen2.5-1M（2025-01）：4K→32K→256K 渐进训练 + Dual Chunk Attention（块内/块间双层位置映射）推理外推 1M。1M passkey 接近完美（14B）。Stage 3 用合成 long-needle 数据。来源：Qwen2.5-1M 技术报告 / 央广网 2025-01-27。
  • Llama 3.1（2024-07）：RoPE base=500,000（50× 提升），原生训练 128K，无需事后外推。post-training 在 128K 全窗口微调。来源：Llama 3 Herd of Models（arXiv:2407.21783）。
  • BaiZe-2B 差异化：Mamba2-hybrid 使 1M 推理显存仅 76.7GB，prefill 14,989 tok/s。但 2.2B 远小于 Qwen 7B/14B，检索能力上限受限 —— 2B 模型在 1M 多跳/聚合任务上达 95% 比 14B 困难得多，需更强 needle 数据和更长阶梯训练补偿。

RULER 基准简介

NVIDIA RULER（Hsieh et al. 2024, arXiv:2404.06654）：合成长上下文评测，13 类任务 4 大类别：

  • 检索：单针 NIAH、多针 MK-NIAH（干扰针找指定针）、多值 MV-NIAH（一 key 多 value 全中）、多查询 MQ-NIAH
  • 多跳追踪：变量追踪 VT（非连续赋值链 → 指代消解）
  • 聚合：常见词汇 CWE、频繁词汇 FWE
  • 问答：基于长上下文的 QA

核心发现：许多声称 128K-1M 的模型，RULER 上「有效上下文」缩水严重。单针 NIAH 已被前沿模型饱和，多针/多跳/聚合才是区分维度。来源：澎湃新闻 2024-06-03。
