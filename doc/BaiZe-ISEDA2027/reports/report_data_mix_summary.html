📋 TL;DR

  1. 配比实验全流程已完成：R1（200 trial，loss objective）→ s_step 归因（8.6× 加速）→ R2（200 trial，lm_eval objective）→ top-K 全量验证（5 trial retrain + 全量 lm_eval）。
  2. 核心发现（诚实）：BO 排名与全量 lm_eval 排名几乎完全反转（Spearman ρ=−0.80，n=5，p≈0.10）；全量评测分差仅 0.3835–0.3899 ≈ 0.6pp，该代理规模下配比差异不可分辨。
  3. s_step 归因是关键转折：MBS 1→16 使每步 1432ms→166ms（8.6×），每 trial 训练量 D 从 0.016B 提到 0.5B token，使 R2（lm_eval objective）成为可行方案。
  4. math 占比始终贴下界：top-5 中 4/5 的 math=0.01（搜索空间下界），BO 试图最小化 math——但全量验证表明这不代表真实最优。
  5. 对 P-8 的建议：沿用先验 88:8:4（web:code:math）。最优区域稳定在 web 0.87–0.94 / code 0.06–0.12 / math≈0.01，但「不可分辨」意味着先验仍是安全选择。

5.3 math 占比贴下界

top-5 中 4/5 的 math=0.01（搜索空间下界），BO 试图最小化 math。但全量验证中 math=0.055 的 t118 排名第 3（与 math=0.01 的 trial 差异在噪声内），BO 对 math 的「嫌弃」不一定反映真实最优，更可能是 --limit 500 抽样噪声导致的伪信号。

7对 P-8 的建议

✅ 建议：沿用先验 88:8:4（web:code:math）

理由：

  1. 代理规模下配比不可分辨：全量 lm_eval 分差仅 0.6pp，低于种子噪声预期 → 无证据表明任何配比显著优于 88:8:4。
  2. 最优区域稳定：BO top-10 集中在 web 0.84–0.94 / code 0.06–0.12 / math≈0.01，与先验 88:8:4 高度重合。
  3. BO objective 不可靠：两轮 BO（loss / lm_eval 抽样）都与全量能力负相关 → BO 的「最优」不可信。
  4. 先验来源可靠：88:8:4 来自文献经验和前期 R/R2 调研（见 DATA_RESEARCH.md），有外部支撑。
  5. 风险最低：在不可分辨的情况下，选择有先验依据的配比是安全策略。

不建议：根据 BO top-1（t23: web=94.1%/code=10.9%/math=1%）调整 P-8 配比——因为 t23 在全量验证中仅排第 4。
