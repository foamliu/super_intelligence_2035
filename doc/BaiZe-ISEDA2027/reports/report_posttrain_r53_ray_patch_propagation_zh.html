R53: Ray Worker Monkey-Patch 传播解决方案

R-009 RESOLVED | BaiZe Stage(ii) Post-Training | 2026-11-08 wake101

核心结论：风险登记册最后一个 OPEN 项已关闭。通过 .pth 文件 + 环境变量 BAIZE_SGLANG_PATCH=1，MiniCPM5 XML parser 注册可自动传播到 Ray worker。实测子进程传播成功。

1. 问题根因

verl_wrapper 在主进程注册 parser 到 SGLang ToolCallParserEnum。Ray worker 是独立 Python 进程，各自 import sglang → patch 不传播。影响仅 Phase 2（多轮 RL）。

2. 解决方案

主进程: import patch → apply_patch() → set env var → ray.init(env_vars) Worker: Python启动 → site.py处理.pth → if env=1 → import patch → apply_patch() ✅

.pth 被 site.py 在每个进程启动时自动执行，比 Ray py_modules（仅可导入不自动导入）更可靠。
