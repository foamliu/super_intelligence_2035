2.3 对照组设计（隔离退火贡献）

由于退火只改变数据分布，我们将其与「仅做 SFT」的对照组比较，以把退火的贡献从随后的行为微调中隔离出来：

  • Arm A（退火 + SFT）：pretrain ckpt → 领域退火 → SFT →（→ RL）
  • Arm B（仅 SFT，对照）：pretrain ckpt → SFT →（→ RL），跳过退火

两臂后续 SFT/RL 配方完全一致，差异仅在退火。评测时报告 Δ(退火) = Pass@1(A) − Pass@1(B)。

退火语料组装的阻塞项：P1-d（PyAether 领域语料）来源尚未确认——需调研 eda_fastmcp 的 API 知识库能否导出为纯文本。 已知可复用来源线索：pyAether_API_Docstring / emyDesign / sklangref（曾被污染检查扫描，0 命中 ⇒ 属「来源材料」，允许入训练）。 退火正式起跑前必须：(1) 确认语料体量 ≥2B tok；(2) 经污染闸门 baize_posttrain_contamination_gate.sh 扫描 0 命中。

3步骤 1 · 监督微调（SFT）

SFT 教授部署目标所要求的「生成—执行—改进」闭环（论文 §5.2）。语料由 agentic 指令集 + 通用指令集 + PyAether 专属合成材料合并，并消融数据配比、工具轨迹、微调方式与序列长度四个轴。

3.2 工具轨迹 vs 纯代码

含 CoT + 工具轨迹

预期：M1/M3 增益大

纯代码（对照）

SFT 样本只有 instruction → final code，不含中间执行/改写步骤。验「轨迹」本身的价值。

预期：闭环能力弱

4步骤 2 · 强化学习 RLVR+GRPO（4 臂奖励）

执行沙盒把正确性转化为可验证信号，因此采用无需价值网络的组相对策略优化（GRPO）（论文 §5.3）。这是 Stage~(ii) 的核心，也是成本最高的一步。

4.3 Reward hacking 风险与反作弊

最大风险（风险 #2）：奖励由策略原则上可以直接瞄准的断言计算而来——模型可能学会「绕过断言」（如硬编码答案、篡改测试代码、伪造通过）而非真正解决问题。 必须：(1) PreToolUse hook 全程启用且所有实验臂逐字一致；(2) BaiZe RL 挂同一套 anti-cheat；(3) 每个 accuracy 数字旁单独报告 cheat rate（被 hook 拦截的作弊尝试比例）。 cheat rate > 5% ⇒ 该臂结果作废，需调查并加固 hook 后重跑。

4.4 预算口径换算（风险 #9）

沙盒时延 bound，不是 GPU bound：RL 带沙盒执行，单次 rollout 超时 2500s，瓶颈是沙盒时延而非 GPU 计算。 不能沿用 GPU-hour 口径。规划按「沙盒并发数 × 墙钟」算：
  • 16 并发 × 2500s/任务 × 158 任务 × 16 group × N 步 ≈ 沙盒墙钟
  • 例：158 任务 × 16 rollout × 平均 600s（非全超时）= 1,516,800s ≈ 420h 单并发；16 并发 ≈ 26h/epoch
  • 3 epoch ≈ 78h 沙盒墙钟（≈3.3 天），GPU 侧仅做策略更新，显存占用远小于此
预算按天而非 GPU-hour 报告。

4.5 RL 训练数据

RL 的 prompt 来源：合成 PyAether 任务（从 API 文档合成 instruction + 断言，禁用 158 评测题）。合成规则：(1) 按 API 名/函数签名隔离，确保不与评测集重叠；(2) 经污染闸门扫描 0 命中；(3) 覆盖 4 场景配比（Layout 64 / Schematic 47 / Design Mgmt 24 / Others 23 的比例）。预计合成 ~2000 条 RL prompt。

7.1 点估计阈值

声明判定条件（先定后测）

7.2 配对检验（统计显著性）

158 任务固定集上两系统比较，仅比均值不敏感（binomial SE @ p=0.8, n=158 ≈ 3.2 pp，95% CI ≈ ±6.2 pp）。 必须用配对检验：

  • McNemar 检验：构建 2×2 列联表（两模型在 158 任务上的 pass/fail 配对），检验边际齐性。适用于二值结果配对比较。
  • Paired bootstrap：对 158 任务做有放回重采样 B=10000 次，计算 Pass@1 差值的经验分布，取 2.5%/97.5% 分位为 95% CI。不依赖正态假设，对小样本更稳健。

判定：p(McNemar) < 0.05 且 bootstrap 95% CI 不含 0 ⇒ 差异显著。两者皆满足才声明「显著优于」。
