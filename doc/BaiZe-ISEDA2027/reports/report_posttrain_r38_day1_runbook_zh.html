4. 关键决策树

场景1: GPU 未释放
条件: T+0:30 时仍有 8/8 GPU 忙
→ 轮询每15分钟，最多等到 T+2:00
→ 仍未释放 → 上报运维（不杀其他进程，红线）
→ GPU到位 → 重新启动时线
场景2: SGLang 启动失败
检查: 模型路径? venv有sglang? 端口8866空闲?
→ 换端口: --port 8867
→ 降低显存: --mem-fraction-static 0.75
→ 持续失败 → 回退 vLLM（失去工具调用解析，仅单轮）
→ 记录到日志 + 上报
场景3: RL 冒烟全零奖励
检查: reward_arm=R0? parquet加载? compute_score返回非零?
→ R0 std=0.3718 (R35实测) → 应有梯度信号
→ 若仍零 → 检查 parquet格式 + task字段
场景4: RL OOM
→ 减: ppo_micro_batch_size_per_gpu 4→2
→ 减: gpu_memory_utilization 0.35→0.25
→ 减: max_response_length 4096→2048
→ gradient_checkpointing已开启（config=True）
场景5: 监控告警 (P1-P7)
P1 KL大于10: 减lr(3e-6→1e-6), 增kl_loss_coef(0.02→0.04)
P2 reward小于0.01: 检查奖励函数, 切换arm
P3 方差小于0.01: 增entropy_coeff(0.001→0.01)
P4 熵小于0.1: 减kl_loss_coef, 增entropy_coeff
P5 梯度大于100: 减grad_clip(1.0→0.5)
P6 NaN/Inf: 停止, 减lr, 从检查点重启
P7 作弊率大于5%: 报告(不停), 收紧anti-cheat

7. 回滚程序

如果 Day-1 出现不可恢复的错误：

  1. 停止所有训练进程
  2. 停止 SGLang 服务
  3. 保留日志: cp /tmp/baize_posttrain_rl_train.log 到备份
  4. 保留检查点: 最新 checkpoint 自动保存在 save_dir
  5. 从检查点重启: baize_posttrain_rl_grpo.sh --reward-arm R0 --resume-ckpt path
  6. 如果数据污染: 重跑污染闸门，不可继续训练
