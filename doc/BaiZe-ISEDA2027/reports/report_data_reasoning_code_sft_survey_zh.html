§2 检索方法与口径

2.1 检索工具与流程

  • 检索工具: 使用 HF API (huggingface.co/api/datasets) 通过代理 (http://172.19.92.25:13128) 发起针对性搜索查询, 获取数据集元信息 (repo id, downloads, gated, lastModified, license, size_categories, tags)。
  • 检索查询: 共发起 30+ 轮针对性搜索, 覆盖: math reasoning SFT, code SFT reasoning, chain of thought, GSM8K, MATH olympiad, open-r1, deepscaler, open-thoughts, code repair bugfix, code instruct, repo-level code SFT, science reasoning, logical reasoning, SWE-gym, SWE-smith, codecontests, numina, magicoder, commitpack, metamath, OpenCodeReasoning, RLVR code, terminal-bench, SWE-bench Verified, proofwriter, natural reasoning, big-math 等。
  • 逐条核实: 对每个候选数据集, 通过 HF API 获取 cardData (license, size_categories), gated 状态, downloads, lastModified, tags。部分数据集额外获取 siblings (parquet 文件结构) 以确认 shard 数量和格式。

2.2 核实的字段

2.3 未核到的字段

  • 确切字节数: HF API siblings 的 size 字段返回 0, 无法获取确切 parquet 字节数 → 体量基于 size_categories 区间值估算。
  • 部分 license: saurabh5/open-code-reasoning-sft, qingyangzhang/Natural-Reasoning-STEM-25K, wentingzhao/commit0_combined, allenai/rlvr-code-data-python-r1-format-filtered, tasksource/proofwriter, garage-bAInd/Open-Platypus 的 license 未在 cardData 中标注 → 标注「未核到」。
  • 部分体量/样本数: open-r1/Mixture-of-Thoughts, open-r1/codeforces 的确切样本数未核到。
