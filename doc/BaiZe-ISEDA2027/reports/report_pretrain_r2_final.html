1TL;DR

  1. 架构锁定 Mamba2-hybrid 56L/4-attn（2.220B）：P-3 在 500/1000/2000/3000/5000 全 5 个 checkpoint 均优于 dense MiniCPM5-2B（2.512B），Δ=0.22–0.43（末段 ≈0.30），少 11.6% 参数。B1：1M ctx PPL=55.42（vs 128K=53.34，+3.9% 噪声内），无退化。
  2. LR=1e-3 / WSD 为最终超参：P-1 十点 LR（2e-4…3e-3）明确 U 形，极小值齐整落在 1e-3（网格内部全局极小值，非边界截断）。P-5a 证明 1e-3 跨 GBS{8,64,256,1024} 无需 batch rescaling。val loss 2.2054（655M, GBS=8 胜出配置）。
  3. hybrid vs dense 推理加速 2.8–4.3×@128K–256K（warmup-corrected T1/T2 v2）：原 P-9.11-E「dense 3.3× faster」= warmup 假象已撤回。float32 vs bf16 SSM 无差异（1.00×）。
  4. delayed FP8 可用于 P-8：P-9.8 1000 步 A/B 4/4 PASS（iter700 spike-then-recovered），速度 +19.4%（s=1.194），省 5.6GB/卡。P-9.9 tensorwise FAIL → 沿用 delayed。
  5. P-5b scaling law：20B token 全程（38.7h / 309 GPU·h），loss 5.367→1.9141，stable 段未变平。P-6② R²=0.986，55% Avg≈55B token → P-8 推荐 100B 合理。

5FP8 裁定：delayed 可用于 P-8

5.1 P-4 / P-4R：FP8 理论上限 → 不接（Amdahl <2×）

P-4 BF16 profile（80 步）：GEMM 占比 g≈28.6%（含通信墙钟）/ ~49.2%（纯计算）。Amdahl FP8 上限纯计算 1.97×，含通信 1.40×，现实 ~1.1–1.2×。P-4R 实测单算子 s：生产口径 M=4094，实测 s≈0.65（FP8 在瘦 GEMM 上反慢 35%，访存受限）。端到端 0.79× → 慢 21%。

P-4R 注：单算子结论（M=4094）。P-9.6② 端到端（M=65536/TP4/SP）实测 s=1.21–1.24 → FP8 在大 M 下有加速。最终采用 P-9.8 长程裁定。

5.2 P-9.8：长程一致性 A/B（1000 步）→ 4/4 PASS

TP4·SP-on·MBS8·seq8192·GBS512·M=65536。臂 A=bf16，臂 B=FP8 delayed。

判据阈值实测初始修订后
#1 末段 100 步均值差≤1%0.558%PASSPASS
#2 nan/skip 全程=00/0PASSPASS
#3 grad-norm 差≤10%4.98%PASSPASS
#4 max 偏离≤2%4.36%@iter700FAILPASS*
图 5.1 — 两条曲线几乎重合，iter700 处 FP8 瞬时 spike（4.36%）但 iter770 后完全恢复
修订裁定：#4 改为「持续性」判据——一次偏离在 ≤100 步内回落到 ≤1% 不计 FAIL（spike-then-recovered）。iter 680–740 约 7 个点 >2%，iter 770 恢复 ≤1%（~60–90 步 < 100）→ 4/4 PASS → delayed FP8 可用于 P-8。速度 +19.4%（s=1.194），省 5.6GB/卡。

5.3 P-9.9：tensorwise FP8 → FAIL → 沿用 delayed

改用 tensorwise（current per-tensor scaling，消除 delayed amax lag）。T1/T4 FAIL → P-8 沿用 delayed。blockwise（DeepSeek-V3 fine-grained 128×128）因 CUDA 12.8 < 12.9 不可用。

10局限与诚实交代

  1. 655M token 代理实验：P-1/P-2/P-3/P-5a 等选型实验均在 164M–655M token（5000 步）下完成。LR 最优、min_lr 噪声、架构对比的结论尚未在 P-8 生产级（100B）上验证。P-5b 20B token 提供了部分外推支撑（scaling law R²=0.986），但 100B 级实际行为可能与外推有偏差。
  2. 未收敛：P-5b stable 段到 17.9B 仍 ≈1.977 持续缓降、未明显变平。20B 的 1.9141 是 decay 尾段压下，不代表 stable 已收敛。P-8 实际 token 预算需根据 loss 曲线动态调整。
  3. 单 seed 方差：P-2 n=5 的 σ≈0.0349 已收窄，但 P-5b / P-9.8 等长程实验均为单 seed。min_lr Δ 在噪声内的结论基于 5000 步口径，长程（100B）下方差行为未测。
  4. P-5a GBS=1024 caveat：仅 39 步 = 3 满 log 点，1e-3 vs 2e-3 的 Δ≈0.046 落在 σ≈0.035 量级（统计上不可区分）。「无右移」结论依赖「4e-3 在 GBS=64/256/1024 全部明显更差」的稳健性，而非 GBS=1024 单档显著性。
  5. P-9.8 FP8 spike 未完全解释：iter 700 的 4.36% spike 可能由 delayed scaling 的 amax 估计累积误差导致。修订判据归为 spike-then-recovered，但根因未定位。P-8 若用 FP8，前 500 步需密切监控。
  6. 推理对比口径变化：P-9.11（0.85）vs P-9.11-E（0.3+float32）vs T1/T2 v2（0.3+warmup-corrected）三套口径有差异。最终采用 T1/T2 v2 为权威结论，不同口径绝对数值不可直接比较。
  7. 复杂推理贴地板：A 36/36 中 5/6 任务贴地板，仅 BBH 有微弱信号且非单调。2.2B / 20B token 无法做复杂推理——如实测量，需 Stage (ii) SFT/RL 解锁。
  8. P-8 尚未启动：本报告所有结论均为选型实验结论。Stage (i) 本体（P-8 从零 100B token）尚未开始。实际 loss 曲线、GPU·h、最终 val loss 与 P-5b 预测的对照需 P-8 完成后回填。
