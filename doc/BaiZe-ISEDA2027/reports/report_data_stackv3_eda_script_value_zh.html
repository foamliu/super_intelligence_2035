§8 风险与隔离

许可证：stack-v3-train 使用 ODC-By（Open Data Commons Attribution），允许使用、修改、分发，但需署名。商用路径需注意署名合规。
Vendor 剔除：Phase A 实测 vendor 文件 16,439,240（1.3%），已在 tokenize 和 Phase B 中剔除（is_vendor=false 过滤）。
评测集污染隔离（红线）：
  • EDA-Eval-PyAether 158 任务（prompt/entry_point/test）绝不能入训练集
  • zhulong / designflow 相关 repo_path 必须排除
  • 必须跑 13-gram 闸门（复用 phase5 isolation 的 NFKC/8-gram 框架，升级为 13-gram）
  • 改写/paraphrase 不洗白
污染隔离实测证据：在 Phase B 抽样的 3200 个文件中，搜索 repo_path 含 ['eda-eval', 'pyaether', 'zhulong', 'designflow', 'baize'] 关键词 → 命中 1 个（需排除）。命中清单：opendesignflow/tcl-integration
注：此为抽样级检测，全量入库时仍需跑 13-gram 闸门做完整校验。
