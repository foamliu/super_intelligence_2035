1. 🔴 P0：Skeleton 模式 RL 无学习信号

问题

EDA sandbox 是 skeleton 模式，exec_success 恒 False。R1-R4 全依赖 exec_success → 所有 reward=0.0 → GRPO advantage=0 → 梯度=0 → RL 空转。不报错、不崩溃、日志正常，但模型没学习。

修复：R0 Skeleton-Mode 奖励臂

Auto-fallback：arm=R2 但无沙盒结果 → 自动切 R0。11/9 首日隧道未就绪 RL 仍有非零信号。

✅ R0 梯度差异 0.06–1.02，GRPO advantage 非零。

2. Checkpoint Resume（L3 解决）

verl 原生支持 --trainer.resume_from_checkpoint <path>（来源：CSDN verl 实操 + HuggingFace GRPO campaign）。

  • 新增 --resume-ckpt <path> CLI 参数
  • 训练后自动扫描 checkpoint，打印恢复命令
  • checkpoint 含完整 optimizer state + lr scheduler + seed

✅ Dry-run 验证：--resume-ckpt /tmp 正常。
