.75 上的 WaveView 已由烛龙 benchmark 实测验证可用（来源：doc/ZhuLong_DAC2027/benchmark/.pi_debug/EDA-Eval-DesignFlow-Wave-005/）：
  • wv 路径：/apps/synopsys/SRB/wv/T-2022.06-SP1/bin/wv
  • 批处理模式：wv -ace_no_gui <script.tcl>，rc=0 ✅
  • Demo FSDB：/apps/synopsys/verdi/Verdi_M-2017.03-SP2-9/demo/mixed/mixed.fsdb（240 信号 / 128 bus / 1 top scope）
  • API 实测：sx_open_sim_file_read / sx_signal / sx_first_wave / sx_next_wave / sx_get_name / sx_close_sim_file 全部 PASS
  • 实测陷阱：sx_signal <glob> 比 iterate+stringmatch 多匹配 4 个 alias 信号（*clock*=9 vs 5）
  • 访问方式：烛龙 benchmark 通过 eda_flow MCP（open_session/run_code/close_session）访问 .75，非 SSH
关键阻塞：本机（.12）→ .75 的 SSH 不可达（端口 22/2222 超时），且本机无 eda_flow MCP 工具。
烛龙 benchmark 的 run.sh 工作目录为 /nasdata/...（.75 本地路径），说明 benchmark 在 .75 上运行，而非从 .12 远程调用。
需运维协调：① 开放 .12→.75 SSH；② 或在 .75 上部署 RL 训练；③ 或提供 MCP 访问通道。

2. 四个待核项实测

待核①：FSDB 转换工具链 → RED（备选 GREEN）

检查项本机实测判定
vcd2fsdbwhich vcd2fsdb = 空 → 不存在RED
verilator（VCD 生成）which verilator = 空 → 不存在RED
ngspice（.raw 生成）/usr/bin/ngspice ngspice-36 ✅GREEN
ngspice write .raw646 点 × 3 变量 binary double ✅GREEN
Python .raw 解析器struct.unpack double → numpy (646,3) ✅GREEN
判定：vcd2fsdb 需 Synopsys license（本机无）→ FSDB 路径 RED。
备选路径 GREEN：ngspice .raw + Python 解析器可完全替代 wv+FSDB 的数据获取功能—— ngspice 生成 SPICE tran 仿真 → binary .raw → Python struct/numpy 解析 → 数组数据。 损失：失去 FSDB 格式兼容性和 wv Tcl API；保留：RL 环境框架（7 动作/奖励/观测）全部可用。

待核②：sx_export_image 截图导出 API → RED（备选已定）

检查项状态判定
sx_export_image 存在性需 .75 实测，本机不可达RED
备选方案episode 开始时外部预处理一次性截取（matplotlib 渲染 .raw → PNG）备选 GREEN
备选方案：用 matplotlib 将 ngspice .raw 数据渲染为 PNG 截图（plt.plot(time, signal) → savefig）， 在 episode 初始化时一次性生成。这比 sx_export_image 更灵活（可控制分辨率/范围/标注），且不依赖 Synopsys。

待核③：sx_open_sim_file_read 崩溃阈值 → RED（保守预算）

检查项状态判定
崩溃次数统计需 .75 实测，本机不可达RED
保守预算单 episode wv 调用 ≤ 3（按计划书保守值）保守
保守策略：在 .75 实测前，单 episode wv 调用上限 = 3（计划书保守值）。 备选路径（ngspice .raw）无崩溃风险——ngspice 是成熟开源工具，ngspice -b 批处理模式在本机 3/3 成功，rc=0。

待核④：license 并发上限 → RED（保守=1）

检查项状态判定
license 串 / 并发上限需 .75 实测，本机不可达RED
保守并发RL 并行 episode = 1（串行）保守
保守策略：在 license 并发上限确认前，RL 并行 episode = 1（串行）。 备选路径（ngspice .raw）无 license 限制——ngspice 是开源工具，可任意并行。这是备选路径的一大优势。

3. Gym 冒烟测试

3.1 环境架构

vision/wave_rl/waveview_gym.py 实现了完整的 Gym 风格环境：
  • 数据源：ngspice 生成 4 类电路（RC / RC-pulse / CMOS inverter / RL），参数随机化
  • 解析器：Python struct+numpy 解析 ngspice binary .raw（646 点 × 3-4 变量）
  • 7 动作空间：A1 open / A2 get_signal / A3 get_type / A4 get_bits / A5 get_values / A6 dump_hier / A7 submit
  • 奖励：R_main（数值相对误差分档 ≤1%→1.0 / ≤5%→0.7 / ≤10%→0.4 / ≤25%→0.1）+ R_evidence(0.3) + R_budget(0.1) + R_dense(0.2) + R_anti(-2.0)
  • 预算：MAX_WV_CALLS=3 / MAX_STEPS=15（保守值，待 .75 实测后调整）
  • Oracle 参照线：oracle_measure() 用 Python 信号分析（周期/幅度/上升沿/占空比）
