GRPO 路线（v1/v2/v3）：CPU 上 GRPO 受限于小 group（std=0 问题持续）、近零 loss、波动 avgR。 即使连续化奖励（v2/v3）也未扭转颓势 —— v3 C=25.0% < B=34.0%（控制 D 待完成）。

5.3 诚实边界

  • CPU pilot 结论不外推为 GPU 结论：CPU 上 step 数/group_size 受算力限制，GPU 阶段需重新验证。
  • text-only backbone 局限：当前用文本工具交互（ngspice），非直接看波形图。多模态版 Qwen3.5-2B 可直接处理图像，是未验证的更高上限。
  • 负结果同样有价值：证伪了「CPU 上 GRPO/RFT 能提升波形读数」这一假设，为后续方向选择提供了排除证据。
