3.2 spike 统计（与 ArmE 发散对比）

spike 性质：对比损失 (contr) 的周期性跳升，patch 损失全程平稳（~0.005–0.015） → spike 由 InfoNCE 批次统计噪声驱动（per-microbatch 对比 batch = 2048，因 MBS 256 显存回退，非 4096）。每个 spike 后均自恢复，未演变为发散。

结论：降 LR(1e-3→5e-4)+warmup(2000→3000) 未消除 spike 的发生（contr 批次噪声客观存在），但把 spike 从"不可逆发散"降级为"可自恢复的短暂跳升"。ArmE 在 s29200–29400 的 spike 升级为 loss 8.1 / C1 0.0007 且永久不归；ArmE-R2 同期 spike 仍在 0.5–1.4 量级且数百步内恢复。这是两变量干净对照的核心结论。

5.1 🔧 eval bridge bug（修复）

根因：lmms_eval_baize_llava.py hardcoded NUM_IMAGE_TOKENS=196 (ViT-B/16: 224/16=14x14=196); ViT-L/14 patch14 -> 224/14=16x16=256 patch tokens -> projector/LLM embed dim mismatch -> 8-GPU eval all crashed.

现象：12-集评测首次运行时 8 卡全部崩溃（embedding 维度不匹配，256≠196）。

修法（3 处动态计算）：3 places changed to dynamic calc: (1) self.num_image_tokens = 256 if vision_backend in ('armE','armE_r2') else 196; (2) _expand_image_tokens expands by actual token count; (3) feature buffer allocated by actual shape.

冒烟验证：ai2d --limit 32 smoke test: [inject] img_mask sum=256 OK (see /tmp/smoke_armE_r2_ai2d.log)

[inject] inputs_embeds shape=torch.Size([32, 327, 2560]), img_mask sum=256
[inject] img_feat stats: min=-3.828, max=4.188, mean=0.013

修复文件：vision/mllm_bridge/lmms_eval_baize_llava.py。此 bug 为 ViT-L/14（patch14, 256 tokens）与 ViT-B/16（patch16, 196 tokens）的 patch 数差异所致，属本次 ArmE-R2 特有工程问题（ArmB/C/D-R2 用 B/16，无此问题）。

7. 结论与局限 + 复现命令

① 编码器（最可靠，ProtB，🏆 历史最高）：lp 68.236% / 5-NN 58.904%，全实验最高。vs ArmD-R2 Δlp=+3.899pp / Δ5-NN=+2.948pp。⚠️ 三变量(塔+LR+warmup)+容量混杂，不得归因单一变量。编码器质量核心结论已 secured。

② MLLM 下游（不可分辨）：12 集 avg 26.10%，vs ArmD-R2 -0.02pp / vs ArmC +0.32pp / vs ArmB −0.00pp。视觉塔增大 3.5×，MLLM 下游完全持平 → 容量不是 MLLM 下游瓶颈（在 224px 单块 + 当前 MLLM 架构下）。

③ ProtB→MLLM 传递性再次证伪（最强烈一例）：编码器 +3.9pp 的 ProtB 优势完全未转化为 MLLM 下游优势。这是所有实验中 ProtB 差距最大而 MLLM 持平最明确的一例。

④ 降 LR 效果（ArmE-R2 vs ArmE，两变量干净对照）：ArmE(LR 1e-3) s29400 永久发散(C1~0.0007)；ArmE-R2(LR 5e-4) 全程稳定，0 步 C1<0.01（warmup 后），C1 最高 0.9664 → 降 LR+warmup 把 spike 从"不可逆发散"降级为"可自恢复跳升"。

⑤ 诚实条款：内部 ProtB/MLLM 口径，非官方榜；单 backbone/单预算点；MLLM 三阶段单 seed；224px 单块（无 anyres），细粒度任务天然偏低；Stage-2 数据为原版 quick-start（同 ArmD-R2）；MBS 512→256 是显存强制回退非消融变量。
