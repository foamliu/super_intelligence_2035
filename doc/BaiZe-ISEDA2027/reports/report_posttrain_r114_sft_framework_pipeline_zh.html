verl FSDP SFT Advantages

  • Zero install: verl 0.4.0 in cu124 venv (torch 2.6.0+cu124, flash_attn 2.7.4)
  • Unified toolchain: SFT + RL same framework, venv, model loading
  • Direct parquet: MultiTurnSFTDataset accepts parquet, no MEGATRON format
  • Multi-turn loss masking: auto train only assistant tokens
  • FSDP on A40: 2B+FSDP = ~8GB/GPU, 46GB A40 plenty
  • LoRA built-in: lora_rank config switch
  • WSD scheduler: consistent with pretrain
