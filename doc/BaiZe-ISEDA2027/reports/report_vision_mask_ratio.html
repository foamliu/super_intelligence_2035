2实验设计

2.1 研究问题

AIMv2-style recipe（InfoNCE + 1.0×masked-patch-MSE）中，随机掩码比例（mask-ratio）的最优值是多少？mask-ratio=0.6 借鉴自 MAE 文献（75%），但从未在对比项存在的情况下做过消融。掩码比例过低（→ 少量监督信号）或过高（→ InfoNCE 负样本不足）都可能损害表征质量。

4坍缩判据与健康度

BaiZe vision 线使用 C1–C4 四指标体系监控表征坍缩（详见 EXPERIMENTS_VISION_ROUND8.md）：

  • C1（同塔 off-diag）：对比对齐度。< 0.95 = 健康；→ 1.0 = 完全坍缩（所有 patch 塌成同一向量）。
  • C2_gap（diag vs off-diag gap）：> 0.005 = 健康（对角 vs 非对角有区分度）。
  • C4（综合判据）：OK = 无坍缩（C1 + C2 + loss scale 三项联合判定）。

4.2 关键发现：arm 0.75 的「峰值早现但不稳定」

arm 0.75（mask-ratio=0.75）的 C1 峰值 0.4458@step19800 为全 5 臂最高，但在 step 19800 之后持续回落： 0.4458@19800 → 0.4068@20100 → 0.3942@20400 → 0.3888@20700 → … → 0.3736@30000。

最终 C1（0.3736）< arm 0.6 最终 C1（0.3810），且 lp（12.49%）< arm 0.6（13.49%）。

解读：高 mask-ratio（0.75）在训练中期可获得更高的对比对齐度（C1 peak），但终态不稳定——可能因为可见 patch 太少（~49/196 = 25%），后期 InfoNCE 负样本不足导致对比信号退化。这解释了为何 0.75 的 lp 虽在噪声带内但低于 0.6。

4.3 C1 vs lp 的非单调分歧

arm 0.3 的 lp（12.69%）> arm 0.5 的 lp（11.91%），但 C1 相反（0.3495 < 0.3756）→ 对比对齐（C1）与线性可分性（lp）不完全正相关。
可能原因：mask-ratio=0.3 时可见 patch 更多（~137/196 = 70%），InfoNCE 负样本更丰富 → 更好的 lp 特征，尽管对比对齐度（C1）较低。这说明 mask-ratio 对对比项和生成项的影响机制不同，不能仅用单一指标判优劣。

5结论

  1. mask-ratio 存在最优值 ≈ 0.6：IN-1k lp 呈倒 U 形——0.6 最高（13.49%），两侧递减。C1 probe 同样在 0.6 达 final 最高（0.3810）。lp 与 C1 双指标一致指向 0.6 为最优。
  2. [0.3, 0.75] 区间不敏感：arm 0.3（Δ=−0.80）和 0.75（Δ=−1.00）均在 ±1.5pp 噪声带内 → mask-ratio 在此区间的选择对 lp 稳健（flip 不会翻转结论）。
  3. 极端值显著更差：arm 0.5（Δ=−1.58⚠️）和 0.9（Δ=−1.96⚠️）超出噪声带 → 过低或过高的 mask-ratio 均损害 lp。0.5 的异常低值值得注意——它低于 0.3，暗示 0.5 附近可能存在一个局部「甜点外」区域，但单 seed 下尚不能确定是否为噪声。
  4. 全区间无坍缩：5 臂 C1 全部 ∈ [0.347, 0.381]，C2_gap 全部 ≈ +0.11~+0.12 → InfoNCE 对比项提供了充分的防坍缩约束，mask-ratio 不是坍缩的诱因。
  5. 可复现性确认：arm 0.6 受控复现 lp@30k=13.49% vs R11-L arm6-A 原始 12.08%（Δ=+1.41pp，噪声带内）→ R11-L 的 AIMv2 翻盘结论（+6.00pp）可复现。
  6. 实践建议：后续 AIMv2-style 训练应继续使用 mask-ratio=0.6；若需在 [0.3, 0.75] 内微调，不会显著影响 lp，但应避免 ≤0.5 或 ≥0.9。

6与既有 lp 结论的关系

🔴 lp 口径警告（必读）：本报告所有 lp 数值均使用 BaiZe 内部协议（Protocol A）：
  • 冻结 trunk + 线性分类器 + ImageNet-1k（与 DINOv2/MAE/iBOT/VISSL 同框架）
  • AdamW lr=3e-3 固定无 schedule + 100 epoch
  • full-batch 前向 49,970 张（每 epoch 仅 1 次梯度更新 → 100 epoch = 100 次更新）
  • 探针训练集 = 50 张/类（vs 主流全量 1,281,167 张 → 小 ~25×）
  • 预处理 = CLIP mean/std（vs 主流 ImageNet mean/std）
→ 该协议系统性低估 lp ~10pp（详见 report_vision_lp_protocol.html）。

6.1 Δlp ≈ +10pp 的来源

lp 协议 A/B 桥接实验（同 ckpt · 同 eval 集 · 3 seeds）实测：

协议设置lp（R12b final ckpt）3-seed σ
A（BaiZe 内部）AdamW 3e-3 · full-batch · 100ep · 50/类 · CLIP norm18.79%—
B（主流）SGD+momentum 0.9 · cosine · 90ep · bs1024 · 全量 1.28M · IN norm28.84%±0.03%
Δlp = B − A+10.05pp（cross-ckpt 极稳：+10.05 / +10.05 / +10.17，σ=0.06）

6.2 不可直接混比的理由

  1. 协议偏移 = 系统性：Δlp ≈ +10pp 是协议差异（优化器/步数/batch/数据量/预处理），不是模型差异。同一 ckpt 在两协议下差 10pp。
  2. 本消融用 Protocol A：所有 5 臂共享同一协议 → 臂间相对比较有效（Δlp vs 0.6 基线是公平的），但绝对值不可与主流公开值并列。
  3. 若换 Protocol B：本消融的 lp 绝对值预计会整体上移 ~10pp（如 0.6 从 13.49% → ~23.5%），但倒 U 形的相对形状不变（协议偏移是加性常数，不改变臂间排序）。
  4. 论文措辞建议：报告 mask-ratio 消融时必须标注「BaiZe internal protocol (Protocol A)」，并加 caveat：「绝对 lp 受协议系统性低估 ~10pp，臂间相对差异不受影响」。🚫 不得与本报告 lp 数值和 DINOv2(~78%)/MAE(~68%) 公开值同表并列。

6.3 内部横比是否受影响？

不受影响：本消融 5 臂全部使用 Protocol A → 臂间 Δlp（−0.80 / −1.58 / 0 / −1.00 / −1.96）是纯 mask-ratio 效应，不含协议偏移。 同理，此前 InfoNCE / AIMv2 / CoCa / 纯 AR 四臂因果分解（R11-L 系列）也共享 Protocol A → 内部横比结论不受 lp 协议偏移影响。

7局限（如实）

  1. ±1.5pp 噪声带：本噪声带来自 R9/R10/R11 多轮实验的 lp 重复测量经验值，未经严格多 seed 方差估计标定。arm 0.5（Δ=−1.58）仅勉强超出噪声带边界 0.08pp → 其「显著更差」的判定处于边缘，可能随 seed 变化而翻转为「噪声带内」。
  2. 单 seed，未做多 seed 方差：所有 5 臂均使用 seed=1234（与 R8–R12 一致），未做多 seed 重复。lp 的 seed-to-seed 方差未知 → Δlp 的统计显著性无法严格量化。arm 0.3 vs 0.5 的非单调（C1 与 lp 分歧）可能是 seed 噪声而非真实效应。
  3. NFS 吞吐波动：训练期间 NFS 争用导致 img/s 在 2100–5400 间波动（ms/iter 93–276），不同臂的训练时长差异（6910–7138s，~3.3% 波动）可能引入微量训练动态差异，但步数固定（30k）控制了主要变量。
  4. 30k 步可能未充分收敛：R11-G 108k 长跑显示 lp 在 30k 后仍有上升趋势 → 本消融的 30k 截断可能低估了高 mask-ratio 臂（如 0.75）的最终潜力（arm 0.75 的 C1 peak@19800 暗示其可能需要更长训练来稳定）。
  5. lp 协议偏移（见 §6）：绝对 lp 受 Protocol A 系统性低估 ~10pp → 本报告的 lp 数值不可与主流公开值直接比较，仅臂间相对比较有效。
  6. 数据口径：使用 CC12M+Amshaker（~7.7M unique），不含 GPIC（GPIC 尚在下载中）。不同数据集下 mask-ratio 最优值可能不同（caption 长度/质量会影响生成项信号密度）。
