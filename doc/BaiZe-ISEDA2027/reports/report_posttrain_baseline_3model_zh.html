7.5 三模型静态对比（核心发现）

🔑 核心发现：API 知识是通用瓶颈，与模型规模无关

三模型（MiniCPM5-2B base / SFT / Qwen3.8-27B）的 all_apis_correct 完全相同 = 3/113 = 2.7%， 且是相同的 3 个任务（各仅 1 个 expected API）。规模差距 13.5x（2B vs 27B）未带来 API 知识提升。 API coverage 三模型接近（0.141 / 0.166 / 0.145）→ 所有模型都难以正确调用 PyAether API。
