🔴 L2 异常诊断（P0 · 用户令 2026-11-11）

核心问题：GSM8K=1.52%(flex)/0.00%(strict)，对 2B 模型异常低（正常应>5%）。
维度证据指向
strict-match=0%模型从未产生 "The answer is X" 格式 → 格式生成能力缺失能力
训练量极低P-8 仅 44.4B tok（当前 160k=671B，15×）→ 早期 ckpt 生成能力必然弱能力(早期)
L1 正常同期 L1=48.01%(loglikelihood 正常) → 模型加载/权重/分词无误排除配置
LL vs generationL1=loglikelihood，L2 GSM8K=generation → 生成路径可能有差异部分配置
stop tokenseval log: until:['Question:','</s>','<|im_end|>'] → 标准，无误排除配置
初步结论：主要是 44.4B tokens 早期训练的能力问题，非评测配置错误。
① strict-match=0% → 模型尚未学会生成答案格式（训练量不足）；② L1 正常 → 模型加载/权重/分词无误；③ stop tokens/few-shot 配置均标准。
当前 160k(671B tok, 15× P-8) 生成能力可能已显著改善 → 正在重评确认。
