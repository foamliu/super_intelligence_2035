现象：glm-5.3-flash 网关 keyB 多次返回 HTTP 429。

影响：TB-2.1 codex 路被 KILL；后续路排队等待。网关429持续(恢复~3.3h)·恢复需~3.3h。

归因红线：429 不得写成「模型能力」结论。

3.2 cline 路失败归因

  • 能力失败（真实做错）：agent 生成 patch 但未通过 verifier — 占比最高
  • 超时（TB_AGENT_TIMEOUT=3600s）：部分复杂编译任务未在时限内完成
  • 429 阻塞：网关额度耗尽期间 agent 无法获取 LLM 响应

归因红线：能力差不得用「基础设施问题」掩盖。
