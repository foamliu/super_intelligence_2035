失败归因复核 (2026-11-17 用户令)

复核目的: 用户质疑「失败的 Case 是否均为能力不足，而非 infra 问题」。本节合并各路 original + 全部 rerun 目录后，对仍失败的题做四桶归因，并计算修正后 Pass% = passed / (89 − 纯 infra 题数)，与当前 Pass% 并排对比。

四桶定义: ability = 模型真跑且答错 (有 run_result / iterations>1 / exc_type 等真实证据); quota = 全部 trial 命中网关额度耗尽; conn_refused = 全部 trial 连接被拒 / CLI bug; synthetic = 无 run_result、stdout≈空，占位假结果 / 未真跑。

合并逻辑: 任一 trial (跨 original + rerun) reward==1.0 即记 PASS。失败题若任何 trial 有 proper evidence → 归 ability (模型至少跑过一次)。
