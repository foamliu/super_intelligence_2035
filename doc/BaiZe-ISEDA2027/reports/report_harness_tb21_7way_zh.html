3. 失败归因分析

3.1 网关 429 quota 耗尽（基础设施问题）

现象：glm-5.3-flash 网关 keyB 在评测期间多次返回 HTTP 429「本次 Token 额度已用完」。

影响：TB-2.1 codex 路被 KILL（18/89）；后续路因 sequential launcher 排队等待。网关已于 00:35 恢复 HTTP 200，429 滚动限流结束。

归因红线：网关额度耗尽 / 429 不得写成「模型能力」结论。

3.2 cline 路 72 题失败归因

  • 能力失败（真实做错）：agent 生成 patch 但未通过 verifier — 占比最高
  • 超时（TB_AGENT_TIMEOUT=3600s）：部分复杂编译任务未在时限内完成
  • 429 阻塞：网关额度耗尽期间 agent 无法获取 LLM 响应

归因红线：能力差（真实做错）不得用「基础设施问题」掩盖。
