PRE-REGISTERED EVALUATION PROTOCOL (frozen before testing): Significance level: alpha = 0.05 (two-sided) Primary test: McNemar's exact test (paired, 158 tasks) Secondary test: Paired bootstrap CI (2000 resamples) Multiple comparison: Benjamini-Hochberg FDR for success ladder Effect size: Cohen's h ( arcsin(sqrt(p2)) - arcsin(sqrt(p1)) ) Decision: Declare M_k achieved if (a) point estimate >= M_k threshold, (b) McNemar p < alpha, (c) bootstrap 95% CI excludes 0, (d) effect size h > 0.3 Baseline -> M1: min 34.2pp (critical |b-c| >= 54) M1 -> M2: min 34.2pp (critical |b-c| >= 54) M2 -> M3: min 29.1pp (critical |b-c| >= 46) M3 -> M4: min 22.1pp (critical |b-c| >= 35)

9. 方法论说明

McNemar 精确检验：158 配对任务，b=A通过B失败数，c=A失败B通过数。p=2*BinomCDF(b+c,min(b,c),0.5)。

配对 Bootstrap：每任务通过率差 Di，重采样2000次，2.5%/97.5%分位数为95%CI。0不在CI内则拒绝H0。

功效模拟：蒙特卡洛 N_sims 次完整实验(158任务xN运行)，拒绝H0比例为功效。

局限：假设任务独立、伯努利模型、测量噪声简化。实际功效可能偏离估计。
