1. 摘要

2. 沙盒架构发现(源码分析)

  • 沙盒是 HTTP API 服务,非 SSH: POST http://{HOST}:{PORT}/v1/run_code
  • 请求: {"code":"<pyAether代码>","lang":"pyAether"} → 响应: {"response":"...","error_log":"...","print_log":"..."}
  • 默认主机: 10.129.32.75, 多端点: 端口 8664/8665/8653/8669

纠正: baize_posttrain_eda_tool.py 用 SSH 隧道,但实际协议是 HTTP API。新脚本修正为三层回退。
