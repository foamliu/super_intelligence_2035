1. 本线定位

BaiZe data 线的任务是把盘上原始语料变成训练可直接消费、配比正确、不污染评测集的形态，产出 Megatron .bin/.idx（通用文本主体 + 退火混合源）与 webdataset tar（多模态），并维护污染隔离红线（见 BAIZE_DATA_TASK.md §3）。本线不占 GPU，瓶颈在磁盘 I/O、NFS 带宽与单核 BPE 分词吞吐，因此近期工作的主线是「下载 / 分词 / 迁移 / 清理 / 映射」四件离线工程。

本报告覆盖区间（10-20 起）正好是 MiniCPM5 训练数据管线的收尾冲刺阶段：en_v1_4 主体下载收官、5 源退火分词完成并迁出 /nas_train、磁盘 prune 与不可映射产物清理、未分词 4 源分词进入 finalize 冲刺。所有数字均可溯源到具体文件（行号见每节末「溯源」块）。
