一、使命与主线

一句话目标：验证 MLLM（多模态大模型）作为 EDA agent 系统一部分，在 WaveView 波形图识图任务上带来显著增益，并交付可引用的统计检验结果。

技术路线

  1. 合成数据 SFT/RL：在合成波形数据上验证 SFT → RFT → GRPO 的训练管线有效性
  2. 真实题迁移：用 designflow WaveView 真题（等价重建）验证合成训练的迁移效果
  3. Agent 编排：MLLM 作为 agent 系统一部分（非单打独斗），通过 VQA 工具编排获取增益
  4. 统计交付：McNemar / Bootstrap 配对检验，cheat rate = 0
迁移说明：视觉线于 2026-11-13 从 .12（CPU-only，GPU 被 pretrain 占用）迁至 .17（8×A40，与 posttrain 共享）。基座模型从 qwen3vl_2b（困在 .12）切换为 Qwen3.5-2B（.17 本地可用）。

六、诚实总结

正向结论（可引用）：
  • v5 RFT 在波形类型分类上显著有效（16%→53%, p=0.0009, cheat=0）
  • v2-RFT 在合成集上显著有效（60→90, p=0.0156, cheat=0）
  • Agent 编排（G1）比单模型（V1）多翻转 5 整题，每量 38.2%→82.7%
  • CoT 提示杠杆可修复单位/标度误差，翻转 1 整题
负向结论（诚实记录）：
  • GRPO 连续 6 轮（v1-v4/v6-v7）均无显著提升，advantage 方差=0 是结构性瓶颈
  • v8-v11 频率比较任务 RL 不显著（2/6 seed only）
  • 合成训练→真题迁移 gap 大：合成 90/90 但真题仅 1/10 整题通过
  • rft2 adapter 在 agent 设置下未额外增益（G2=4 < G1=5），需扩样确认
路线判断：RFT > GRPO（在当前 2B+LoRA 规模下）；Agent 编排 > 单模型；CoT 提示 > 权重微调（对单位/标度类误差）。下一步重心应放在真题扩样 + 针对 domain gap 的 SFT 数据设计，而非继续调 GRPO 超参。
