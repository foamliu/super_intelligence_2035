# v11 设计文档：回归 vs 生成 三臂对照（period regression）

> vision wake#1180 · 2026-11-14 · 路线切换依据：任务书护栏「连续 3 轮无提升必须换方向」(v6-v10 已 5 轮无提升) + 任务书常驻 research-日报规则「若本线建议有相关条目 -> 纳入本轮计划」(2026-11-14 日报 vision 栏 line181「波形回归 vs 生成三臂小对照」) + 2026-11-07 用户令「放开 idea / 改任务定义」。

## 1. 为什么换方向（为什么上次 freqcmp 不 work）

| 版本 | 任务/方法 | 结果 | 判定 |
|:--|:--|:--|:--|
| v5 | 波形类型 4 分类 + RFT | A16%→B37%→C53% p=0.0009 | ✅ 显著（唯一成功）|
| v6 | 类型分类 + GRPO | 无提升 | ❌ |
| v7 | 超参 sweep | 无提升 | ❌ |
| v8 | 频率比较(A/B) | B=45% < 机会 | ❌ 损坏 |
| v9 | 频率比较扩大 | n_disc=0 NO CHANGE | ❌ |
| v10 | 频率比较 + Qwen3.5-2B + GPU | C=51.6% < B=54.9% NOT SIGNIFICANT(2/6) | ❌ |

根因：**频率比较(2 分类 A/B)** 天花板≈55%，headroom 极小；离散 A/B 奖励 advantage 方差近零（gs4/gs8 诊断的同一瓶颈）。GRPO 在低 headroom + 离散奖励下学不动。⇒ 5 轮无提升，触发换方向。

## 2. 新任务：PERIOD REGRESSION（回到原始难题）

- 输入：1µs 窗口内 16 个等间距电压采样（单周期波形）。
- 目标：估计基波周期（µs）。
- 判定：相对误差 |pred−true|/true < 0.15 ⇒ correct。
- 这是 v2-v4 未能突破的硬任务（SFT 天花板≈34%），正是「回归 vs 生成」该被检验的场景。

## 3. 三臂（固定数据 & 预算；全部 SFT，不用 GRPO）

> 为何不用 GRPO：v2/v3/v6/v10 已反复证明 GRPO 在这些波形任务上无效（advantage std=0 / n_disc=0 / C<B）。本轮的科学问题是「生成式路线是否优于直接回归」，与 RL 无关，故全部用 SFT 控变量。

| 臂 | 名 | 做法 | 对应日报条目 |
|:--|:--|:--|:--|
| Arm 1 | direct 直接回归 | SFT 直接输出周期数字 | 「直接回归」 |
| Arm 2 | augment 生成式增广 | Arm1 + 用参数化生成器在更密/更广的周期网格上合成额外训练数据 | 「回归 + 生成式数据增广」 |
| Arm 3 | synthesis 生成后取统计量 | SFT 输出紧凑生成式规格 `type,freq`（analysis-by-synthesis），周期=1/freq 程序化计算 | 「扩散生成后取统计量」 |

### 关于「扩散」的诚实说明

完整扩散模型训练在 CPU/单卡 A40 上对 2B 模型做 pilot 不可行。**参数化波形生成器本身就是一种生成式模型**（给定参数→生成波形），我们以它作为生成式组件的有原则的轻量代理。科学问题（生成式路线是否降低周期误差 vs 直接回归）被完整保留；仅生成器的实现从「扩散」换为「参数化程序」。若 Arm2/Arm3 有效，后续可在 GPU 上把生成器升级为扩散模型复验；若无效，则「本期不做生成式路线」结论同样成立。

## 4. 预注册判据（跑前写定，不许事后改）

- Arm 1 (direct) 预期：~30-40%（v2-v4 已知 SFT 天花板）。
- Arm 2 (augment) 预期：> Arm 1，当且仅当生成式增广提供了有用的周期覆盖。
- Arm 3 (synthesis) 预期：> Arm 1，当且仅当「先 type+freq 再 1/freq」是比「直接回归周期数字」更易学的表示。
- **成功**：≥1 个生成式臂（2 或 3）较 Arm 1 提升 ≥5pp，McNemar p<0.05，3 seed 一致。
- **负结果（同等有价值）**：两个生成式臂均未降低周期误差 ⇒ 「本期不做生成式路线」，报告原因 + 下一步。
- 控制：3 seed（20261114/15/16）一致性；train/eval 用不相交 RNG seed（cheat_rate=0，无泄漏）。

## 5. 为什么这次能 work（或诚实地为什么不 work）

- **能 work 的理由**：v5 已证明「分类」比「回归」易学（53% vs 34%）。Arm3 把回归拆成「分类(type) + 估计(freq) + 程序化换算」，借力 v5 的发现；Arm2 用生成器补足 direct 在短周期(hard)端的训练稀疏。
- **可能不 work 的理由**：周期=1/freq，freq 与周期信息等价，表示差异未必带来学习差异；Arm2 增广若与 base 分布同源，可能只是「更多同类数据」而非「新覆盖」。
- **承诺**：无论正负，按 §研究口径「负结果如实记录」，不挑好看的 run。
