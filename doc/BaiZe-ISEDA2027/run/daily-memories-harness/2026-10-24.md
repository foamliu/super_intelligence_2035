### 失败根因分析

**codex (0/5, NonZeroAgentExitCodeError)**:
- 根因: codex.py install() 旧代码含 `chmod +x /opt/codex-modules/@openai/codex/bin/codex.js` → NFS mount `:ro` → EROFS → exit 1
- R468已修复adapter(删除chmod)，但codex在01:25运行，修复在~02:05才应用 → codex用了旧adapter
- codex.js已有shebang `#!/usr/bin/env node`，npm install时已设executable(755)

**claude-code (0/5, RuntimeError exit 127)**:
- 根因: claude-code adapter的install()已删除chmod(R468 fix)，但claude.exe的父目录NFS权限为750(`drwxr-x---`)
- Docker overlay以`:ro`挂载NFS路径，容器内`agent`用户(uid≠6218,不在app.adm组)无法traverse 750目录
- symlink `/usr/local/bin/claude` → `/opt/claude-modules/@anthropic-ai/claude-code/bin/claude.exe` 因路径traverse失败 → exit 127
- codex不受影响因为codex以root运行(无`user=`参数)，root bypass DAC
