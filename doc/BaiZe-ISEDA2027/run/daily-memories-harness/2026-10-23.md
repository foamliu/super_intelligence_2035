### codex 失败根因 + 修复

**根因**: codex.py install() 的 fast path 执行:
```
ln -sf /opt/codex-modules/@openai/codex/bin/codex.js /usr/local/bin/codex && chmod +x /opt/codex-modules/@openai/codex/bin/codex.js && codex --version
```
→ `chmod: changing permissions of '/opt/codex-modules/@openai/codex/bin/codex.js': Read-only file system`
→ exit 1 → NonZeroAgentExitCodeError

**原因**: NFS volume mount 是 `:ro`（read-only），无法 chmod 目标文件。但文件在 npm install 时已设为 executable（`-rwxr-x---`），chmod +x 完全不必要。

**修复**:
- `codex.py:100` — 删除 `chmod +x /opt/codex-modules/@openai/codex/bin/codex.js && `
- `claude_code.py:108` — 删除 `chmod +x /opt/claude-modules/@anthropic-ai/claude-code/bin/claude.exe && `
- codex.js 有 `#!/usr/bin/env node` shebang → symlink 直接可执行
- claude.exe 是原生 ELF binary → symlink 直接可执行
- py_compile 两个 adapter OK ✅

**关键**: claude-code phase 尚未开始（pilot 当前在 opencode phase）→ 修复后的 adapter 将被自动加载。
