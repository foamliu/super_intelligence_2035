§6 v2→v3修订说明

v2错误：v2引「MiniCPM5-1B基座训练300B(200B@4K+75B@32K+25B@128K)」标注CSDN二级源。但：
①MiniCPM5没有独立训练论文——arXiv 2602.09003是UltraData数据管理框架论文(2026-02)，不是MiniCPM5模型论文。
②MiniCPM5-1B(2026-05-26)/2B(2026-09-07)为OpenBMB模型发布(GitHub/HF)，模型卡未公开训练token数。
③「300B」出自CSDN二级源，无一手依据。
④v2自相矛盾：说「MiniCPM5有300B」又说「本项目可训2,015B」——若实盘2,015B，300B从何而来？
v3修正：
①弃用300B——不引任何论文/CSDN训练量数字。
②唯一口径=实盘：du -sb+find|wc -l盘点在盘数据，分词实测token。
③实盘=9.81TB/~2,232B token(2015B实测+217B估)。
④训练预算给全谱(44B~2,232B)供用户决策。
