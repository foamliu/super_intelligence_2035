# 2026-09-30 · BaiZe Stage(iii) 视觉编码器预训练

## 目标
四架构（500–600M）从零预训练公平对比，24h 预算，P0 三硬指标（loss/训练吞吐/推理吞吐）。

## 本轮进展

### 环境/数据
- 确认 LLaVA-OneVision-1.5 parquet schema（id / image{bytes,path} / caption）。imagenet/EN 20 分片×25K=500K 对。
- 用 prep_data.py 切统一子集 imagenet/EN 500K → webdataset tar（25 shard × 20K，~74GB，`/nas_train/app.e0031982/datasets/baize-vision/en500k/`）。

### 四架构落地（run/vision/models.py）
- OpenVision2（纯 Attention）：505.0M
- MambaEye（纯 SSM，Vim 双向）：534.9M
- MoE-ViE（稀疏 MoE，8 expert×ff512 top-2）：505.2M / 激活 222.0M
- DeepEncoderV2（Attn+SSM 混合 AAMM）：516.9M

### 关键坑（webdataset 1.0.2）
1. `TarWriter.write()` 签名改为 `write(dict)`（`__key__`+扩展名键）。
2. 默认 `nodesplitter=single_node_only` 在 world_size>1 报错 → 用 `_no_split` 恒等 + 手动 rank 切片。
3. 「fewer shards than workers」→ num_workers=2 + 保证 shard≥rank。
