### 根因定论（22:0x §6 附带阻塞项）

| 假设 | 证据 | 结论 |
|:---|:---|:---|
| cgroup/单进程上限 | `.29` `/sys/fs/cgroup/memory.max` = `max`（无限制）；swappiness=60, overcommit=0 | ❌ 排除 |
| worker 泄漏/RSS 累积 | num_workers=8→step70 崩、num_workers=4→step90 崩（正相关）；.29 SwapFree=0（7G 满）、.12 SwapFree=1.9G | ✅ **根因** |
| swap 无法回收 | 无 root 权限，无法 `swapoff -a` | 限制条件 |

**结论**：DataLoader worker RSS 随步数累积 → swap(7G) 耗尽 → 内核 OOM-kill 单个 worker → 该 rank forward 停 → NCCL 集合通信超时连锁。与 worker 数量正相关（8→step70, 4→step90）。**不是 cgroup 上限**（cgroup memory.max=max 无限制）。
