**实测**：
1. **test_longseq_nan.py**：4 ckpt × 4 序列长度（2/17/55/150 token）

   - 说明 NaN 不仅是 checkpoint 相关，还与**输入 token 模式**有关（重复性文本比自然语言更易触发 SSM 状态溢出）

**根因**：Mamba2 SSM 数值不稳定（PyTorch reference 实现，CPU float32，无优化内核）
- SSM 状态递推在某些输入模式 + 某些权重配置下溢出 → NaN → attention 层传播 → logits 全 NaN

- iter_10000/30000 权重对自然语言更稳定（lm_eval 可出分），但仍对重复性文本敏感
- **#1362 的「前向传播正常」结论有误**：因其仅测 2-token 序列（\"Hello world\"），未触发 NaN 阈值

**处置**：
- gen_cpu_eval_8sets_report.py §⑥ 更新为正确根因（含阈值测试发现）
