### 关键发现总结
1. **真正的瓶颈是 DDP all-reduce 暴露时间**（17ms/micro × 60 = 1021ms/step = 5.3%），不是 data loading 或 optimizer
2. **MBS 提升有限**：t_fwd_bwd 随 MBS 近线性增长，因模型 ~58% MFU（compute-bound 而非 overhead-bound）
3. **grad_ckpt OFF 无收益**：重算开销被小模型规模掩盖
4. **下一步**：torch.compile() 可能再给 10-30%（kernel fusion + CUDA graphs），组合后可能接近 249K 目标
