## 2. R10-② 二维 scaling law 拟合

### 2.1 数据合并口径

- 阶段二 w512 的 **11 点**（N=5.12M…55.3M，M=126.8M）来自 `/tmp/r9_stage2.log`（R9 已复盘）：lp 5.39%→7.70%→7.40%。
- 阶段一 9 点（N=5.12/10.24/15.36M × M=126.8/284.5/505.2M）。
- 合并 → **约 19 (N,M,acc) 点**（w512 上 N 轴密、M 轴上仅 3 档、且 w768/w1024 只有 N≤15.36M 三点）。

### 2.2 拟合模型

- **对数线性（主）**：`acc = a + b·log10(N) + c·log10(M) + d·log10(N)·log10(M)`
- **Chinchilla 式（辅）**：`L = E + A·N^(−α) + B·M^(−β)`

### 2.3 拟合结果

> 拟合集（n=19）：stage2 w512 的 11 点（N 轴，N=5.12M…55.3M）+ stage1 w768 与 w1024 各 3 点（M 轴，N≤15.36M）。
> stage1 w512 重复区**剔除**出拟合（由 stage2 覆盖），仅作 §1.5 一致性核对。
> 证据 = `/tmp/r10_scaling2d_points.csv`（23 点全量） + `r10_scaling2d.py` stdout。

**拟合 A（带交互，主）**：`acc = a + b·log10(N) + c·log10(M) + d·log10(N)·log10(M)`

```
a = -1.73661      (常数)
b = +0.33257      (log10 N 系数)
c = +0.18481      (log10 M 系数)
d = -0.03597      (交互项系数)
R² = 0.9803
```

**拟合 A0（无交互，辅）**：`acc = a + b·log10(N) + c·log10(M)`

```
a = +0.35858   b = +0.03743   c = -0.07041   R² = 0.9746
```

**M 的边际效应（固定 N，观测区间内）**：

```
[A ] dacc/dlog10(M) @N=5.12M = -0.0565   @N=55.3M = -0.0937   （全区间为负）
[A0] dacc/dlog10(M)          = -0.0704   （常数，负）
每 2×M 的效果 @N=15.4M：  [A] -0.0222 acc   [A0] -0.0212 acc   （≈ -2.2 lp 百分点 / 参数翻倍）
```

→ **在当前数据受限区间（N≤55.3M），塔宽 M 越大、IN-1k lp 越差**（R9 阶段一的定性「越小越高效」在此被 2D 拟合量化，且 N 越大该负效应越强，交互项 d<0 一致）。

### 2.4 最优 N/M 分配

> 算力预算代理 `C ≈ 6·N·M`（OpenVision2 depth30 ViT 的训一步 FLOPs ≈ 6×N×M）。

- **参考预算**：`C_ref = 6 × 55.3M × 126.8M = 4.21e16 FLOPs`（= R9 阶段二长训练）。
- **在 C_ref 下 sweep M**（`r10_scaling2d.py` [A] 分支，M∈[20M..2G]，N=C_ref/(6M)）：
  → `max acc = 21.05% @ M=20M（sweep 下界）, N=350.6M`
  → **最优 M 落在观测下界（126.8M）之下**，20M 为外推值。
- **[A] 锚点边际**：`dacc/dlog10(M) @(N=15.4M, M=126.8M 自身预算) = -0.1148` → **此处加宽塔是负收益（数据受限区）**。

**⚠️ 外推诚实标注**（`r10_scaling2d.py` "span & uncertainty"）：

```
N span : 5.12M .. 55.30M 样本 (10.8x, ~1 个数量级)
M span : 126.8M .. 505.2M 参数 (4.0x, ~0.6 个数量级, 仅 3 点, 无 <126.8M 点)
→ M 轴极稀 (3 pts, 4x)。向更小/更大 M 外推均高度不确定。
→ run variance: 同 (N,M) 两 run 差 0.5~1.1 pp (见 §1.5)。
```

→ 「最优 M 在 20M 或更低」**只能当方向判据**（加宽无益、应向下探），不能当精确最优值 —— 这正是触发 R10-③ 补 w384/w640 的理由。

## 4. 结论

1. **M 轴补上后的硬结论**：在 N≤55.3M 数据受限区间，IN-1k lp 随塔宽 M **单调下降**（w512 6.08% > w768 3.63% > w1024 0.93%）；2D 拟合量化 ≈ **−2.2 lp pp / 参数翻倍**（R²=0.98），且 N 越大该负效应越强（交互项 d<0）。
2. **最优 N/M 分配**：固定算力下最优 M 向**更小塔**滑（sweep 下界 20M 处 acc=21.05%，外推）。→ 数据量不够时**加宽塔是负收益**，瓶颈在「样本/参数比」。
3. **与 N 轴结论合一**：R9 已证 N 轴斜率平缓（+4 lp / 10×数据）、外推 20% 需 619 亿样本；R10 再证 M 轴加宽无益 → **此从零对比学习路线在本地数据规模（上限 ≈53M）下，无论调 N 还是 M 都够不到 20%+**，瓶颈在**数据量与目标函数，非架构**。
4. **待收尾**：R10-③（w384/w640）完成后用 **5 点 M 轴**重跑 2D 拟合，确认「更小塔是否持续更优 / 是否存在最佳塔宽（饱和点）」，并回填 §2/§3/§4 最终数值。
