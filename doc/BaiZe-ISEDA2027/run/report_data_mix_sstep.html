3. 瓶颈归因

每 microbatch 开销 = s_step / n_microbatches：MBS=1: 89.5ms, MBS=4: 104.5ms, MBS=8: 110.0ms, MBS=16: 166.0ms。

每 μbatch 开销随 MBS 增加而增加（compute 部分开始非忽略），但总步时仍大幅下降（μbatch 数 16→1）。

GPU 利用率仅 ~15 TFLOP/s / 1000（远未饱和）→ 确认 overhead-bound。

显存 3→42GB（MBS=1→16），80GB H100 可容纳。
