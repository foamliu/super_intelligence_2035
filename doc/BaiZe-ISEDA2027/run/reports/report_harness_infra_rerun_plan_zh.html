一、分类口径

桶定义是否重跑
infra_failed空（或 real）patch + infra 信号：quota_blocked/timeout 标志位、429/额度/rate-limit、上游 500/502/503/504、鉴权 401/403/forbidden/适配器、超时关键字或 wall≥1799s是（重跑）
