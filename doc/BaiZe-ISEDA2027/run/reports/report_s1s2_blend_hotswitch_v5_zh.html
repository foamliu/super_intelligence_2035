§4 游标映射规则（本方案核心）

步骤操作零重叠保证
① S1 训练switcher.track(di[i]) 逐样本记录 consumed_per_source[s]—
② 切换点switcher.switch_weights(S2_weights, S2_size, shared_mask)—
②a 重建索引用 S2 权重建 dataset_index/dataset_sample_index（Bresenham）新比例生效
②b 游标映射共享源 s: dsi[di==s] += consumed_per_source[s]S2 从 S1 停止处继续 → 文档集不相交
③ 新源shared_mask[s]=False → offset=0新源天然零重叠
④ checkpointswitcher.to_json() 写入 ckptresume 正确
禁止：用全局 consumed_samples 直接套 epoch=consumed//active_total（samplers.py:263-264）——v4 认定的 epoch 错位根因。

§5 零重叠证明方法

定义：S2 消费文档集 ∩ S1 消费文档集 = ∅（针对共享源，新源天然为 0）。
证明：shuffle_index 是 [0, num_samples) 的排列（无重复）。S1 消费 [0, consumed[s]) → D_s1。S2（游标偏移后）消费 [consumed[s], ...) → D_s2。一个 epoch 内两区间不相交 → D_s1 ∩ D_s2 = ∅。
边界：若 consumed[s] > len(shuffle_index[s])（完整 epoch），shuffle 回绕 → 重叠不可避免。如实报告（epoch_wrap_warnings）。BaiZe S1+S2 < 1 epoch → 不触发。
验收：离线验证器 validate_overlap.py 读 S1 消费记录 + S2 index 序列，按 doc id 求交。
