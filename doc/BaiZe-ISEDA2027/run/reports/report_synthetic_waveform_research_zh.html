§1 文献综述

1.1 TD-Interpreter（最直接对标工作）

来源：Ničković et al., "TD-Interpreter: Enhancing the Understanding of Timing Diagrams with Visual-Language Learning", TU Wien, arXiv:2507.16844, 2025.

方法：基础模型 LLaVA 7B（与 Qwen3.5-2B MLLM 同类：轻量 VLM + LoRA）；合成数据管线 Verilog + 随机 testbench → Icarus Verilog 仿真 → VCD → WaveDrom 渲染时序图 → QA 对；~222K 时序图 + 10M 简单 QA + 10K 推理样本（FSM/AHB/SPI/异步FIFO）；310 题基准。结果：超越未微调 GPT-4o。

启示：① 管线与本线 synth_waveform_qa.py 高度一致（已有 PIL 渲染 + 6 种 QA + LoRA SFT）；② GT 从仿真参数直接计算（反作弊），与本线方法一致；③ 10K 高质量推理样本 > 222K 简单样本——推理深度比数量更重要；④ 限制：特定渲染工具训练难泛化到示波器截图——多样化渲染可缓解。

1.2 VCDiag（波形分类 + LLM 合成 bug）

来源：arXiv 2506.03590, 2025。方法：LLM 自动修改 RTL 注入 bug → Icarus Verilog 仿真 → VCD → 统计压缩特征 → ML 分类器定位 bug。启示：LLM 自动生成 Verilog + testbench 可用于大规模合成波形数据。

1.3 VCD2Image（VCD→PNG 工具）

来源：SJTU-YONGFU-RESEARCH-GRP/vcd2image, GitHub。功能：pip install vcd2image，VCD→PNG/SVG/PDF。核心 API：WaveExtractor→WaveRenderer（matplotlib）。CLI：vcd2image timer.vcd --auto-plot --image timer.png

1.4 WaveDrom（JSON→SVG 时序图）

来源：wavedrom.com。用 WaveJSON 描述波形渲染 SVG。CLI：npx wavedrom -i src.json5 > out.svg。TD-Interpreter 即用此工具。波形字符串如 "p......"（时钟）、"0.1..0."（电平）非常紧凑。

1.5 AI-EDA-Playground（LLM→Verilog→VCD→PNG 全链路）

来源：GitHub KushalPitaliya/ai-eda-playground。自然语言→GPT-4 生成 Verilog+自检 testbench→Icarus Verilog 仿真→VCD→matplotlib PNG。启示：可复用 LLM 生成多样化 Verilog→自动仿真→批量 VCD→渲染 PNG。

1.6 GTKWave CLI（工业级波形查看器）

来源：gtkwave.github.io。CLI：-o 优化 VCD→FST，-a savefile.gtkw，--script tcl Tcl 脚本含 PNG dump。需 Xvfb headless。评估：功能强但 GUI 依赖复杂，本线用 PIL 更轻量。

§8 P5 实验结果（合成数据 SFT + GRPO）

核心结论：大规模合成波形数据（1040 训练样本 × 8 技能）SFT 显著有效（0.625→0.8125，+18.75pp，McNemar p=0.0118）；GRPO 为持平（0.8125→0.8125，Δ=0，p=1.0），reward 饱和（82.65%% 样本 reward=1.0）是根因。合成数据路线突破了 GRPO 改进瓶颈——SFT 阶段的增益远超此前 GRPO 自身的微调。

8.4 GRPO 结果

项post-SFT（冷启动）post-GRPOΔ
通过率52/64 (0.8125)52/64 (0.8125)+0.0000
McNemarb=1 c=1 p=1.0000
paired bootstrapΔ=0.0000 95%CI=[-0.0469, 0.0469] p=1.0000
训练500 步 / 4000 rollouts / wall=2260.3s / grad_signal=19/500 (3.8%)

GRPO 判据：post-GRPO > post-SFT AND p<0.05 → 未达（持平 Δ=0 p=1.0）

GRPO 持平根因分析：reward 饱和——82.65%% 的 rollout 获得 reward=1.0（完全正确），仅 17.05%% 为 −β（完全错误），α 档（部分正确）仅 0.3%%。这意味着 SFT adapter 在训练集上已接近天花板，GRPO 几乎没有可利用的梯度信号（grad_signal 仅 3.8%%）。这与 P1 GRPOv2 的 reward 饱和问题一致，但 P5 的 SFT 基线更高（0.8125 vs P1 的 0.70），进一步压缩了 GRPO 的改进空间。

8.5 P5 结论与启示

  1. 合成数据 SFT 路线可行且有效：+18.75pp 增益（p=0.0118）证明合成波形数据能实质强化 MLLM 读懂波形图的能力
  2. GRPO 在高 SFT 基线上遇到瓶颈：reward 饱和导致梯度稀疏，与 P1 结论一致——需要更难的训练数据或更细粒度的奖励设计
  3. 技能间干扰：duty_cycle 退步提示 LoRA 容量有限，后续可考虑按技能分组训练或增大 rank
  4. 与 P1 对比：P5 SFT（0.625→0.8125）> P1 GRPOv2（0.70→0.667），合成数据 SFT 是比 GRPO 更有效的路线
  5. 下一步：① 扩大合成数据规模到 5000+（参考 TD-Interpreter 222K）；② 混合真实波形图（WaveView 真题 PNG）提升泛化；③ 对 duty_cycle 等退步技能做针对性数据增强；④ 在 WaveView 真题上评测合成 SFT adapter 的迁移效果
