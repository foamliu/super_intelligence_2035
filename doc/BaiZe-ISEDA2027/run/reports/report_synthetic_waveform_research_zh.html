核心结论：合成波形数据 → SFT/RL 路线可行且已验证。业界已有直接对标工作（TD-Interpreter, TU Wien, 2025）：Verilog → VCD → 波形图 → QA → LLaVA+LoRA 微调，在 310 题基准上超越 GPT-4o。本线已有等价管线（synth_waveform_qa.py + synth_vcd_demo.py），可立即扩展到 ≥1000 样本。工具链在 .17 上可用（纯 Python PIL 渲染，无需 iverilog root 权限）。

§1 文献综述

1.1 TD-Interpreter（最直接对标工作）

来源：Ničković et al., "TD-Interpreter: Enhancing the Understanding of Timing Diagrams with Visual-Language Learning", TU Wien, arXiv:2507.16844, 2025.

方法：基础模型 LLaVA 7B（与 Qwen3.5-2B MLLM 同类：轻量 VLM + LoRA）；合成数据管线 Verilog + 随机 testbench → Icarus Verilog 仿真 → VCD → WaveDrom 渲染时序图 → QA 对；~222K 时序图 + 10M 简单 QA + 10K 推理样本（FSM/AHB/SPI/异步FIFO）；310 题基准。结果：超越未微调 GPT-4o。

启示：① 管线与本线 synth_waveform_qa.py 高度一致（已有 PIL 渲染 + 6 种 QA + LoRA SFT）；② GT 从仿真参数直接计算（反作弊），与本线方法一致；③ 10K 高质量推理样本 > 222K 简单样本——推理深度比数量更重要；④ 限制：特定渲染工具训练难泛化到示波器截图——多样化渲染可缓解。

1.2 VCDiag（波形分类 + LLM 合成 bug）

来源：arXiv 2506.03590, 2025。方法：LLM 自动修改 RTL 注入 bug → Icarus Verilog 仿真 → VCD → 统计压缩特征 → ML 分类器定位 bug。启示：LLM 自动生成 Verilog + testbench 可用于大规模合成波形数据。

1.3 VCD2Image（VCD→PNG 工具）

来源：SJTU-YONGFU-RESEARCH-GRP/vcd2image, GitHub。功能：pip install vcd2image，VCD→PNG/SVG/PDF。核心 API：WaveExtractor→WaveRenderer（matplotlib）。CLI：vcd2image timer.vcd --auto-plot --image timer.png

1.4 WaveDrom（JSON→SVG 时序图）

来源：wavedrom.com。用 WaveJSON 描述波形渲染 SVG。CLI：npx wavedrom -i src.json5 > out.svg。TD-Interpreter 即用此工具。波形字符串如 "p......"（时钟）、"0.1..0."（电平）非常紧凑。

1.5 AI-EDA-Playground（LLM→Verilog→VCD→PNG 全链路）

来源：GitHub KushalPitaliya/ai-eda-playground。自然语言→GPT-4 生成 Verilog+自检 testbench→Icarus Verilog 仿真→VCD→matplotlib PNG。启示：可复用 LLM 生成多样化 Verilog→自动仿真→批量 VCD→渲染 PNG。

1.6 GTKWave CLI（工业级波形查看器）

来源：gtkwave.github.io。CLI：-o 优化 VCD→FST，-a savefile.gtkw，--script tcl Tcl 脚本含 PNG dump。需 Xvfb headless。评估：功能强但 GUI 依赖复杂，本线用 PIL 更轻量。

§5 与现有 SFT/RL Pipeline 对接

5.1 数据格式

JSONL 与现有 sft.jsonl 完全兼容：

{"id":"vcd_counter_q1","skill":"clock_freq",
 "image":"/path/waveform.png","gt":"50.0",
 "messages":[
   {"role":"user","content":[
     {"type":"image","image":"file:///path/waveform.png"},
     {"type":"text","text":"What is the clock frequency in MHz?"}]},
   {"role":"assistant","content":"50.0"}],
 "meta":{"gt_num":50.0,"verify_method":"freq=1000/period"}}

5.2 SFT 对接

  • 复用 sft_train_wave.py / sft_rl_strengthen.py
  • Qwen3.5-2B MLLM + LoRA, GPU 6-7
  • 合成数据与现有 150 条混合或单独训练
  • 目标：≥1000 样本 → SFT 3000 步 → eval n=30 held-out

5.3 RL 对接

  • 复用 grpo_mllm_wave_v2.py
  • 奖励：回归 R=exp(-rel_err/tau)，二值 R=1.0/0.0
  • 可验证奖励：verify_method 直接计算 GT
  • 预注册判据：post-RL ≥ post-SFT+5pp, McNemar p<0.05, ≥3 seeds, cheat_rate=0

5.4 评测对接

  • Held-out 合成测试集（参数空间隔离）
  • WaveView 真题：36.15 上 182 case × V0/V1/V2
  • 三段对比 pre-SFT/post-SFT/post-GRPO + McNemar

5.5 P5 执行计划

  1. 扩展 synth_vcd_demo.py→synth_vcd_batch.py，≥1000 样本
  2. SFT：Qwen3.5-2B+LoRA, GPU6-7, ~3000 步
  3. 评测：held-out 合成集 + WaveView 真题
  4. RL（若 SFT 有效）：GRPO 500 步
  5. 配对检验 McNemar/paired bootstrap，负结果照写

§6 可行性结论

P4 调研结论：通过 ✅

  1. 文献支撑：TD-Interpreter（TU Wien 2025）已验证 Verilog→VCD→波形图→QA→VLM+LoRA 路线可行，超越 GPT-4o
  2. 工具链可用：纯 Python（numpy+PIL）已验证全链路，无 root 依赖
  3. 规模达标：10 电路×100 参数×6 QA = 6000 样本（≥1000 目标 6 倍）
  4. 管线兼容：JSONL 与现有 SFT/GRPO 完全兼容，无需改训练代码
  5. 反作弊：GT 从仿真参数直接计算，cheat_rate=0 可验证
  6. 多样性：数字波形（时钟/数据/总线/复位/毛刺）+ 模拟波形，覆盖 6+ QA 类型

风险与缓解：

  • 渲染风格泛化：合成图与真实示波器风格不同 → 多样化渲染参数 + 混合真实波形图
  • QA 难度上限：当前 6 种偏简单 → 参考 TD-Interpreter 10K 推理样本，后续扩展推理型 QA
  • iverilog 未安装：Python 模拟 VCD → 运维安装后无缝切换真实仿真
