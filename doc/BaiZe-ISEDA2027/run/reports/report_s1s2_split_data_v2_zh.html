§1 — 最终配比表（S2 shard 级 blend TSV）

1.1 设计原则

  1. web:code:math = 4:4:2 严格满足（各类别 prop 加和 = 目标值，总 prop = 1.0）
  2. 优先使用预训练语料（非 SFT）—— SFT 推理链数据留给 decay 段或 post-train
  3. Code 混合 3 源（UDC L2 + UDC L3 + stack-v3 L4 filtered）增加多样性、降低单源 epoch
  4. Math 混合 3 源（UDM L1 + UDM L3 + MegaMath）增加多样性
  5. Web 以 en_v1_4 为主体，少量 L1-HQ + ZH 补充（与 S1 一致，保持连续性）
  6. 每源累计 epoch（S1+S2）控制 < 1.2，避免过拟合
