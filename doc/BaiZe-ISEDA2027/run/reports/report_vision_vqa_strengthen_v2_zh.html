1. 动机与单一变量（预注册）

  • 缺口证据：#3 后半探针（wake#1227/#1228）实测 Qwen3.5-2B「看懂图是什么但读不准图上的数」——稳定失败在「精确计数 / 精确数值 / 跨面板反推」。v1（wake#1209）合成 held-out 上 amplitude 40%→20%(SFT 反降)、duty 0%→0%、cycle 80%→66.7%(SFT 反降)。
  • 假设：v1 的 SFT target 只给最终答案，没教「从坐标轴读数」的程序。
  • v2 单一变量：对 cycle_count/amplitude_read/duty_cycle 的 assistant target 改成「读数推理链 + Final Answer: X」；分类/比较/上升沿 target 保持 v1 原样。训练集同图同问同 seed(20261114)、held-out 同 seed(20261115)——唯一改变是 target 文本。
  • 判据（预注册）：成功 v2 = post-RFT_v2 ≥ post-SFT_v1 +5pp 且 McNemar(best-SFT_v1 vs RFT_v2) p<0.05 且 ≥3 seed 且 cheat_rate=0；负结果照实上报。
