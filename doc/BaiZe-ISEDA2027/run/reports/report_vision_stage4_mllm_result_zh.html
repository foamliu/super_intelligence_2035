8.3 核心瓶颈

① 分辨率限制：224px 单块是当前最核心瓶颈。OCR/Doc/Chart/Count 等需要细粒度文字/物体感知的任务全面偏低，根因是 196 token(14×14 patch)信息密度不足。官方 LLaVA-OV 用 384px + anyres 多块切分。提升分辨率(→384/anyres)是下一步最高 ROI 的改进。

② 训练规模：Stage-2 仅 3500 步指令微调，对多选题(MC)格式学习不足(模型在 MC 中偏好"A")。增加 Stage-2 步数或加入 MC 格式数据可改善 mmstar/mmmu_pro。

③ 视觉编码器代际：BaiZe ④-4ep 视觉编码器 ProtB=67.05%，低于外部参考(SigLIP2 87.46%)。ArmA 用 open_clip 标准架构从头训练，正是为解决「自研架构不兼容 + 表现不及标准 CLIP」的双重问题。
