项现状
现象160k ckpt（25% 训练）用 llama.cpp 评 L2 时，生成类基准全面 0%
根因（已定案）llama.cpp SSM 生成 bug：PR #31703 修了权重映射，但生成仍退化（repetition loop）。HF transformers 生成正常 ⇒ 权重 / SSM 计算本身正确。
HF 五重验证（160k）HumanEval 15.0%(3/20) · GSM8K 10.0%(1/10) · MBPP 5.0%(1/20) · BBH 3.3%(1/30) · MATH 0.0%(0/10) → 生成 5 集平均 6.66%；MMLU 23.16%（≈随机 25%，MC 题不受生成 bug 影响 ⇒ 纯知识能力不足）

口径纪律L2/L3 的 0% 不得作为「模型弱」的证据（属 harness 故障非能力）；MMLU 23% 才是纯能力信号

需要用户裁定（4 选 1）：① 维持现状等 350k 再判；② 提前调整 decay phase 的 code/math 配比（当前 code 19% + math 7% = 26%，建议提到 15–20%）；③ 等 .17 SSH 恢复后接 L3；④ 等 700k 训完在 post-train 阶段补 L3。

卡点 2：早期阶段知识能力未建立（MMLU ≈ 随机）

160k 时点 MMLU 23.16% 接近随机猜测（25%），说明知识类能力尚未建立——与「25% 训练进度、仍处 stable phase（lr=1e-3 恒定）、未进入 instruction-SFT/decay」一致。 需持续观察 MMLU 是否随训练单调上升；若 350k 仍 ≈25%，建议改 decay 配方。
