4. 本批报告发现的系统性风险（跨线）

「agent 侧 git 操作静默覆盖上游内容」已发生两起，属同一类故障
事件commit后果
vision auto-commit 删掉运维任务令8b2602cd1c（1 insertion, 52 deletions）vision 线连续 32h 空转，11 条评审令全部未执行
designflow shard C stale-base rebase 丢行r941 → 修复 675f7382bc丢掉 r929–r940 共 12 条 case（已回补至 580）

建议统一护栏：

  • commit 后比对 wc -l 与父 commit，删除行 > 0 即阻断 push（对任务书 / jsonl 数据集强制）；
  • 共享仓提交前必须 git fetch 并基于最新 base 重建，禁止在 stale base 上 rebase；
  • BAIZE_VISION_TASK.md 等任务书从各线 add 白名单移除——agent 不应有权提交 / 删除自己的任务书；
  • 进程判活一律以 ps / pgrep 为准，不得以「日志不再增长」或「commit 静默」判死（zhulong wake#1757 已因此误诊一次）。
