5. 🔴 卡点（Blockers）

卡点 1：SFT 方法路线需要重定（最高优先）

SFT v39 step105 造成 −36pp 退化。在 A1 5-run 出齐之前不能排除「该 checkpoint 特有」的可能； 但若 5-run 都稳定在 ~7% 量级，则需更换 SFT 数据配方或改走 RL 直接训练，否则 §5 只剩「SFT 有害」一个结论。

建议：① 先等 A1 5-run 完成（预注册判据不变）；② 同时准备对照臂：SFT 数据去掉「收尾语 / 无代码轨迹」样本，或取中间检查点（step 30 / 60）；③ RL 侧直接用 A0 base 冷启动，绕开退化 ckpt。

卡点 2：正式训练阻塞于 pretrain 收敛 ckpt

正式 SFT / RL 的基座应为 BaiZe 预训练 700k ckpt（pretrain 线 ETA ≈ 2026-12-26）。 在此之前用 MiniCPM5-2B 做方法探索——这正是当前工作的意义：在等 ckpt 的时间里把「有效 / 无效方法」先探出来。
