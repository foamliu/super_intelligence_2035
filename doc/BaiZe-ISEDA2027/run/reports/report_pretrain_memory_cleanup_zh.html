5. S2 OOM 修复（常驻职责执行）

✅ 修复方案：nw=8→2 + no_mmap=1

根因（参考 data S2_OOM_MEMORY_PLAN.md + 本线 #801/#802）：S2 180 shard / 75.5 GB .bin 被 mmap → fork 时 COW 触发 RSS 放大 （8 worker × 75 GB = 600 GB 峰值）→ 920 步处 swap 耗尽 → SIGKILL。

修复：BAIZE_NUM_WORKERS=2（2 worker × RSS = ~150 GB 峰值，充足） + BAIZE_NO_MMAP_BIN_FILES=1（用 read() 替代 mmap，page cache 共享无 COW）。 保持 fork（spawn 重传参数性能差）+ persistent_workers=0。

修改文件：code/baize-llm/configs/common.env L71-83
