3 · 诚实解读

  • 确实存在多模态信号：text-only 基线在 image-required 用例上 0 deliverable；VQA tool 能读出 轴标签 / 单面板简单量 （如 β9 的 max=1.0V 读 y 轴、α4 的 v_max=1.25V、β10 顶图的 vmax=1.2V/t_at_max=4us、α4 的 multi_pulse 分类）—— 这正是「基线 fail → 上 VQA 后部分可读」的增益证据。
  • 能力仍弱，距通过全 12 条件远：三类系统性缺口—— ① 精确计数/周期：β9 周期 1ns 读成 2ns（把相邻同相峰当一周期）；α4 激活窗数 5 读成 54（误把信号名 "sel54" 当计数）。 ② 精确数值读取：β9 的 min/offset/p2p 均偏差超容差（offset 0.6→0.55，min 0.26→1.0）。 ③ 跨面板推理：β10 是「看顶图 v(temp) + 底图 v(det) 翻转时刻反推 vth_high/vth_low/迟滞」—— VQA tool 仅读出顶图两量，跨面板阈值反推全错（vth_high/low/hysteresis/t_cross 全 fail）。
  • 对 08:4x 分析报告 α 判断的修正：原 α 分析把 β10 等归为「识图可解」；本探针显示「识图能读 部分 量， 但 check.py 要求的 12 条件（尤其跨面板推理）远超当前 VQA 能力」→ α 的「大概率能过」对 全题通过 而言偏乐观， 应下调为「识图有部分增益、但全题通过需更强模型/训练」。
  • 对 #4（SFT/RL 强化）的指向：本探针定位的缺口（精确计数、数值精度、跨面板推理）正是 #4 合成数据应新增的技能维度； #4 此前 SFT/RFT 在合成波形上 Δ=8.9pp 但 p=0.5 未显著——本探针说明合成训练分布与真实 EDA 图（无标签、多面板、需反推）存在 gap， 后续 #4 应加入「无标签轴读数 + 跨面板推理」类合成样本。

4 · 结论与下一步

  • 结论：VQA tool 在真实 EDA 风格波形图上提供 可度量但较弱的多模态增益（0→27.3% 量级）， 能力集中在轴标签/单面板简单量，跨面板推理与精确计数是主要缺口。
  • #3 后半仍需 designflow 跨线：官方对照（字节相同图 + 同一 cline harness + check.py 全条件）必须由 designflow 用本 VQA tool 跨线再跑——恢复后的真 PNG 在 .15（独立 NFS），.17 取不到，本探针无法替代。
  • 下一步：① designflow 恢复剩余 3 题后跑官方「有 VQA」臂；② #4 合成数据补「无标签轴读数 + 跨面板推理」维度后再训； ③ 本探针可在 #4 强化后重跑，作 pre/post 配对对照。
