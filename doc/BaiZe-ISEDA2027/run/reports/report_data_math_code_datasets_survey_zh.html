一、结论

一句话结论:数学预训练语料是当前最大缺口(我们目前为零),优先级排序为Nemotron-CC-Math-v1 > IFM/MegaMath第一批 > OpenMathInstruct-2(SFT) > OpenCodeReasoning(代码SFT) > code_contests(RL可验证)。RL可验证数据(数学答案+代码单测)是另一个关键空白,posttrain的GRPO/RLVR阶段急需。

五、污染检查与风险

数据集污染风险检查结论
IFM/MegaMath可能含GSM8K/MATH题目(从CommonCrawl抓取)⚠️需在下游使用前做n-gram比对GSM8K test+MATH-500
IFM/Math-ReasoningSFT数据可能含MATH/GSM8K原题⚠️需检查math-thinking-*子集是否含评测题
IFM/Code-Reasoning可能含HumanEval/MBPP题目⚠️需检查code-thinking-*子集是否含评测题
Nemotron-CC-Math-v1CommonCrawl来源,可能含评测题⚠️NVIDIA论文称已做decontamination,但需独立验证
OpenMathInstruct-2基于GSM8K+MATH train split生成✅NVIDIA明确使用train split,非test;但仍需验证
deepmind/code_contests含train/valid/test split⚠️需确保只用train split,test split与评测隔离
codeparrot/appsAPPS基准本身是评测集🚫APPS全量是评测集——只能用train split,且需隔离
openai/gsm8k同时含train和test⚠️只能用train(7.5K题),test(1.3K题)禁止入训练
HuggingFaceH4/MATH-500MATH测试集子集🚫纯评测集,绝对不可入训练

结论:所有数学/代码数据集在入训练前都必须经过污染检查——用我们的phase5污染隔离闸门(NFKC归一化+8-gram指纹比对)扫描GSM8K test/MATH-500/HumanEval/MBPP test。尤其MegaMath和IFM Reasoning系列从CommonCrawl抓取,污染风险最高。
