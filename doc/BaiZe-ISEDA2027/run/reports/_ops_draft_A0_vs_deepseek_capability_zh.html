结论：两者在 4 个口径维度上不同（机器 / RAG / MCP / 规模）， 绝对数值差（−38.8pp）同时包含「模型能力差」和「环境配置差」两个成分，不能归因于任何单一因素。 本报告因此不做分数排名，只做能力维度的结构性对照——即「失败在哪里、行为模式如何、产出形态如何」。 这也是 AGENTS.md §4.3 明确写下的纪律：「大模型参照不可与 2B 比较」。

1. 一句话结论

MiniCPM5-2B 与 DeepSeek-V4-Pro 的差距不在「愿不愿意干活」，而在「一次做对的能力」。

  • 接近的部分：工具使用意愿与探索能力——agent 循环进入率 93.67%、RAG 查询率 100%、 平均工具调用 30+ 次、10 类工具全部用到（含 editor / run_code / submit_and_exit）⇒ 它不是「不会用工具」的模型。
  • 明显不足的部分：领域 API 精确记忆 + 一次写对——主导失败是 逻辑错误 40 题（AssertionError 26） 与 API 误用 21 题（TypeError 17 / AttributeError 4），合计 61/89 = 68.5% 的失败是「代码写出来了但写错了」。
  • 最尖锐的证据：失败任务平均 40.6 次工具调用 / 44.6 万 input token， 而成功任务只要 17.0 次 / 23.8 万——失败组付出了 2.4 倍努力却失败了， 且搜索/编辑比高达 17.1（成功组仅 4.0） ⇒ 典型的「探索瘫痪」：反复查 API 却不敢/不能写出正确代码。

✅ 结论：68.5% 的失败是「写出来了但写错」

F5 + F4 = 40 + 21 = 61 题（68.5%），即模型成功产出了可执行代码，问题在于语义/逻辑/API 细节不精确。 真正「不会动手」的只有 F1 18 题（20.2%）+ F2 1 题。

这与「小模型工具能力差」的常见假设相反——MiniCPM5-2B 的 agentic 骨架是通的， 缺的是 PyAether 领域 API 的精确语义记忆与算法逻辑的正确性。

🔴 这是本报告最重要的行为学发现

失败组搜索 API 的次数是成功组的 5.3 倍（2055 vs 390），但真正写代码的次数几乎一样（120 vs 97）。

⇒ 失败模式是 「反复查 API 却写不出代码」，而不是「查不到 API」。 它们在搜索阶段就耗尽了自己——这是典型的决策瘫痪 / 规划失败， 不是工具不可用，也不是检索质量差（RAG 查询率 100%、工具错误率仅 0.74%）。

对 DeepSeek-V4-Pro 的对照含义：大模型的核心优势不在于「会调用工具」，而在于 「看完 API 就能一次写对」 —— 这正好解释了 82.1% vs 43.29% 的差距主体。

一句话总结对照结论

接近的：做事的态度与手段——愿意进循环、会用全部工具、会检索、会收尾。
明显不足的：做事的水准——API 记不准（24 次符号级错误）、逻辑算不对（26 次断言失败）、一次做不稳（仅 15.8% 稳定通过）、规划效率低（2.4 倍无效努力）。
⇒ 用一个类比：它的「手」已经够用了，差距全在「脑」的精度上。

6. 对后训练路线的直接含义

发现推得的后训练策略与本轮实验的对应
51.9% 的题「有时能做对」（partial）rejection sampling / RL 优于纯 SFT——已有正确样本可强化，不必外部灌知识支持从 A0 base 冷启动做 RL，而非先 SFT
SFT v39 导致 −36pp 退化（退化循环）SFT 会破坏「愿意写代码」这一已有优势解释了为什么 A1 反而更差：把「手」也弄坏了
F4 API 误用 23.6%（符号级记忆错误）需要精准的 API 用法监督（正例 + 反例对照），不是泛泛的领域文本数据侧应提供 API 签名级样本
F5 逻辑错误 44.9%（AssertionError 26）需要可验证奖励（执行结果判分）而非下一 token 拟合支持 RLVR / GRPO，而非 SFT 拟合
「探索瘫痪」search/edit = 17.1需要规划约束 / 步数惩罚，抑制无效搜索可在 reward 中加入工具调用成本项
与令 2（A5 = Qwen3.5-2B）的关系

若 A5 显著优于 A0（预注册判据：McNemar p<0.05，逐题配对 158 题），则说明 这些短板主要是「2B 通用基模的先天能力差异」，而非 EDA 领域知识缺失—— 那么后训练的资源应优先投向强化已有正确解（RL），而不是继续堆领域语料。 反之若 A5 ≈ A0，则说明 MiniCPM5-2B 已接近 2B 同规模上限， 提升必须来自方法创新（奖励设计 / 数据构造）而非换基座。

  1. DeepSeek-V4-Pro 在 A0 同口径下重跑（.17 起评 / 无 RAG / 无 MCP / 5-run）——消除环境差异；
