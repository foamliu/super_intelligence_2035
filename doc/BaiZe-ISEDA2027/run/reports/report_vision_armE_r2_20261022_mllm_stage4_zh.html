5. 关键结论与诚实披露

① 主裁定: 不可分辨 (indistinguishable, 边界值)。平均=26.10% 落在 22-26% 区间。ArmE-R2 vs ArmD-R2 (主对照) 平均 Δ = -0.02pp。

② 三变量限制 + 容量混杂: ArmE-R2 vs ArmD-R2 同时改了塔(B/16→L/14, 86.2M→304M)、LR(1e-3→5e-4)、warmup(2000→3000) 三项, 任何 Δ 都不能拆出单一变量因果。视觉塔容量增大 3.5× → 若 MLLM 胜出, 须并列说明"容量+架构"复合变量, 不得单独归因"架构更好"；若持平/落后, 则说明"容量不是 MLLM 下游瓶颈"。

③ 编码器结论 (已 secured, 🏆历史最高): ArmE-R2 ProtB lp 68.236% / 5-NN 58.904% = 全实验最高。vs ArmD-R2 Δlp=+3.899pp / Δ5-NN=+2.948pp, vs ArmC Δlp=+5.904pp, vs ④-4ep Δlp=+1.186pp/Δ5-NN=+16.554pp。ViT-L/14(304M)+降LR(5e-4)双因子 → 线性可分性与近邻检索均大幅改善。这是"容量+架构+降LR"三因子复合结果。

④ ProtB→MLLM 传递性: ArmE-R2 ProtB lp (68.24%) 显著高于 ArmD-R2 (64.34%, +3.9pp) / ArmC (62.33%, +5.9pp) / ArmB (62.09%, +6.1pp), 但 MLLM 12集平均 vs ArmD-R2 仅 -0.02pp → 再次印证线性探针不直接预测 MLLM 下游表现。编码器 ~4-6pp 的 ProtB 优势未转化为 MLLM 下游优势。

⑤ ArmE-R2 vs ArmE (降 LR 效果, 两变量干净对照): ArmE(LR 1e-3) 于 step~29200 发散 (C1=0.0014); ArmE-R2(LR 5e-4) 全程稳定, C1 历史最高 0.9664@s45240, 末段 ~0.80, spike25 全闭合 → 降 LR(1e-3→5e-4)+warmup(2000→3000) 成功消除 ViT-L/14 的 spike 反复与发散。

⑥ 诚实条款: 内部 ProtB/MLLM 口径, 非官方榜; 单 backbone/单预算点; MLLM 三阶段单 seed; 224px 单块 (无 anyres), 细粒度任务天然偏低; Stage-2 数据为原版 quick-start (同 ArmD-R2); MBS 512→256 是显存强制回退非消融变量。
