3. 学习率调度（WSD）

LR = 1e-3 / min_lr = 1e-5，调度 = WSD（warmup → stable → decay），比例 5%·85%·10%。warmup 线性 0→1e-3，stable 恒 1e-3，decay 线性 1e-3→1e-5。

token/step = GBS1024 × seq4096 = 4,194,304 ≈ 4.19M。P-5b 在 GBS=1024 下 20B=4,770 步实测 warmup 238 / decay 477，验证 5%/10% 比例口径；任务书第 224/244 行的旧「warmup 250 / decay 500」是 Round 1 小规模残值，P-8 按比例换算不用旧值。

8. 训练纪律

  • 从零开始，不加载任何预训练权重；真实语料，非 742M 小分片。
  • WSD 完整走完，decay 尾段必须真的吃到 SFT 退火混合。
  • 每 500 步记 train loss / val loss / grad norm / tok/s / GPU 独占核验。
  • 禁在 P-8 期间叠加重 I/O 或抢卡任务（vision / data 侧避让）。
  • NaN / 发散 / OOM 一律记录并保留 ckpt 与日志，不静默重启掩盖。
  • MaxLogit / Q-K 谱范数监控（建议预案）：Muon 全秩正交更新可能抬升注意力谱范数，建议每 N 步记录 per-head Q/K 谱范数 + logits 最大值，超阈值按 μ(·) 归一化干预（MuonClip），防长训练 logits 爆炸。
