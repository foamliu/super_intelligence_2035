## wake80 R32: GPU 显存预算 + GRPO 吞吐量估算

### 动机
R1-R31 验证了脚本/配置/数据/奖励函数，但从未定量计算 2B + FSDP + SGLang 在 A40 45GB 上是否放得下，也没估算 GRPO 迭代吞吐量。R32 填补这个缺口。

### 方法
- 从 `/tmp/models/MiniCPM5-2B/config.json` 提取模型架构
- 按 verl hybrid engine 内存模型逐项计算（FSDP 持久层 + SGLang 预分配 + 训练/推理交替）
- 创建 `baize_posttrain_gpu_budget_analysis.py`（251 行，零 GPU 纯计算）

### 关键发现

1. **模型参数量**：2.517B（42 层，hidden=2048，vocab=130560，GQA 2 KV heads），bf16 = 4.69 GiB
2. **显存预算**：
   - FSDP 持久层：8.20 GiB（分片参数 1.17 + Adam 7.03）
   - 训练阶段总计：13.55 GiB（+grad 1.17 + act 2.0 + ref 2.17）
   - SGLang 推理：8.63 GiB（模型 4.69 + KV cache 3.94）
   - **峰值 = 36.01 GiB (80.2%) → 余量 8.92 GiB ✅ 放得下**
3. **配置确认**：
   - `param_offload=False, optim_offload=False` 正确
   - `gpu_memory_utilization=0.50` 正确（0.60→90.2% 过紧）
   - `entropy_checkpointing=True` 对 vocab=130560 必要
4. **吞吐量**：
   - Smoke (10 iter, G=4, batch=16)：**28-31 min ✅** 匹配 20-40 min 窗口
   - Full (2000 iter, G=8, batch=128)：**723-811h (30-34 天) 🔴 > 21 天窗口**
   - Baseline eval：纯生成 ~6 min（harness 开销另计 30-60 min）
5. **🔴 关键发现**：全量 RL 2000 iters 需要 30-34 天，超出 21 天训练窗口
   - 建议：正式训练用 500-800 iters + batch=64 + max_turns=2 → ~5-8 天
