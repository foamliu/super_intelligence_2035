### 问题
R26 遗留：SGLang launch_server 和 verl import 均失败。

### 诊断
三重 torch 2.7+ API 依赖链：
1. torchao 0.18.0 → `torch.nn.functional.ScalingType` (torch 2.7+)
2. transformers 4.51.1 → `torch.utils._pytree.register_constant` (torch 2.7+)
3. compressed_tensors → `transformers.masking_utils` (transformers 4.52+)

根因：torch 2.6.0 是 CUDA 12.4 最高支持版本（torch 2.7+ 需 CUDA 12.6+），但 SGLang 依赖链预期 torch 2.7+。

### 修复（四重 fix）
1. setuptools 84.2.1 → 69.5.1（恢复 pkg_resources，verl import 需要）
2. 卸载 torchao + 降级 compressed_tensors 0.15 → 0.14.0
3. 创建 `transformers/masking_utils.py` shim + `_torch_pytree_shim.py` + `.pth` 文件
4. verl deps 用 constraint file 安装（防 tensordict 拉 torch 2.14.1 554MB）
