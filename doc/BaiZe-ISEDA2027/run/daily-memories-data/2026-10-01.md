## 唤醒 3（phase5 修 bug → v0.2：修复中文 prompt 指纹丢失 + 8-gram 短串兜底）

- **定性（红线缺口）**：冒烟发现 cuhk 80 任务只命中 21、59 条"过短跳过"。实测定位根因——**不是长度问题，而是 `normalize()` 的 `[^a-z0-9_]` 把全部非 ASCII 字符（含 CJK 汉字）当空格丢弃**，中文 prompt 因此完全丧失指纹。cuhk 数据还混用 Kangxi 部首兼容字符（⼀ U+2F00、⻆ U+2EC6 等，category So），需 NFKC 才能映射回标准 CJK。
- **修复**：
  1. `build_blacklist.py::normalize()` 改为 `NFKC 归一化 → 小写 → 非 Unicode \w 折叠为空格`（纯 ASCII 英文行为无回归）。
  2. 新增 `short_shingles()` + `--short-ngram 8`：NFKC 后仍 <13 字的任务（实测 4 条 cuhk）改切 8-gram，生成独立 `short_ngram_hashes.txt`。
  3. `check_contamination.py` 增加短 tier：文档 8-gram 与该文件重合 ≥1 即命中（并能捕捉嵌在长文档中的短串）。
- **重生成黑名单**：536 任务 / 193,295 去重 13-gram（较 v0.1 的 191,718 多 1,577，全来自被修复的中文 cuhk 内容）+ 4 短任务 / 10 个 8-gram。
