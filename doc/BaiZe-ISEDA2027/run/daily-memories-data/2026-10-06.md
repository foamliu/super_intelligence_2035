**根因分析**：GPSurrogate 线程安全竞态条件
- `add()` 方法：先 `self.gp = GPR(...)` 再 `self.gp.fit(...)` — 两步之间有窗口
- 另一worker线程的 `suggest()` → `_ei()` → `self.gp.predict()` 在此窗口内执行
- GPR对象已存在但未fit → 无 `alpha_` 属性 → crash
- 19个trial已完成后，trial 20（GP-EI引导）触发此竞态

**修复**（baize_mix_optuna.py）：
1. `GPSurrogate.__init__`: 加 `self._fitted = False` + `self._lock = threading.Lock()`
2. `add()`: 在 `with self._lock:` 内执行 append + fit + set `_fitted = True`
3. `_ei()`: 检查 `self.gp is None or not self._fitted` → return 0.0
4. `suggest()`: 在 `with self._lock:` 内检查 `_fitted`，未fit则 return None
5. worker条件：`gp.gp is None` → `not gp._fitted`
