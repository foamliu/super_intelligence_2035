5. 关键观察

5.1 跨分辨率不可比性

5 个模型的 native 分辨率分别为 336/384/336/336/560 px。更高分辨率意味着更多 patch token 和更丰富的空间信息，理论上对 linear probe 有利。因此跨分辨率的 ProtB 数字不可直接排高下——RICE-ViT@560 的优势可能部分来自分辨率而非模型架构。

5.2 公众预训练 vs from-scratch

公众模型在数亿至数十亿图文对上进行大规模预训练（CLIP ~400M, SigLIP ~4B, AIMv2 ~6B），而 BaiZe from-scratch 仅使用 ~96M 图文对（4 epoch）。两者数据规模相差 1~2 个数量级，不应在同表中不加区分地排名。

5.3 BaiZe from-scratch 定位

BaiZe ④-4ep ProtB = 67.05%，作为 from-scratch 模型（224px, 126.8M, 96M pairs x 4ep），其绝对数值低于公众大模型是预期的。本评测的价值在于提供同协议下的参考锚点，帮助理解 BaiZe 模型在大格局中的相对位置。

5.4 OpenVision2 对比

OpenVision2 ViT-L/14@336 是 BaiZe 架构的原型来源。R13 已用 Protocol A 测得 79.81%，本次用 Protocol B 重新评测，可对比 ProtA/ProtB 协议差异在该模型上的表现。
