3.2 合成方法

GPU2-7 被 data 实验占用 → 复跑只能 DP2。DP2 低估 comm，但 compute 类别是架构内禀（与 DP 度无关）。 合成：comm ← P-4 DP8 实测 41.7%；compute（58.3%）← 两轮 compute-only 均值（GEMM 47.4%, SSM 14.8%, attn 1.2%, elem 36.5% of compute）× 58.3%。 两轮 compute-only 高度一致（GEMM 45.8% vs 49.1%）→ 合成可信。

  • FP8（delayed）打中 #2 GEMM → P-8 沿用 delayed FP8（与 P-9.9 一致）。
  • attention 0.7% 是 hybrid 优势的直接量化 → 论文 §4 可引用。
  • SSM 8.6%：非瓶颈，kernel 路径正确。
