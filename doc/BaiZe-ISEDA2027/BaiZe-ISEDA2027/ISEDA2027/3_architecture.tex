\section{Architecture and Pipeline Overview}\label{sec:overview}

BaiZe is an end-to-end multimodal agentic system assembled in five stages: (i) from-scratch pre-training of a hybrid language backbone, (ii) post-training of that backbone (instruction tuning and reinforcement learning to strengthen agentic capability), (iii) pre-training of a custom vision encoder, (iv) alignment of the two into a multimodal large language model, and (v) semiconductor-domain adaptation via reinforcement learning.
This section fixes the shared scaffolding---the two backbones, the overall pipeline, and the global training environment---before each stage is detailed in its own section.

\subsection{Language Backbone}\label{sec:arch}
The language backbone is a Nemotron-H-style sequential hybrid model~\cite{dao2024transformers,nvidia2025nemotronh}: 56 transformer layers interleave Mamba-2 state-space layers, four grouped-query-attention (GQA) layers, and MLP layers.
Each Mamba-2 layer uses 8 state-space groups; the four attention layers use 16 query heads and 4 query groups (GQA) with untied word embeddings.
The full configuration is listed in Table~\ref{tab:config}; the model totals $\approx$2.22B parameters.
