\section{Introduction}

Large language models have recently demonstrated agentic capabilities---planning, tool invocation, and long-horizon reasoning---that make them attractive cores for intelligent assistants spanning chip design, verification, and other domains of electronic design automation.
% 中文：大语言模型近来展现出智能体能力——规划、工具调用与长程推理——这使其成为覆盖芯片设计、验证及其他电子设计自动化领域的智能助手的理想内核。
However, state-of-the-art agent backbones are routinely 7\,B parameters or larger, demanding high-end accelerators and memory footprints that are incompatible with edge, embedded, and cost-sensitive deployments where inference latency and energy are first-class constraints.
% 中文：然而，最先进的智能体骨干网络通常为 70 亿参数或更大，需要高端加速器与大显存，这与边缘、嵌入式以及对成本敏感的部署场景不兼容——在这些场景中，推理时延与能耗是第一等约束。
The constraint is sharper than raw cost in the settings we target: proprietary design artifacts---layouts, schematics and review judgements---cannot leave the premises, so an agentic core must be served locally; and because an agentic session accumulates context, what dominates serving cost is not prompt throughput but the memory that grows with the session.
% 中文：在我们面向的场景中，这一约束比单纯的成本更严苛：专有的设计产物——版图、原理图与评审判断——不能离开本地，因此智能体内核必须在本地部署；并且由于智能体会话会累积上下文，主导服务成本的并非提示词吞吐，而是随会话增长的内存占用。
For a hybrid backbone this is architectural: only the four attention layers carry a session-growing state, while the Mamba-2 layers hold a constant-size recurrent one.
% 中文：对混合骨干网络而言，这是架构层面决定的：只有 4 个注意力层携带随会话增长的状态，而 Mamba-2 层持有恒定大小的循环状态。

Recent small language models (SLMs, $<\,$2\,B) have closed much of the gap with larger counterparts on single-turn benchmarks, but building such a model \emph{from scratch} remains an under-documented engineering problem.
% 中文：近期的小语言模型（SLM，$<$ 20 亿参数）已在单轮基准上大幅缩小与更大模型的差距，但从零构建这样一个模型仍是一个缺乏文档记录的工程问题。
Every choice---architecture, optimizer, learning-rate schedule, data mixture---interacts with every other, and a naive grid search is prohibitively expensive.
% 中文：每一个选择——架构、优化器、学习率调度、数据配比——都与其他选择相互影响，而朴素的网格搜索代价高昂到不可行。
Our goal is therefore twofold: (i) to construct, from scratch and on a strictly limited compute budget, an end-to-end multimodal agentic system---an efficient hybrid language core paired with a custom vision encoder, aligned into a semiconductor-domain agent---and (ii) to expose the concrete, reproducible decisions that lead to it.
% 中文：因此我们的目标有两重：(i) 在严格受限的算力预算下从零构建一个端到端多模态智能体系统——一个高效的混合语言内核配以自研视觉编码器，并对齐为半导体领域智能体；(ii) 把导向这一结果的具体且可复现的决策过程完整公开。

\paragraph{BaiZe.}
We present BaiZe, an end-to-end multimodal agentic system assembled from scratch across five stages: (i) pre-training a $\approx$2.2B-parameter hybrid (state-space + attention) LLM, (ii) post-training it for agentic capability, (iii) pre-training a custom vision encoder, (iv) aligning the two into a multimodal model, and (v) adapting the result to the semiconductor domain.
% 中文：BaiZe。我们提出 BaiZe，一个从零开始、由五个阶段组装而成的端到端多模态智能体系统：(i) 预训练一个约 22 亿参数的混合（状态空间+注意力）LLM；(ii) 为智能体能力进行后训练；(iii) 预训练自研视觉编码器；(iv) 将两者对齐为多模态模型；(v) 将其适配到半导体领域。
Three design pillars organise our work:
% 中文：三项设计支柱组织起我们的工作：

\begin{itemize}
\item \textbf{Architecture.} A sequential hybrid language backbone---56 layers interleaving Mamba-2 state-space layers, four grouped-query-attention layers, and MLP layers---giving linear-time decoding for inference-heavy agents, paired with a from-scratch vision encoder.

\item \textbf{Reduced-horizon proxy search.} We exploit short, cheap proxy runs to rank candidate hyper-parameters, so that the ranking discovered at small scale carries over to the full model without re-tuning at scale.

\item \textbf{Budget-constrained stage-wise pipeline.} Each of the five stages is trained under a hard GPU-hour budget, with a staged search protocol (S1--S5) for the language backbone and a single frozen evaluation protocol shared by the later stages.
\end{itemize}

We hope BaiZe serves as a minimal, reproducible blueprint for building efficient agentic SLMs from scratch, and that our search methodology is of practical value to cost-bounded training efforts in the EDA and embedded-AI communities.
% 中文：我们希望 BaiZe 能成为从零构建高效智能体 SLM 的最小化、可复现蓝图，也希望我们的搜索方法学对 EDA 与嵌入式 AI 社区中受成本约束的训练工作具有实用价值。
