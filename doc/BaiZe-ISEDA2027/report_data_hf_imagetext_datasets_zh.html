互补维度

  1. 来源多样性：GPIC/CC12M = 互联网爬取 alt-text（噪声高）；COCO/Flickr = 人工标注（质量高但小）；RobotDesign1M = 机器人/设计领域；BLIP3o = VLM 生成 caption
  2. caption 质量：现有多为 alt-text（噪声高）；COCO/Flickr = 人工标注（高质量）；BLIP3o = VLM 生成（中等）；enhanced = 原始+增强双列（可做质量对比）
  3. 语言互补：现有主要英文；新增可补 Turkish (1.05M)、Portuguese (123K)、Persian (32K)
  4. 重叠风险：CC12M webdataset (W4) 与已用 Amshaker 同源 → 标注「已用」；COCO 系 5 个上传者版本同源 COCO → 取一个（推荐 jxie 617K）；Flickr30k 系同理 → 取一个

  1. 许可不确定：多数 COCO/Flickr 变体未标注 license。COCO 原始 CC-BY 4.0，各上传者版本可能有额外约束。使用前需核实。
  2. 重复/重叠：COCO 系 5+ 个 HF 版本同源 → 只取一个；Flickr30k 同理。
  3. 规模估算：对数取自 datasets-server num_examples，the_cauldron (50+ 配置) 总量为加总估算。
