Official AIMv2 AR Paradigm vs. Ours — Controlled A/B Report

1. TL;DR

  • Core question: Can the official AIMv2 pure-AR paradigm (causal ViT + next-patch pixel + text AR, no contrastive) succeed at our data scale (~7.7M pairs, short captions)?
  • Arm B (pure AR, no InfoNCE): 🔴 Collapsed at step 600 — C1 rises 0.86→0.97 in 300 steps, circuit-breaker triggers at 2% of training. Loss was decreasing (6.77→5.08); collapse is a representation failure, not an optimization failure.
  • Arm B-hybrid (AR + InfoNCE): 🟡 No collapse, but lp = 1.37% — InfoNCE prevents collapse (C1≈0.48, 30k steps), but representation quality is catastrophically lower: Δlp = −12.1 pp vs. baseline 13.49%. Zero-shot at chance (0.37%).
  • Verdict: ❌ Non-AR + contrastive paradigm is strictly superior at our data scale. We retain bidirectional + InfoNCE + masked-patch-MSE as the final recipe.
  • Key handicap: Official AIMv2 uses 12B pairs with LLaMA-3 long synthetic captions; we use 7.7M pairs with short alt-text (~20 tokens) — a 1557× data gap. This is a scale finding, not a paradigm condemnation.

Implementation Notes (revision points ①–②)

① AR ≠ MAE: AR = "given prefix, predict next" — position i sees patches 0..i, target is patch i+1. Loss: MSE(pred[:, :-1], target[:, 1:]) (shift-by-1). This is not MAE's "given bidirectional context, reconstruct masked positions." Boundary: position 0 sees only patch 0; position 195 has no target (shifted away) — loss on positions 0..194 only.

② Text decoder cross-attention: ARTextDecoder cross-attends to causal vision patches (output of OpenVision2.forward(causal=True)), where each patch contains only prefix info. 🚫 Attending to bidirectional features = "bidirectional vision + causal text" ≠ official AIMv2.

⚠️ Critical Handicap — Short Caption & Small Data Scale (Revision Point ③)

This experiment reproduces the official AIMv2 paradigm but not the official AIMv2 scale. Two fundamental differences must be prominently noted:

  • Data volume: Official AIMv2 trains on ~12B pairs; we use ~7.7M pairs — a 1557× gap. The AR paradigm's autoregressive signal accumulates with data volume; at 7.7M pairs, the signal may be insufficient.
  • Caption length/quality: Official AIMv2 uses LLaMA-3 long synthetic captions; we use short alt-text (~20 tokens). The text AR next-token loss (cap_loss) is inherently weaker with short captions.

Interpretation guardrail: A negative result here means "short captions + small data cannot sustain causal AR" — it does not mean "the official AIMv2 paradigm is bad." This is a scale boundary finding, not a paradigm condemnation.

6. Difference Attribution

6.1 Why Arm B Collapsed

Pure causal AR without contrastive collapses because the AR next-patch task admits a trivial solution: if all features collapse to one direction, a constant prediction satisfies the loss. Loss decreases (cap 6.77→5.08) but representations are destroyed (C1→0.97).

Causal vs. bidirectional: R11-H (bidirectional, no InfoNCE) did not collapse (C1=0.43). Bidirectional attention provides implicit regularization. Causal attention restricts to prefix-only, making trivial collapse easier. → Collapse = causal × no contrastive (combined effect).

6.2 Why Arm B-hybrid Survives but Underperforms

InfoNCE prevents collapse (C1 0.30–0.55 for 30k steps) by forcing feature dispersion. But lp@30k=1.37% (−12.1 pp vs baseline):

  • Information restriction: Each patch attends only to prefix (0..i). Early patches see very little context.
  • Representation quality: Linear probing needs globally-aware features; causal features are locally biased → poor for classification.
  • Zero-shot at chance (0.37%): Causal vision features cannot align with frozen CLIP text embeddings.

6.3 Why Official AIMv2 Succeeds (Scale Hypothesis)

  1. Data volume (1557× gap): 12B pairs vs 7.7M. At 12B scale, diverse examples may overwhelm the trivial collapse solution.
  2. Long LLaMA-3 captions: Rich captions provide strong text-AR signal. Our short alt-text (~20 tokens) → weak cap_loss.
  3. Possible additional regularization: Unspecified techniques (EMA, init, scheduling) may further stabilize training.

Conclusion: Causal AR requires large-scale data + long captions. At our scale, bidirectional + contrastive is strictly superior. This is a scale boundary finding.
