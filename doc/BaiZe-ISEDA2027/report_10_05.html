1.2 机制解读（顺带给出了「坍缩的归因」）

  • 坍缩不是「稠密监督」的错，而是「caption 依赖」的错：arm④ CoCa（稠密 + 依赖 caption）坍缩到 0.47%；arm⑥ AIMv2（稠密 + 不依赖 caption）翻盘到 12.08%。
  • 合理机制：MAE 式 masked patch 重建提供逐 patch 的空间稠密监督，在数据受限（~15M 对）下显著优于 InfoNCE 的「每对 1 个全局标量」。
  • ⚠️ 诚实限定（C2）：本臂是 AIMv2-style 自研改编（InfoNCE + masked patch MSE，PatchPredictor 仅 +0.66M），非官方复现（官方是纯 AR、无对比项）；结论只对我们 recipe 成立。

11🔌 跨线网络口径定案（下午）：外网命令必须显式带 proxy

一句话：不是集群禁网、也不是「代理挂了」—— 是 loop 启动 cline 时会执行 env -u http_proxy -u https_proxy，把代理从 agent shell 里摘掉了。
这一步是故意的、且不能改（内网 LLM 网关必须「不带代理」才认证通过，带上 = 网关 403 + cline 静默空转）；代价是 agent shell 里所有外网命令都得自己带 proxy。

11.1 真因与证据（同一台机、只差一个环境变量）

观测结果说明
shell 里 env | grep -i proxy空loop 用 env -u http_proxy -u https_proxy … 起 cline ⇒ agent 子 shell 继承的是无代理环境
curl / pip 直连（无代理）Errno 101 / http=000DNS 能解析、公网 IP 直连被挡 ⇒ 这就是各线报的「网络不通」
同一台机显式带 proxy200.29 的 ~/.bashrc:140 本来就有 export https_proxy="http://172.19.92.25:13128"；RUN_ID 28 实测：外网 无 proxy = FAIL / 有 proxy = OK，内网网关两种都 200，no_proxy/NO_PROXY 均为空
同机反证（关键）harness 这两天装包一直成功因为它在 run/harness/r1_eval.py:144-148 里显式钉死 http_proxy/https_proxy + PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/；实测 aliyun 镜像 200，而 pypi.org / files.pythonhosted.org = 000（⇒ 官方源在这台机上不通，镜像是通的）

Errno 101 的正确读法：101 = Network is unreachable ⇒ 流量没走代理（不是「代理不可用」：那会报 111 ECONNREFUSED 或超时）。三个常见来源（自查是哪个）：① 非交互 shell 不读 ~/.bashrc；② 脚本沿用了给 cline 的剥 proxy 配方；③ chroot/容器里跑、env 没带进去。

11.2 正确用法（复制即用）

P=http://172.19.92.25:13128

# ① git（走 proxy 读/写 GitHub）
https_proxy=$P http_proxy=$P git ls-remote https://github.com/foamliu/super_intelligence_2035

# ② pip（显式 --proxy；⚠️ 决定碰共享 env 之前先确认「此刻没有训练在跑」）
python -m pip install --proxy $P --target /nas_train/app.e0031982/<隔离落点> <pkg>

# ③ 只想验证「这条路通不通」：只取响应头，不要抓正文
https_proxy=$P http_proxy=$P curl -sS -m 10 -D - -o /dev/null https://mirrors.aliyun.com/pypi/simple/
🚫 不要改 loop 里那行 env -u *_PROXY —— 它是内网网关鉴权的前提，去掉会让 cline 直接 403 + 静默空转（10-04 已踩过一次，见 10-04 报告 §1）。要改的是「需要外网的命令」，让它自己带上 proxy。
✅ MCP 检索（cimi_search / cimi_fetch）不受影响：它走 .29:8090 的内网 gateway，不需要 agent shell 带代理 ⇒ 「MCP 能查网」与「shell 直连不通」可以同时成立（这正是先前那条「不上网也能核验文献」的解释）。
