1.评测框架：自建跨脚本语言与场景的 EDA-Scripting-Bench（PyAether/SKILL/Tcl 三切片 449 题，统一任务 schema + 断言判据 + 沙盒执行），并用反作弊 hook 锁死文件读写，保证测到的是真实生成能力而非抄答案。

2.沙盒执行：`run_code` 在 EDA 沙盒里真跑代码并高保真回读完整异常栈与逐条断言结果，让 agent 在单 trace 内自主迭代修复——这是把准确率从 71.8% 拉到 82.1% 的决定性一环。

3.RAG 检索：用 BGE-M3+FAISS 对 API 建索引并叠加 BM25/缩写/同义词，更关键的是离线对每个 API 做反事实自探索、把实测出的参数约束与返回结构沉淀回知识库，让检索拿到的不再是干瘪签名而是带实战语义的知识。

4.自进化：把沙盒里跑过的成功/失败 trace 沉淀为可复用经验，持续反哺检索与生成策略，论文将其定位为下一步自进化的基础。
