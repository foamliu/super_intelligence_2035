----------------------- REVIEW 2 ---------------------
: 636: ZhuLong: Execution-Grounded LLM Agent for EDA Scripting with Offline API Self-Exploration
----------- Overall evaluation -----------
: 0 (borderline paper)
----- TEXT:
paper presents ZhuLong, an execution-grounded LLM scripting agent for PyAether and SKILL.:
- The system demonstrates strong engineering value by integrating API retrieval, script generation, sandbox execution, and iterative error correction into a unified workflow for commercial EDA scripting.
- Validation is rigorous: generated scripts are executed in a real commercial EDA environment and verified via automated assertions, which is far more reliable than static or human-judged evaluation.
- The ablation study is well-structured and clearly quantifies the individual contributions of retrieval, sandbox execution, and self-exploration.:
- The core claimed contribution, offline API self-exploration, yields only a marginal +3.2 pp gain over the already strong sandbox-execution baseline. Given the relatively small benchmark size (158 tasks), this improvement may not hold up under repeated trials or statistical significance testing.
- The self-exploration mechanism lacks crucial implementation details: the total scale of APIs explored, computational cost, stopping criteria for the exploration agent, and the degree of human intervention are not reported, making the method difficult to assess or reproduce.

----------------------- REVIEW 3 ---------------------

----- TEXT:
This paper presents ZhuLong, an LLM agent for PyAether and SKILL scripting that combines API retrieval, documentation lookup, sandbox execution, and offline API self-exploration. It also introduces a 158-task PyAether benchmark with assertion-based execution for evaluation. . The use of real execution feedback is practical and much more convincing than evaluating scripts by text similarity or human judgment. The paper also provides a reasonably detailed ablation study and error analysis, which makes it clear where the performance gains come from. . The claimed self-exploration contribution improves Pass@1 by only 3.2 points, while sandbox execution accounts for most of the gain, making the core algorithmic novelty rather modest. . Generality is also unclear: the main benchmark is PyAether-only, and SKILL is evaluated on just 20 interactive tasks without the full execution and self-exploration loop.
