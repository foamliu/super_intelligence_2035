\begin{abstract}
Frontier LLM agents collapse on long-chain EDA design-flow orchestration: on \bench, a single frontier backbone reaches only \textbf{\MzeroPass{} Pass@1} (62/620 decided runs, frozen 696-run snapshot) versus \textbf{\ScriptPass{}} on single-script EDA benchmarks---a 7.6$\times$ drop. We hypothesize that the gap is not merely a model-capacity ceiling but a \emph{memory and self-improvement} deficit that is mechanistically tractable. We pre-register \textbf{3 core falsifiable hypotheses} (H1: governed long-term memory + recursive self-improvement yields transferable gains on long-chain flow; H2: the gains arise from three affective-memory-inspired computational mechanisms---surprise-gated writing, weapon-focus compression, state-aware retrieval---rather than mere prompt lengthening; H3: the prior finding that single-agent $\geq$ multi-agent replicates in the flow setting) decomposed into \textbf{7 sub-hypotheses}, and design a \textbf{10-arm main ablation (3 appendix arms)} including an equal-token killer control (N1) and a cross-domain transfer contamination probe (M4). The three mechanisms map cognitive-neuroscience principles (amygdala--hippocampus arousal consolidation, weapon-focus central/peripheral trade-off, mood-congruent retrieval) to computable formulas: $w_{\text{write}}=\alpha\cdot\text{surprise}+\beta\cdot\text{penalty}$, $r_{\text{cp}}=|\text{central}|/|\text{total}|$, $\text{score}=\text{sim}+\gamma\cdot\text{state\_match}$. Results for the M0 baseline are available from the frozen snapshot; all other arms are to be evaluated after the pre-registration date (\PreregDate). Negative results will be reported as publishable boundary conditions on RSI and affective-memory mechanisms in symbolic tool orchestration. We release a protocol white-paper (harness protocol + criteria + desensitized task specs) under a controlled NDA review package, without releasing executable Lite-set assets.
\end{abstract}
