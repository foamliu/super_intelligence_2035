\begin{abstract}
Frontier LLM agents collapse on long-chain EDA design-flow orchestration: on \bench, a single frontier backbone reaches only \textbf{\MzeroPass{} Pass@1} (62/620 decided runs, frozen 696-run snapshot) versus \textbf{\ScriptPass{}} on single-script EDA benchmarks---a 7.6$\times$ drop. We hypothesize the gap is a mechanistically tractable \emph{memory and self-improvement} deficit, not merely a model-capacity ceiling. We formulate \textbf{3 core falsifiable hypotheses} (H1: governed long-term memory + recursive self-improvement yields transferable gains on long-chain flow; H2: the gains arise from three affective-memory-inspired computational mechanisms---surprise-gated writing, weapon-focus compression, state-aware retrieval---rather than mere prompt lengthening; H3: the prior finding that single-agent $\geq$ multi-agent replicates in the flow setting) decomposed into \textbf{7 sub-hypotheses}, and design a \textbf{10-arm main ablation (3 appendix arms)} including an equal-token killer control (N1) and a cross-domain transfer contamination probe (M4). These map cognitive-neuroscience principles (amygdala--hippocampus consolidation, weapon-focus trade-off, mood-congruent retrieval) to three computable formulas (\S\ref{sec:harness}). Results for the M0 baseline are available from the frozen snapshot; all other arms are to be evaluated. Negative results are reported as publishable boundary conditions. No data or code is released; reproducibility is supported via a detailed protocol description (this paper) and an NDA-gated review package for qualified reviewers.
\end{abstract}
