\begin{abstract}
We introduce \bench{}, a benchmark of \Ntasks{} long-chain EDA design-flow tasks across 13 domains, each derived from real IC-design engineer coding-agent traces in a production environment, with a \mode{} contract (submit.zip + $\geq$8 executable assertions + a PreToolUse anti-leakage hook). On \bench{}, a single frontier backbone reaches only \textbf{\MzeroPass{} Pass@1} (62/620 decided runs, frozen \Neval{}-run snapshot) versus \textbf{\ScriptPass{}} on single-script EDA benchmarks---a 7.6$\times$ gap that is not uniform (highest-passing domain 7.1$\times$ the lowest). We hypothesize this collapse is a mechanistically tractable \emph{memory and self-improvement} deficit, not merely a model-capacity ceiling, and \emph{formulate} 3 core falsifiable hypotheses (H1/H2/H3) decomposed into 7 sub-hypotheses, mapping three cognitive-neuroscience mechanisms (surprise-gated writing, weapon-focus compression, state-aware retrieval) to computable formulas (\S\ref{sec:harness}). To test them we \emph{design} a 10-arm main ablation (3 appendix arms) with an equal-token killer control (N1) and a cross-domain transfer contamination probe (M4). M0 results are available from the frozen snapshot; other arms are to be evaluated. Negative results are reported as publishable boundary conditions. No data or code is released; reproducibility is supported via a detailed protocol description and an NDA-gated review package.
\end{abstract}
