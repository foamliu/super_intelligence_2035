\begin{abstract}
We introduce \bench{}, a benchmark of \Ncases{} long-chain EDA design-flow tasks across 13 domains, each derived from real IC-design engineer coding-agent traces, with a \mode{} contract (submit.zip + $\geq$8 executable assertions + a PreToolUse anti-leakage hook). On this benchmark, a single frontier backbone (DeepSeek-V4-Pro) reaches only \textbf{\MzeroPass{}$\pm$\MzeroStd{} Pass@1} over 3 runs, while three weaker backbones range from \DoubaoMini{} to \DoubaoPro{}---a 2.0$\times$ spread non-uniform across domains. We hypothesize a mechanistically tractable \emph{memory and self-improvement} deficit, not merely a capacity ceiling, and \emph{formulate} 3 core falsifiable hypotheses (H1/H2/H3) decomposed into 7 sub-hypotheses, mapping three cognitive-neuroscience mechanisms (surprise-gated writing, weapon-focus compression, state-aware retrieval) to computable formulas (\S\ref{sec:harness}). To test them we \emph{design} a 10-arm main ablation (3 appendix arms) with an equal-token killer control (N1) and a cross-domain transfer contamination probe (M4). M0 is evaluated; other arms are to be evaluated. Negative results are publishable boundary conditions. No data or code is released; reproducibility is via a protocol description and an NDA-gated review package.
\end{abstract}
