\section{Introduction}
\label{sec:intro}
% 【中文】\section{引言}

LLM agents have mastered single-function EDA code generation---VerilogEval, RTLLM, and similar benchmarks report $\geq$\ScriptPass{} on isolated scripting tasks---yet they collapse on \emph{long-chain design-flow orchestration}: multi-step tasks that require driving live commercial EDA tools (schematic capture, SPICE simulation, DRC/LVS, synthesis) through dozens of tool calls, inspecting outputs, and recovering from errors. On \bench, a frozen 696-run evaluation snapshot shows a single frontier backbone (DeepSeek-V4-Pro) reaching only \MzeroPass{} Pass@1---a 7.6$\times$ drop from the scripting ceiling. The gap is not uniform: the highest-passing domain (\texttt{pnr\_signoff}, 20.8\%) exceeds the lowest (\texttt{physical\_verify} and \texttt{layout\_aether}, both 2.9\%) by 7.1$\times$ (descriptive point estimate; CIs overlap), and the hardest domains are precisely those demanding the deepest live-tool interaction.

We argue this is not merely a model-capacity problem but a \emph{memory and self-improvement} deficit. Long-chain flow tasks exceed any context window: an agent that cannot consolidate lessons across sessions---which errors recur, which tool sequences work, which project conventions matter---is condemned to re-discover the same knowledge on every run. Recursive self-improvement (RSI), the ability to expand a skill library and refine the harness itself from experience, is only meaningful if memory persists across sessions to accumulate that experience.

\textbf{Contributions.} (1) We \emph{formulate} 3 core pre-registered falsifiable hypotheses (H1 functional: memory+RSI gains; H2 mechanistic: gains from affective-memory mechanisms; H3 boundary: single-vs-multi-agent) decomposed into 7 sub-hypotheses, each with falsification conditions (\S\ref{sec:preregistered}). (2) We \emph{design} a 13-arm ablation with an equal-token killer control (N1) and a cross-domain transfer contamination probe (M4) (\S\ref{sec:preregistered}). (3) We \emph{formalize} three cognitive-neuroscience mechanisms---emotional arousal $\rightarrow$ surprise/penalty gating, weapon-focus $\rightarrow$ central-peripheral compression, mood-congruence $\rightarrow$ state-aware retrieval---as computable mappings (\S\ref{sec:harness}). (4) We \emph{introduce} long-chain flow orchestration as a new task modality with a released evaluation protocol white-paper. (5) We commit to reporting \emph{negative results} as publishable boundary conditions on RSI and affective-memory mechanisms.
