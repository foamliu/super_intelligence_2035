\section{Reproducibility Statement}
\label{sec:reproducibility}

We release a \emph{protocol white-paper} (harness protocol, evaluation criteria, desensitized task specifications) and an \emph{NDA-controlled review package} granting reviewers access to a sandbox with the commercial EDA tools. We do \textbf{not} release executable Lite-set assets or a mock-EDA mode (v1.4 open-source boundary narrowing). The falsifiability of our claims does not depend on proprietary licenses: an independent party can re-derive an equivalent benchmark on open-source EDA tools (Yosys/OpenROAD/Magic) and test the same 3 core + 7 sub-hypotheses using the released protocol. The M0 baseline (\MzeroPass{}) is reproducible from the frozen 696-run snapshot configuration (DeepSeek-V4-Pro, Cline v3.0.51, \texttt{thinking=low}, 2400s timeout). Full benchmark construction, per-domain results, and experimental details are in Appendices~\ref{sec:benchmark-details}--\ref{sec:exp-details}.
