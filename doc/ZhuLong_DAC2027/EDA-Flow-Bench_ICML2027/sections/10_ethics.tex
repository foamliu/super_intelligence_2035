\section{Ethics Statement}
\label{sec:ethics}
% 【中文】\section{伦理声明}

\bench{} tasks are derived from real IC-design engineer coding-agent traces in a production environment. All tasks are desensitized: no proprietary IP, customer data, or identifiable engineer information is released. Commercial EDA tool licenses are not redistributed; the protocol description and NDA review package let reviewers verify claims without proprietary tools. Negative results are reported as publishable boundary conditions, not suppressed.
