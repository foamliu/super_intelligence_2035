\textbf{EDA benchmarks.} VerilogEval and RTLLM evaluate single-function Verilog generation; FlowFixer-EDA \cite{dong2026flowfixer} targets open-source flow repair. \bench{} is the first to evaluate end-to-end orchestration of multi-step \emph{commercial}-tool design flows from real engineer traces ($\geq$8 assertions, anti-leakage hooks). Prior script-layer work (DATE27 \cite{PLACEHOLDER_DATE27_ZHULONG}; ZhuLong-DAC \cite{liu2026runreadbackrefine}) established the three-layer memory + RSI framework on short-chain tasks; this paper tests transfer to long-chain flow.

\textbf{Agent memory and self-improvement.} Reflexion, ExpeL, and SkillOpt accumulate experience within or across episodes; MUSE provides a create-evaluate-refine loop for skill libraries. Generative Agents \cite{park2023} filter memory writes by an importance score---a functional precursor to our surprise-gated writing (H2a), but without a predictive-error formulation or mechanism-level falsification. EM-LLM segments events by Bayesian surprise; PsychoAgent retrieves by affect + conflict. This paper \emph{tests} three affective-memory mechanisms with mechanism-level negative controls (equal-token, mechanism-off) on real long-chain EDA flow, rather than reporting post-hoc gains.

\textbf{Affective neuroscience $\times$ agent memory.} Emotional arousal modulates consolidation \cite{mcgaugh2004}, triggers a central/peripheral trade-off (weapon-focus \cite{loftus1987}), and mood-congruent state-dependent retrieval \cite{bower1981}; prediction error gates memory formation \cite{ittibaldi2009}. Whether these principles \emph{transfer} to LLM-agent symbolic orchestration is the empirical question this paper tests (full citations in Appendix~\ref{sec:affective-appendix}).
