5跨场景成败模式归纳

成功 case 的共性

  1. 读资产充分：read_files 9-13 次先吃透输入格式再动手（不等同于 list_files 反复探索）
  2. 沙盒实测闭环：eda_flow__run_commands 5-19 次在真实 EDA 沙盒跑脚本验证非离线猜结果
  3. 迭代深度足：25-35 轮迭代遇问题继续修而非放弃
  4. 交付物精确对齐 brief：纯 stdlib / CLI 接口 / 文件名逐字符合要求
  5. declare_done 正常收口：有明确 text 总结 + declare_done

失败 case 的共性

  1. 联网查资料（离线题不该联网）：fetch_web_content 出现在 2/3 失败 case（schematic 1x / waveform 3x）查 CDL 语法/svwf 格式 但 EDA-Flow-Bench 是离线评测联网查到也不直接帮上忙
  2. 目录探索低效：list_files 10 次（schematic_fail）反复探索未先 read_files 吃透资产
  3. 未沙盒复现失败：analog_fail 仅 1 次 eda run_commands 没在沙盒复现 Totem-SC 失败 漏报 bug
  4. 过早放弃：waveform_fail 仅 9 轮 / 52s 遇不熟悉格式（svwf）联网查不到就静默退出 0 交付
  5. 交付物布局错位：schematic_fail 产出了脚本但 judge 找不到 assets harness 对齐失败
