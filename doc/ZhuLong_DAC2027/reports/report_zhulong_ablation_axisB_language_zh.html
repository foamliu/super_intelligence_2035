4.2 audit 关键发现

阈值核对（任务书 §3）：en ≥4/5 TARGET ⇒ 真切换 ✅；zh 同 ✅（但被基础 prompt「思考用中文」confound，注入只是重复）；es 仅 3/21 TARGET + 1 MIXED ⇒ 未生效 ✅；fr 6/18 TARGET ⇒ 部分生效（偏弱）✅。

未发现 COPIED_PROMPT —— 所有「未遵循」样本都真实地用英语/中文思考，而非敷衍复述注入短语。

结构性失败模式：长难题（task 120 inverter-symbol / 150 sdl-flow）在所有非英语语言里几乎必漂回英语，与注入强度无关。答案/代码部分仍为英语（仅要求思维链换语言，未影响输出）。

2 个根因（再确认）：① 基础 prompt 已强制中文思考 → zh 注入 confound / es+fr+ru 部分被基础 prompt 覆盖；② 长难题 reasoning 负载高 → 模型在非母语表达力不足时自动漂回英语。

4.3 影响评估

B 轴现有结论不能按「语言真切换」口径采信：
  • zh 分数实质≈基线（基础 prompt 已强制中文，注入只是重复）
  • es 三轮实质=「模型默认英语思维链 + 末尾无效西语提示」，应作废「西班牙语」标签
  • fr 三轮是法语/英语思维链混合（按题难度分层），轮级 mean±std 不能当作「法语思维链效应」
  • en 真切换但 en_r1 基座(glm-5.2)与 en_r2/r3(deepseek-v4-pro-cloud) 不同，轮内亦不纯
  • 叠加基座违规，B 轴需在同基座 + 基础 prompt 中性化前提下重跑才能做语言间因果对比

七、结论与建议

⚠️ 降级结论：轴 B 数据仅能报告「在当前（违规）配置下各语言轮的绝对 Pass@1」，不能做语言间 Δpp 横比或因果归因。

7.1 可陈述的事实

  • 5 语言 Pass@1 落在 76.2~81.2% 区间（en 80.0 / zh 81.2 / es 80.8 / fr 76.2 / ru 79.3）
  • 5 语言均低于基线 83.3%（Δ −2.1 ~ −7.1pp），但受基座违规 + thinking 模式 + 语言切换未全生效三重污染
  • es 最稳定（std=0.3%），en 最不稳定（std=4.5%，r1 早停异常）
  • fr converged 最低（85.2%）、gen-fail 最高（21.3/轮），与「部分切换混乱」吻合
  • zh token 消耗最高（131.8 万/题），fr 最低（96.9 万/题）
  • 语言切换 audit：en 17/17 真切换 · zh 14/18 真切换（confound）· es 3/21 未生效 · fr 6/18 部分生效

7.2 不可陈述的（已降级）

  • ❌ 「中文思维链比法语高 5pp」—— 基座不恒定，不可归因
  • ❌ 「西班牙语思维链 Pass@1 = 80.8%」—— es 未生效，实质=英语思维链 + 无效西语提示
  • ❌ 「法语思维链导致 gen-fail 升高」—— fr 部分生效，是「部分切换混乱」而非「法语本身」
  • ❌ 「思维链语言对 EDA 任务有显著影响」—— 当前数据不支持此结论

7.3 修正建议（如需评估思维链语言真实效应）

  1. 同基座：全部用 glm-5.2（或全部用 dsv4-pro），不可混用
  2. 基础 prompt 中性化：移除「思考用中文」等强制指令，让 LANG_HINT 成为唯一语言控制变量
  3. 验证切换生效：每轮跑完抽 5-10 题做 lang-switch audit，未生效的轮作废重跑
  4. 同 thinking 档：与基线对齐 thinking 模式（要么全 omitted，要么全 medium），不可混
  5. 增加轮次：N=3 std 偏大（en 4.5），N≥5 才能做 McNemar 配对检验
生产配置建议：当前数据不支持改生产语言配置。如需评估思维链语言效应，须先在同基座（glm-5.2 恒定）+ 基础 prompt 中性化前提下重跑，audit 报告 §5.3 已给出最低改写建议。在修正前，保持现有（基础 prompt 中文 + thinking=medium）配置即可。
