⚠️ 审计结论对主结果的影响：
  1. en / zh 注入有效（TARGET 96.8% / 87.6%）—— 二者的 Pass@1（81.0% / 81.2%）是可信的语言效应（注：zh 的 58 条 CHINESE 是中文 trace 本身，非漂移）。

八、结论与局限

8.1 结论

  1. 思维链语言对 EDA 代码生成能力影响不显著：5 语言 Pass@1 落在 76.2-81.2%，极差 5.0pp，多数在 1σ 内。
  2. 中文与英文并列最高（81.2% / 81.0%）—— 这是唯二注入有效的语言，可信度最高。中文略高 0.2pp 在方差内，无显著差异。
  3. 中文 token 成本最高（1.32M/题 vs en 1.28M），比 es/ru（1.01M）多 ~30%——中文 token 化效率低。
  4. 中文执行质量最佳（converged 97.5%，gen_fail 3.3）—— 中文思维链反而最稳定。
  5. 法语最差（76.2% / converged 85.2% / gen_fail 21.3）—— 注入服从度低，生成失败多。

8.2 局限

局限影响缓解
es/fr/ru 注入未完全生效（audit 显示 ENGLISH 漂移 40-67%）三语 Pass@1 实际测的是「英文思考 + hint 干扰」，不能作为非英语思维链能力的证据需更强的 LANG_HINT（如 few-shot 示例 + 输出格式约束）或换用多语言基座
B_en_r1 重跑基座切换（glm-5.2 → dsv4-pro）en 3 轮基座虽已对齐，但 r1=78.5% 低于 r2/r3（80.4/84.2），可能有基座适应期已 SUPERSEDED 旧值留档；en mean 用 3 轮池
每语言仅 3 轮（n=3）std 自由度低，效应力不足，小差异（<2pp）难达显著如需统计显著，建议每语言 5-10 轮
与基线 glm-5.2 不可直接归因轴 B 用 dsv4-pro，与轴 A（glm-5.2）基座不同，跨轴 Δpp 含基座效应本报告仅作轴 B 内横比，不作跨轴归因
zh 的 58 条 CHINESE 是 confoundzh trace 中 12.2% 是中文（目标语言），但 trace_source 用户本身用中文，难分离 hint 效应 vs 用户语言效应audit 标注 confound，zh 的「真切换」含此混杂

8.3 未来方向

  1. 强化 LANG_HINT 注入：对 es/fr/ru 增加 few-shot 示例（用目标语言写的思维链示例）+ 输出格式约束（要求 reasoning 字段用目标语言），提升 TARGET 率到 >80% 后重测。
  2. 换用多语言基座：若 dsv4-pro 对非英语服从度低，可换用明确支持多语言的基座（如 Qwen-Max 多语言版）对比，分离「基座能力」与「语言效应」。
  3. 增加轮次：每语言 5-10 轮以提升统计效力，用 t-test / bootstrap 检验 en vs zh 的 0.2pp 差异是否显著。
  4. 跨语言 token 效率研究：中文 token 成本高 30% 是否值得？若 Pass@1 无显著优势，英文思维链在成本-性能上更优。
