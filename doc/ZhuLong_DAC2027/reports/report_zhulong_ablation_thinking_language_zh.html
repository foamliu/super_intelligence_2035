④ 口径校验

4.1 thinking flag 是否真生效（逐题 thinking 块计数）

从 cline session 逐 assistant 消息统计 type==thinking 块数与字符量。若跨档计数差异显著 → flag 生效；若字符量相近而 Pass@1 仍差异 → flag 影响 reasoning 结构/质量而非体量。

已知现象（需在报告中说明）：A-none（不传 flag）仍有非零 reasoning 字符量。两种解释：(a) GLM-5.2 模型自发产生 thinking 块（flag 仅调节档位而非开关）；(b) 抽取法计入非 thinking 内容。判定依据：若 A-none 的 块计数 显著低于 low/medium → flag 仍生效（仅体量相近）；若计数也相近 → flag 对该模型 reasoning 体量无显著控制。Pass@1 跨档差异（none<low≈medium）已证明 flag 对 行为结果 有效。

⑥ 与既有基线对照（Δpp + 配对 McNemar）

⑦ 结论（边际收益 · 是否值得改生产配置）

初步趋势（基于已跑轮次）：
  • 开 thinking（none→low）: Δ+4.6pp（79.5%→84.2%）
  • low→medium: Δ+1.3pp（84.2%→85.4%）
边际收益：thinking none→low 显著提升（+4.7~5.9pp），low→medium 边际趋平（≈+0.6pp），说明对 GLM-5.2 + PyAether 158 任务，开 low 档即获大部分增益，medium 以上边际收益递减。成本：reasoning token 跨 none/low/medium 体量相近（待 high/xhigh 确认是否陡增）。
语言（轴 B · 同基座横比 / 与基线不可单归因）：轴 B 5 语言 Pass@1 落在 76.2~81.2% 区间（en 81.0±2.9 [r1 78.5 重跑 / r2 80.4 / r3 84.2] / zh 81.2±3.2 / es 80.8±0.3 / fr 76.2±2.6 / ru 79.3±2.5）。轴 B 15/15 轮已同基座（deepseek-v4-pro-cloud），5 语言间可作同基座横比（B_en_r1 已于 11-12 重跑对齐基座，旧 75.3% glm-5.2 版标 SUPERSEDED 留档）。但与基线 B.glm-5.2 = 83.3±3.1% 的 Δpp 仍不可直接归因为「思维链语言效应」：(1) 基座不同（轴 B = deepseek-v4-pro-cloud vs 基线 = glm-5.2）；(2) thinking 模式不同（轴 B = medium vs 基线 = omitted）；(3) 语言切换实测 es 未生效 / fr 部分生效 / zh 与基础 prompt confound（见 §4.2）；(4) 基础 prompt 已强制中文思考，与 B 轴注入冲突。故轴 B 与基线的 Δpp 应理解为「dsv4-pro + medium + 语言注入（部分生效）vs glm-5.2 + omitted」的多变量混合效应，非单变量语言效应。fr 偏低（76.2%）可能与长难题漂回英语 + 部分切换有关。
生产配置建议：轴 A——若成本敏感，low 档为性价比最优点；若追求上限且 quota 充裕，medium。high/xhigh 边际不升反降（倒 U 形）。轴 B——5 语言同基座横比已成立（11-12 重跑 B_en_r1 对齐后），但与基线 glm-5.2 的 Δpp 仍不可单归因为语言效应（基座+thinking 模式均不同）；如需评估思维链语言真实效应，须先在基础 prompt 中性化前提下重跑（同基座条件已满足），audit 报告 §5.3 已给出最低改写建议。
