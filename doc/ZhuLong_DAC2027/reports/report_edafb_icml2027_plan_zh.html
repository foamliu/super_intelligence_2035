§0 结论先行（摘要卡）

一句话结论

把 ICML 2027 论文的主线从「卖一个不可开源的评测集」升格为「在真实 EDA design flow 上检验一个可迁移的认知命题」——long-term memory 与 recursive self-improvement 在长链工具编排中的可证伪收益与边界条件；评测集 EDA-Flow-Bench 降为副线载体（协议 + 判据 + harness + 脱敏 mock 资产 + Lite 集构造方法开源，原始 trace 不发布）。新论文显式继承两篇 zhulong（DAC27 的 grounding-gap 叙事 + DATE27 的自进化方法骨架），把 DATE27 在单脚本层得到的认知搬到 flow 层检验是否仍成立，并补上 DATE27 未覆盖的「负结果也发」的诚实路线。

六条判据（验收标准自检）

  1. 贡献重定位：三条硬伤（不可开源 / benchmark 社区价值被削弱 / 单点数字会过期）已诊断；替代结构 = 主线认知 + 副线任务形态 + bench 作载体；开源边界表见 §2.3。✅
  2. 与 DATE27 delta 表：五维 delta（任务粒度 / 自进化载体 / 失败信号 / 评测单位 / 可迁移性主张）见 §3。✅
  3. 可证伪命题：4 条预注册假设（H1 记忆增益 / H2 自改进随链长单调 / H3 记忆是自改进前提 / H4 单 agent 与自主 spawn 结论复现），每条含自变量、因变量、判据阈值、样本量、统计检验、证伪条件，见 §4。✅

三个最大风险

  1. R1 H2 负结果（自改进收益不随链长单调，甚至转负）—— Plan B：写成「在真实 design flow 上自改进的边界条件」诚实路线，这本身是可发表认知（§8）。
  2. R2 不可开源被审稿人质疑复现性 —— Plan B：受限评审复现包 + mock-EDA 模式 + Lite 集 500 题脱敏构造方法开源 + 第三方可在 mock 沙盒复跑 harness（§2.3 / §8）。
  3. R3 cases 增长与评测口径漂移（Full 集 \Ntasks=1684 仍在增长，696-run 冻结快照可能过期）—— Plan B：所有论文数字绑定冻结快照 + Lite 集 500 题固定 + 多骨干扫描在 camera-ready 补（§8）。

§2 贡献重定位与开源边界

§2.1 为什么「只卖评测集」立不住（审稿人视角三条硬伤）

硬伤 ①：trace 源自公司生产资产，不可开源 ⇒ 外部不可复现

EDA-Flow-Bench 的 1684 个任务构建于「IC 设计工程师在生产环境中使用 Cline 编程智能体的真实交互轨迹」之上，trace_source 记录 host/user/session_file，且「用户标识保留（不做哈希）以保证可复现性」。 2_benchmark.tex:8-9 · 2_benchmark.tex:14 这意味着原始 trace 是公司 IP，不能离开保密边界。一个外部研究者拿到 Lite 集 500 题的 prompt + check.py，无法复现「从真实 trace 构建 bench」的过程，也无法验证任务是否真正代表真实工程实践。审稿人会问：「如果数据不可发布，这个 benchmark 的社区价值是什么？」

硬伤 ②：数据不可发布 ⇒ benchmark 论文的社区价值被大幅削弱

Benchmark 论文的价值在于「社区可在其上比较方法」。但 EDA-Flow-Bench 的 Full 集（1684 题）完全不发布，Lite 集 500 题虽有可释放性筛选（2_benchmark.tex:86-97），但需 mock-EDA 模式（7_conclusion.tex:28）才能在没有商业工具许可证的环境下跑——这意味着外部研究者只能在 mock 沙盒上复跑，而 mock 沙盒无法复现真实工具的 grounding depth 差距（physical_verify 2.9% 的 DRC/LVS 真跑在 mock 下不存在）。一个「真实商业工具编排」的卖点在开源后变成「mock 工具编排」，benchmark 的差异化优势被削弱。

硬伤 ③：10.0% Pass@1 这类单点数字会随基座更新迅速过期

10.0%（62/620, Wilson CI [7.9,12.6]）是 DeepSeek-V4-Pro + Cline v3.0.51 + thinking=low 的单骨干单配置快照。 4_experiments.tex:22-26 · 66 696-run 冻结于 2026-11-09（main.tex:100）。ICML 2027 截稿 2027-01-22（README.md:7），发表要到 2027 年中——届时基座已更新 1-2 代，10.0% 会变成历史数字。一个「benchmark + 单点天花板」的论文，1-2 年后只剩 benchmark 本体（而本体又不可开源）——整篇论文的时效性资产会快速贬值。相比之下，认知命题（如「记忆是自改进的前提」）即使数字过期，命题的真伪仍是长效贡献。

§4 可证伪命题（pre-registered hypotheses）

4 条假设，每条含：自变量、因变量、判据阈值、样本量、统计检验（预注册 α）、证伪条件。所有假设在数据冻结前预注册（§7 时间线标「预注册日」）。

H1 · 长期记忆提升长链任务 Pass@1

项内容
陈述跨 session 的长期记忆（工具知识 + 项目约定 + 失败模式）提升长链 flow 任务的 Pass@1，且提升在「所需上下文接近/超过窗口」的子集上更大。
自变量记忆有无（M0 无记忆基线 vs M2/M3 自动记忆，§5 臂表）
因变量Pass@1（每任务一次轨迹，2400s 超时，≥8 断言全过）
判据阈值M3 Pass@1 ≥ M0 Pass@1 + 3pp（pooled），且在「超窗风险高」子集上 Δ ≥ 5pp
样本量最小矩阵：Lite 集 500 题中取 trace 最长 top-120（按 47 pilot 的 median 26.5 calls / IQR 13.8-38.0 分层，5_analysis.tex:85），每臂 1 trace × 120 题 = 120 run；理想矩阵：500 题 × 3 重复 = 1500 run/臂
统计检验McNemar（配对，方向一致）+ paired bootstrap 95% CI（1000 resample）；预注册 α=0.05（Bonferroni 校正后 α=0.05/4=0.0125 用于 4 假设族）
证伪条件M3 − M0 < 1pp（pooled）或 McNemar p > 0.05 或 方向反转（M3 < M0）⇒「记忆在 flow 层无增益」成立，H1 被证伪

H2 · 递归自我改进收益随链长单调增长

项内容
陈述自改进（技能库自扩 + harness 自改）的 Pass@1 收益随任务链长（tool call 数）单调增长——链越长，自改进积累的编排知识越有用。
自变量自改进有无（M3 vs M3+S1，§5）× 链长分层（short: <14 calls / mid: 14-38 / long: >38，按 5_analysis.tex:85 IQR 分层）
因变量分层 Pass@1 + (M3+S1 − M3) 的分层 Δ
判据阈值Δ_long ≥ Δ_mid ≥ Δ_short，且 Δ_long − Δ_short ≥ 3pp（单调性 + 显著差异）
样本量每层 ≥ 40 题（120 题分三层）；理想矩阵每层 ≥ 150 题
统计检验 单调性：Cochran-Armitage 趋势检验；分层差异：paired bootstrap CI on (Δ_long − Δ_short)；预注册 α=0.05
证伪条件单调性不成立（Δ_long < Δ_mid 或 Δ_mid < Δ_short）或 Δ_long − Δ_short 的 95% CI 含 0 ⇒ H2 被证伪。若 Δ 在所有层都 ≈ 0，则「自改进在 flow 层无收益」⇒ 走 §8 R1 Plan B（边界条件论文）

H3 · 记忆是自改进的前提

项内容
陈述无记忆时自改进收益消失或转负——自改进依赖记忆来积累跨 session 经验，记忆是自改进的必要条件。
自变量记忆（有/无）× 自改进（有/无）= 2×2 析因：M0 / M3 / S1(无记忆自改进) / M3+S1
因变量Pass@1 + 交互效应（two-way ANOVA 或其非参数替代）
判据阈值自改进的主效应在「无记忆」条件下 ≤ 0（S1 ≤ M0），在「有记忆」条件下 > 0（M3+S1 > M3）；交互效应 (M3+S1 − M3) − (S1 − M0) ≥ 2pp
样本量4 臂 × 120 题 = 480 run（最小）；理想 4 × 500 = 2000 run
统计检验交互效应 paired bootstrap CI（排除 0 为显著）；预注册 α=0.05
证伪条件S1 > M0 + 2pp（无记忆时自改进仍有收益）或 交互效应 95% CI 含 0 ⇒「记忆是自改进前提」不成立，H3 被证伪（自改进可能在无记忆时通过 prompt 内 in-context learning 起作用）

H4 · 单 agent 与自主 spawn 结论在 flow 场景的复现

项内容
陈述结案结论（单 agent ≥ 多 agent；自主 spawn ≥ 用户定制，见 MEMORY_ZHULONG.md 顶部结案结论）在 flow 场景是否复现——即记忆/自改进臂内部，单 agent 仍优于多 agent。
自变量agent 架构（单 agent / 自主 spawn subagent / 用户定制 subagent）嵌套在 M3+S1 臂内
因变量Pass@1 + token 效率（input tokens / Pass@1）
判据阈值单 agent Pass@1 ≥ 自主 spawn + 0pp（复现结案结论）且 单 agent token 效率优于自主 spawn
样本量3 架构 × 120 题 = 360 run（最小）
统计检验McNemar（单 agent vs 自主 spawn，方向一致）；预注册 α=0.05
证伪条件自主 spawn > 单 agent + 3pp（McNemar p < 0.05）⇒ 在 flow 场景多 agent 反超单 agent，结案结论不在 flow 层复现，H4 被证伪（这本身是重要发现：长链任务可能让多 agent 分工优势显现）
H4 的特殊说明：H4 直接对应用户 2026-11-17 09:3x 结案令的两条认知（「单 agent > 多 agent；自主 spawn > 用户定制」，源自 2026 暑假清华博士研究积累）。该认知在 subagent 消融线（40 题子集）上成立，但是否在长链 flow 任务上仍成立是经验问题——长链任务可能恰好满足「所需上下文 > 窗口」的条件（用户 2026-11-15 07:2x 提出的 H_ctx 思路），使多 agent 分工优势显现。H4 用预注册方式正面检验这一边界。无论结果如何都可发表：复现 → 巩固认知；不复现 → 界定长链是单 agent 优势的边界。 MEMORY_ZHULONG.md:1-5（结案结论）· 用户 2026-11-15 07:2x H_ctx 思路（ZHULONG_TASK.md 用户裁令节）

§5.2 污染防护

  • Held-out 任务：自改进的写入侧（distillation）只用在「训练子集」上的 trace；held-out 子集（120 题或 500 题）从不参与 distillation。继承 DATE27 的 instance-disjoint split（1_intro.tex:7 + 4_self_evolve.tex:22）。
  • 时间切分：记忆写入只用 2026-11-09 冻结快照之前的 trace；冻结快照之后的 case 不进入记忆库（防止「用未来数据解释过去」）。
  • 答案泄漏检查：复用 EDA-Flow-Bench 的 PreToolUse 防泄题钩子（3_harness.tex:51-65）—— reference/ + check.py 不进入 workdir；hook_blocks 字段统计 ACCESS RESTRICTED 事件（3_harness.tex:67）。自改进记忆条目经 anti-leakage retrieval（names-only + docstring generalization，4_self_evolve.tex:22）防止跨划分答案复制。
  • 记忆内容审计：每条 L1 记忆条目记录 trace_source + reliability tier（verified/unverified/pitfall，4_self_evolve.tex:10）+ 写入时间戳；审计脚本统计「错误条目占比」「淘汰条目数」「冲突消解次数」——作为「记忆质量」的协变量报告。
  • 基座固定：所有臂用同一基座（DeepSeek-V4-Pro，与 696-run 快照一致，4_experiments.tex:22）；多骨干扫描仅在 camera-ready 补且仅对 M0/M3 两臂（控制成本）。
  • 判据不变：所有臂用同一 check.py + 同一 ≥8 断言 + 同一 2400s 超时（2_benchmark.tex:120）—— 不得为论文数字改判据/改题/挑样本（防伪底线）。
