§0 结论先行（摘要卡）

一句话结论

把 ICML 2027 论文的主线从「卖一个不可开源的评测集」升格为「在真实 EDA design flow 上检验一个可迁移的认知命题」——long-term memory 与 recursive self-improvement 在长链工具编排中的可证伪收益与边界条件；评测集 EDA-Flow-Bench 降为副线载体（协议 + 判据 + harness + 脱敏 mock 资产 + Lite 集构造方法开源，原始 trace 不发布）。新论文显式继承两篇 zhulong（DAC27 的 grounding-gap 叙事 + DATE27 的自进化方法骨架），把 DATE27 在单脚本层得到的认知搬到 flow 层检验是否仍成立，并补上 DATE27 未覆盖的「负结果也发」的诚实路线。

六条判据（验收标准自检）

  1. 贡献重定位：三条硬伤（不可开源 / benchmark 社区价值被削弱 / 单点数字会过期）已诊断；替代结构 = 主线认知 + 副线任务形态 + bench 作载体；开源边界表见 §2.3。✅
  2. 与 DATE27 delta 表：五维 delta（任务粒度 / 自进化载体 / 失败信号 / 评测单位 / 可迁移性主张）见 §3。✅
  3. 可证伪命题：4 条预注册假设（H1 记忆增益 / H2 自改进随链长单调 / H3 记忆是自改进前提 / H4 单 agent 与自主 spawn 结论复现），每条含自变量、因变量、判据阈值、样本量、统计检验、证伪条件，见 §4。✅
  4. 消融设计：≥6 臂（M0/M1/M2/M3/S1/M3+S1 + 两类负对照）+ 等 token 预算无记忆长 prompt 杀手级对照 + 最小可跑矩阵 + 理想矩阵，见 §5。✅
  5. 论文规划：3 标题候选 + 4 贡献 + 与两篇 zhulong 同构章节大纲 + 图表清单 + 实验矩阵表 + ICML2027 倒推时间线 + 风险清单，见 §6–§8。✅
  6. 现有资产衔接：今天就能跑 / 需新造题 / 需新基座沙盒三档清单 + 防伪底线，见 §9。✅

三个最大风险

  1. R1 H2 负结果（自改进收益不随链长单调，甚至转负）—— Plan B：写成「在真实 design flow 上自改进的边界条件」诚实路线，这本身是可发表认知（§8）。
  2. R2 不可开源被审稿人质疑复现性 —— Plan B：受限评审复现包 + mock-EDA 模式 + Lite 集 500 题脱敏构造方法开源 + 第三方可在 mock 沙盒复跑 harness（§2.3 / §8）。
  3. R3 cases 增长与评测口径漂移（Full 集 \Ntasks=1684 仍在增长，696-run 冻结快照可能过期）—— Plan B：所有论文数字绑定冻结快照 + Lite 集 500 题固定 + 多骨干扫描在 camera-ready 补（§8）。
诚实路线声明（必写进论文）：若自改进在 flow 层无收益，本论文写成「在真实 design flow 上自改进的边界条件」——DATE27 在单脚本层得到 +2.5pp 的自进化收益，在长链 flow 编排上是否仍成立是经验问题而非定论；负结果本身界定了 long-term memory + RSI 的适用边界，是可发表的认知贡献。这一立场继承自两篇 zhulong 的「负结果照写」纪律。 参照：DATE27 0_abstract.tex:4（80.0% vs 77.5%, +2.5pp）· DAC 7_discussion.tex:7（SKILL 自探索 +2.0pp 在噪声内 [-2.9,6.9] 仍作次要贡献报告）

§1 现稿诊断（逐节）

现稿为 EDA-Flow-Bench_ICML2027/，结构遵循 ML 会议惯例（Intro → Benchmark → Harness → Experiments → Analysis → Related → Conclusion → Ethics/Reproducibility → Appendix A/B/C）。 main.tex:132-157（章节装配） 下面逐节标注「benchmark 叙事」与「可升格为认知叙事」的位置。

§1.1 Abstract（0_abstract.tex）

现稿主张：首句定位「现有 EDA benchmark 只评单函数代码生成或开源 flow 修复，无人评多步编排」；贡献 = EDA-Flow-Bench（\Ntasks=1684 任务、13 域、真实 trace 构建）；结果 = DeepSeek-V4-Pro 10.0% Pass@1 vs 单脚本 76.5%；分析 = tool-chain grounding depth（pnr_signoff 20.8% vs physical_verify/layout_aether 2.9%，7.1×）。 0_abstract.tex:2-10 · \Ntasks main.tex:76 · \Neval main.tex:104 · 10.0% 62/620 4_experiments.tex:66

诊断：① benchmark 叙事 全文是「我们造了一个 bench + 跑了一个数字 + 解释一个 gap」——没有可证伪的认知命题，grounding depth 是「事后解释的描述性标注」而非「事前预注册的预测」；② 可升格 10.0% vs 76.5% 的 7.6× 跨任务难度跳变 + grounding-depth 排序的稳定性，可升格为「任务链长放大了 harness（观测/记忆/自改进）轴相对于基座轴的决定性」这一认知命题（继承 DAC 的 grounding-gap 框架）；③ 10.0% 是单点数字，会随基座更新迅速过期——这正是用户指出的第三条硬伤。

现稿主张：把 EDA 工作流自动化重构为 agentic flow orchestration；贡献三条 = Benchmark / Evaluation（10.0% 天花板 + 7.1× 域差距）/ Analysis（失败分类法 + 47 trace 解剖）。 1_intro.tex:5-35 · 贡献三条 1_intro.tex:29-35

§2 贡献重定位与开源边界

§2.1 为什么「只卖评测集」立不住（审稿人视角三条硬伤）

硬伤 ①：trace 源自公司生产资产，不可开源 ⇒ 外部不可复现

EDA-Flow-Bench 的 1684 个任务构建于「IC 设计工程师在生产环境中使用 Cline 编程智能体的真实交互轨迹」之上，trace_source 记录 host/user/session_file，且「用户标识保留（不做哈希）以保证可复现性」。 2_benchmark.tex:8-9 · 2_benchmark.tex:14 这意味着原始 trace 是公司 IP，不能离开保密边界。一个外部研究者拿到 Lite 集 500 题的 prompt + check.py，无法复现「从真实 trace 构建 bench」的过程，也无法验证任务是否真正代表真实工程实践。审稿人会问：「如果数据不可发布，这个 benchmark 的社区价值是什么？」

硬伤 ②：数据不可发布 ⇒ benchmark 论文的社区价值被大幅削弱

Benchmark 论文的价值在于「社区可在其上比较方法」。但 EDA-Flow-Bench 的 Full 集（1684 题）完全不发布，Lite 集 500 题虽有可释放性筛选（2_benchmark.tex:86-97），但需 mock-EDA 模式（7_conclusion.tex:28）才能在没有商业工具许可证的环境下跑——这意味着外部研究者只能在 mock 沙盒上复跑，而 mock 沙盒无法复现真实工具的 grounding depth 差距（physical_verify 2.9% 的 DRC/LVS 真跑在 mock 下不存在）。一个「真实商业工具编排」的卖点在开源后变成「mock 工具编排」，benchmark 的差异化优势被削弱。

硬伤 ③：10.0% Pass@1 这类单点数字会随基座更新迅速过期

10.0%（62/620, Wilson CI [7.9,12.6]）是 DeepSeek-V4-Pro + Cline v3.0.51 + thinking=low 的单骨干单配置快照。 4_experiments.tex:22-26 · 66 696-run 冻结于 2026-11-09（main.tex:100）。ICML 2027 截稿 2027-01-22（README.md:7），发表要到 2027 年中——届时基座已更新 1-2 代，10.0% 会变成历史数字。一个「benchmark + 单点天花板」的论文，1-2 年后只剩 benchmark 本体（而本体又不可开源）——整篇论文的时效性资产会快速贬值。相比之下，认知命题（如「记忆是自改进的前提」）即使数字过期，命题的真伪仍是长效贡献。

§4.5.1 三条机制的计算映射（不停留在比喻）

认知神经科学机制生物证据（附录 G）→ EDA agent 记忆架构映射可计算公式（v1.4 给出）
① 情绪唤醒度 → 惊奇度 / 高惩罚信号门控（Surprise / High-Penalty Gating） 杏仁核-海马交互：情绪唤醒度（arousal，无论正负效价）增强记忆巩固；肾上腺素/皮质醇 → 杏仁核 NE → 海马 LTP。McGaugh 2004 Annu Rev Neurosci 27:1-28 · McGaugh 2013 PNAS 110(S2):10402 · Richter-Levin & Akirav 2003 emotional tagging 人类不平均记流水账，只对「强烈挫败（报错/崩盘）」或「意外突破（一次性通过）」高权重写入。Agent 记忆写入不应均匀采样，应由预测误差（prediction error）或高代价失败触发优先级巩固。 写入权重 w = α·surprise + β·penalty。surprise = 新事实相对记忆库先验的预测误差（KL 散度 / Shannon 自信息，Itti & Baldi 2009 Bayesian surprise）；penalty = 失败代价（长链中途崩盘的已耗 tool calls / 已耗 token）。α/β 由消融标定（M5 vs M2 均匀采样）。
② 武器聚焦效应 → 根因抽象与噪声剥离（Weapon-Focus Compression） 高唤醒时记忆权衡：核心刺激（central details）巩固增强，边缘背景（peripheral details）编码受抑；Easterbrook 1959 注意窄化；Loftus et al. 1987 / Steblay 1992 weapon focus；Mather & Sutherland 2011 arousal-biased competition。Easterbrook 1959 · Kensinger 2009 Emot Rev 1(2):99 · Mather & Sutherland 2011 PMC3110019 高唤醒时大脑只记核心冲突、丢弃无关背景；同理，Agent 遇长链工具报错时，应触发高强度上下文压缩，只将核心报错栈 + 根因因果链固化进 L1/L2，剥离冗余中间日志。 压缩比指标 central_vs_peripheral_ratio = |central_tokens| / |total_tokens|。central = 报错栈 + 根因因果链（M7 触发）；peripheral = 中间 tool call 日志。M7 vs M2 全量写入比较该比值与 Pass@1。
③ 心境一致性 / 状态依赖提取 → 状态感知检索（State-Aware Retrieval） Bower 1981 Network Theory of Affect：心境一致提取（mood-congruent recall，匹配效价）+ 状态依赖提取（state-dependent recall，匹配编码/检索状态）；Eich et al. 1994 自生成事件下效应更强。Bower 1981 Mood and Memory · Bower, Gilligan & Monteiro 1981 · Eich et al. 1994 Agent 陷入连续失败（高「挫败/风险」状态）时，检索系统应自动调高防御性避坑规则与负面教训权重；正常推进时优先检索成功范式。情绪状态成为检索的索引标签。 检索打分 score(query, mem) = sim(q, mem) + γ·state_match(query_state, mem_encode_state)。state = (近 N 步失败率, 当前 tool 域, 链长阶段)；γ 由 M6 消融标定（M6 vs M3 状态无关检索）。
机制 → 假设的可证伪性升级：H1（v1.2）只问「记忆有无增益」——即使 M3 > M0，也不知道增益来自「正确相关记忆」还是「prompt 变长」（这正是 N1 杀手级对照要排除的）。v1.4 的 H5-H7 把问题深化为「增益是否来自该具体机制」：H5 检验惊奇度门控 vs 均匀采样；H6 检验状态感知检索 vs 状态无关检索；H7 检验武器聚焦压缩 vs 全量写入。每条都有机制级负对照（关掉该机制、保留等量 token），比 H1 的功能级对照更精细。这与 AI 情感记忆前沿（Generative Agents 用 importance score 过滤写入 Park et al. 2023、EM-LLM 用 Bayesian surprise 切分事件 arXiv:2407.09450、PsychoAgent 用 affect + conflict 检索 arXiv:2608.07438、somatic-marker emotion vector re-injection arXiv:2605.08611）同构，但首次在真实 EDA long-chain flow 上预注册可证伪检验。 附录 G 调研文献（research.cimi_search 8 次调用）

§5.2 污染防护

  • Held-out 任务：自改进的写入侧（distillation）只用在「训练子集」上的 trace；held-out 子集（120 题或 500 题）从不参与 distillation。继承 DATE27 的 instance-disjoint split（1_intro.tex:7 + 4_self_evolve.tex:22）。
  • 时间切分：记忆写入只用 2026-11-09 冻结快照之前的 trace；冻结快照之后的 case 不进入记忆库（防止「用未来数据解释过去」）。
  • 答案泄漏检查：复用 EDA-Flow-Bench 的 PreToolUse 防泄题钩子（3_harness.tex:51-65）—— reference/ + check.py 不进入 workdir；hook_blocks 字段统计 ACCESS RESTRICTED 事件（3_harness.tex:67）。自改进记忆条目经 anti-leakage retrieval（names-only + docstring generalization，4_self_evolve.tex:22）防止跨划分答案复制。
  • 记忆内容审计：每条 L1 记忆条目记录 trace_source + reliability tier（verified/unverified/pitfall，4_self_evolve.tex:10）+ 写入时间戳；审计脚本统计「错误条目占比」「淘汰条目数」「冲突消解次数」——作为「记忆质量」的协变量报告。
  • 基座固定：所有臂用同一基座（DeepSeek-V4-Pro，与 696-run 快照一致，4_experiments.tex:22）；多骨干扫描仅在 camera-ready 补且仅对 M0/M3 两臂（控制成本）。
  • 判据不变：所有臂用同一 check.py + 同一 ≥8 断言 + 同一 2400s 超时（2_benchmark.tex:120）—— 不得为论文数字改判据/改题/挑样本（防伪底线）。
