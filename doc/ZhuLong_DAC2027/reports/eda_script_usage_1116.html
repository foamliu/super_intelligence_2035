九、MCP 服务架构

RAG_MCP_Server
API 检索服务 · 33,686 次
SandBox_MCP_Server

架构说明：EDA 脚本能力通过两个 MCP 服务暴露给 Cline 编程智能体： RAG_MCP_Server 提供 search_apis / get_api_details / search_apis_by_keyword 三个 API 检索工具（基于向量嵌入 + BM25）， SandBox_MCP_Server 提供 run_code 代码执行工具（支持 pyAether / SKILL / Tcl 三种语言，对应 Aether / Virtuoso / WaveView 等宿主工具）。 用户在 Cline 中自然语言描述需求 → 智能体自动检索 API → 生成代码 → 沙盒执行 → 返回结果。

十、核心结论

  1. 已形成生产级使用规模：323 位工程师、696 台工作站、65,481 次调用，月环比增速 ~56%
  2. pyAether 是主力语言（57.6%），覆盖 285 人，9 月起成为调用量第一的 EDA 脚本语言
  3. SKILL 是成熟稳定的基础（33.1%），175 人使用，Virtuoso 版图操作场景刚需
  4. Tcl 是 11 月新增增长极，16 天 41 人 5,904 次，WaveView 波形分析需求旺盛
  5. 用户加速扩散：6 月 3 人 → 11 月 182 人，9 月为扩散拐点（+678%），尚未触顶
  6. 查/跑比 52:48，API 检索与代码执行并重，检索能力是降低使用门槛的关键
  7. 重度用户驱动：Top 15 用户贡献 58% 调用量，长尾用户仍处于早期探索阶段
