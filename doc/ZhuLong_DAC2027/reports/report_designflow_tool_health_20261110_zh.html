⑥ 方法与被排除项

  • 本批次 696 条 case：判分证据 1130 条（PASS/FAIL/ERROR），ABSENT 6 条。
  • 解析到 cline session 的 case：636；未找到 session 文件：60（多为 ERROR/ABSENT，如 assets 目录缺失、check.py 缺失、cline 未启动）。
  • 工具命中规则（关键）：按 可执行名 命中——命令按 ; | && || 换行切分段，剥去前导 cd ... && / VAR=val 后取段首可执行名（basename），匹配工具清单才算"调用"。仅出现在 ls/cat/find/grep 路径参数里的工具名（如 ls /proj/.../finesim/workdir/）不计为调用。pyAether 是 Python 库，按 python3 ... "import pyAether" 风格命中。
  • 工具四态：ok=exit 0 且 stdout 非空且无 error 标记；err=exit≠0 或 stderr 含 error 标记；no_product=exit 0 但 stdout 与 stderr 均空；mcp_refused=MCP 校验拒绝（如缺 workdir）；从未调用=全批次零命中（不计为失败）。
  • 本地 run_commands 仅回显 NOTICE（harness 阻断本地执行），其 NOTICE echo 命令不计入工具命中；其余本地命令仍参与检测。
  • 失败签名两类来源：工具输出=eda_flow__run_commands 的 stderr 首行（stderr 空则取 stdout 首个 error 行；Traceback 取末行异常类型）；判分原因=check.py 判分 reason（每个 FAIL/ERROR case 一条）。两者归一化路径/时间戳/行号/PID/hex/数字后聚类。
  • domain 来自 EDA-Eval-DesignFlow_{{A,B,C,D}}.jsonl 的 metadata.domain。
  • 失败类别：PASS / SEM（check.py 语义拒绝）/ NO_SUBMIT（未产 submit.zip）/ RT（cline 崩溃或 harness 错）/ ABSENT / UNKNOWN。
  • 被排除项：从未调用 10 个工具（smartspice/asc/pvx/icc2/design_compiler/spyglass/star-rc/redhawk/totem/siliconsmart，其中 design_compiler 实际通过 dc_shell 调用）；6 个 ABSENT case 与 60 个无 session case 不参与工具统计。
