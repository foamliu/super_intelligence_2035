\section{Background and Motivation}
\label{sec:background}

We target two widely-used EDA scripting interfaces: PyAether for Empyrean Aether \cite{empyrean_pyaether} and SKILL for Cadence Virtuoso \cite{cadence2024virtuoso}. EDA scripting poses three challenges beyond what generic LLM code generators address: (i) APIs are long-tailed, tool-specific, and poorly documented; (ii) correctness depends on side effects in a live, stateful database, not return values; and (iii) no benchmark exists to evaluate whether generated scripts actually work.

\textbf{Prior work stops short of execution.} LayoutCopilot \cite{liu2025layoutcopilot}, ChaTCL \cite{rui2025chatcl}, and RAG-EDA \cite{pu2024rag} combine LLMs with static knowledge bases, but none executes generated code: correctness is assessed by human judgment or retrieval quality, not by whether the script actually modifies a layout. Recent concurrent benchmarks for Tcl/Innovus flows \cite{xu2026iscript, li2026pdagent} confirm the growing recognition of this gap, yet target different toolchains; a dedicated PyAether/SKILL benchmark remains absent.

\textbf{Our approach.} ZhuLong closes the loop from generation to execution to refinement via sandbox feedback, with a \textbf{theoretical grounding} (Section~\ref{sec:grounding-theory}) explaining \emph{why} execution is necessary, and \textbf{EDA-Eval-PyAether}, the first standardized PyAether benchmark. The contribution boundary is the \emph{harness}---the three MCP tools (\texttt{search\_apis}, \texttt{get\_api\_details}, \texttt{run\_code}), the evaluation protocol, and the benchmark; the agent backbone is outside the scope of this paper.
