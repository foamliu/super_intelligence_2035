\section{Introduction}
\label{sec:introduction}

Design engineers' daily work is less about writing fresh scripts than about orchestrating design flows and patching the gaps between EDA tools that refuse to interoperate---a flow that cannot run end-to-end is the single largest source of lost design time. Commercial EDA tools are closed: where they leave a gap, the only recourse is hand-written glue (a Makefile target, a Tcl driver, a SKILL wrapper), precisely the small intent-to-code synthesis at which LLMs excel. This reframes EDA scripting as the connective tissue that lets a general coding agent orchestrate flows natively and fill the breaks where tools stop. ZhuLong is built around this insight, and this paper asks which factor sets the ceiling of such an agent---grounded by a system deployed in production EDA flows at a leading memory design house.
% 引言动机段（09:2x 重定位：编排 + 补断链）。设计工程师日常工作与其说写全新脚本，不如说编排 design flow、补上 EDA 工具拒绝互通的断链——flow 跑不到端到端是设计耗时单一最大来源。商用 EDA 工具封闭，留白处只能手写胶水（Makefile 目标、Tcl 驱动、SKILL 封装），而这恰是 LLM 最擅长的小型"意图→代码"合成。这重新界定 EDA scripting 为让通用 coding agent 天生编排 flow、在工具停步处补断链的结缔组织。ZhuLong 围绕此洞察构建，本文追问决定这类智能体上限的因素——由已部署于一家头部存储芯片设计公司服务数百名工程师的量产系统支撑。

We present \textbf{ZhuLong}, an execution-grounded LLM coding agent for PyAether, SKILL, and Tcl, built on Cline-CLI \cite{cline2024cline} and four unified MCP tools \cite{lee2025autoeda}---semantic and keyword API search, documentation lookup, and sandbox execution---that form a closed generate--execute--refine loop over four commercial runtimes via a single \texttt{lang}--\texttt{host} pair. An offline \textbf{API self-exploration} mechanism enriches the documentation prior as a bounded complement. Beyond the engineering, we give a \textbf{theoretical grounding} (Section~\ref{sec:grounding-theory}): EDA correctness is a situated (L4) property, and a Bayesian argument bounds the grounding gap by observation fidelity, not model scale---a prediction the experiments could refute rather than a post-hoc explanation.

\noindent\textbf{Contributions.}
\begin{itemize}
    \item \textbf{RQ1 (ceiling).} We formalize the grounding gap and measure it from both
    sides: the observation-fidelity axis (no observation $\to$ full observation) spans
    57.4~pp (LLM fixed), while the backbone axis spans 22.0~pp (harness fixed)---observation,
    not scale, sets the ceiling (Section~\ref{sec:grounding-theory}, \ref{sec:experiments}).
    % RQ1（上限）：形式化落地鸿沟，两侧测量——观测保真度轴（无观测→全观测）跨 57.4pp（固定 LLM），backbone 轴跨 22.0pp（固定框架）。

    \item \textbf{RQ2 (necessary components).} Ablation isolates retrieval, execution, and
    belief update as jointly necessary, with toolchain-specific magnitudes that make them
    complementary rather than interchangeable; offline self-exploration
    is a bounded complement, not a substitute (Section~\ref{sec:experiments}).
    % RQ2（必要组件）：消融分离检索、执行、信念更新，联合必要且不可互换；自探索为有界补充非替代。

    \item \textbf{RQ3 (toolchain generality).} \textbf{EDA-Scripting-Bench} (449 tasks, 4
    runtimes, one schema) re-measures the same structure slice by slice; we specify the
    harness, schema, and assertion protocol in full (Section~\ref{sec:benchmark}) so that
    the benchmark can be re-instantiated on other toolchains.
    % RQ3（工具链通用性）：EDA-Scripting-Bench（449 任务、4 运行时、单一 schema）逐切片重测同一结构；完整规范 harness、schema 与断言协议，使基准可在其他工具链上重新实例化（暂不开源，匿名版）。
\end{itemize}
