\section{Introduction}
\label{sec:introduction}

Design engineers' daily work is less about fresh scripts than about orchestrating design flows and patching the gaps between EDA tools that refuse to interoperate---a flow that cannot run end-to-end is the single largest source of lost design time. Commercial EDA tools are closed: where they leave a gap, the only recourse is hand-written glue (a Makefile target, a Tcl driver, a SKILL wrapper), precisely the small intent-to-code synthesis at which LLMs excel. This reframes EDA scripting as the connective tissue letting a general coding agent orchestrate flows and fill the breaks.
% 设计工程师日常工作与其说写全新脚本，不如说编排 design flow、补上 EDA 工具拒绝互通的断链——flow 跑不到端到端是设计耗时最大单一来源。商用 EDA 工具封闭，留白处只能手写胶水（Makefile 目标、Tcl 驱动、SKILL 封装），而这恰是 LLM 最擅长的小型"意图→代码"合成。这把 EDA scripting 重新定义为让通用 coding agent 天生编排 flow、在工具停步处补断链的结缔组织。

We present \textbf{ZhuLong}, an execution-grounded LLM coding agent for PyAether, SKILL, and Tcl: four unified MCP tools \cite{lee2025autoeda} close a generate--execute--refine loop over four commercial runtimes, with offline \textbf{API self-exploration} as a bounded complement. We also give a \textbf{theoretical grounding} (Section~\ref{sec:grounding-theory}): EDA correctness is situated (L4), a layer that offline knowledge---and hence model scale---cannot reach; the grounding gap on L4 failures is bounded by observation fidelity.
% 我们提出 ZhuLong，面向 PyAether、SKILL、Tcl 的执行接地 LLM coding agent：四个统一 MCP 工具在四个商业运行时闭环"生成–执行–修正"，并以离线 API 自探索为有界补充。
% 理论论证（§4）：EDA 正确性是情境化属性（L4），是离线知识——因而也是模型规模——无法触及的层；我们论证 L4 失败上的落地鸿沟受观测保真度约束，这是可被实验反驳的预测而非事后解释。

We name the system \emph{ZhuLong}, after the Chinese mythological creature whose open eyes bring day and closed eyes bring night: for an LLM, EDA's long-tailed, under-documented API ecosystem is that night, execution read-back is the opened eye, and $\epsilon$ is how clearly it sees. Grounding a general coding agent in a domestic full-custom platform (PyAether for Empyrean Aether) alongside SKILL and Tcl is a necessary step toward end-to-end-operable EDA flows.

% PREPRINT-ONLY (remove for double-blind): ZhuLong is named after the red dragon of Chinese mythology---red for contemporary China, dragon for its heritage---and is grounded in a domestic EDA platform, reflecting our commitment to AI-native EDA on domestic toolchains.
% 命名 ZhuLong 取自中国神话"开目为昼、闭眼为夜"的烛龙：对 LLM，EDA 长尾、文档不全的 API 生态即那个夜，执行回读即睁开的眼，ε 即看得多清楚。将通用编码智能体落在国产全定制平台（PyAether for Empyrean Aether）并兼容 SKILL/Tcl，是通往端到端可操作 EDA flow 的必要一步。

\noindent\textbf{Contributions.}
\begin{itemize}
    \item \textbf{RQ1 (binding constraint).} We formalize the grounding gap and measure both
    axes it depends on: with the LLM fixed, the system-level observation axis (pure LLM, no
    observation $\to$ full system) spans 57.2~pp; with the harness fixed, the backbone axis
    spans 23.7~pp, while model scale still sets the L1--L3 ceiling
    (Section~\ref{sec:grounding-theory}, \ref{sec:experiments}).
    % RQ1（binding 约束）：形式化落地鸿沟，测量其依赖的两条轴——固定 LLM 时，系统级观测轴（纯 LLM 无观测→完整系统）跨 57.2pp；固定 harness 时，backbone 轴跨 23.7pp，模型规模仍决定 L1–L3 上限。

    \item \textbf{RQ2 (necessary components).} Ablation shows retrieval and execution are statistically necessary (both effects exclude zero) and belief update is monotone in the execution budget, while self-exploration is a cost-negative prior-side aid rather than a substitute (Section~\ref{sec:experiments}).
    % RQ2（必要组件）：消融表明检索与执行统计上必要（效应均排除 0）、信念更新随执行预算单调，而自探索是成本为负的先验侧辅助而非替代。

    \item \textbf{RQ3 (toolchain generality).} \textbf{EDA-Scripting-Bench} (449 tasks, 4
    runtimes, one schema) re-measures the same structure slice by slice; we specify the
    harness, schema, and assertion protocol in full (Section~\ref{sec:benchmark}).
    % RQ3（工具链通用性）：EDA-Scripting-Bench（449 任务、4 运行时、单一 schema）逐切片重测同一结构；完整规范 harness、schema 与断言协议，使基准可在其他工具链上重新实例化。
\end{itemize}
