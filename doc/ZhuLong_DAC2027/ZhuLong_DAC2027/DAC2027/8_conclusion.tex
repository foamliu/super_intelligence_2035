\section{Conclusion and Future Work}
\label{sec:conclusion}

ZhuLong reframes EDA scripting as the connective tissue that makes design flows runnable end-to-end: a general coding agent orchestrates flows natively and, where closed EDA tools leave gaps, synthesizes the missing glue. The execution-grounded loop and the grounding-gap framework explain why this works: on L4 failures---those that offline knowledge, and hence model scale, cannot reach---the gap is bounded by observation fidelity, while model scale continues to set the L1--L3 ceiling. The full system reaches \textbf{76.9\%} pooled Pass@1. Future work: (i) domain-specializing the harness, (ii) long-term memory and recursive self-improvement (RSI), (iii) multimodal grounding, and (iv) benchmarking design-flow orchestration.
