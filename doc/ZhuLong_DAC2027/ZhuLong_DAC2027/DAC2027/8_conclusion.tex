\section{Conclusion and Future Work}
\label{sec:conclusion}

ZhuLong reframes EDA scripting as the connective tissue that makes design flows runnable end-to-end: a general coding agent orchestrates flows natively and, where closed EDA tools leave gaps, synthesizes the missing glue. The execution-grounded loop and the grounding-gap bound on observation fidelity---not model scale---explain why this works; the full system reaches \textbf{76.9\%} pooled Pass@1. Future work: (i) domain-specializing the harness, (ii) long-term memory of verified API constraints, (iii) multimodal grounding, and (iv) benchmarking design-flow orchestration.
