\section{Conclusion and Future Work}
\label{sec:conclusion}

ZhuLong reframes EDA scripting as the connective tissue of design-flow orchestration: a general coding agent orchestrates flows natively, and where closed tools leave gaps, its EDA-scripting ability synthesizes the missing glue. The execution-grounded loop and the grounding-gap bound (observation fidelity, not model scale; Section~\ref{sec:grounding-theory}) explain why this works: EDA correctness is situated, so the agent must read the environment's API facts and read back its code's effect on the live design. The complete system reaches 75.7\% pooled Pass@1 and is deployed in production EDA flows at a leading memory design house---making design flows runnable end-to-end, not writing more scripts. Three directions invite future work: (i) \emph{domain-specializing the harness}---context compression and retrieval tailored to EDA's long-tailed, stateful APIs, where generic token-budget heuristics leave the agent re-reading the same docstrings across rounds; (ii) \emph{long-term memory and self-evolution}---accumulating verified API constraints and repair patterns across runs so the agent starts each task with prior knowledge rather than rediscovering it; (iii) \emph{multimodal grounding}---reading schematics, waveforms, and layout images alongside text, extending $\Omega$ beyond what code execution returns.
