\section{Conclusion and Future Work}
\label{sec:conclusion}

ZhuLong reframes EDA scripting as the connective tissue that makes design flows runnable end-to-end rather than an end in itself: a general coding agent orchestrates flows natively and, where closed EDA tools leave gaps, synthesizes the missing glue. The execution-grounded loop and the grounding-gap bound on observation fidelity---not model scale---explain why this works. The full system reaches \textbf{76.9\%} pooled Pass@1 on \textbf{EDA-Scripting-Bench}. Four directions invite future work: (i) \emph{domain-specializing the harness}; (ii) \emph{long-term memory} that accumulates verified API constraints; (iii) \emph{multimodal grounding}; and (iv) \emph{benchmarking design-flow orchestration}, so the connective-tissue claim can be measured rather than only asserted.
