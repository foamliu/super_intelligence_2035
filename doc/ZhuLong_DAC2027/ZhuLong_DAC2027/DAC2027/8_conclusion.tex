\section{Conclusion and Future Work}
\label{sec:conclusion}

\textbf{ZhuLong} is an execution-grounded LLM coding agent for PyAether, SKILL, and Tcl that closes the generate--execute--refine loop via sandbox feedback. Its theoretical grounding---EDA correctness is a situated (L4) property, and the grounding gap is bounded by observation fidelity, not model scale---explains why runtime observation is necessary. On \textbf{EDA-Eval-PyAether} (158 real-world tasks), the complete system achieves 81.4\% Pass@1 ($\pm$1.5), substantially outperforming static RAG (72.2\%); ablation shows execution and retrieval are jointly necessary. This work establishes three foundations: (1)~the grounding-gap theory, (2)~the execution-grounded agent paradigm generalizable to other long-tail-API domains, and (3)~\textbf{EDA-Scripting-Bench} (449 tasks across three toolchains) as evaluation infrastructure. The harness, task schema and protocol will be released.

Future work proceeds along three directions. First, extending all ablation axes to the full EDA-Scripting-Bench (PyAether + SKILL + Tcl, 449 tasks), together with extending the benchmark to systematically cover GUI-bridged tasks on open design sessions. Second, evolving the agent through self-improvement—learning from both successful and failed execution traces to refine its retrieval, code generation, and exploration strategies. Third, adapting the architecture to additional EDA platforms, including Synopsys tools with Tcl scripting, to broaden the scope of execution-grounded EDA agents.
