\section{Conclusion and Future Work}
\label{sec:conclusion}

Beyond the benchmark numbers, ZhuLong reframes EDA scripting as the connective tissue of design-flow orchestration: a general coding agent orchestrates flows natively, and where closed tools leave gaps, its EDA-scripting ability synthesizes the missing glue---precisely where design engineers lose the most time. The execution-grounded loop and the Bayesian argument bounding the grounding gap by observation fidelity, not model scale, explain why this works: EDA correctness is situated, so the agent must read the environment's API facts and read back what its code does to the live design. The complete system reaches 75.7\% pooled Pass@1 and is deployed in production EDA flows serving hundreds of engineers at a leading memory design house---evidence that the value lies not in writing more scripts but in making design flows runnable end-to-end. Future work will complete the RQ1--RQ3 structure on the SKILL and Tcl slices, extend the benchmark to GUI-bridged tasks, and adapt the architecture to further EDA toolchains.
