\section{Conclusion and Future Work}
\label{sec:conclusion}

ZhuLong reframes EDA scripting as the connective tissue of design-flow orchestration: a general coding agent orchestrates flows natively, and where closed tools leave gaps, its EDA-scripting ability synthesizes the missing glue. The execution-grounded loop and the grounding-gap bound (observation fidelity, rather than model scale; Section~\ref{sec:grounding-theory}) explain why this works: EDA correctness is situated, so the agent must read the environment's API facts and read back its code's effect on the live design. The complete system reaches 76.9\% pooled Pass@1 and is deployed in production EDA flows at a leading memory design house---making design flows runnable end-to-end, not writing more scripts. Four directions invite future work: (i) \emph{domain-specializing the harness} (retrieval and context compression tailored to EDA's long-tailed, stateful APIs); (ii) \emph{long-term memory and self-evolution} (accumulating verified API constraints across runs); (iii) \emph{multimodal grounding} (schematics, waveforms, and layout images extending $\Omega$); and (iv) \emph{benchmarking design-flow orchestration} (end-to-end flow metrics, so the connective-tissue claim can be measured rather than only asserted).
