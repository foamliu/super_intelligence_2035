\section{Conclusion and Future Work}
\label{sec:conclusion}

Beyond benchmark numbers, ZhuLong reframes EDA scripting as the connective tissue of design-flow orchestration: a general coding agent orchestrates flows natively, and where closed tools leave gaps, its scripting ability synthesizes the missing glue. The execution-grounded loop and the grounding-gap bound (observation fidelity, not model scale; Section~\ref{sec:grounding-theory}) explain why: correctness is situated, so the agent must read the API facts and read back its code's effect on the live design. The complete system reaches 75.7\% pooled Pass@1 and is deployed in production EDA flows serving hundreds of engineers at a leading memory design house---making design flows runnable end-to-end rather than requiring more scripts. Future work will complete the RQ1--RQ3 structure on the SKILL and Tcl slices, extend the benchmark to GUI-bridged tasks, and adapt the architecture to further toolchains.
