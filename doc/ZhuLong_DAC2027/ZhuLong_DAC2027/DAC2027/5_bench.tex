\section{Benchmark Construction}
\label{sec:benchmark}

\subsection{Dataset: EDA-Scripting-Bench}

\textbf{EDA-Scripting-Bench} is the instrument for both of this paper's comparisons: within one toolchain, the effect of each grounding component, and across toolchains, the effect of language structure. It covers PyAether, SKILL, and Tcl on four commercial runtimes, \textbf{449 tasks} in four slices (Table~\ref{tab:benchmark-composition}), all specified by one schema---a target language and runtime, a natural-language prompt, a function signature, and language-appropriate assertions---so a single harness (Section~\ref{sec:agent-workflow}) scores all four platforms uniformly. Scoring is execution-based (a task passes only when the generated code acts correctly in the live runtime), and the cross-language slices are difficulty-controlled by construction (Section~\ref{sec:benchmark-slices}). Each task is a real break in a design flow where a closed tool stops and glue must be hand-written.
% EDA-Scripting-Bench：449 任务、四切片、单一 schema（语言/运行时/提示/签名/断言），单一框架统一评分。执行式评分；跨语言切片构造上控难度。每任务是设计流中"封闭工具停步、需手写胶水"的真实断链——本文所瞄 flow 编排断链的微缩切片。

\subsection{The PyAether slice (EDA-Eval-PyAether)}

The reference slice, \textbf{EDA-Eval-PyAether} (158 tasks), anchors every task to a concrete PyAether API; EDA experts curated each assertion to be self-contained and executable in a clean sandbox without vendor-internal context. Tasks span layout, schematic, and design-management workflows, compose several distinct APIs, and sometimes depend on a technology library, so passing reflects command of the tool's behavior, not surface retrieval.
% 参照切片 EDA-Eval-PyAether（158 任务）：每任务锚定一个 PyAether API，专家确保断言自包含可在干净沙盒执行。覆盖 layout/schematic/design-management 工作流，组合多 API，部分依赖工艺库——通过反映对工具行为的真正掌握。

\subsection{SKILL and Tcl slices}
\label{sec:benchmark-slices}

The remaining slices are built so cross-language scores are comparable. \textbf{EDA-Eval-Skill} (157 SKILL tasks on Cadence Virtuoso) is \emph{function-aligned} with PyAether: each task re-implements the same entry point and functional specification as its PyAether counterpart, holding difficulty fixed. The \textbf{Tcl} slices are graded by difficulty across two further toolchains: waveform measurement on WaveView (\textbf{EDA-Eval-WaveViewTcl}, 77 tasks) and floorplanning, placement, and routing on Innovus (\textbf{EDA-Eval-InnovusTcl}, 57 tasks), so the cross-language comparison (Section~\ref{sec:cross-language}) attributes score differences to language structure rather than task hardness.
% 其余切片为跨语言可比性而建。EDA-Eval-Skill（157 SKILL）与 PyAether 函数级对齐，固定难度。Tcl 切片按难度分级跨两工具链：WaveView 波形测量（77）、Innovus floorplan/place/route（57），使跨语言比较将分差归因于语言结构而非难度。

\subsection{Evaluation Protocol}

A task passes if the generated code executes in its target runtime sandbox without errors and all assertions hold; the primary metric is Pass@1 \cite{chen2021evaluating}, reported as mean $\pm$ s.d.\ over five independent runs (reshuffled task orderings, fresh agent contexts), per slice and pooled over all 449 tasks.
% 评测协议：代码在目标运行时沙盒无错执行且所有断言通过即 pass；主指标 Pass@1，5 次独立运行均值±标准差，分切片与 449 合并。
