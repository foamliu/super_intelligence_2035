\begin{abstract}
    Design engineers lose the most time orchestrating flows and patching the gaps
    where closed EDA tools refuse to interoperate. We present \textbf{ZhuLong}, an
    execution-grounded LLM agent for PyAether, SKILL, and Tcl that closes a
    generate--execute--refine loop over unified MCP tools (API retrieval,
    documentation, sandbox execution), with a \emph{grounding-gap framework} arguing
    EDA-scripting correctness is bounded by \emph{observation fidelity}, not model
    scale. On \textbf{EDA-Scripting-Bench} (449 tasks, three languages, four
    commercial runtimes), ZhuLong reaches \textbf{76.9\%} pooled Pass@1 versus
    \textbf{19.7\%} (pure LLM)---a $57.2$~pp observation-fidelity swing exceeding
    the $23.7$~pp backbone range; ZhuLong is deployed in production EDA flows.
\end{abstract}
