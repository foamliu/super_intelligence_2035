\begin{abstract}
    Design engineers lose the most time orchestrating flows and patching the gaps
    where closed EDA tools refuse to interoperate. We present \textbf{ZhuLong}, an
    execution-grounded LLM agent for PyAether, SKILL, and Tcl that closes a
    generate--execute--refine loop over unified MCP tools (API retrieval,
    documentation, sandbox execution) and is already deployed in production EDA
    flows, with a \emph{grounding-gap framework} positing that EDA-scripting
    correctness is bottlenecked by \emph{observation fidelity} at the L4
    (situated) layer, which model scale alone cannot reach. On
    \textbf{EDA-Scripting-Bench} (449 tasks, three languages, four
    commercial runtimes), ZhuLong reaches \textbf{76.9\%} pooled Pass@1 versus
    \textbf{19.7\%} (pure LLM): the controlled read-back ladder (no read-back
    $\to$ binary $\to$ full observation, LLM fixed) spans $7.1$~pp pooled (binary
    adds $1.2$~pp), while the system-level observation axis (pure LLM $\to$ full
    system) spans $57.2$~pp with the model fixed, exceeding the $23.7$~pp
    backbone range with the harness fixed---two axes answering different
    questions; observation is under-invested with measurable, graded returns.
\end{abstract}
