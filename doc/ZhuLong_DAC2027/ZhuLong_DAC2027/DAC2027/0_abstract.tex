\begin{abstract}
    Design engineers lose the most time not writing fresh scripts but orchestrating
    design flows and patching the gaps where closed EDA tools refuse to interoperate---a
    flow that cannot run end-to-end is the top reason a design stalls. We argue that
    this is exactly where a general coding agent fits: it orchestrates flows natively
    (Makefile targets, Tcl drivers, scheduling scripts), and where tools leave gaps,
    its EDA-scripting ability synthesizes the missing glue---the kind of small,
    intent-to-code task at which LLMs excel. We present \textbf{ZhuLong}, an
    execution-grounded LLM coding agent for PyAether, SKILL, and Tcl that couples API
    retrieval, documentation inspection, and sandbox execution via unified MCP tools
    into a closed generate--execute--refine loop, with a theoretical grounding showing
    EDA correctness is a \emph{situated} property whose ``grounding gap'' a Bayesian
    argument bounds by \emph{observation fidelity}, not model scale. On
    \textbf{EDA-Scripting-Bench} (449 real-world tasks, three languages, four
    commercial runtimes), ZhuLong reaches \textbf{75.7\%} pooled Pass@1 vs.
    \textbf{18.3\%} (pure LLM) and \textbf{62.5\%} (retrieval-only); with the LLM fixed,
    the observation-fidelity axis (no observation $\to$ full observation) spans 57.4~pp,
    22.0~pp. ZhuLong is already deployed in production EDA flows serving hundreds of
    engineers at a leading memory design house. This reframes EDA scripting as the
    connective tissue that makes design flows runnable, not an end in itself.
\end{abstract}
