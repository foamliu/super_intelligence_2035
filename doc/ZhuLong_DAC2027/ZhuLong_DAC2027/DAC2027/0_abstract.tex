\begin{abstract}
    EDA scripting with tool-specific, often undocumented APIs remains a long-tail bottleneck. We present \textbf{ZhuLong}, an execution-grounded LLM coding agent for PyAether, SKILL, and Tcl that combines API retrieval, documentation inspection, and sandbox execution via unified MCP tools into a closed generate--execute--refine loop. We formalize the ``grounding gap'': EDA correctness is a \emph{situated} property that cannot be guaranteed from static knowledge, bounded by observation fidelity---not model scale.
    
    On \textbf{EDA-Eval-PyAether} (158 real-world tasks), the complete system achieves \textbf{81.4\%} Pass@1 ($\pm$1.5), outperforming a pure LLM baseline (\textbf{10.5\%}). Ablation shows the execution loop is decisive: adding sandbox execution to retrieval yields +9.2~pp, while removing it ($-9.2$~pp) or retrieval ($-0.4$~pp) reduces accuracy---consistent with the theoretical prediction. A cross-language reproduction on the SKILL and Tcl slices of \textbf{EDA-Scripting-Bench} (449 tasks total) reproduces the same structure---the complete system is the top and the prior-only baseline the bottom on every language.
\end{abstract}

\keywords{LLM Agents for EDA, EDA Scripting, Code Generation, Sandbox Execution, Execution Grounding}
