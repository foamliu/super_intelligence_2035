\section{Discussion}
\label{sec:discussion}

The error analysis (Section~\ref{sec:error-analysis}) shows that 67\% of execution-stage failures are L4 (situated truthfulness) violations caused by undocumented API contracts and hidden type signatures, motivating type-aware retrieval and case-level knowledge distillation. More broadly, the dominance of sandbox execution ($+9.2$~pp) over static knowledge elevates execution grounding from an empirical observation to a structural principle: the grounding gap is bounded by observation fidelity, so execution channels---not larger priors---are the binding constraint for domains with long-tailed, under-documented APIs. This paradigm may generalize to other domain-specific scripting tasks with similar characteristics.

\subsection*{Limitations}
\label{sec:limitations}

Several limitations apply. (1)~Performance varies across base LLMs (60.1\%--83.3\%); the model remains a decisive factor. (2)~The interactive bridge is single-threaded. (3)~Main results are on the 158-task PyAether slice; the $\Omega$ and $\Phi$ axes are PyAether-only (cross-language component ablation in Section~\ref{sec:cross-language}). (4)~Benchmark size limits statistical power for small effects; we report McNemar/bootstrap for main contrasts but treat small gaps (e.g.\ $-0.4$~pp, $p{=}0.81$) as directional. (5)~The primary backbone is FP4-quantized; quantization effect is not ablated. (6)~Convergence-cost comparison is complete for (F) and (B) only; (N$'$) traces were discarded.
