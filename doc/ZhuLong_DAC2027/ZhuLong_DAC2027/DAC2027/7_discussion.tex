\section{Discussion}
\label{sec:discussion}

Section~\ref{sec:grounding-theory} elevates the error analysis of Section~\ref{sec:error-analysis} from observation to structural principle: in domains with long-tailed, under-documented APIs, the grounding gap is bounded by observation fidelity, so execution channels---not larger priors---are binding---a paradigm that may generalize to other domain-specific scripting tasks.
% §4 的理论刻画把错误分析从经验观察提升为结构原则（16:1x 微调压缩）：长尾、文档不全 API 的领域，落地鸿沟受观测保真度约束，执行通道——而非更大先验——才是约束所在。可推广到其他相似特征的领域特定脚本任务。

Three limitations: base-LLM performance varies significantly (53.7\%--75.7\% pooled) and the benchmark size limits power to certify small effects, so the self-exploration gain ($+3.1$~pp) is complementary, not headline. Offline self-exploration incurs a one-time upfront cost per API (amortized), and the interactive bridge is single-threaded, limiting concurrency. Per-slice dispersions can be large for ablated configurations (e.g., Tcl w/o Retrieval $\pm 13.8$), so slice-level comparisons need care; Pass@1 is assertion-based, certifying the code produces the effects the assertions check, not full functional equivalence.
% 三个局限（16:1x 微调压缩）。（一）不同基座 LLM 表现差异显著（53.7–75.7% 合并），评测集规模限制检验小效应的统计功效，故自探索增益（+3.1pp）作互补收益非头条。（二）离线自探索每 API 一次性预计算成本（后续摊销），交互桥单线程限制并发。（三）消融配置切片离散度可能很大（如 Tcl w/o Retrieval ±13.8），切片级比较需谨慎；Pass@1 基于断言，只证明代码产生断言所检查的效果，非完全功能等价。
