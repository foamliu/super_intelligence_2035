\section{Discussion}
\label{sec:discussion}

Section~\ref{sec:grounding-theory} elevates the error analysis of Section~\ref{sec:error-analysis} from observation to structural principle: in domains with long-tailed, under-documented APIs, execution channels are the binding constraint on L4 failures---those that offline knowledge, and hence a larger prior, cannot reach---while a stronger prior raises the L1--L3 ceiling without substituting for that observation. On the L4 failures that dominate this setting, full observation is both more accurate and cheaper than binary feedback (Section~\ref{sec:omega-fidelity}).
% §4 的理论刻画把错误分析从经验观察提升为结构原则：长尾、文档不全 API 的领域，执行通道是 L4 失败（离线知识、因而是更大先验触及不到的那一类）上的 binding 约束；而更强先验抬高 L1–L3 上限、不替代该观测。在本设定中 L4 失败占主导，全观测比二值反馈既更准又更省（§6.2）。

Three limitations. Base-LLM performance varies widely (53.2\%--76.9\% pooled)---itself consistent with the framework, since the $\mathcal{K}$ axis is what moves L1--L3---and the benchmark size limits power to certify small effects, so the self-exploration gain ($+2.4$~pp) and the binary-over-none read-back rung ($+1.2$~pp) are complementary rather than headline; self-exploration also costs a one-time pass per API, and the interactive bridge is single-threaded. Per-slice dispersions can be large (e.g., SKILL w/o Retrieval $\pm 9.4$), so slice-level comparisons need care, and the SKILL self-exploration regression ($-1.2$~pp) fits SKILL's smaller API surface---offline facts are often redundant with retrieval and crowd out task-relevant evidence. Pass@1 certifies only the effects its assertions check, not full functional equivalence. The system is deployed in production EDA flows, but deployment metrics and full details cannot be disclosed here.
% 三个局限。（一）不同基座 LLM 表现差异显著（53.2–76.9% 合并）——这本身与框架一致，因 K 轴正是移动 L1–L3 的因素——且评测集规模限制检验小效应的统计功效，故自探索增益（+2.4pp）与回读轴二值对无回读档（+1.2pp）作互补收益而非头条；自探索另需每 API 一次性预计算成本，交互桥单线程限制并发。（二）消融配置切片离散度可能很大（如 SKILL w/o Retrieval ±9.4），切片级比较需谨慎；SKILL 自探索回归 −1.2pp 机制推测：SKILL API 面较小，离线自探索事实多与检索冗余，挤占任务相关证据。（三）Pass@1 基于断言，只证明断言所检查的效果，非完全功能等价。系统已在生产 EDA 流程部署，但部署指标与完整细节此处不便披露。
