\section{Discussion}
\label{sec:discussion}

Section~\ref{sec:grounding-theory} elevates the error analysis of Section~\ref{sec:error-analysis} from observation to structural principle: in domains with long-tailed, under-documented APIs, the grounding gap is bounded by observation fidelity, so execution channels---not larger priors---are binding, and full observation is both more accurate and cheaper to operate than binary feedback (Section~\ref{sec:omega-fidelity}), a pattern for other scripting domains.
% §4 的理论刻画把错误分析从经验观察提升为结构原则：长尾、文档不全 API 的领域，落地鸿沟受观测保真度约束，执行通道——而非更大先验——才是约束所在；且保真度是打折买入的：全观测比二值反馈既更准又更省（§6.2）。可推广到其他相似特征的领域特定脚本任务。

Three limitations. Base-LLM performance varies widely (53.2\%--76.9\% pooled), and the benchmark size limits power to certify small effects, so the self-exploration gain ($+2.4$~pp) and the binary-over-none read-back rung ($+1.2$~pp) are complementary, not headline. Offline self-exploration costs a one-time pass per API, and the interactive bridge is single-threaded. Per-slice dispersions can be large (e.g., SKILL w/o Retrieval $\pm 9.4$); Pass@1 certifies only the effects its assertions check, not full functional equivalence. The SKILL self-exploration regression ($-1.2$~pp) fits SKILL's smaller API surface (offline facts duplicate retrieval). The system is deployed in production EDA flows, but deployment metrics and full details cannot be disclosed here.
% 三个局限。（一）不同基座 LLM 表现差异显著（53.2–76.9% 合并），评测集规模限制检验小效应的统计功效，故自探索增益（+2.4pp）与回读轴二值对无回读档（+1.2pp）作互补收益非头条。（二）离线自探索每 API 一次性预计算成本（后续摊销），交互桥单线程限制并发。（三）消融配置切片离散度可能很大（如 SKILL w/o Retrieval ±9.4），切片级比较需谨慎；Pass@1 基于断言，只证明代码产生断言所检查的效果，非完全功能等价。SKILL 自探索回归 −1.2pp 机制推测：SKILL API 面较小，离线自探索丰富的 L1–L3 事实多与检索冗余，额外上下文可能挤占任务相关证据。部署指标（采用/任务完成/工程师节省时间）受单独披露审查约束，将在扩展版报告。
