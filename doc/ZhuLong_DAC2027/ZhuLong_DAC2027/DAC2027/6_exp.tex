\subsection{Experimental Setup}
\label{sec:exp-setup}

\textbf{Research questions.} The framework of Section~\ref{sec:grounding-theory} makes three testable claims, one per RQ: \textbf{RQ1 (binding constraint)}---which axis, observation fidelity $\Omega$ or the prior $\mathcal{K}$, is binding, and over what range? (S1 varies $\Omega$, S3 varies $\mathcal{K}$; the two axes answer different questions and are reported as such.) \textbf{RQ2 (necessary components)}---do observation, execution, and belief update each matter, and can one substitute for another? (S2 varies the effector and update budget.) \textbf{RQ3 (toolchain generality)}---does the structure reproduce on another toolchain? (S4 re-runs S1--S2 on SKILL and Tcl.)
% 研究问题（框架三条可检验主张，一 RQ 一条）：RQ1 binding 约束——观测保真度 Ω 与先验 K 哪条轴是 binding、在什么区间？（S1 固定 LLM 变 Ω；S3 固定框架变 K；两轴回答不同问题，分别报告）。RQ2 必要组件——是否同时需观测/执行/持续信念更新，能否互换？（S2 变执行器与信念更新预算）。RQ3 工具链通用性——同结构能否在不同工具链复现？（S4 在 SKILL/Tcl 切片重跑 S1–S2）。

\textbf{Benchmark and protocol.} We evaluate on \textbf{EDA-Scripting-Bench} (449 tasks, Section~\ref{sec:benchmark}) using \textbf{Pass@1}: one trace per task (the agent may iterate within it via $\Phi$ but is never restarted), a 2500-second timeout, and a \texttt{PreToolUse} hook that enforces a tool whitelist, blocks shell/code-search tools, and confines file access to a fresh directory---identical in every configuration. Each configuration runs five times (reshuffled order, fresh contexts), reported as mean $\pm$ s.d. Task cases derive from non-redistributable vendor documentation (unlikely in public pretraining), and no third-party agent can run these runtimes without the MCP bridge, so baselines are tool-registration ablations of the same harness---enabling single-variable attribution.
% 评测集与协议（同前，未改动）。

\textbf{Configurations.} We isolate components by tool registration (a disabled tool is unregistered and invisible; the agent policy is held fixed), giving five configurations (Table~\ref{tab:main-ablation}): \emph{Pure LLM} (no retrieval, sandbox, or self-exploration), \emph{RAG} (retrieval + self-exploration, no sandbox; $=$ w/o-Sandbox), \emph{w/o Self-Expl.} (retrieval + sandbox), \emph{w/o Retrieval} (sandbox + self-exploration), and \emph{ZhuLong (Full)} (all three on). S1 probes the observation axes at their extremes; S2 bounds $\Phi$. All main experiments use DeepSeek-V4-Pro as the backbone; S3 evaluates five additional backbones under the identical harness.

\subsubsection{S1: Observation fidelity (RQ1)}
\label{sec:omega-fidelity}

Principle 2 predicts that with the model fixed, accuracy is bounded by the fidelity of $\Omega$ \emph{on the failures that require observing the live design}. \textbf{Documentation axis.} Holding the agent loop, effector, and LLM fixed, removing retrieval costs 10.7~pp pooled, but highly toolchain-specific: on PyAether the read-back channel partially substitutes for retrieval (sandbox introspection via \texttt{dir()}/\texttt{inspect}/\texttt{\_\_doc\_\_} rises from 49.0\% to 86.7\% of traces once retrieval is removed, reconstructing the API knowledge retrieval would return). Tcl substitutes likewise through its own enumeration channels---WaveView's \texttt{info commands} returns the full command surface in one call, and Innovus's \texttt{get\_db} probing enumerates attributes by trial and error---recovering the API surface but not its deep semantics, so removing retrieval there costs only $7.7$~pp. SKILL's sandbox has no such enumeration channel (\texttt{apropos}/\texttt{describe} fail), leaving only \texttt{boundp}/\texttt{isCallable} existence checks on guessed names, so the API surface cannot be systematically rediscovered and retrieval there is not replaceable ($15.1$~pp). Retrieval is thus one \emph{implementation} of $\Omega$, not the channel itself.
% S1 观测保真度（RQ1）。原则 2 预测固定模型时准确率在"需要观测实时设计"的失败上受 Ω 保真度约束。文档轴（同前）。

\textbf{Read-back axis.} The second axis is how much of the live state execution returns. We compare three closed-loop variants differing only here (Table~\ref{tab:omega}, lower block): (N$'$) \emph{no read-back}---\texttt{run\_code} executes but returns nothing; (B) \emph{binary feedback}---pass/fail only; (F) \emph{full observation}---stdout, traces, per-assertion outcomes, and queried state (the default). The predicted monotone ordering N$'$ $<$ B $<$ F holds pooled and on the two largest slices, though on PyAether the middle rung is narrow ($+1.2$~pp, within one combined s.d.): a bare pass/fail verdict adds little actionable information, and the F rung carries almost the whole ladder ($+7.9$~pp of the $9.1$~pp N$'$-to-F gap). On Tcl it inverts at the middle rung, because Tcl scripts are short and near-single-shot, largely solved from documentation, so a binary signal supplies no actionable information. Cost sharpens the reading (Table~\ref{tab:cost}): binary feedback is \emph{more} expensive than full observation in time, \texttt{run\_code} calls, input tokens, and total tool calls (634 vs.\ 464~s, 22.8 vs.\ 10.6, 887k vs.\ 710k, and 43.9 vs.\ 26.3 per task), emitting fewer output tokens (7.7k vs.\ 12.0k)---without actionable error information the agent probes blindly---while no read-back collapses cost ($253$~s, $1.1$ calls) together with accuracy. What the channel returns, not how often the agent acts, drives both. This is the $\epsilon$-axis the claim of Section~\ref{sec:bayesian} predicts tracks accuracy on L4 failures; the N$'$-to-F gap operationalizes the grounding gap as an accuracy difference.
% 回读轴（同前）。末句改为"在 L4 失败上预测准确率跟随 ε 轴"，限定适用范围。

\textbf{Self-exploration rung.} The top rung adds constraints discovered offline (Section~\ref{sec:selfdoc}); per the framework this enriches only the L1--L3 facts $\Omega$ can return, so it should move the result less than the channel's own fidelity. Removing it (retrieval and effector kept) drops Pass@1 from 82.5\% to 77.0\% on PyAether (76.9\% to 74.5\% pooled), a bounded prior-side complement rather than a substitute. Self-exploration is cost-negative at runtime (cutting net-active solve time by 28.1\%, see Table~\ref{tab:cost}), whereas removing retrieval makes the agent fall back on sandbox introspection (2.1$\times$ the full system's time).

\subsubsection{S3: The prior axis (the prior-side contrast of RQ1)}
\label{sec:k-axis}

% 表~\ref{tab:llm-comparison} 未改动，原样保留。

Principle 1 separates knowledge from belief: the frozen prior sets the L1--L3 ceiling a harness can reach without substituting for observation. Table~\ref{tab:llm-comparison} changes only $\mathcal{K}$ (the LLM) with the harness fixed; DeepSeek-V4-Pro is the primary backbone, yet the backbone remains decisive---even with retrieval, sandbox, and self-exploration in place, the strongest-to-weakest spread is 23.7~pp pooled. Read against Principle 2, this spread is what the $\mathcal{K}$ axis can move; it raises the L1--L3 ceiling but cannot reach L4, so it does not substitute for observation. The system-level observation axis spans 57.2~pp against a 23.7~pp backbone range---two axes answering different questions (how much observation buys at a fixed model versus how much a stronger prior buys under full observation), whose relative magnitude places observation as the binding constraint in the current model-capability regime, without implying that it dominates at all scales or on all task distributions. GLM-5.3-Flash beats the primary on PyAether yet loses $2.4$~pp pooled---slice-level snapshots can invert backbone rankings, itself an argument for the pooled protocol.
