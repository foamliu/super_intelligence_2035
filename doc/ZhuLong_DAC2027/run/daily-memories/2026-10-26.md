### 根因（运维 10-26 修复未生效的真因）

运维 10-26 令 ①2 说「已把 `~/.zhulong/settings/providers.json`（正确值）复制到 `~/.zhulong/data/settings/providers.json`（run_cli.sh 复制源）」。**这个假设是错的** —— `run_cli.sh` 实际复制源是 `${CLI_DATA_DIR}/settings/`，而 `CLI_DATA_DIR` 在 zhulong 跑时解析为 `~/.cline/data`，不是 `~/.zhulong` 或 `~/.zhulong/data`。

**证据链**：
1. `eda_fastmcp/.env` line 215：`CLI_DATA_DIR=$HOME/.cline/data`
2. `run_zhulong_script.sh` line 17：`set -a; source "${PROJECT_DIR}/.env"` → 加载 .env，`CLI_DATA_DIR` 被设为 `~/.cline/data`（set -a 自动 export）
3. `run_zhulong_script.sh` line 28：`export CLI_DATA_DIR=${CLI_DATA_DIR:-$HOME/.zhulong}` → `:-` 只在「未设」时取默认；此处 `CLI_DATA_DIR` 已被 .env 设为 `~/.cline/data` → **保持 `~/.cline/data`**，`~/.zhulong` 默认值从不触发
4. `run_cli.sh` line 37：`CLI_DATA_DIR="${CLI_DATA_DIR:-$HOME/.cline/data}"` → 已设，保持 `~/.cline/data`
5. `run_cli.sh` line 85-86（并行模式）：`if [[ -d "${CLI_DATA_DIR}/settings" ]]; then cp -r "${CLI_DATA_DIR}/settings" "${worker_dir}/data/"; fi` → 从 `~/.cline/data/settings/` 复制（= `deepseek-v4-pro + 16384 + /cloud/v1`，stale）
