2. 改动摘要（按模块）

2.1 S1 保真度轴 —— Ω 文档轴（检索降保真）

server/rag_server/query_knowledge.py 新增 OMEGA_FIDELITY（读 EDA_OMEGA_FIDELITY，缺省 high）。当 low 时：search_apis 跳过双向缩写展开与 BM25 描述补充、结果经 _omega_strip() 只留 api_name + similarity；search_apis_by_keyword 跳过语义重定向、只保留名称类命中。

2.2 S1 保真度轴 —— readback 回读轴（执行结果降保真）

tools/run_code.py 新增 _apply_readback()，按 EDA_RUNCODE_READBACK ∈ {full, binary, none} 压缩回给 agent 的观测：full 完整、binary 只回 PASS/FAIL、none 只回 "executed"。代码照常执行，仅「回传观测」被降保真。

2.3 S2 Φ 轴 —— 预算 k 上限（hook 侧拦截）

scripts/cline_hooks/PreToolUse 在反作弊 hook 之后追加 Φ budget 钩子：读 EDA_PHI_BUDGET=k（≤0 = 无限），对 run_code 按 task/session 归零计数（/tmp/cline_phi_budget_<uid> + fcntl.flock）；超预算用 overrideInput 把 run_code 改写为 print('[PHI-BUDGET-EXHAUSTED] k=N') no-op——不 cancel、不断 trace。

2.4 S2 Φ 轴 —— 滞后回读（handler 侧，L=1）

tools/run_code.py 拆为 _run_code_inner() + 入口，EDA_PHI_LAGGED=1 时 _phi_lagged_apply() 返回上一拍状态（单槽 L=1），并带 reported_call_index 审计滞后量 =1。main.py 注入 ctx，用 SSE ServerSession 对象本身作 dict 键（替换旧 id(session)）修复「旧 session GC 后地址复用的跨任务串槽」根因。

2.5 trace 元数据（S2 Φ 轴审计）

memory_bank/trace_parser.py 新增 _trace_to_text()（整 trace 打平检索）、extract_hook_denial()（拒绝归因 phi_budget/anti_cheat）、extract_phi_metadata()（finish_reason / timed_out / 各类调用计数 / reported_call_index[]），并给 _parse_cline_tool_result() 增加 tool 与 reported_call_index。
