6. 沙箱阻断说明（预期行为，非故障）

S1 每轮都出现 3–4 个唤醒周期的 run_commands 返回 ACCESS RESTRICTED、read_files 读工作区外返回 /dev/null， 随后自动复通。这是 eval cline 活跃期间反作弊 PreToolUse hook 的正常拦截——agent 按「pgrep 有输出 → 什么都不做，退出」处理即可，wait 至下一唤醒周期。conductor loop 的 30min 间隔正是用于消化这一自然过程，无需人工干预，切勿重复启动同一轮。
