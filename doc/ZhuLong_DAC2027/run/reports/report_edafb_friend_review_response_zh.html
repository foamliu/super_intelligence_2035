R1 · H1c 定义漏洞采纳 判据层 已落

研判理由：评审逻辑成立。session 内 in-context learning 确实构成短期记忆，原判据无法干净分离「跨 session 长期记忆」与「session 内自改进」两个变量。精确化为「跨 session」口径既消除伪证伪风险，又保留可证伪性，且为零成本（设计层措辞，不重跑）。
