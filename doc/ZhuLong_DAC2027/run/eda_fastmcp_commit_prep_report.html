2. 改动明细（按模块）

2.1 S1 保真度消融 —— Ω 文档轴（检索降保真）

server/rag_server/query_knowledge.py（+39）新增 OMEGA_FIDELITY（读 EDA_OMEGA_FIDELITY，缺省 high）。当 low 时：

  • search_apis：跳过双向缩写展开，直接用原始 query 召回；跳过 BM25 描述补充；结果经 _omega_strip() 剥离到只留 api_name + similarity（丢弃 description）。
  • search_apis_by_keyword：跳过自然语言语义重定向；结果只保留名称类命中（name_overlap / exact_match）并剥离为 name+similarity。

语义：在「工具全开」前提下只降文档保真度，agent 只能看到 API 名字 + 相似度，看不到描述性文档——这是 Ω 轴要测的效应。

2.2 S1 保真度消融 —— readback 回读轴（执行结果降保真）

tools/run_code.py 新增 _apply_readback()，按 EDA_RUNCODE_READBACK ∈ {full, binary, none} 压缩回给 agent 的观测：

  • full：完整结果（缺省，上游行为）。
  • binary：只回 PASS / FAIL（据 error_log 是否为空判定），不回 error_log/print_log/result。
  • none：只回 "executed"。

代码照常执行、error_log 照常在 sandbox 侧产生，只有「回给 agent 的观测」被降保真。

2.3 S2 Φ 轴消融 —— 预算 k 上限（hook 侧拦截）

scripts/cline_hooks/PreToolUse（+133）在反作弊 hook 之后追加 Φ budget 钩子（与反作弊共存）：

  • 读 EDA_PHI_BUDGET=k（≤0 或未设 = 无限）。对 run_code 按 taskId/sessionContext.rootSessionId → workspace → cwd 归零计数，计数文件在 /tmp/cline_phi_budget_<uid>（fcntl.flock 防并发）。
  • 超预算（count > k）时用 overrideInput 把 run_code 的 code 改写为 print('[PHI-BUDGET-EXHAUSTED] k=N') 的 no-op——绝不 cancel、绝不中断 trace；marker 落入结果 print_log，供 trace 元数据核对。

预算约束的是「agent 能观测/执行多少次 run_code」，而非「何时提交」，故不改写任务、不打断 trace。

2.4 S2 Φ 轴消融 —— 滞后回读（handler 侧，L=1）

tools/run_code.py + main.py：

  • run_code.py 拆为 _run_code_inner()（真实执行）+ run_code()（入口）。EDA_PHI_LAGGED=1 时 _phi_lagged_apply() 返回上一拍执行状态（单槽 L=1，非队列），第 1 次返回占位 [PHI-LAGGED] no prior state；结果带 reported_call_index 用于审计滞后量恰好 =1。
  • main.py 给 run_code 注入 ctx: Context，新增 _trace_key_from_ctx()：用 SSE ServerSession 对象本身作 dict 键（按对象身份哈希）而非 id(session)。修复根因：旧 id() 是内存地址，旧 session 被 GC 后新 session 可能复用同一地址 → lagged 槽位跨任务串槽、滞后作废。

2.5 trace 元数据（S2 Φ 轴审计）

memory_bank/trace_parser.py（+98）新增：

  • _trace_to_text()：整条 trace 打平为可检索文本（捕获 hook 拒绝标记的任意嵌套位置）。
  • extract_hook_denial()：归因被哪个 hook 拒绝（phi_budget / anti_cheat）及拒绝原因片段。
  • extract_phi_metadata()：汇总 finish_reason / timed_out / run_code_calls / search_apis_calls / get_api_details_calls / denied_by_hook / reported_call_index[]。
  • _parse_cline_tool_result() 增加 tool 与 reported_call_index 字段（解析 lagged 回读来源序号）。
