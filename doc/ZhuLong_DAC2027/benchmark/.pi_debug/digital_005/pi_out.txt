## Final proc definition

```tcl
proc inn_count_nets {} {
    return [llength [dbGet top.nets]]
}
```

### Why this works
- `dbGet top.nets` returns a Tcl list of the net dbObjects in the top cell `C1` (including the 2 power/ground SPECIALNETS as well as the 1915 regular NETS, since `top.nets` covers all nets at that level).
- `llength` counts the list elements, yielding an integer. For an empty design, `dbGet` returns an empty list and `llength` returns `0`, satisfying the "0 nets" requirement.
