# Task
Implement `proc pattern_speed_weekly_stats {manifest} { ... }` in Tcl per this spec:

You are analyzing pattern-simulation AVC files from a DDR memory verification flow. Given a manifest of `.avc` pattern files (each record is a 4-element list `{name folder_exists folder_files mtime}`), compute weekly pattern-speed statistics with STRICT folder validation.

Rules:
1. A pattern's SPEED is the SECOND-TO-LAST `_`-delimited field of the avc basename (strip the `.avc` extension first).
   - `pattern_simulation_16Gb_LP6_Fix_10667_001.avc` -> speed `10667`
   - `pattern_simulation_16Gb_LP6_Fix_9600_0928_9600_996.avc` -> speed `9600` (NOT 996)
   - `pat_8000_007.avc` -> speed `8000` (NOT 007)
   If the basename has fewer than 2 `_`-fields, count it as `no_speed` and skip it.
2. Folder validation - a pattern counts as a LEGAL/validated pattern ONLY IF ALL hold:
   - its matching folder exists (folder_exists = 1); otherwise -> `no_folder`, skip.
   - the folder is non-empty (folder_files is a non-empty list); otherwise -> `empty`, skip.
   - the folder does NOT contain ONLY `irun.log`. A folder whose single entry is exactly `irun.log` is a FAILED simulation with no compare result -> `only_irunlog`, skip. A folder containing `irun.log` PLUS any other file (e.g. A_Compare.rpt, B_Compare.rpt, ncsim.shm) is VALID.
3. For each VALID pattern: tally by speed, and group by ISO week of its mtime using `clock format $mtime -format %G-W%V -gmt 1` (yields labels like `2026-W34`). Track min/max mtime epoch among valid patterns.
4. Return a FLAT dict string (single line, space-separated `key value` pairs) with EXACTLY these keys in this order:
   total_avc total_valid num_no_folder num_only_irunlog num_empty num_no_speed time_span_lo time_span_hi speeds speed_totals weeks week_totals week_speed
   - total_avc = total records seen; total_valid = number of legal/validated patterns.
   - num_no_folder / num_only_irunlog / num_empty / num_no_speed = respective skip counts.
   - time_span_lo / time_span_hi = min / max mtime epoch among VALID patterns (empty string if no valid patterns).
   - speeds = valid speeds sorted NUMERICALLY ascending, space-separated.
   - speed_totals = `speed:count` for each valid speed, in the same numeric order, space-separated.
   - weeks = ISO-week labels sorted ascending (lexicographic == chronological), space-separated.
   - week_totals = `week:count` in week order, space-separated.
   - week_speed = `week:speed:count` sorted by week then speed, space-separated.
   Put scalar counts first; list-valued keys (speeds, speed_totals, weeks, week_totals, week_speed) last so each list value is terminated by the next key.

Use only Tcl builtins (no external packages). The manifest is a Tcl list of records; each record is a 4-element list `{name folder_exists folder_files mtime}` where folder_files is a Tcl list of filenames (possibly empty) and mtime is an integer epoch (seconds, UTC).
