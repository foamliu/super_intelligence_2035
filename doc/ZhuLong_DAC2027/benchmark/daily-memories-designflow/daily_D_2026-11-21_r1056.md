## produce-script
`parse_sp_netlist.py` CLI `<netlist.sp> [-o report.json]`:
- 解析 `.subckt`/`.ends` 块 (case-insensitive), 记录 ports + body
- X* → subckt call (inst=tokens[0], callee=tokens[-1])
- M* → MOS, R* → resistor, C* → capacitor
- top_cell = 最后定义的、不被任何其它 subckt 调用的 subckt (root of hierarchy)
- top 体内统计: mos_count / resistor_count / cap_count / total_instances
- subckt_call_counts: 全网表范围内 (top + 所有 subckt body) 每个 subckt 被 X* 调用总次数
- hierarchy_depth: BFS from top (top=1), max depth
- JSON 报告: {top_cell, subckts:[{name,ports,instances}], top_instances:[{name,type:"X",subckt}],
  mos_count, resistor_count, cap_count, total_instances, hierarchy_depth, subckt_call_counts}
