### 背景
r1274 发现 SineScanStdout-001（D shard waveform case）check.py 用 `subprocess.run(["wv","-ace_no_gui",...])` 本地调 wv binary，但 eval host 36.15 `which wv` = not found（tclsh 在）。run_one.sh 判分阶段本地跑 python3，不 ssh .75 → 真实判分时 `_run_wv` FileNotFoundError，(d) 起下游全 FAIL，**参考解也会被误判 FAIL**。这是 P0：一个 broken case 在评测中产生 false FAIL，污染 Pass@1 数据。

### 修法
照 WvSineWaveAnalyze-001（A shard）的 L2-static 模式：
1. 嵌入 `MOCK_SX_TCL` 常量（plain tclsh8.6 仿真 WaveView ACE `sx_*` API）：
   - `sx_add_wave name type` → 创建信号，返回 name
   - `sx_append_real sig x y` → 追加 (x,y) 数据点
   - `sx_scan_data_points sig POINT thr` → 创建 scan 游标（idx=-1）
   - `sx_jump_to_x scan FIRST|NEXT` → 移动游标，返回 1/0
   - `sx_x_value scan` / `sx_y_value scan real` → 取当前点 x/y
   - `sx_release scan` → 清理
   mock 忠实还原 WaveView POINT scan：候选 append 的数据按插入序被 scan 遍历，候选 proc 的 `puts "PT ..."` 和 `SINESCAN_OK` 输出正常出现在 tclsh stdout。
2. `_run_wv` → `_run_tclsh`（`["tclsh", driver]`，timeout 60s）
3. `_build_driver` 加 `source mock_sx.tcl` 前置
4. `_run_spec` 写 mock_sx.tcl 到 tmpdir
5. **14 条断言全保留**（a-n），逻辑、判分严格度、FORBIDDEN_REFS 全不变
