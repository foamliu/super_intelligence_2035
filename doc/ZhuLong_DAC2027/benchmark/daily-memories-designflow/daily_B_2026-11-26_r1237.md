### Mt0Reorg-001 详情
**问题 (P3 latent bug)**: check.py cond h (iddq/idda 绝对值, 禁负) 原实现:
```python
for c in cells[1:]:
    try:
        v = float(c)
        if v < 0:
            _fail("h", "negative %s value %s ..." % (...))
    except: pass          # <-- bare except 吞掉 _fail 抛的 AssertionError
```
`_fail` = `raise AssertionError(...)`. bare `except: pass` 把它一起抓了 -> cond h 永远不 fail = no-op。
负 iddq/idda 的退化提交会漏判 (假阴性风险, L3 牙口缺失)。

**修法** (只改返回/异常形状, 不动断言数与严格度, 反而让 h 真正生效):
```python
for c in cells[1:]:
    try:
        v = float(c)
    except ValueError:
        continue          # 非数字 token (blank/placeholder) 跳过
    if v < 0:
        _fail("h", "negative %s value %s ..." % (...))
```
