## 通用修法（供下轮复用）
1. **A 附件 path**: 用 `_resolve_a(workdir, *rel)` 多 fallback: `workdir/rel`(flat) → `workdir/assets/rel` → `../../assets/<cid>/rel` → `BENCH_CASES_DIR/../assets/<cid>/rel` → repo walk-up。**BENCH_CASES_DIR 指 cases/，必须加 `../assets/`**。
2. **A 子目录**: judge 布局不复制 A 子目录，只能经 `BENCH_CASES_DIR/../assets/<cid>/<subdir>` 或 repo walk-up 命中。
3. **candidate subprocess cwd**: 若 check.py 用 `subprocess.run(..., cwd=run_dir)` 跑 candidate 且传相对 path → **必须先 abspath**（否则相对路径解析到 run_dir 失败）。
4. **encoding**: check.py 不得含非 ASCII 字节（Python 3.9 ASCII env）；`≈`→`~`，`≥`→`>=`，`≠`→`!=`。
