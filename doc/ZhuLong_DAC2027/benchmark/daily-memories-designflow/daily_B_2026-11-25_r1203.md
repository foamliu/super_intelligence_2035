## 通用根因
judge 布局 workdir='.', check.py 在 $JUDGE/g1/g2/check.py。两种 path bug:
1. **A 子目录不可达**: run_one.sh 只 symlink A 顶层文件 + hidden 到 $JUDGE/assets/<cid>/,
   不复制子目录 (v5_all / matrix_run_A)。check.py 用 HERE/../../assets/<cid>/<subdir> →
   $JUDGE/assets/<cid>/<subdir> 不存在 → FileNotFoundError / 空数据 → KeyError crash。
2. **walk-up 从 FILE 起步**: Wtm 的 _bench_root() 用 os.path.abspath(__file__) (FILE 非 dir)
   做 walk-up, iter0 检 <file>/assets 无意义, 且误匹 /tmp/assets+/tmp/reference 残留 → 返 /tmp。

## 通用修法
1. **iso harness 设 BENCH_CASES_DIR env**: _iso_runner.py + lite_verify_judge_B.py 顶部
   `os.environ.setdefault("BENCH_CASES_DIR", .../benchmarks/EDA-Eval-DesignFlow/cases)`,
   镜像 run_one.sh 真实 eval 环境。
2. **check.py 路径改多 fallback resolver** (_assets_root()/_hidden_dir()):
   (a) BENCH_CASES_DIR env → ../assets/<cid>  (real eval, repo 在 eval 机)
   (b) HERE/../../assets/<cid>  (repo layout, selftest from reference/<cid>/)
   (c) HERE/hidden judge symlink  (hidden only)
   (d) walk-up 8 级找 benchmarks/EDA-Eval-DesignFlow/assets/<cid>
