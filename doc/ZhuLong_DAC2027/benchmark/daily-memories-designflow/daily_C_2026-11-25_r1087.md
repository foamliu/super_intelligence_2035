### 实测结论（.75 真实 skipper 2020.06.sp3）

1. TEXT 元素的 purpose = **COLROW 记录值**（rt 0x16），不是 TEXTTYPE (0x0F)。
   - 探针 TEXT@L99 COLROW=5 → dbLibLayers 报 `99.5`
   - 探针 TEXT@L100 COLROW=0 → 报 `100.0`
2. skipper 拒绝 TEXT 里的 TEXTTYPE 记录：
   `Purpose type is not expected: 15, 22 (expected)`（15=0x0F TEXTTYPE，22=0x16 COLROW）
   → 解释 A.gds TEXT 为何用 COLROW（Cadence 按 skipper 方言导出）。
3. BOUNDARY/PATH purpose = DATATYPE (0x0E)（标准语义）。
4. dbLibLayers = BP(layer,datatype) ∪ TEXT(layer,colrow)，全库去重。
