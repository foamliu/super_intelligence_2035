### ⚠️ `*.log` gitignore 陷阱（新发现，与 `env/` 坑并列）
EDA-Flow-Bench 根 `.gitignore` line 181 有 `*.log` 规则，会忽略**任何** `.log` 后缀文件。本 case 隐藏 B 的主日志 `ptn_w1.600u_l0.130u_nf2.log` 被该规则忽略，`git add` 不追踪、`git status` 不显示，险些漏提交（check.py 依赖该文件解析 simulator_version/host/run_method/model_name/alter_count/gm_max_vg/conditions）。
- **修法**：`git add -f` 强制加该 .log 文件（已 r654 补提交 79fd16e1）。
- **今后造 case**：asset 若用 `.log` 后缀（NanoSpice/FineSim 主日志天然是 .log），**必须 `git add -f` 强加**；或改用 `.lis`/`.txt`/`.nlog` 等非忽略后缀并同步 task_spec 文件类型规则。A 档 HSPICE 用 `.lis` 不受影响。
- 另：本仓 4 shard 共享工作副本，broad `git add`（如 shard D 的 bench loop）会扫进别线新建文件——本 case 的 reference/ + 多数 asset 文件被 shard D commit 30121ecb 扫入（内容正确，未重写），仅 .log 因 gitignore 漏网。已记此交叉 hazard。
