- schematic_ops：copy_template → set C0(2S+C1) NumCol/NumRow → set text1=cellname

- symbol_ops：create_symbol → clear → copy_template_symbol → set text1=symbol_text
  → check_and_save
- placement：按 TYPE 分 block；x=(wi%per_row)*step_x；
  y=block_index*block_step_y+(wi//per_row)*row_step_y；
  instance_name=`{inst_prefix}{cellname}_{wi}`
