### 2.1 BlClampRailDiagQA-001 — CRITICAL judge bug 修复

**Bug**：`check()` 末尾无条件 `return True`，**忽略** per-condition `results` dict → 任何不崩溃的提交都判 PASS = 假阳性。参考解侥幸 PASS（所有 cond 恰好 True），但 `neg_hardcoded`/`neg_no_parse` 也返回 True → selftest 在 `res.values()` 上 crash（bool 无 .values）。

**根因取证**（修前）：
```
neg_hardcoded: return type bool value True   ← 假阳性！
neg_no_parse:  return type bool value True   ← 假阳性！
cond[c]=False got eqsel / cond[d]=False got inh_vap2 / cond[e]=False got 0.475 ...
（conditions 记录正确，但末尾 return True 无视它们）
```

**修法**（断言条数 12、严格度、题面、assets、hidden 零改动）：
- 新增 `_finish(results)` helper：`return {'pass': all(ok for ok,_ in results.values()), 'conditions': results}`（judge 契约合规：`pass` 键 True=PASS / False=FAIL；`conditions` 子 dict 保留供 selftest/main 读取 per-condition）。
- 5 处 `return results` / `return True` → `return _finish(results)`。
- `__main__` 与 `negative/negative_selftest.py` 改读 `res['conditions']`。

**自验（修后）**：
```

neg_empty:      pass=False fails=[b]                       first-fail b
neg_hardcoded:  pass=False fails=[c,d,e,h,i,j]             first-fail c
neg_no_parse:   pass=False fails=[c,d,e,f,g,h,i,l,j]       first-fail c
selftest: RESULT: ALL NEGATIVES FAIL check (correct)  exit 0
```
失败轮廓 distinct（fail-set 互不相同）。
