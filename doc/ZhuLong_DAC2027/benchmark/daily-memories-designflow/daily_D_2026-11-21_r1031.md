## produce-script
`lint_filelist_audit.py` 四参 CLI `<filelist> <rtl_root> <top_module_file> --known-tags TAG1,TAG2 [-o OUT_DIR]`:
1. 解析 filelist(每行一条相对路径, // / # 注释跳过)
2. 扫 rtl_root 递归所有 .v 文件
3. 按 --known-tags 顺序(早→晚)从文件名首次子串匹配提取版本标签, 剥标签得 base name
4. 按 base name 分组 rtl_root 文件, 按标签优先级排序
5. 对每条 filelist 条目: 若文件不存在→missing; 若标签≠同 base name 最新标签→stale, 替换路径为最新版
6. 解析 top_module_file 实例化模块名(正则 `^\s*(\w+)\s*(?:#\s*\([^)]*\)\s*)?(\w+)\s*\(` skip Verilog keyword), 剥标签得 base name, 与 filelist base name 集合比较, 未覆盖→missing_from_list
7. 产 `updated_filelist.list`(stale 替换非 stale 保留, 行数不变) + `audit_report.json`{stale[]/missing[]/missing_from_list[]/version_map{}/summary{}}
