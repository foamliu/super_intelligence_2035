### 发现的问题（3 个，超出原 GAP 范围）

#### 问题 1: 判分契约返回值违规（P0，正解也会被判 FAIL）
- check.py 返回 `{'pass': passed}`，其中 `passed` 是 **int**（条件通过计数）
- 2026-11-24 契约：`{'pass': True}` 算 PASS，value 必须为 **boolean True**
- `{'pass': 16}` 中 16 is not True → 即使 16/16 全通过，judge 也判 FAIL
- **修复**: `{'pass': passed}` → `{'pass': all_pass}` where `all_pass = (passed == len(conditions))`
- 同步更新 cases/D JSON 的 test 字段

#### 问题 2: 无 negative_selftest.py（原 GAP）
- 已有 3 fake（empty.py/print_only.py/hardcode_a.py）但无 selftest 自动化
- **修复**: 新建 negative/negative_selftest.py

#### 问题 3: judge sandbox 缺 B/C netlist 文件（P0，hidden B/C 读不到）
- run_one.sh 只拷 `*.py` 和 `*.json` sibling 到 judge dir（line 366）
- task_B.netlist / task_C.netlist 是 `.netlist` 文件 → **不拷贝**
- check.py 用 `ref_dir/task_B.netlist` 加载 hidden B/C → judge sandbox 中路径不存在
- 后果：oracle 用空文本（top=None→KeyError 崩溃），SUT subprocess 也读不到 B/C 文件
- **修复**: B/C netlist 嵌入 check.py 为 base64 literal，sibling 缺失时 fallback decode + 写 temp 文件（供 SUT subprocess 读）
- 同步 test 字段
