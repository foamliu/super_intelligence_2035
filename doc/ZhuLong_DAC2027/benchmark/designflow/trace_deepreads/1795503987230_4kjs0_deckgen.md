**Core functions**:
- `parse_subckt(cdl_path)` → `(subckt_name, pin_list)`: parse first `.subckt` line from CDL
- `build_context(args)` → `ctx` dict: pack args + derived voltages (v1l=vdd*0.9, v1h=vdd*1.1, v2l=vddp*0.9, v2h=vddp*1.1)
- `render_deck(ctx, spec)` → `.sp` text: .lib include + VDD/VDDP/VSS sources + X1 instantiation (port order from CDL) + stim + .tran + .measure + PVT .alter blocks (4 corners × 2 temps × 4 voltage combos)
- `render_docs(ctx)` → README_sim.md: cell name + input params + per-spec analysis/load/measure table
- `render_runner(ctx)` → run_hspice.py: batch hspice runner
- `FILE_SPECS`: list of dicts `{group, file, title, stim, extra, stim_extra, analysis, meas}` defining the 21 simulations

**PVT .alter block** (per deck): for each (corner, temp, volt_combo): `.alter` + `.temp <T>` + `.param VDD=<v> VDDP=<vp>` + `.lib <lib> <corner_section>`

