## .75 HSPICE 排雷
1. `.subckt NAME n1.. params: p=v` 形式 HSPICE 把 `params:` 算作节点 → 改用 inline `n1.. p=v`（无 `params:` 关键字）
2. 行为级 E 源 `Eout out 0 VOL=' V(in)*b0*(1-b1)...'` 可混节点电压 V() 与 .param 算术，b0/b1/b2 作 0/1 标量
3. `.alter` sweep 时只写最后一个 .mt<alternum>，per-sel_code measure 不可靠 → 改用 6 次独立 hspice 调用（candidate 脚本循环 sel_code）
4. tran 时长须 ≥128*tclk 使 DIV32 有 ≥4 周期供 RISE=2→RISE=3 measure
