## 抽象成 benchmark 用例（EDA-Eval-DesignFlow-PvtPwrWinAvg-001）

把专有 fsdb 波形抽象成**纯文本 CSV 长表**（`corner_idx,time_s,i(<sig>),...`，电流单位 A），去掉 FineSim/Verdi/numpy 依赖，保留 EDA 数据流核心：

```
解析 top_spice .probe i(<sig>) → 解析 corners.sp ALTER <idx> <name>
→ 读 CSV 长表(列名 i(<sig>) 匹配 probe) → 窗口[300n,1us]内 mean|i|
→ A 转 mA(×1000) → pwr_corners.csv(长) + pwr_table.csv(宽,total=sum) + pwr_summary.txt
```

- **A 可见**：5 corner（vvddq/vvdll/vdpg）+ example_* 参考输出
- **B 隐藏**：45 corner 同信号名不同数值（判分器跑 SUT on B 验数值泛化）
- **C 嵌入 check**：avdd/avss/ccio 不同 probe token + 不同 corner 命名（反硬编码信号名）
- **判别齿**：①忘 ×1000 → 值差 1000× ②不窗口过滤 → 含 5×inrush+0.5×tail 偏大 ~10% ③硬编码 A 数值 → B 不同 ④硬编码 probe 名 → C 不同

check.py 16 条件 a-p，独立 oracle 重解析 CSV（不 import SUT），subprocess 真跑 SUT on A/B/C + 4 negatives（empty/print_only/core_removed/hardcode_A）。ref 16/16 PASS，discriminator（nowin/nox1000）各 11/16 FAIL，4 negatives 全 FAIL。
