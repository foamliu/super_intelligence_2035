## cd_inst_hier.il 关键 SKILL 实现 (可移植核心)
```
procedure(cdHierRec(cv l_path l_visited nDepth)
  let((subcx nkids key)
    foreach(inst cv~>instances
      cdH_rows = cons(list(l_path inst~>name inst~>cellName inst~>libName) cdH_rows)
      when(nDepth < 12
        subcx = dbOpenCellViewByType(inst~>libName inst~>cellName "schematic" "" "r")  ; BY NAME, schematic view
        nkids = length(subcx~>instances)
        key = sprintf(nil "%s.%s" inst~>libName inst~>cellName)
        when(subcx && nkids > 0 && !member(key l_visited)
          cdHierRec(subcx strcat(l_path "/" inst~>name) cons(key l_visited) nDepth+1))
        when(subcx dbClose(subcx))))))
procedure(cdInstHierExportCSV(l_lib t_cell t_view t_path)
  let((rows port n)
    rows = cdHierGather(l_lib t_cell t_view)
    port = outfile(t_path "w")
    fprintf(port "path,name,cell,lib\n")
    foreach(r rows fprintf(port "%s,%s,%s,%s\n" (car r) (cadr r) (caddr r) (cadddr r)))
    close(port) ...))
```
Row schema: `(hierPath instName cellName libName)`, 顶层 path="TOP", 子层 path="TOP/Ix/Iy".

## 关键 gotcha (可移植核心, 造题显性化)
1. **按名开 schematic view, 非 inst~>master**: 助手先试 `I~>master` → 返回 symbol view (`I~>master~>instances=0`) → 不展开. 正解: `dbOpenCellViewByType(inst~>libName inst~>cellName "schematic")` 按名开 schematic. 这就是本 case 第一个 gotcha — 朴素「用 master/symbol view」得到 0/假实例, 不展开.
2. **环路保护 visited + 深度上限 12**: ADC_SAR_CDAC 子电路 ADC_SAR_CDAC_SW 互引? 实际无环, 但 visited 集合 + depth cap 是防御性正确做法. 造题在隐藏 B 里放 CYC_X<->CYC_Y 互递归来抓「无 visited guard」bug.
3. SKILL loader 怪癖 (car/cadr 必须显式括号 `(car r)`, `and(...)` 误判变量, `?formTitle sprintf(...)` 单层) — 非可移植核心, 造题不考.
