## 关键 bug / 洞察（→ 隐藏 B + negatives 素材）

1. **`NameError: cvId`**：pyAether `exec()` 加载时函数参数未注入全局帧 → 函数须显式传 `cvId`，不能依赖外层变量。
2. **`UnicodeDecodeError: 'ascii' codec can't decode byte 0xe2`**：Aether pyAether 用 ascii 编码加载脚本 → 文件含非-ascii（中文注释/破折号 —）即崩；脚本必须纯 ASCII（中文注释用 ASCII 转写或 GBK→ASCII）。
3. **`ERROR: Bottom Lib name is empty!`**：GUI 表单未填 bottom lib 名即调用主函数 → 须校验非空。
4. **`ERROR: Cannot find instance of / in top layout`**：instance 名拼接用了 `/` 分隔符，layout 里查不到 → 须用 Aether hierarchy 分隔规则（`.` 或 `dbGetInstByName`）。
5. **pyAether `exec()` 对空行敏感**：`try/except` 间空行会把 try 块提前结束 → try/except/else 必须连续无空行。
6. **多次 editor 编辑累积垃圾**：文件被反复 patch 后 168 行后全是重复 → 最终「从头写干净版本」才解决（轮 A383-A414）。
