1. **deck 构造**: `.param vdd/vds/vgs/w/l` + `.MODEL` 包在 `.LIB tt...ENDL tt` + `.lib 'corner.lib' tt`
   - level-1 NMOS: `m1 vd vg vs 0 nch w=w l=l ad=2p pd=4u as=2p ps=4u`（注意 `m1` 不是 `xm1`）
2. **.op + .alter 扫点**: 每个 (Vgs,L) 用 `.alter` + `.param vgs=X l=Y`（两行分开，不能 inline）
3. **.option post=0 ingold=2** 抑制绘图 + 定点输出，便于正则解析
4. **解析**: `txt.split("**** mosfets")` 切块，正则 `^\s*<key>\s+([0-9.eE+-]+)\s*$` 抓 id/gm/gds/vth/cgtot/cgs/cgd
5. **派生量**: gm_id=gm/id, id_over_w=id/W, ft=gm/(2π·cgg)（cgg>0 才算）
6. **CSV**: 列 vgs,l,id,gm,gds,vth,cgg,cgs,cgd,gm_id,id_over_w,ft，每点一行

## Lessons
- **Vds=0 → Cgg=0 截止区陷阱** 是 trace 的真实错误，也是本 case 的核心 teaching point；cond-f + neg naive_vd0 直接复刻
- **square-law gm_id=2/Vov** 用来反推 vgs_list：要让 gm_id ∈ [1,25]（物理范围），Vov∈[0.1,0.95]；level-1 进不了弱反型（gm_id>25 需 BSIM subthreshold）
- **cross-input guard** 单看 mean id/cgg 太弱（A/B 在 4.4%/4.7% 内），加 gm_id mean（差 35%）+ row_diff 才稳；cond-n 用三指标 OR
- **HSPICE level-1 gotchas**: `.MODEL` 必须在 `.LIB...ENDL` 块里 + `.lib 'corner.lib' tt`；MOS 元件 `m1` 不是 `xm1`；`.alter` 必须独立行后跟 `.param` 行
- **write tool 字节漂移**: repo check.py 首次写入比 .75 原件少 247B（少了若干注释 + cond-n 详细消息），用 .75 read_file 拉原件覆盖 repo 才拿到 md5 一致；以后写入 check.py 后必须 md5 比对 .75 selftest-passing 原件
