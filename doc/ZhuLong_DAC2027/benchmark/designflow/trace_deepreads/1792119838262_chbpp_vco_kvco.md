```
* 4-stage ring VCO -> quadrature outputs via buffers
.options post=1 probe=1 measdgt=8 accurate=1 method=gear
.options converge=1 gmin=1e-14 gmindc=1e-14 runlvl=5
.option scale=0.855
.lib '/proj/m2701/V0_DDR4/model/current/model.sp' top_tt
.lib '/proj/m2701/V0_DDR4/model/current/model.sp' pre_simu
.temp 25
.param VVDD=0.85
Vvdd vdd 0 dc VVDD  /  Vvss vss 0 dc 0
.SUBCKT cs_inv in out vdd vss
XMP out in vdd vdd prvt_ckt w=0.4e-6 l=30e-9 m=2
XMN out in vss vss nrvt_ckt w=0.2e-6 l=30e-9 m=2
.ENDS cs_inv
.IC v(s1)=0 v(s2)=0.85 v(s3)=0 v(s4)=0.85
Xi1 s4 s1 vdd vss cs_inv  / Xi2 s1 s2 vdd vss cs_inv
Xi3 s2 s3 vdd vss cs_inv  / Xi4 s3 s4 vdd vss cs_inv
Xbuf_i buf_i_out s1 vdd vss cs_inv ... (4 buffers, I+/I-/Q+/Q-)
C*_out buf_*_out vss 1e-15
.tran 0.25p 5n uic
.param vm=0.425 td=2n
.meas tran tper TRIG v(s1) VAL=vm TD=td RISE=5 TARG v(s1) VAL=vm TD=td RISE=9
.meas tran fosc param=4/tper
.meas tran ph12/13/14 param='(t_sN-t_s1)/tper*360'
.meas tran swing PP v(s1) FROM=2n TO=5n  /  iavg AVG i(Vvdd) FROM=2n TO=5n
.end
```
