## Fan-in path 文法（idx 451，逐 token）
路径由 ` --> ` 分隔，5 类 token：
- `leaf_pin`  `.B(Mn1[2])`           →  regex `^\.(\w+)\((\w+)\[(\d+)\]\)$`  {pin, inst, bit}
- `gate_pin`  `I26(nor3GFLx1).Y`     →  regex `^(\w+)\((\w+)\)\.(\w+)$`      {inst, cell, pin}
- `bus_net`   `[RRH12N[1]]`          →  regex `^\[(\w+)\[(\d+)\]\]$`         {net, bit}
- `net`       `[net_37]`             →  regex `^\[(\w+)\]$`                  {net}
- `bare_pin`  `.A`                   →  regex `^\.(\w+)$`                   {pin}（下一级门输入端）
