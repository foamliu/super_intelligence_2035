## 核心难点（4 步流水）

### 1. SPICE netlist 层次解析
- 扫 `.subckt NAME ports...` → `cell_ports[cell] = set(ports)`，进入该 cell 作用域。
- 扫 `x<inst> nets... <cellname>` → `inst_cell["parent\x00inst"] = child_cell`。`+` 续行合并到前一行 accum。
- `xi0<7>` 这类总线实例名按字面量存键（不展开位域）。

### 2. CSV Path → leaf cell 映射（最难）
CSV `Path` 是点分 `I_FOO.I_BAR.I_BAZ`，每段 `I_FOO` 对应 netlist 实例 `xi_foo`（小写、前缀 x）。`I0<7:0>` → `xi0<7>`（总线取高位）。
- 顶层段：在 `inst_cell` 里找任何 `key.endswith("\x00xi_foo")`。
- 后续段：`key = parent + "\x00" + inst`，查 `inst_cell[key]`。
- 任一段查不到 → leaf=None → 该行跳过（不能臆造 cell）。
- 防"光凭路径叶子名当 cell"：例如 `I0<7:0>` 不能当成 cell `"i0"`，必须沿层次走到真实实例化的 `rbuf`。

### 3. netName 端口/内部分类
`netName` 若 ∈ `cell_ports[leaf]` → 归 `port { }`，否则 → `intNet { }`。

### 4. voltage 归一化
- 去 `V` 后缀（`0.5V`→`0.5`）。
- `mV` 转 V（`541mV`→`0.541`）。
- `A/B` 范围 → `{A B}`（递归归一化两端）。
- 纯数字保留（`5`→`5`）；负值保留（`-0.2V`→`-0.2`）。
