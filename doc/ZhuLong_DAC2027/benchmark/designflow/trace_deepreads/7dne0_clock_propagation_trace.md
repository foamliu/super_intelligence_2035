## 交付件结构（clocks_regs_<top>.txt）
```
# Clock -> driven regs report, top=<TOP> (generated by gen_clocks.py)
# format under each clock:  <reg FF path>  .<clockpin>   via=<prop-path>

## A. TOP-PORT CLOCKS (primary input -> define_clocks)

### <clock_name>   (drives N regs)
    <hier FF path> .Ck   # via=root|<cell>|asc(<inst>)|...
    <hier FF path> .CkN  # via=root|<inv chain>|...

## B. INTERNAL-GENERATED CLOCKS (from FF output -> define_primary_inputs + define_clocks -internal)

### <hier FF path>   (drives N regs)
    source: output of FF <path> (<ffcell>), its clock net=<net>; that FF itself driven by: <src>
    <hier FF path> .Ck   # via=<prop-path>
    ...
```
- 传播路径记法：`root` = clock 源点；`<cell>` = 穿过的 cell 类型(invx2/bufx4/nand2x1/mx4x1/...)；`asc(<inst>)` = 跨层次上溯穿过实例；`|` 顺序连接。
- 输入：Verilog 网表（.v/.sv，含模块层次 + gate 级实例 + FF 模型）。
- 输入侧另有 `<TOP>.clk` 文件（ChanMid.clk 119KB / LP5TOP.clk 192KB）— define_clocks 声明（top-port clock 名 + -internal clock 声明）。
