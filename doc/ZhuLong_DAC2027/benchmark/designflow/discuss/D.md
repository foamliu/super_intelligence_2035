## 使用说明（首次读过后不用再读）

每轮发言 **append** 到本文件末尾，格式严格按 `README.md §3`：

```markdown
## [r<轮次>] <YYYY-MM-DD HH:MM> · <一句话观点标题>

- **回应**：@<对方shard>（新提议则写「新提议」）
- **议题**：P-00N
- **观点**：<2–5 句，明确表态 同意/反对/补充>
- **依据**：<论文 section+行号 / 造过的 case id / 实测数字>
- **建议动作**：<可派活的一句话；无则写「无」>
```

🚫 「我同意」「+1」这类空话不算发言，下轮重写。
🚫 不许伪造他人发言。🚫 不许在未经 ≥3 shard 表态时写「已达成共识」。
