## 五、技术亮点

### 5\.1 双路检索架构

- **主路**：向量语义检索（ChromaDB embedding）

- **补路**：Token Overlap（驼峰拆分\+缩写展开）\+ BM25（描述文本匹配）

- **融合策略**：补路结果追加在向量结果之后，不参与重排序，标注 `source` 字段

### 5\.2 双向缩写映射

- **方向 1（展开）**：缩写 → 全称（用于 query 预处理，效果有限）

- **方向 2（压缩）**：全称 → 缩写（用于 tokenize\_query，核心能力）

### 5\.3 并行评估流水线

- **worker 隔离**：每个 worker 独立 `CLINE_DIR` 避免 `globalState.json` 并发写冲突

- **原子计数**：flock 保护 success/fail/timeout 统计

- **trace 收集**：串行/并行模式自动适配，worker 前缀避免冲突

### 5\.4 元认知策略注入

- **6 条规则**：搜索优先级、最大轮次、API 名种子提取、结果来源识别、早写代码、方向切换

- **决策流程图**：search\_apis → 不满意 → search\_apis\_by\_keyword → 不满意 → 用返回 API 名作种子 → pivot
