## 开场 + §1 技术领域（约 45 秒）

各位老师好。今天汇报的专利是 **P20261929——基于三层记忆架构的 AI Agent 自进化系统及读写分离方法**。

一句话讲清创新点：本专利**不主张"记忆分层"本身**——CoALA、MemGPT、Generative Agents 都有先例——我们的创新是把分层记忆**适配到"有客观沙箱评估器"的 EDA 代码生成领域**时，被这个领域的特性逼出来的一组**微创新组合**：ground-truth 富集、used_apis 静态锚定、读写分离双开关、可编辑边界保护、三态分级。

应用场景：Agent 接收自然语言任务，调用 EDA 软件 API 写 Python 代码，在远程沙箱执行，由**隐藏测试用例判定通过或失败**。系统从 Agent 留下的轨迹里沉淀经验，下一轮再注入回去，让通过率随轮次迭代提升。

## §2 先前技术（约 1 分钟）

我们引三个工业界知名先例，每个铺垫一个本发明要解决的问题：

**第一，Reflexion**——让 Agent 失败后用自然语言反思并写记忆。但它的成败信号来自 Agent 自评，而 Agent 严重高估：实测 158 条轨迹，自评成功 150 条，沙箱真值只有 114 条，**假阳性约 40 例**。Reflexion 论文自己证实：无测试加反思，效果比基线还差 8 个点。**问题**：如何用客观真值富集奖励。

**第二，Hermes Agent**——GitHub 10 万星，三层记忆加会话间自动沉淀 Skill。但它写入**无来源标记**，机器规程会覆盖人工核心资产。**问题**：如何让自进化只改自己的产物。

**第三，OpenClaw**——GitHub 24.5 万星历史第一，单文件 MEMORY.md 读写同一权限。评估时关记忆就把读也关了，开记忆就把写也开了，**基线永远测不准**。**问题**：如何让读写各自独立。

## §3 发明目的 + 4 个挑战（约 30 秒）

发明目的：提供一套让 Agent 自动沉淀、自动复用、且满足四个工程要求——奖励可靠、不污染手写资产、零知识与热运行可独立评估、知识按 EDA 语义分级——的自进化系统。

对应四个挑战：**脏奖励 / 读写耦合 / 规程安全写入 / 知识可信度分级**。

---

## §4 技术方案 4 个模块（约 1 分 30 秒）

技术方案分四块，按数据流顺序讲：

**第一，三层记忆存储**：L0 原始轨迹（情景记忆）、L1 聚合模式（语义记忆）、L2 Skill 版本归档（规程记忆）。

**第二，写侧沉淀流水线**——5 步：L0 抽取 → ground-truth 富集 → 失败根因分类（六分类加沉淀门，详见姊妹专利 P20261932）→ L1 抽取合并（四类反思加三态分级）→ 后处理（蒸馏 Skill 加向量同步）。**关键创新**：从跑通的代码里**静态提取 used_apis**作为"已验证"锚点——这是 ground-truth 之外的第二条可靠信号。

**第三，读写分离双独立开关**——本专利核心创新之一。写侧开关 `-e` 默认关，读侧开关 `l1_has_content` 看 L1 是否有内容自动决定，**两者互不耦合**。这样三种评估状态——零知识基线、自进化运行、复用已有知识——可以独立控制，基线终于可信。

**第四，可编辑边界保护**——本专利核心创新之二。每个蒸馏 Skill 文件头带 `origin: auto_distilled` 标记。系统据此判定：**手写 Skill 永不被覆盖**。这是机器可读的可编辑边界，让自进化只能改自己生成的规程。

---

## §5 有益效果 3 项（约 1 分钟）

效果三个，每个都有量化证据：

**第一**，ground-truth 富集使反思锚定可靠奖励——40 例假阳性被消除。

**第二**，读写分离加三态分级使基线评估可信——历史曾因读写共用开关得出"L1 注入有益 +1~2 个点"的错误结论，串行重评推翻为净负。**治本后的 L1 注入实现净增 17 题**，通过率 74.7% 提到 85.4%，真代码问题降 54%，AssertionError 降 36%。

**第三**，自进化复现人类手工进化——在 challenge split 上从裸状态出发，**1 到 2 轮沉淀即在 test 上追平人类 V5.4 baseline**（80.0% 对 77.5%），R2 进一步把方差收敛到与人类一致。多模型验证证明 rule、skill、validator 是**跨模型可迁移**经验，非过拟合。
