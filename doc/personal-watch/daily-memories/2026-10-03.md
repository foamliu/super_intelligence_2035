## 模型名复核（用户追问 · 2026-10-03）

- 用户要求核对 DeepSeek **官方**支持的模型名。**实测** `GET https://api.deepseek.com/models`
  （`Authorization: Bearer <key>`）→ **HTTP 200**，官方**只注册两个 ID**：
  - **`deepseek-flash`** —— 显示名 `DeepSeek-V4.1-Flash`，ctx 1,048,576，input text+image，reasoning（effort low/high/max）
  - **`deepseek-v4-pro`** —— 显示名 `DeepSeek-V4-Pro`，ctx 1,048,576，input text
- 实测 `chat/completions`：`deepseek-flash` → **200**；**`deepseek-v4-flash` → 200 但被别名成 `deepseek-flash`**
  （返回体 `"model":"deepseek-flash"`）→ **它不是官方 ID，是兼容层别名，换机可能直接报错**；`deepseek-v4-pro-fp4` → 400。
- **结论**：本线 `MODEL` 定为 **`deepseek-flash`**（规范 ID）；要更强可切 `deepseek-v4-pro`。
- 备注：仓库里 BaiZe/ZhuLong 用的 `deepseek-v4-pro-fp4`、`deepseek-v4-flash` 属于**另一台网关** `agi-gateway.cxmt.com`，两套命名不同，勿混。

## 睡眠时间纠错（用户追问 · 2026-10-03）

- 用户质问：**6 小时睡眠怎么来的？BaiZe 那边有 6 小时吗？**
- **核查（`Select-String` BaiZe 全部 `*_loop.sh`）**：BaiZe **4 条 loop 用的都是同一组值** ——
  `SLEEP_BUSY=60`（1 分钟）/ `SLEEP_WAIT=1800`（30 分钟）/ `PUSH_INTERVAL=18000`（5 小时，**这是"兜底 push 间隔"，不是睡眠**）/ `CLINE_TIMEOUT=1500`。
- **结论**：**BaiZe 从无小时级睡眠**。我的 `SLEEP_LONG=21600`（6h）是**自己拍脑袋加的**（很可能是把 `PUSH_INTERVAL=18000` 那个"5 小时"张冠李戴成了睡眠），**属错误**。
- **修正（已 push）**：news loop **完全对齐 BaiZe** —— `SLEEP_SHORT=60` / `SLEEP_LONG=1800` / `PUSH_INTERVAL=18000` / `CLINE_TIMEOUT=1500`；
  并清理了任务书 / `MEMORY_NEWS.md` / `MEMORY.md` 里所有 "6h / 1h" 的陈旧表述。
- **教训**：**别自创数值，先照抄已验证的模板**；引用"XX 那边是多少"必须**实际去读源码**再下结论。

## 降低思考量（用户提问 · 2026-10-03）

- 用户问：能否在 `loop.sh` 里让 cline **思考少一点**。
- **查证（`cline --help`，v3.0.61）**：CLI **原生支持**
  `--thinking <level>`：`none|low|medium|high|xhigh`（省略 = provider 默认）。
- **关键**：`deepseek-flash` provider **默认 effort = high** → 想得久、费 token。新闻采集是"搜索+读+写摘要"，无需深推理。
- **处置**：`watch_news_loop.sh` 新增变量 **`THINKING="low"`**，调用改为
  `cline -c "$CWD" --auto-approve true -m "$MODEL" -t "$CLINE_TIMEOUT" --thinking "$THINKING" "$prompt" ...`。
  要更省可把 `THINKING` 改 `none`。
- **实测校验**：`cline --thinking bogus ...` → `error: invalid thinking level "bogus" (expected "none","low","medium","high","xhigh")` → 参数与枚举属实。
- ⚠️ **改 loop.sh 需重启 loop 才生效**。
