## 🚨 事故与修复（首轮空转）

- **现象**（用户 2026-10-03 反馈 `/tmp/watch_news_loop.log`）：loop 拉起后
  `error: The supported API model names are deepseek-flash, deepseek-v4-pro, but you passed deepseek-v4-pro-fp4`
  → cline **报错却 `exit 0`**，本轮没干任何事；且 `MEMORY_NEWS.md` 初始 `WAITING: 1` → **白睡 21600s**。
- **根因**：① loop `MODEL` 照抄了 BaiZe 脚本的 `deepseek-v4-pro-fp4`，**本机网关不认**；② 初始 `WAITING` 置 1；③ loop 无法识别 cline 失败。
- **修复（已 push）**：
  1. `MODEL` → **`deepseek-v4-pro`**；
  2. `MEMORY_NEWS.md` `WAITING` → **0**；
  3. loop 增加**失败兜底**：tee cline 输出 + 命中致命特征即**强制短睡重试**（不受 `WAITING` 影响）；
  4. `SLEEP_LONG` **6h → 1h**。
- **教训**：**换机器先核对模型名**；**cline 报错未必有非零退出码**，loop 必须自己抓错。
