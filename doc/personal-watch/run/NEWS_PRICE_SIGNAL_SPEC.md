### 2.3 价格 Y

- **主口径 = 对数收益** `r_t`（必去趋势）；**副口径 = 已实现波动** `|r_t|` 或 `r_t²` —— **两者分开报，🚫 不得混为一谈**。

### 2.4 核心分析：滞后互相关（lagged cross-correlation）

- **日频**：`ρ(k) = corr(X_t, r_{t+k})`，`k = 0 … +20` 交易日（**只做「新闻在前」方向**）；
  `k < 0`（`-20…-1`）**只作对照 / 预期检验**，必须**单列并标注"预期性"**。
- **周频 / 月频**：`k = 0 … +4` 周 / `0 … +3` 月（覆盖低频口径；**低频样本小 ⇒ 必须给 CI**）。
- **检索面**：`信号类别 × 资产 × 频率 × k` 全网格，**一次跑完、全表落盘**（🚫 不许只报好看的格）。

### 2.5 必须处理（**缺一即结论作废**）

| # | 问题 | 处置（硬性） |
|:--|:--|:--|
| ① | **自相关 / 重叠窗** | **HAC（Newey–West）** 或 **block bootstrap** 给 SE/CI；🚫 不用朴素 `t` |
| ② | **同期混杂** | 控制 `r_{t-1}`、**星期效应**、**节假日前后**季节性（回归里做，别只做裸相关） |
| ③ | **反向因果** | 另报 `corr(r_{t-1}, X_t)`（**市场 → 新闻**）作对照；标出「稳市场/救市」类**回应性**新闻（`EXPLORE.md` §3.2 口径） |
| ④ | **多重比较** | **全网格 FDR（Benjamini–Hochberg）** 校正；**未校正一律标「探索性」** |
| ⑤ | **样本外** | 切 **2016–2022 训练 / 2023–2026 检验**；报**样本外**系数/方向命中率 **并与随机基线对比**（**赢不过随机 = 不算线索**） |
| ⑥ | **稳定性** | 分年度 / 滚动窗**符号一致性**；不一致 ⇒ 标 `unstable` |
| ⑦ | **N 与 CI** | 每格必给 **N + 置信区间**；**N<30（日频）/ N<8（月频）⇒ 直接写「样本不足」**，不许硬算 |
