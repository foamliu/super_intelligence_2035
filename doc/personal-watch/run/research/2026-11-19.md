## 1. 推理服务 / KV cache

- **Storing the Gemma 4 K=V Cache Once: Exact Global-KV Memory Savings in a Paged Serving Engine with Unchanged Attention Kernels**（arXiv:2611.23035，2026-11-17）
  作者：Kushagra Bainsla（San José State University）
  分类：cs.LG ｜ 🏷 领域标签：推理服务 / KV cache / 长上下文
  一句话摘要：利用 global attention 层 value = 归一化 key 投影、key = value × 固定权重的结构，把每 KV head/token 缓存从 1,024 值压到 640 值（−37.5%），以两个重叠 strided view 保持原 paged attention kernel 不变；vLLM 原型（16-bit 31B）32K–64K 解码 KV 内存降至 1/1.34–1/1.40。
  🔗 abs: https://arxiv.org/abs/2611.23035 ｜ pdf: https://arxiv.org/pdf/2611.23035
