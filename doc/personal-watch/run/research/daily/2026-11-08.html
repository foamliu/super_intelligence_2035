1Hard Issue, Weak Model, or Bad Run? Rethinking Failure Prediction for Coding Agents

中文一句话
给 SE agent 做「轨迹失败预测」的方法很多（读一段半截轨迹，判断这次跑得对不对，错了就停、重跑或换模型），但它们真学到了「这一跑」吗？作者在公开的 SWE-bench Verified 轨迹上（每个模型对每题只跑一次）做分解，发现预测器表现几乎被两个与「跑」无关的因素吃掉：① 题目难度——一个完全不看轨迹、只根据「这题对其他模型有多难」的参考分 Dext，AUROC 达 0.92，而轨迹预测器只有 0.62–0.63；② 模型能力——在同一题内部，光知道「是哪个模型跑的」就比预测器更准（within-issue AUROC 0.82），且预测器基本只是在复现模型的整体能力排名。扣除难度与能力后，轨迹带来的增益在统计上等价于 0（例如 −0.001，90% 区间落在预注册范围内；18 个配置全部如此）。这个混淆还传导到「预测后做什么」：常被用来做模型切换依据的「最佳单模型 vs any-model oracle」差距不比随机波动更大，逐题切换在留出跑上无收益。而在重复跑 pilot 中，同一模型常常「有些跑解出、有些跑解不出」——所以重跑确实有空间救回失败，但它只救「这一跑运气差」，救不了「超出该模型能力」的题，而现有预测器分不清这两种原因。作者据此呼吁：失败预测要能解释「为什么这一跑失败」，并且必须在重复跑基准 + 闭环等预算下评估。

推荐理由（借鉴 · 与 harness 线的「失败归因」直接对口）
  1. 正是 harness 线当轮的判据问题：harness 目前要回答「TB-2.1 某路 0 passed / hermes 35 个 no-reward / predict 里 499 条 empty」到底是能力不足、infra 故障（网关 429）还是单跑波动。本文给出可复用结论：「单跑」数据无法区分专门化与运气，必须用重复跑才能把方差拆成「题」「模型」「跑」三部分。它的分解口径极简：先用一个不看轨迹的难度参考分（该题在其他模型上的通过率）作基线，再看轨迹/预测器是否还有增益。

  3. 可迁移的方法论：① 报指标时同时给 pooled AUROC 与 within-issue AUROC（并把后者与「不看 run 的基线」比）；② 归因落到「题 / 模型 / 跑」三元分解，而不是笼统说「agent 不行」；③ 决策（重跑 / 换模型）要在闭环、等预算下评估收益。不绑定具体 harness 实现，可直接套到 SWE-bench / Terminal-Bench 的 7 路矩阵上。
  4. 边界（必须写清）：① 证据主要来自一个基准 + 一个 scaffold 的已发布标签，重复跑 pilot 只是小规模公开语料；② 只评估「轨迹型」预测器，未覆盖其他失败检测形态；③ 结论针对单次尝试的公开评测设置，「多跑取最优」下分解的稳定性未验证；④ 作者自报、本线未复现。

2Benchmarks as Software: Terminal-Bench and the Case for Continuous Benchmarks

中文一句话
coding agent 的评测结果正在影响真实的工程与采购决策，但基准会腐坏：模型变强后会给出合法却被现有 verifier 判错的解法，评测代码或环境的改动也会让题目里隐含的假设失效——作者把这种「基准分数与它想衡量的能力之间不断拉大的差距」命名为 benchmark maintenance debt（基准维护债）。他们提出一套持续校验工作流：社区报告 + 任务工件 + agent 轨迹 + 自动 oracle 检查 + 人工闸门修复，并把它用在经过大量人工与 LM 辅助审查/红队的 Terminal-Bench 2.0（89 题）上：审计发现约 30% 的基准存在问题，修复后以 Terminal-Bench 2.1 发布（28 题被修订，含 89 处环境修复 + 11 处指令修复）。修复改变了评测结果：准确率整体提升超过 10 个百分点、排行榜名次最多移动 3 位（尽管整体排序仍高度相关，Spearman ρ=0.958）。更关键的是第二层结论：资源预算本身是测量规格的一部分——固定 wall-clock / 输出 token 预算会实质改变 agent 表现，例如放宽时间上限后，GPT 5.4 上约 20pp 的 harness 差距被抹平，GPT 5.4 mini 上 30pp 的差距缩到 5pp（时间预算最多扫到原设定的 32×）。因此「修题」之外，评测假设与资源设置必须一起被持续复核。

中文一句话
小模型的训练数据预算很紧，此时「换成哪套语料」可能和模型大小、训练配方一样重要。作者做了一次严格配对实验：在对齐的 1,000 万词与 3,700 万词两个预算下，比较两份反差极大的语料——1911 年版《大英百科全书》与 BabyLM 2026 严格预训练语料；对每套语料都训练教师模型、蒸馏出的 5,800 万参数 Baby-Llama 学生、以及不做蒸馏的学生消融，且模型族、训练配方、评测协议全部相同。结果不是「谁更好」的单一排序，而是不同的技能画像：BabyLM 2026 在语言可接受性类基准（BLiMP / BLiMP Supplement）上稳定更强，Britannica 在 Entity Tracking（合成状态跟踪）上常常更强；反差在教师与学生在两个预算下都出现，其中蒸馏学生对照的跨种子复现最干净。针对性控制显示：在匹配训练曝光量以及拉长诊断上下文之后，该反差依然存在；而「直接集成教师」也复现不出 10M Britannica 学生的 Entity Tracking 行为。作者因此指出：小规模下比较预训练数据时必须做多基准评测，因为最后拿到的可能只是「技能画像差异」而不是「质量差异」。

4How Finite Brains Generalize Without Bound: Spatial Memory as a Universal Computer

中文一句话
一个只学过小数加法的孩子会加任意长度的数；而在 ≤40 个符号的短串上训练的 LSTM / Transformer，到 41–500 长度就崩（连「复制一个串」都不行；一个能在 40 符号上完美反转的 Transformer，到 50 就已掉到随机水平）。作者把差别追到「决策那一刻它在读什么」：位置、计数、时间这类量会随输入变长不断取新值，是「坐标」——读坐标的学习器在长输入里必然遇到训练从未覆盖的取值；而「两样东西是否相同」在每个长度上答案都一样，是「巧合」——只读巧合的学习器在长输入里找不到短输入里没有的东西，于是有限经验就能把它的规则固定到任意长度。推论很硬：只要记忆负责携带输入的「长度」、而规则保持有限，这段记忆从每个位置看就必须一模一样 ⇒ 它只能由「环」组成；环就是网格细胞（grid modules），检测「回到原位」的细胞是位置细胞，记录是海马索引，「前额叶控制器只移动环、从不读环」。而且「只读巧合」不损失计算力：这类学习器被有限经验固定的，正是图灵机随输入逐步算出的东西——这解释了为什么一个为「找到回家的路」而演化的回路，能学会算术与文法。实验：在 ≤40 符号上训练后，15 个基准任务里 9 个在长度 41–500 上平均 ≥99% 正确（其中 5 个任务 LSTM / Transformer 一个都解不出）；训练后给新的环，能零错反转 15,015 个符号，更长的失败点落在理论预测的曲线上；控制器可原样跑在神经元上。

  1. 大众看点（不需要任何背景）：孩子只学过 3 位数的加法，却会加 100 位；大模型在短句上训练，长一点就露馅。「为什么人越用越会，模型越长越笨」是本篇最抓人的钩子，而答案落在一个非常好画的机制上：大脑里有一组像「环形跑道上的格子」的细胞（网格细胞），它只数「走了几步」而不记「具体走到哪」——所以无论路多长，它要读的东西永远只有那么多。
  2. 反直觉的点（有传播力）：① 让学习器「只会判两个东西一样不一样」，居然不损失计算能力——它能算的正好是图灵机能「随着输入一步步算」的那些事；② 论文给出的最硬证据是一个数字：训练后给新环，它能零错反转 15,015 个符号，而训练时最长只见过 40 个。

  4. 边界（必须写清，别把它讲成「AGI 解法」）：① 全部为离散符号任务 + 小规模（单次训练 12,000 步、批量 32、长度 1–40 均匀采样），未在自然语言或 2B 级模型上验证；② 45 次基准运行里 23 次一次成功、7 次重试后成功、15 次始终未成功（即那 5 个 LSTM/Transformer 也解不出的任务上本方法同样全灭），说明它有任务依赖；③ 与神经科学的对应（网格细胞 / 位置细胞 / 海马索引）是作者的解释性映射，不是实测结论；④ 作者自报、本线未复现。

5Same Behavior, Different Mechanism: What Finite Experiments Can Certify About Integrated Information

中文一句话
两个网络可以算出完全相同的函数，却在「怎么算」上完全不同——可解释性、AI 审计、甚至「机器有没有意识」的判据，靠的都是这种机制层的量。作者把这件事做成一个算得清的问题：一个机制层的量，能不能从有限、残缺、有噪声的干预实验里被识别出来？他们挑了最苛刻的例子——整合信息论（IIT）的 φ——在 4 个 / 5 个单元、真值已知的随机网络上精确求解。三条结论：① 行为可能完全沉默：一个循环网络与一个前馈网络在各自的响应延迟上输入-输出规律一模一样，φ 却是 0.28 vs 0 bit，而内部记录 4–53 次试验就能把它们分开；② 看得不全同样盲：一步记录里漏掉的单元会带来 0.30–1.02 bit 的精度地板，样本量再大也降不下去；在 all-but-self 奇偶网络里，任意长度的记录只能通过若干隐藏单元保真度的乘积看见它们（一种对称性，一次干预即可打破）；③ 这个量有「悬崖」：φ 用一个准则挑选划分、却报另一个准则的结果，于是跨过边界的极小机制变化就让 φ 跳 25–100%（他们找到的边里 99% 如此），而约 1% 几乎完美拟合干预数据的「替代模型」会把 φ 误报 >20%。可救的是单侧结论：同一批数据能在边两侧都给出下界，作者证明某个 64 维机制区域内恒有 φ>1.004 bit，并用约 107 次受控转移给出「误证明概率 ≤ α」的证书。作者因此说：可测性不是数据量的问题，是设计问题——能不能证明，往往可以在做实验之前就算出来。

推荐理由（科普 · 「AI 有没有意识」的硬核版；兼与 harness / designflow / zhulong 的「实验能证明什么」口径对口）
  1. 大众看点：「AI 到底有没有意识」是常年在榜的话题，本文给的不是哲学口水，而是三条可计算的边界：看行为什么都看不出（同样的输入输出，φ 可以差 0.28 bit）、看得不全就永远测不准（有样本量也降不下去的地板）、这个量本身有悬崖（极小变化跳 25–100%）。一句话卖点：「不是数据不够，是这个问题本身能不能测，得先算清楚。」
  2. 反直觉的点：直觉是「多测几次就准了」；本文给出反例——漏掉一个单元 ⇒ 0.30–1.02 bit 的精度地板，任何样本量都跨不过去。
  3. 与在研工作的公共口径（它进日报的真正原因）：本页早报三篇都在讲「分数/行为 与 机制/能力 不是一回事」（2611.08285 轨迹预测器其实只在复现难度与模型身份；2611.08417 基准缺陷与预算会改变分数；2611.07812 换语料是技能画像差异）。本篇把这条直觉形式化了：行为静默 + 部分访问有地板 + 度量有悬崖 ⇒ 只能单侧认证。可直接用来给「消融 / 评测 / 造题」报告划「我们能声称什么」的上限。
  4. 边界（必须写清）：① 结论建立在 4–5 单元、已知接线与单元、受控干预的小网络上，φ 的精确计算随单元数超指数增长（有向割数 4 单元 150 → 5 单元 1,061），真实规模只能退到粗粒化模型或代理量，这些障碍在该规模是否保持，作者明说 open；② 证书本身很贵（已证明区域中心 750 万次、到边界一半处 2,800 万次受控转移）；③ 作者不判断哪个系统「真有意识」，只讨论「这个量能不能被测出来」；④ 作者自报、本线未复现。
