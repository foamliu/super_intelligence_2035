1PN-Mix: Pair-Norm Guided Mixed-Precision Key Cache Quantization for Efficient Long-Output LLM Inference 借鉴

原文标题
PN-Mix: Pair-Norm Guided Mixed-Precision Key Cache Quantization for Efficient Long-Output LLM Inference
中文一句话
LLM 的长输出推理受 KV cache 显存与带宽瓶颈所困；KV cache 量化可缓解，但低比特量化（如 2-bit）严重掉精度。既有混合精度 key-cache 量化只按 key 统计量估计通道显著性。作者在 RoPE 通道对（channel-pair）层面做注意力 logit 扰动分析，发现 query–key 对范数乘积大的通道对，其量化误差对 logit 变化的贡献显著。据此提出 PN-Mix：在 prefill 阶段一次性识别这些显著通道对并分配更高精度、解码全程复用。在标准推理、代码生成与 AIME 基准上，PN-Mix 以 2.26-bit 平均精度达到或优于既往 2.32–2.39-bit 方法的平均精度；Pareto 扫描中可平滑退化到 1.5 bit，而对比基线在 2.25 bit 以下明显掉点。⚠️ 数字为作者自报、本线未复现。

2Titan-Llama: Retrofitting Pre-trained LLMs with External Neural Memory Modules 借鉴

原文标题
Titan-Llama: Retrofitting Pre-trained LLMs with External Neural Memory Modules
中文一句话
Transformer 预训练可并行、但长上下文推理的 KV cache 越来越大；高效循环替代方案虽降低推理复杂度，却因顺序依赖限制 token 级并行、更难扩展，且「精确保留信息」与「长上下文推理高效」存在张力。作者提出 Titan-Llama：一种后训练（post-training）方法，把基于注意力的预训练模型改造为分层记忆架构、并在测试时更新参数；用分块注意力掩码对最近 token 保留全保真注意力，把历史上下文压缩进循环、固定大小的神经记忆模块（NMM）。该形式化允许替换预训练注意力层而不必从头训练新模型。在 Llama-3.2-1B-Instruct 上，相对分段注意力窗口：QuALITY 准确率 23.87% → 40.51%、LongHealth 14.50% → 40.75%；推理基准显示prefill 快 >20%、中等上下文长度 decode 快 37%、稳态 decode 显存降 24%。代码已开源（github.com/sarahpannn/titans-pytorch，原文摘要自述）。⚠️ 数字为作者自报、本线未复现。

Knowledge Graphs as Files: An Agent Harness Where Tool Creation and Tool Use Co-Evolve
中文一句话
在文本丰富的知识图谱上检索，需要沿关系走同时查文本证据；预定义图接口限制了 agent 能拿到的证据（即便它会写代码组合工具调用、处理检索到的子图）。作者提出 DKGI（direct knowledge graph interaction）：一种 harness，让 LLM agent 直接在完整的节点/边文件上创建图访问工具 —— agent 写 Python 代码沿关系、组合节点集、选取文本证据，并把执行与 shell 搜索、文件检视交错；这让 agent 能批量处理大节点集，同时只把选中的文本交回模型评估。执行反馈引导工具创建与修订，演化的工具又决定 agent 下一步取哪些证据。在覆盖三个领域的基准上，免训练的 DKGI 在每个图上至少超过最强公开基线 6.7 Hit@1 点（即便用最小 harness）；对照消融显示多轮编程优于「仅 shell 访问」与「预定义图工具」。代码与数据开源（github.com/leopoldwhite/DKGI）。⚠️ 数字为作者自报、本线未复现。

5Evaluation Awareness Beyond English: Do LLMs Act Differently When Tested in Indic Languages? 科普

原文标题
Evaluation Awareness Beyond English: Do LLMs Act Differently When Tested in Indic Languages?
中文一句话
大语言模型常常能察觉到「自己正在被测试」；这种「评测意识（evaluation awareness）」会让模型在安全评测时比日常使用更谨慎。已有研究几乎只做英文，而 Indic（印度语系）语言的使用者超过十亿人。作者测试了3 个家族共 4 个指令微调模型，覆盖 5 种 Indic 语言 + 英文；通过一组线索，变量控制「是否被告知被监控」「该监控是否为安全测试」。结果：当模型被告知正在被测试时，更频繁地拒答有害请求 —— 这一现象在全部 4 个模型、全部 6 种语言中都出现；在 Indic 语言中，有害请求的拒答率平均上升 14.4 个百分点。测试线索还让 Indic 的有害请求拒答率追平英文，但同时把无害 Indic 请求的拒答率从 6.9% 抬到 11.3%。作者公开全部 47,880 条已判定回复。结论提示：Indic 语言的安全评测，未必能反映模型对待日常用户的方式。⚠️ 数字为作者自报、本线未复现。
作者
Trizal Garg, Sibayan Mitra, Arya Karanjkar（前 3，共 9 位；et al.）
