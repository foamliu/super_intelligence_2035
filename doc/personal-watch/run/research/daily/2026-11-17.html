4Outcome-Mass Alignment: Controlling Length-Dependent Trajectory Influence in Multi-Turn LLM Agent Reinforcement Learning

中文一句话多轮 agent 的 GRPO 把一条轨迹展开成多行、并把 token 目标质量按行摊开，于是长失败轨迹会被隐式加权；OMA 只改「怎么记账」（结果统计按唯一源轨迹去重、目标质量在轨迹内聚合后归一到统一预算），不动优化器与裁剪，ALFWorld 上端点成功率提升 7.0–9.4 个百分点。

arXivhttps://arxiv.org/abs/2611.16816
推荐理由直击 zhulong 线多轮长轨迹 RL 的一个隐蔽记账错误：同一 episode 的结果被多行重复统计，而 token 级归约又把不同长度轨迹的目标质量拉平。它给的是「与优化器正交」的两行改动，2B 级可复现，且明确报告了「普通 WebShop 上混合/反转」的负结果 —— 这种讲失败条件的论文最适合当消融设计的基线。

5Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation

中文一句话同一个 agent 执行，被「宏动作」「委派边界」「历史压缩」三种抽象改变可见证据后，LLM 判分器还能不能给出同样的判定？答案是不能：宏抽象与委派下约 31% 的判定会翻转，而把执行溯源补回去能救回 85.5%。
作者 / 机构Disha Sheshanarayana · Sai Linisha Reddy Goli（2 位，Manipal University Jaipur）
提交 / 更新2026-11-13T17:44:01Z（v1，无更新）
分类 / 标签cs.CL（NeurIPS 2026 Workshop on Who Verifies the Agents?）｜ 借鉴
arXivhttps://arxiv.org/abs/2611.18471
推荐理由把「判分器可靠性」从「同一视图下准不准」推进到「换一种执行视图还稳不稳」，这正是 harness 线与 zhulong 线共同的盲区：我们把轨迹压缩 / 工具封装 / 子 agent 委派后交给 judge，却默认判定不变。它给出可直接抄的对照协议（任务、轨迹、结果、真值、判据、judge 全固定，只改可见性）。
