1 · Mixture-of-Loops Transformer

原题Mixture-of-Loops Transformer
中文一句话循环 Transformer 复用共享层换表达力但牺牲效率；MoLT 用「把 KV 当作跨层/跨圈可选复用的记忆」的 Mixture-of-Loops Attention 重做相邻圈衔接：MoLT-R 保留残差流并跨圈读局部 KV，MoLT-KV 从嵌入重启、读当前圈局部 KV + 前圈记忆 KV 提效，配合 loop forcing 并行训练实现单趟 MoL 解码；U-shaped MoLT 把记忆构建与预测读出分离、跳过无用解码遍历。400B token 预训练下 U-MoLT 在 700M/1.5B dense 与 3B MoE 上均优于 OLMo3（700M 验证 CE token 效率 1.7×；3B MoE 十域困惑度降 0.75、十任务准确率 +2.1pp）；Qwen3.5-0.8B-Base 上 100B token 继续预训练 11 域 CE 全降、平均 token 效率 1.4×；S 规模（~113M）推理延迟 996.6ms ≈ OLMo3 1000.6ms。

2 · Tracking Any Point with Agentic Visual Reasoning

原题Tracking Any Point with Agentic Visual Reasoning
中文一句话通用 VLM 已在目标检测/视频识别超专家模型，但「点对应」需像素级定位同一物理表面点（外观变化或消失重现时尤难）；AgenTAP 让 VLM agent 直接预测点坐标与可见性并主动在视频中推理——从自身估计出发自主选择检查位置、用证据核验点身份并修正；GPT-6 Astra 下在点定位与可见性预测上超过专家模型且无需点对应专项微调；并用于「消失后重认 + 重连碎片轨迹」，构建长时第一视角视频 3D 点轨迹数据集 EgoTAP-4D，加入 D4RT 训练提升平均 3D 跟踪。

3 · Can image generation help visual reasoning? An empirical study

原题Can image generation help visual reasoning? An empirical study
中文一句话用「先生成辅助图再连同原图作答」实测「在图像中思考」是否真有用：13 个 VLM-生成器配对下生成平均使准确率降 3.7pp、10 个任务中 9 个下降；两个统一模型 BAGEL / Janus-Pro-7B 各在 8 个任务上掉分；VSTAR 上同一规划提示外加生成图反而降 10.47pp；ChartQAPro / MathVista 始终低于不生成基线，仅 ERQA 连续编辑 10 次后 +3pp。

4 · DRBench Pro: A Knowledge-Centric Benchmark for Professional Deep Research Agents

原题DRBench Pro: A Knowledge-Centric Benchmark for Professional Deep Research Agents
中文一句话现有深度研究 agent 基准多评报告质量，缺「覆盖了哪些研究方向、挖得多深」的知识中心评测；DRBench Pro 用自动流水线从维基百科构建本地知识树、采样子图生成查询与有证据支撑的评分细则（每条细则对应树中一个关系、保留知识结构），据此测「主要方向上的广度」与「相关知识链上的深度」并取几何平均；含 24 域 144 例、44,102 条细则，评 16 个深度研究 agent（最好者总覆盖 57.04%），细则判分与人工高度一致且排名跨指标配置稳定。

5 · Repairing the Trustworthiness of Distilled Language Models

原题Repairing the Trustworthiness of Distilled Language Models
中文一句话知识蒸馏让小模型可部署，但压缩即使保持下游性能也会带来「可信性回归」，而直接偏好优化可能改掉从教师继承的能力；作者提出基于近端 Bregman 响应函数（PBRF）的定向修复：用替代代理数据估曲率以摆脱对原蒸馏语料的依赖，再用几率比目标扩展到偏好监督（用「偏好/非偏好回答对」在约束改动幅度下修复）；对预训练与后训练蒸馏模型均提升目标可信行为（可信性回归最多改善 8%、困惑度下降 <1%），是「再蒸馏 / 无约束偏好优化」之外的实用替代。
