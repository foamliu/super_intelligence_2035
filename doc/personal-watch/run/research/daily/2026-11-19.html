1Storing the Gemma 4 K=V Cache Once: Exact Global-KV Memory Savings in a Paged Serving Engine with Unchanged Attention Kernels

作者 / 机构Kushagra Bainsla（San José State University，单作者）
提交 / 更新2026-11-17（v1）
分类 + 标签cs.LG ｜ 借鉴 推理服务 / KV cache / 长上下文
中文一句话Gemma 4 的 global attention 层里 value 是归一化后的 key 投影、key 是 value 乘一个固定权重，作者据此把每个 KV head / token 的缓存从 1,024 个值压到 640 个值（−37.5%），并用两个重叠的 strided view 让原版 paged attention kernel 不改；vLLM 原型（16-bit 31B）解码期每请求 KV 内存在 32K–64K 上下文下降到 1/1.34–1/1.40。
链接abs: 2611.23035 ｜ pdf
推荐理由：这是一篇「用模型结构换服务内存」的精确工程：不改 kernel、不改输出算术，只改缓存布局。对我们在研的两件事直接相关：① 长上下文部署的显存预算（同卡同 batch 能多放多少 token）；② 预训练侧若采用「K/V 共享投影」类结构，服务栈能不能零改动吃到红利。它的证据链也干净：bit-identical 对账 + 2/432 答案差异落在 run-to-run 噪声内 + 一个 block-pool 模型把两个吞吐比预测到 1% 内。
我们的观察（非原文结论）：这类收益的上限由「结构里到底冗余多少」决定，而不是由 kernel 优化决定 ⇒ 选型时应先算「每 head/token 的理论最小存储」，再看 serving engine 是否已经实现。
