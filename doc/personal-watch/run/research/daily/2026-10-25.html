1RIFT: KV Cache Compression for Draft Models with Complementary Compressibility Training

中文一句话
投机解码擅长长输出，而长输出意味着 draft 的 KV cache 越来越大；面向 prefill 信息的 KV 压缩方法会随输出变长而「过期」（作者称之为 decode staleness），从而拉低 draft 准确率。RIFT 提出一族基于选择的 KV cache 压缩策略，在「prefill 信息」与「最近生成的 token」之间做平衡，并在生成过程中刷新 KV 选择；为压低刷新带来的解码延迟，再提出自适应刷新策略，减少打分次数同时保住 draft 质量。作者还用基于稀疏注意力掩码的「可压缩性驱动」draft 训练阶段，提升 draft 在压缩缓存下的质量。与可压缩性训练结合后，Qwen3.5-4B 为 Qwen3.5-122B 做 draft，在 32K 输入 / 4K 输出、8K KV 预算下保留超过 98% 的满缓存接受长度。

推荐理由（借鉴 · BaiZe / 推理侧长上下文加速）
  1. 它给「压缩为什么会坏」起了名字：decode staleness —— 用 prefill 期的相关性去选 KV，输出越长越不相关。这不是又一个压缩比例，而是一条选型判据：我们评估任何 KV 压缩方案时，应在长输出（推理链 / agent 轨迹）而非只在长输入上测（我们判断：这是本篇最可迁移的一点）。
  2. 两处可直接落地的工程件：①「生成期刷新 KV 选择 + 自适应刷新」—— 本质是在精度与 draft 解码延迟之间做预算；②「稀疏注意力掩码驱动的可压缩性训练」—— 这是训练配方，能进 BaiZe 的 draft 训练（不是纯推理侧 trick）。
  3. 数字有明确前提，不宜当普适结论：98% 接受长度是 Qwen3.5-4B→122B、32K 输入 / 4K 输出、8K KV 预算这一组设定下的结果，且是接受长度而非端到端加速比；摘要未给与其它压缩基线的逐项对比。
  4. 边界（我们判断）：作者来自 NVIDIA，视角偏硬件/服务栈（含 hardware-disaggregated inference、edge-assisted serving），对我们的单机训练 / 自建服务未必同构；主实验基于 external draft（非 MTP/EAGLE 类 tail-augmented），我们的 draft 形态若不同需重测；数字作者自报、本线未复现；未精读（刷新触发条件与打分成本需看原文）。

2Edit, Don't Imitate: Minimal-Edit On-Policy Distillation for Multimodal Reasoning

中文一句话
视觉数学推理可能「推理还没开始就错了」：VLM 读错图，后续推理便建立在假前提上。这个感知瓶颈在小模型上尤其明显，而准确的文字描述能显著缩小与大模型的差距 —— 给一个 2B VLM 一份忠实图注，Geometry3K pass@1 从 0.32 升到 0.46，接近约 4 倍大的 8B 模型的 0.49；但推理时要拿到这些描述，需额外标注或模型调用。作者提出最小编辑式纠错 on-policy 蒸馏：只把「参考图注 + 已验证参考解」当训练时信息，让 teacher 以最小编辑目标给学生的错误 rollout 打分，只有 teacher 不认可的 token 进入纠错损失；正确 rollout 则用任务奖励做 RL。这样既保留 on-policy 监督，又避免整段模仿教师。方法在测试时不需要图注，在各模型规模上达到或超过「推理时给基线模型参考图注」的效果；也提升面向感知（尤其低层几何感知）的表现，并可迁移到外部数学与感知基准；用冻结的同尺寸 teacher 仍有效，但多数指标上增益小于更大的 teacher。
原题
Edit, Don't Imitate: Minimal-Edit On-Policy Distillation for Multimodal Reasoning

推荐理由（借鉴 · BaiZe 小模型 + 多模态后训练）
  1. 把「小模型多模态差」拆成两件事：2B 读对图注就能从 0.32 到 0.46（8B 为 0.49）—— 说明相当一部分差距是看错图而不是不会推。这对我们判断「该加参数、加数据，还是改后训练目标」是一个很便宜的诊断实验（我们判断：这一条对 BaiZe 的多模态分支最有价值）。
  2. 「最小编辑」是蒸馏与 RL 的粘合方式：只惩罚 teacher 不认可的 token（而非整段模仿），正确 rollout 走任务奖励 RL。它是对我们现有 SFT/蒸馏配方的一个轻量改动，不是换一套流程；且 teacher 只打分不生成完整解，成本低于常规蒸馏。
  3. 推理时零额外开销：不引入图注检索、不调用额外模型 —— 对线上服务的时延与显存都友好，这一点比「给测试时加图注」的基线更有部署价值。
  4. 边界（我们判断）：主战场是视觉数学/几何，通用图像理解、OCR、图表问答是否同样成立未验证；摘要未给 teacher 的模型名与规模（只说来自同一家族 / 更大模型），不可假定可复现；同尺寸冻结 teacher 增益明显更小 ⇒ 我们的 teacher 选型仍是关键变量；数字作者自报、本线未复现；未精读。

3Forging More Tasks into Better Harnesses: Agentic Harness Evolution via Successive Scale Racing

中文一句话
agentic harness 演化用 agent 自己的任务执行经验当证据，去优化它的指令、工具与控制流；直觉上「演化任务越多越好」，但作者的预备研究却发现一个悖论式失效：任务池扩大时现有方法性能反而下降。进一步分析表明退化来自优化过程中的证据选择不佳 —— 不同证据组合会导致差别很大的演化结果。作者提出 Successive Scale Racing（SSR）：每轮按任务的质量与覆盖度构造多样化证据组合，并在小算力预算下对候选 harness 做竞速筛选（逐级淘汰）。在 3 个基准 × 6 种配置上取得 SOTA；任务池从 40 增到 200 时，SSR 通过率从 64.3% 稳定升到 68.3%，而基线全部下降；竞速机制在识别近最优候选的同时把验证执行减少 60%。
