2CADET: Construction of PCB Routing Instances with Executable Demonstrations

中文一句话
指出公开 PCB 布线数据只有终态、没有 EDA 引擎动作的可执行演示，于是联合生成合成板与演示：RouteDemos 给出 100,000 块零 DRV 合成板及逐步演示，17 项统计量分布贴近 142 块真实参考板；在其上先行为克隆再 RL 微调，真实测试板的「完全无 DRV 布线率」从 RL-only 基线 38.0% → 67.2%，与开源自动布线器 FreeRouting 相当、优于其余基线（含 GPT-6 Astra）。

3EvoX: Rethinking the Agent Harness as a Runtime Policy

中文一句话
把 harness 当成与模型语义策略互补的运行策略（Operational Policy）：用 Action Realization（动作落地）、Execution Continuity（流程不中断）、Outcome Grounding（完成声明必须有证据）三个确定性机制，解决「模型决策看起来对、执行却失败」（工具调用失配 / 流程中断 / 无根据的完成声明）；并提出 Contrast 评测框架（公平约束 + provider 侧请求核验 + 证据裁定）。在 5 个基准 / 6 个基座 / 6 个 harness、691 个共同 task–model 对上成功率 56.2% 最高，比其余 5 个 harness 均值高约 3.0 个百分点（GLM-5.3 +10.7、Kimi K3 +7.9）。

  1. 「Outcome Grounding」正是我们评分表缺的那一条：agent 说「已修复」但网表没变、DRC 没跑 —— 这类失败在我们 TB-2.1 / zhulong 的失败集里占比不低。可落地做法：凡是「完成」类声明，必须绑定一个可复算的证据文件（时间戳 + 命令 + 退出码 + 产物哈希），否则该步记 unverified_claim，不进成功计数。
  2. 「Execution Continuity」把中断当一等公民：我们的工具链（综合 / 仿真）经常超时或被 OOM 杀掉，当前口径容易把「基础设施故障」计入模型能力。EvoX 的做法是把「恢复」写成运行时策略，与模型解耦 ⇒ 可直接对齐 harness 的额度失败 vs 能力失败归因纪律。

4Unbundling Multimodal Vision Encoding

中文一句话
把多模态模型的视觉编码器拆成三个可分离的设计选择（上游预训练带来的视觉先验 / 专用视觉容量 / 融合前放置），在同一数据、匹配的 lifetime compute 下全部从头预训练做控制对照：视觉先验并非必需（联合从零训练的编码器与预训练编码器持平）；真正起作用的是专用视觉容量（无编码器模型即使把骨干按编码器参数量加大仍落后）；该容量也不必前置，在骨干早期层「融合中加入」视觉模块表现相当，并可降低首 token 时延。结论在骨干规模变化、把编码器预训练视为免费、以及从预训练语言模型出发时均成立。

线建议动作（可直接执行）预注册判据 / 验收
pretrain把 Deep Learning（#110）的论证链写成立项页三段：手工特征基线 → 表示学习 → 规模外推；并在 BaiZe 领域语料上跑一个非神经基线（TF-IDF / n-gram 检索或规则打分）作为「任务是否真需要预训练」的对照。若非神经基线在留出集上与 2B 模型差距 <5 个绝对点 ⇒ 该任务太浅，先换更难的题，🚫 不用它证明预训练价值。
vision视觉塔先跑「AlexNet 级配方」消融：固定小分辨率 + 固定 patch 数，只开关 ReLU / dropout / 数据增广三项，确认管线与判分正确后再上 ViT / 混合结构（#111 vs #88）。三个开关全开时若验证集不如全关 ⇒ 先查数据管线与标签，🚫 不换模型；基线未跑通前不得报「新结构更好」。
harness给所有「模拟环境 / 代理模型」加反事实一致性测试（同一状态给不同动作，产物必须系统性不同）+ 随机动作基线（照 Genie #108 的可控性质疑）。代理模型产物分布与随机动作无显著差异 ⇒ 判「不可用」，不进任何闭环评测。
datamanifest 增列 label_status（有标注 / 仅原始观测）与 action_coverage（覆盖多少种工具调用），报表给出「无标注数据占比」（照 Genie 的无监督价值）。若仅原始观测数据占比 >80% 而下游无增益 ⇒ 瓶颈在筛选与对齐而非采集，暂停扩量、先做数据选择实验。
zhulong本轮起所有性能 / 成本主张三列同报：计算量、访存量、墙钟时间（照 Memory Wall #109）；缺一列即标 不可比。同一实验两次重跑墙钟偏差 >10% ⇒ 先冻结环境（绑核 / 固定 batch / 固定 trace）再谈结论。
designflowL4 成本估计改用周期级模型（DRAMsim3 #79 / Ramulator 2.0 #51）并登记配置哈希；布局题同时登记 DREAMPlace 默认（#103）与 AutoDMP（#106）两个基线。缺「模拟器配置哈希」⇒ 视为不可复现，不进汇总；代理模型对 L4 抽样校准的相对误差 >10% ⇒ 只许用于排序、不许用于报数。
