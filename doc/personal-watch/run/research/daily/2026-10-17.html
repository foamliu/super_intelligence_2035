1Compression Does Not End at Selection: Post-Selection Positional Geometry for Sparse KV Caches 借鉴

原文标题
Compression Does Not End at Selection: Post-Selection Positional Geometry for Sparse KV Caches
中文一句话
稀疏 KV 压缩通过保留部分历史状态降低长上下文推理成本，但这些状态仍沿用原始（全长历史）位置坐标；在 RoPE 下，被逐出 token 留下的位置空隙会继续影响 query–key 匹配，可能削弱对所保留证据的利用。作者在「固定选择器产出的缓存」上研究选择之后的位置几何（post-selection positional geometry），提出 RoPERelay：为缓存键赋予紧凑且保序的 RoPE 坐标，通过逆旋转 + 再旋转迁移已缓存 key 的相位，并同步当前 query 与后续生成；它复用既有 K/V，无需重新选择、历史重预填或额外缓存预算。在跨 2 个模型、6 个稀疏选择器、3 类长期记忆任务的 36 组对比中，RoPERelay 在 32 组提升答案质量；Llama-3.1-8B-Instruct + BM25 在 LongMemEval-S 上准确率 23.6% → 35.4%，实测整请求时间开销约 1%–3%。⚠️ 数字为作者自报、本线未复现。
作者
Wanyang Hong, Zhaoning Zhang（2 位）

2HPCAgent-Bench: A Framework for Sound Benchmarking of Code-Optimizing Agents, Harnesses, and Skills 借鉴

原文标题
HPCAgent-Bench: A Framework for Sound Benchmarking of Code-Optimizing Agents, Harnesses, and Skills
中文一句话
Coding agent 越来越多被用来优化代码，但现有基准把「加速器 / 编程模型 / harness」固定死，因而无法拆出各组件各自的贡献，也看不出新增技能与工具是否值回成本。作者提出 HPCAgent-Bench：含 689 个 kernel、分 3 条赛道（循环级优化挑战 / 从 HPC 代码抽取的 kernel / 机器学习模型）；每个 kernel 只在 NumPy 里写一次，再派生 C 与 Fortran 参考实现，提交可经统一 C ABI 或 Python 接口接入，并可在 CPU / GPU、单机 / 多机上运行。外部裁判用隐藏 fuzz 输入校验正确性并计时，堵住 agent 利用测试系统作弊的路径。作者给出两个报告指标：intervention efficacy（干预效力） —— 通过配对实验在加速比 / 成功率 / 成本上度量一次干预（例如加一个工具）的效果；weighted token cost（加权 token 成本） —— 在显式权重下报告输入 / 缓存输入 / 输出 token。结果：agent 相对自动并行化器最高 4.2× 加速，优化还能迁移到另一台机器（93%–99% 未含设备特有代码的答案仍正确，逐 kernel 加速比保持 秩相关 rs ≥ 0.84）；在 40 组配对设置中，干预只有 2 次显著改变加速比，但 token 成本最多差 3.0×。代码/数据开源（github.com/Copik/HPCAgent-Bench，原文自述）。⚠️ 数字为作者自报、本线未复现。
作者
Yakup Koray Budanaz, Lorenzo Paleari, Marcin Copik（前 3，共 10 位；et al.）

3MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering 借鉴

原文标题
MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering
中文一句话
LLM 正从「辅助科研与工程」走向「自主开发与改进 AI 系统」（AI4AI → 递归自我改进 RSI）。工作流式 MLE（机器学习工程）系统通过复杂编排管理长时程实验，是务实路径；较新的 MLE 系统采用模型主导的交互，让模型自主组织实验、依执行反馈调整优化策略。但每个实验的反馈混合了此前多个决策的影响，且一次长 MLE 运行包含许多昂贵的实验 ⇒ 训练必须从长交互轨迹中选出有用监督、并从中间结果学习。作者提出一种后训练方法，训练出 MLExpert —— 一个 35B Mixture-of-Experts agentic 模型：设计 Kaggle-MLE Factory 构造可执行任务与模型主导实验的交互 harness；分层 agentic SFT 以「结果引导的监督」把通用工具使用与编码能力迁移到 MLE；窗口化交互 RL（WIRL） 把「相邻两次实验结果之间的多轮决策」视为一个执行窗口、赋一个共享的结果奖励；异步采集 + 策略校正支持在轨迹结束前更新策略。在 MLE-Bench Lite 上，MLExpert 把基座模型的平均奖牌率从 37.9% 提到 72.7%，与更大的前沿模型（如 Kimi-K3 / GLM-5.3）可比；在 NatureBench Lite、agent scaffold 优化、算法优化上亦有提升，提示所学优化能力可泛化。代码/模型已开源（github.com/InternScience/MLExpert）。⚠️ 数字为作者自报、本线未复现。
作者
Shangheng Du, Jinxin Shi, Shuaiyu Zhang（前 3，共 10 位；et al.）
