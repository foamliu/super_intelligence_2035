1 · TEA-Bench-BR: Can Coding Agents Turn a Branching Clinical Specification into Correct Code?

原题TEA-Bench-BR: Can Coding Agents Turn a Branching Clinical Specification into Correct Code?
中文一句话把「分支很多的领域规范 → 正确代码」做成可自动判分的 agent 基准：隐藏用例必须杀死参考实现的全部 1,955 个非等价变异体，模型错在输入校验而不是临床判断。
作者 / 机构Marcio Andre de Souza Estevam（单作者；论文摘要区未标机构）
提交 / 更新2026-11-20（arXiv v1；Submitted on 20 Nov 2026）
分类 + 标签cs.SE（primary；另 cs.AI / cs.CL）｜ 🏷 借鉴（harness / designflow 判分可验证性）
链接arXiv:2611.27895
推荐理由论文开篇点出「静默 bug」：代码能跑、返回看似合理的答案——这与 EDA agent 生成 RTL / 脚本的失败模式同构。可复用的不是题目本身，而是判分构造：用参数化生成器采样任务（144 tasks），再用 6,798 个隐藏用例覆盖；隐藏集能杀死参考解的全部 1,955 个非等价变异体（变异体杀灭率作为判分充分性的证据）。分级也值得抄：L1–L3 从单表到 FHIR/RNDS 导出，12B 单表 38.0%、FHIR 层 0 分，31B 为 77.8% / 85.2% / 78.7%，剩余失败多在输入校验而非临床决策。注意：这是 Kaggle Gemma 4 开发者论文赛道的 7 页短文，未经同行评审。

2 · RoSci: Exploring Robustness in Science VLMs

原题RoSci: Exploring Robustness in Science VLMs
中文一句话科学 VLM 被默认「输入信息完整且正确」，RoSci 用 1,220 个样本、六类退化制造「信息错误 / 信息缺失」，并用 Parse-Verify-Decide 流程先审前提再推理。
作者 / 机构Junying Wang · Yijin Guo · Yalun Wu（等；摘要区未列全机构）
提交 / 更新2026-11-20（arXiv v1；Submitted on 20 Nov 2026）
分类 + 标签cs.CL（primary；另 cs.AI / cs.CV）｜ 🏷 借鉴（vision 鲁棒性 / harness 诊断）
链接arXiv:2611.27750
推荐理由它把「鲁棒性」拆成三个可判定的能力：检测异常、判断可解性、自校准；再按 Information Error（不一致）与 Information Loss（不充分）两大类、六种退化生成 1,220 个 seed-variant 样本。对我们的直接价值是评测轴：vision 线现在多在「完整输入」上报指标，缺「输入坏掉时会不会瞎答」这一轴。RoSci-Agent 的 Parse-Verify-Decide 也可作为 harness 的低成本基线。局限：科学题偏文本 + 图表，和图文预训练的数据分布不同，不能直接当视觉编码器结论。

3 · Enhancing Attention with Higher-Order Attention

原题Enhancing Attention with Higher-Order Attention
中文一句话指出自回归注意力「并不严格自回归」，提出把互信息分解为条件互信息、并引入 key/query 相邻相关与广义最大熵，得到三种更高阶的注意力形式。
作者 / 机构R. I. Cukier（单作者）
提交 / 更新2026-11-20（arXiv v1；Submitted on 20 Nov 2026）
分类 + 标签cs.CL（primary）｜ 🏷 借鉴（pretrain 架构假设，纯理论线索）
链接arXiv:2611.27764
推荐理由三条具体构造可讨论：① 把 MI 分解成一组 CMI，让 key 与成对 query 相关；② higher-order attention 引入相邻 key/query 的相关；③ 用广义最大熵得到跨一段 token 序列的注意力表达式。它挑战的是「单 query 对单 key 打分」这个默认假设。⚠️ 摘要未给实验与数字，属理论线索；本线不据此下「更强」结论，若要跟进须先复现小规模对照。

线建议（可落地）
pretrain把「注意力 = 单 query 对单 key」列为待验证假设（2611.27764）：先在 1–2 层实现「相邻 key/query 相关」变体，做同 token 数 / 同参数量对照，判据 = 验证困惑度 + 长上下文检索；摘要无实验 ⇒ 不复现不下结论。ViLT 口径（2102.03334）：若改用 patch 投影输入，报告须同时给吞吐与精度。
vision评测表新增「输入退化」轴（2611.27750）：按 Information Error / Loss 各 3 档造退化，指标 = 异常检出率 + 可解性判断 + 自校准误差；双塔 / 单塔对照（2112.04482）与双塔检索基线（2102.05918）必须同数据同算力。
harness引入「隐藏用例杀灭率」作为判分充分性门槛（2611.27895）：先对参考解生成语义保持变异体，要求隐藏集杀死全部非等价变异体，才允许用于 agent 排名；报告须写采样预算 / 温度 / top_p（沿用 VerilogEval 口径）。
data做「过滤强度 × 规模」预算表（2102.05918）：同一算力下比较强过滤小语料与弱过滤十亿级语料，同时报下游零样本 / 检索指标与清洗成本；只报指标不报成本 ⇒ 不进结论表。
zhulong成本表加「判分构造成本」一列（2611.27895）：隐藏用例数 × 变异体数 × 每次仿真时长；对照 2309.07544 的 156 题规模，给出「题数 → 判分 GPU-hours」的线性假设与实测值。
designflowRTL 题采用「题面 + testbench + 参考解 + 变异体集」四件套（2611.27895 + 2309.07544）：判分先跑仿真，再用变异体杀灭率验判分充分性；L1–L3 分级照搬「单模块 → 多模块 → 系统导出」，每级单独报通过率。
