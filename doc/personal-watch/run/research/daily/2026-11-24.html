中文一句话科学 VLM 被默认「输入信息完整且正确」，RoSci 用 1,220 个样本、六类退化制造「信息错误 / 信息缺失」，并用 Parse-Verify-Decide 流程先审前提再推理。
作者 / 机构Junying Wang · Yijin Guo · Yalun Wu（等；摘要区未列全机构）
提交 / 更新2026-11-20（arXiv v1；Submitted on 20 Nov 2026）

链接arXiv:2611.27750
推荐理由它把「鲁棒性」拆成三个可判定的能力：检测异常、判断可解性、自校准；再按 Information Error（不一致）与 Information Loss（不充分）两大类、六种退化生成 1,220 个 seed-variant 样本。对我们的直接价值是评测轴：vision 线现在多在「完整输入」上报指标，缺「输入坏掉时会不会瞎答」这一轴。RoSci-Agent 的 Parse-Verify-Decide 也可作为 harness 的低成本基线。局限：科学题偏文本 + 图表，和图文预训练的数据分布不同，不能直接当视觉编码器结论。

3 · Enhancing Attention with Higher-Order Attention

原题Enhancing Attention with Higher-Order Attention
中文一句话指出自回归注意力「并不严格自回归」，提出把互信息分解为条件互信息、并引入 key/query 相邻相关与广义最大熵，得到三种更高阶的注意力形式。
作者 / 机构R. I. Cukier（单作者）
提交 / 更新2026-11-20（arXiv v1；Submitted on 20 Nov 2026）
分类 + 标签cs.CL（primary）｜ 🏷 借鉴（pretrain 架构假设，纯理论线索）
链接arXiv:2611.27764
推荐理由三条具体构造可讨论：① 把 MI 分解成一组 CMI，让 key 与成对 query 相关；② higher-order attention 引入相邻 key/query 的相关；③ 用广义最大熵得到跨一段 token 序列的注意力表达式。它挑战的是「单 query 对单 key 打分」这个默认假设。⚠️ 摘要未给实验与数字，属理论线索；本线不据此下「更强」结论，若要跟进须先复现小规模对照。

作者 / 机构Minye Shao · Chenghao Xiao · Xingyue Zhao · Yang Long（Durham University / Shanghai University of Finance and Economics）
提交 / 更新2026-11-20（arXiv v1；citation_date = 2026/11/20）

链接arXiv:2611.27734
推荐理由它的价值不在「又一个 QA 榜」，而在把知识表示本身当变量：同一任务集下比较「无知识 / 纯检索 / agent 自建本体 / 专家本体」四种条件（matched knowledge representations），并用源站原生校验（source-native verification）。两个可直接借用的数字是 +6.1（自建本体相对检索）与 −13.0（相对专家本体），说明瓶颈是知识获取而不是检索；四类任务 Application / Repair / Organization / Construction 也可映射到 EDA 流程题（调用 / 修错 / 归类 / 构造）。局限：领域为通用科研知识，不是版图 / 器件知识，迁移需重造题面。

5 · DistDNA: Language Model Fingerprinting under Stochastic Decoding

原题DistDNA: Language Model Fingerprinting under Stochastic Decoding
中文一句话把模型指纹从「单条响应」改成「prompt 条件响应分布」，用 promptwise MMD 做免训练最近邻匹配，在 115 个 checkpoint 上比 LLM DNA 高 10.36%。
作者 / 机构Lifan Hu · Qian Yu · Zhaomin Wu · Bingsheng He（National University of Singapore）
提交 / 更新2026-11-20（arXiv v1；citation_date = 2026/11/20）
分类 + 标签cs.LG（另 cs.CL）｜ 🏷 借鉴（harness 模型核验 / data 部署一致性）
链接arXiv:2611.27831
推荐理由它抓住了一个常被忽略的评测前提：线上模型是随机解码的，同一 prompt 的响应会随未知 temperature / top-p 变化，而「换解码设置」与「换 checkpoint」对指纹距离的影响可能同量级。做法是先估计每个 prompt 的响应分布，再用 promptwise MMD 与多档解码设置下的参考指纹比最近邻，不训练分类器；并给出方差项随 O(1/R) 下降的理论说明（R = 每 prompt 采样条数）。可直接落到 harness：验收「部署模型是否就是声称的 checkpoint」时，报告须写清 R、解码档位与同家族混淆率。局限：115 个 checkpoint 条目仍是小规模，跨厂商 / 跨 tokenizer 未验证。

线建议（可落地）
pretrain给 EMA / 动量教师做「m 扫描 + 单旋钮」实验（1911.05722）：MoCo 的 key 分支不回传梯度，只更新动量编码器 ⇒ 先检查实现里梯度是否只走 query，再扫 m ∈ {0.9, 0.99, 0.999}，固定其它变量。视觉/语言容量比（2209.06794）：若扩视觉塔，报告须同时给视觉参数量、图像分辨率与语言塔参数量，否则无法归因；论文未给幂律 ⇒ 不当 scaling law 引用。
vision自监督基线先跑 MoCo 配方（1911.05722）：队列长度 K 与 batch size 分开扫，判据 = 冻结特征线性探针 + 7 个下游任务中的至少 2 个。长尾 / 未知类别改用文本头（2205.06230）：闭集头 vs 文本头同数据同算力对照，单列长尾类指标；零样本与单样本条件分开报。
harness把「部署模型核验」写成协议（2611.27831）：固定每 prompt 采样条数 R、列出覆盖的 temperature / top-p 档位，报告同家族（仅差 SFT）checkpoint 的混淆率；缺 R 与解码档位的「指纹一致」不算证据。知识表示对照（2611.27734）：同一题集跑「无知识 / 检索 / agent 自建本体 / 专家本体」四档，报告每档绝对分与差值。
data加中文图文对前先做退化对照（2209.06794）：预注册「加中文后英文任务是否退化」的判据（英文零样本 / 检索各 1 项，允许跌幅阈值）。知识源审计（2611.27734）：18 个知识源的「源站原生校验」可借为 EDA 文档入库的可验证性门槛（每条知识点必须能指回原始文档位置）。
zhulong成本表新增「知识表示」与「核验协议」两列：知识表示列（2611.27734）记录构建本体的人工小时与任务成功率增益；核验协议列（2611.27831）记录每 prompt 采样条数 R × prompt 数 × 解码档位 = 核验采样成本，避免只在论文里报准确率。
