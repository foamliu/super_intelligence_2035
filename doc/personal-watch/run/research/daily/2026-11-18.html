中文一句话用因果 patching 拆出 VLM 描述图像时的四段机制：binding heads 把文本 token 对到图像区域、同一批 heads 用逗号 token 把已写答案变成「游标」、select 选游标之后最近的未写区域或停止、gaze heads 取回该区域内容；主要在 Qwen3-VL-8B-Instruct 上验证，并称该结构在 2B–32B 各规模均出现。
链接abs: 2611.21600 ｜ pdf ｜ 项目页

pretrain把「临时 weight decay 调度」做成一次可复算小实验：162M 模型 × 20B token，比较 ① 全程 λ=0.15 ② 前 44% λ=0.15 后撤除 ③ 前 44% 撤除后恢复；预注册判据 = 终点验证困惑度差 ≥0.01 nats 且撤除后 ≥73% 步数才反超。依据：2611.21608 + 1711.05101 + 2611.17876。
vision加一条「同图多轮追问」口径：固定图像连续问 N 轮，测第 1 轮与第 N 轮定位/读数准确率差；若差 >3 点，再考虑把高分辨率 crop 压成 64-token latent memory（参照 2611.21457 的 7.6–9.9× 压缩与 2.5–4.8 点增益）。依据：2611.21600 + 2611.21457。
harness判分器改为「产物存在性 + 空跑记 0」，exit code 只做旁证：先统计自有 18–20 个产物型任务上「exit code 判分 vs 产物判分」的分数差；差 >5 点即改口径。依据：2611.21407 的 127/357 无产物、85 个正常退出。
