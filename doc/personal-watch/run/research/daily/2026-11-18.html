中文一句话把「看过的 crop」压成 64 个连续 latent token 当作视觉记忆，再丢掉原始 crop token：在两代 Qwen-VL 的 LRS-GRO 上实现 7.6–9.9× 压缩，比只用降采样全图高 2.5–4.8 个百分点，并基本追平直接给高分辨率 crop 的收益；而把记忆换成「另一张图 / 同图另一区域」会掉 5.8–7.4 点，比直接删掉记忆还差。

作者 / 机构Arunkumar V, Manoranjan Gandhudi, Gangadharan G. R., Arun Prakash, S. Senthilkumar（Anna University, BIT Campus, Tiruchirappalli）

中文一句话在 124,416 条可执行授权策略上下文上，用「精确 process oracle」当金标准，逐轴退化判分器（仅结果 / 充分性 / 仅召回 / 抽取噪声 / 粗分类 / 过期策略 / LLM 裁判），结果出现四种表型：乐观判分器被「堆理由」刷分——充分性代理停在 0.940，而真实忠实度从 0.731 掉到 0.667（96 个留出 episode）；仅结果判分器很快饱和、噪声只是稀释、保序偏差无害。
