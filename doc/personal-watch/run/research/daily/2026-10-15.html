原文标题
Mixed Precision Scaling Laws for Quantized Pretraining
中文一句话
既有规模律开始纳入量化（跟随 AI 加速器上的低精度数据类型），但多只考虑量化对「模型容量」的影响。本文从优化理论出发 + 实证校验，给出一个更准确的「前向 / 反向混精度训练」规模律：把量化对模型容量与对优化效率的影响分开建模，并显式刻画收敛分析中发现的「前向 / 反向量化带来的持续优化误差」。为选定拟合与评估区制，作者先把现有 4-bit 训练配方分解为前向 / 反向两部分、隔离出对 loss 影响最大的成分。在 Qwen3 的选定 4-bit 区制实验、加上已发表的 Llama 类实验上，该律随模型规模与 token 数增长的 loss 预测 MSE 比既有律最多低 11 倍；并进一步扩展到逐层混精度，在硬件感知算力预算下给出最优量化预训练配方（模型大小 / 训练 token / 逐层前向反向精度）。与以往「精度规模律」不同，该律预测「最优精度随算力预算提高而提高」。
作者
Jinuk Kim, Rajarshi Saha, Muhammed Fatih Balin, Youngsuk Park（4 位）

原文标题
MLAfication: Efficiently Enabling High-Fidelity MLA for Modern LLMs
中文一句话
Multi-Head Latent Attention（MLA）把 KV cache 压到潜在表示，降低推理显存与带宽；但既有 MHA2MLA / TransMLA 不支持 QKNorm、且在现代 LLM（尤其 MoE）上需要昂贵的恢复训练。作者提出 MLAfication：一个兼容 QKNorm、参数高效的 MHA→MLA 扩展，组合了「校准式 KNorm」「参数高效蒸馏」「贡献感知的 Partial-RoPE」与「激活感知的联合 KV 初始化」。在 MHA 与 GQA 模型（含 QKNorm 与 MoE 变体）上，MLAfication 在显著 KV cache 压缩下仍保持性能，在常识与长上下文基准上超过当前 SOTA，并把 MLA 转换扩展到现代架构。在 Qwen3-30B-A3B 上，服务吞吐最高为 BF16 GQA 的 5.35×；配合 4-bit KV 量化可把 KV cache 占用降低 94.73%。代码开源。

Zile Wang, Zhide Xie, Tao Ji（3 位）

3SWE-Stream: Scaling Executable Training Data for SWE Agents via Progressive Construction and Elastic Streaming 借鉴

原文标题
SWE-Stream: Scaling Executable Training Data for SWE Agents via Progressive Construction and Elastic Streaming
中文一句话
软件工程（SWE）agent 的训练受限于高质量「可执行任务」稀缺；开发历史含可构造此类任务的信号，但环境不全、单测缺失、产物不一致，往往需要大量重建。作者提出 SWE-Stream：通过「渐进式构造 + 弹性流式执行」来规模化可执行 SWE 训练数据 —— 渐进验证与精修任务候选，尽量复用已有产物、仅在必要时做定向补全；弹性调度器在共享资源约束下异步协调各构造阶段，按观测到的负载自适应执行预算。基于 6 种编程语言、10,728 个仓库的开发历史，构造 80,874 个经验证任务、采集 118,688 条成功轨迹。用这些轨迹微调 Qwen3-30B-A3B-Thinking-2507，在 SWE-bench Verified / Multilingual / Pro 上分别达到 69.0% / 49.3% / 45.42% 解决率；在训练预算大致匹配的受控对比中，SWE-bench Verified 上取得 45.6% 解决率、优于三种既有数据源。其流式构造策略效率更高：被接受任务吞吐为批式构造的 1.45×，比固定上限流式多接受 13.2% 任务。
作者
Chengyang Liu, Wen Yang, Shifeng Chen, Delai Qiu, Ji Yang, Junnan Zhu, Yining Wang, Shengping Liu（8 位）

4Moral Combat: Exploiting Moral Foundations Theory to Jailbreak LLMs 科普

原文标题
Moral Combat: Exploiting Moral Foundations Theory to Jailbreak LLMs
中文一句话
社会心理学早就描述了「人如何被说服把有害行为解读为道德」。近期研究表明 LLM 也复现了人类心理的若干侧面（认知偏差、社会从众等），由此引出一个有直接安全含义的问题：能否用「道德化」让 LLM 绕过安全护栏？作者提出一个基于「道德基础理论（MFT）」的多智能体框架：对一个最初被拒绝的有害请求，agent 先诊断该 prompt 违反了哪条道德基础，再找到一个能使同一请求显得「正当 / 美德」的道德基础，据此改写 prompt，并用生成的同类道德重构先例加以强化。作者在三个知名越狱数据集的有害 prompt 上、跨五个开源与专有模型评测：模型对「道德化」高度易感，单次尝试越狱率已很高，且在反复尝试下成功率进一步上升；同时发现安全基准在「所违反的道德基础」上分布不均衡，集中在模型本就存在偏差的那些基础上。
作者
Adel Khorramrouz, Yi-Chia Wang, Sharon Levy（3 位）

原文标题
When Extremists Enter LLM Societies: Investigating Extreme Behavior in Multi-Agent Systems
中文一句话
LLM agent 越来越多地充当多智能体社会模拟中的「计算行动者」；既有工作强调代表性人格与平均行为，而社会科学表明「持续存在的尾部行动者」能不成比例地左右集体动态。作者在受控的 LLM 多智能体系统（LLM-MAS）中研究这一规律：这类行动者不能被简化为固定标量状态 —— prompt、自然语言历史与 backbone 生成共同中介其行为与影响。作者先分析社会学中极端者的三条性质，并以「LLM 原生」视角对 LLM 极端者建模，提出 EXAM（EXtremist Agent Modeling）框架：可为特定任务配置极端者 agent，并精确控制其人口比例、空间分布、交互协议与测量接口。在国会选举、金融危机、疫情舆论、重复囚徒困境四类场景中，观察到「小而持续的尾部群体」会产生可测量的、依赖 backbone 与场景的集体偏移；EXAM 展示了这一社会科学规律如何通过语言中介机制在 LLM 社会模拟中显现。
作者
Guo Chen, Huaijin Xie, Ziwen Li, Reed Li, Yu Lu, Haibo Shi, Bingbing Xu, Junjie Huang（8 位）
