1Dobb: Shard-Local Preconditioning in Block-Diagonal Eigenbases

中文一句话
参数与优化器状态大到一个节点装不下时，张量只能切到多卡上；而在 TP / FSDP 下，Muon 这类「矩阵感知」优化器要做跨分片的全局矩阵运算（如正交化）⇒ 额外通信。Dobb 把它拆成分片内可本地完成的更新：用对角块近似输入激活的二阶矩、在每个块内维护一套完整特征基，把动量投影到该基、对系数做 sign normalization，再反变换回参数空间 —— 只要每个块落在一个分片内（TP / FSDP 的常见切法），矩阵更新就不需要跨卡通信，只剩数据并行对二阶矩的同步。GPT-2 XL（1.56B 参数）上，Dobb 取 16 块的验证损失 2.476，对照同样为削减通信而设计的 Dion（秩比例 1/16）为 2.511；在 32×H100 的 FSDP 上，把摊薄后的优化器调用时间从 124.1 ms 压到 9.2 ms。

推荐理由（借鉴 · 与 BaiZe / ZhuLong 的关系）
  1. 正面命中「大规模预训练的通信账」：BaiZe 这类从零训练的模型，优化器状态往往比权重更占显存（Adam 类是 2× 参数量），一旦上 FSDP / TP，矩阵感知优化器的正交化就成了纯通信开销。Dobb 的思路是把「全局正交化」换成「块内正交化」，把「全局」这件事挪进分片 —— 这跟我们评估任何新优化器时的第一性问题（通信量能不能随分片数不增）直接对齐。
  2. 实验设计可复用：① 与 AdamW / Muon / RMNP / Dion 四个基线在同一 update-scale 协议下比（把更新 RMS 对齐到 AdamW 的 0.2–0.4 区间，共用学习率与 weight decay）；② 在同一 token 预算、同一数据顺序、同一评测下扫 B ∈ 1/4/16/64，并把「块数增加」的代价与「Dion 秩比例下降」的代价逐尺度并列（XL 上 Dobb 从 B=1 到 B=64 损失只涨 0.021，Dion 从满秩到 1/64 涨 0.105）——这种「压缩率对齐 + 同预算」的比法，正是我们做数据配比 / 优化器消融时该抄的表结构。
  3. 边界（必须写清）：① 质量实验只到 1.56B（GPT-2 Small/Medium/Large/XL，OpenWebText、seq 1024、global batch 480 序列、bf16）；更大规模（GPT-2 3B/6B/8B、Qwen3-8B/32B）只测时间、不报损失；② 只在 transformer 块内的 2D 权重上做矩阵更新，embedding / LM head / bias / norm 仍用 AdamW；③ 作者把「块大小与基刷新频率该随层/随训练阶段怎么变」列为 future work ⇒ 超参没有调优结论；④ 数字作者自报、本线未复现。

3On the Fundamental Limits of Prefill-Based Decoding Length Prediction

中文一句话
只用 prefill 阶段隐状态预测一个请求会解码多少 token，是推理调度（批组队、容量规划、SLO）的关键原语。作者先指出：现有基准把「预测器质量」与「任务难度」混在一起 —— 换个目标模型 / 数据集 / 采样配置，报出的准确率就塌，而预测器本身没变。根因是被忽视的误差源：自回归解码的固有随机性。本文把解码当成停时随机过程：单步停止概率不是常数，而是在数百步内逐步上升，长度因此从众多局部决策继承中心极限定理 ⇒ 得到逐 prompt 的正态性与显式误差项，以及仿射方差律 σ = αμ + b（斜率 ≈ 响应分段数的变异系数）。实测（ShareGPT 300 prompts × 每 prompt 200 次解码、Qwen3-32B、temp 0.6 / top-k 20 / top-p 0.95）：E|Y−μ|/σ 中位数 0.783，高斯预测 2/π=0.798（误差 1.9%，且偏保守）；59,600 条标准化长度的 KS 距离仅 0.019。更关键：固定模型/数据/采样后，MLP、EGTP、FiLM、soft-label、MoE 一大片预测器都收敛到接近该上界的性能 ⇒ 「系统误差主导模型误差」。

推荐理由（借鉴 · 与 BaiZe / ZhuLong 的关系）
  1. 给「推理服务吞吐」提供了一个上界，而不是又一个预测器：无论我们是做连续批处理（continuous batching）还是 PD 分离，调度器都要预先猜「这个请求会跑多久」。这篇的结论是：光看 prefill 隐状态，预测精度的天花板由解码随机性决定 —— 也就是说，继续堆预测器模型容量的收益有限，要提精度只能改采样策略 / 分段统计 / 运行时反馈。这条「知道上界在哪」的判断，比多一个 +2 MAE 的模型更有决策价值。
  2. σ = αμ + b 是可直接上手的轻量工具：作者在 ShareGPT 上给每个模型拟合了 (α, b)（例：Qwen3-4B-Instruct α=0.1068、Qwen3-4B-no-thinking α=0.2029、DeepSeek-R1-distilled α=0.1156 / b=147.6），并指出 1/α² ≈ 25–90 可读作「有效独立停止机会数」。这意味着我们不必训练预测器，只用一个均值估计 + 线性方差，就能给调度器一个带不确定性的长度区间（对 SLO 违约率估算尤其有用）。
  3. 对评测纪律的提醒（可直接落到我们的 benchmark）：作者点名现有 ForeLen 基准的三个 split 上，同一预测器换模型就从「好用」变成 MAE > 150 / > 260；跨数据集（LMSYS200K→ShareGPT）MAE 182.40、跨任务（LeetCode→HumanEval）MAE 29.28。结论是「报准确率必须同时固定模型/数据/采样，并报相对误差」——这正是我们内部评测容易踩的坑。
  4. 边界（必须写清）：① 主实验集中在 Qwen3-32B + ShareGPT，其他模型（Llama3-8B、Qwen3-4B、DeepSeek-R1-distilled 等）只做分布律拟合；② 「预测器都收敛到上界」的实证是在固定条件下成立的，不排除换更丰富特征后突破（作者给的是该方法族的界）；③ 正态近似存在系统性小偏离（中位偏度 +0.27、超峭度 +0.35，作者用采样噪声项解释）；④ 数字作者自报、本线未复现。
