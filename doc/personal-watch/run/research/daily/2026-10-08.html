1PHBA: Prefix-State Hybrid Block Attention 借鉴

原文标题
PHBA: Prefix-State Hybrid Block Attention
中文一句话
在「线性序列模型 + softmax 注意力」的混合架构里，把原有的固定滑窗注意力换成 top-k 块稀疏检索，并让每个被检索到的块附带一个紧凑的「前缀状态」（由块边界处的门控线性递推生成），使同一层内同时拿到精确的远程证据与压缩的历史上下文；另给出硬件友好的 Triton 实现，流式处理被路由的 token 块与前缀状态、不落地大中间张量。

Ruijie Li, Jiaxi Hu, Shiyu Wang et al.（含 Yuxuan Liang；前 3 + et al）

原文标题
VETTA: Coordinating Turn- and Token-Level Credit Assignment for Multi-Turn LLM Agents
中文一句话
针对多轮 LLM agent「稀疏任务反馈 + 逐 token 生成」带来的两个信用分配问题，提出在同一次策略更新里同时学 turn 级与 token 级价值：在共享轻量 critic 上接两个头，把每个 turn 的优势与该 turn 内去中心化的 token 残差组合进 PPO 更新；并把 critic 只保留预训练模型的前面若干 Transformer 层以降低价值估计开销。
