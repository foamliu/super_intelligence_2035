## 1. LLM / 预训练架构

- **Latent Lattice Language Models**（arXiv:2611.21608，2026-11-16）
  作者：Shivam Duggal, Zongze Wu, William T. Freeman, Antonio Torralba, Richard Zhang, Eli Shechtman（MIT CSAIL + Adobe）
  分类：cs.LG ｜ 🏷 领域标签：预训练 / 残差流 / 循环状态
  一句话摘要：在垂直残差流之外给每层加一组沿时间循环的「横向 latent 流」，直接参与 attention、KV-cache 写入、MLP 与解码；20B FineWeb-Edu token 上 406M 参数模型验证困惑度 15.41 → 14.40（参数对齐 Transformer），叠加 hyper-connections 与输入残差后 14.22 → 13.61。
  🔗 abs: https://arxiv.org/abs/2611.21608 ｜ pdf: https://arxiv.org/pdf/2611.21608 ｜ 项目页: https://shivamduggal4.github.io/latent-lattice-language-model/

## 3. 多模态 / 视觉语言

- **How VLMs Plan What's Next**（arXiv:2611.21600，2026-11-16）
  作者：Rohit Gandikota, Arnab Sen Sharma, Adam Belfki, David Bau（Northeastern University）
  分类：cs.CV ｜ 🏷 领域标签：VLM 机制解释 / 视觉检索 / 多步规划
  一句话摘要：用因果 patching 拆出 VLM 描述图像时的四段机制——binding heads 把文本 token 对到图像区域、同一批 heads 用逗号 token 把已写答案变成「游标」、select 选游标之后最近的未写区域或停止、gaze heads 取回该区域内容；在 Qwen3-VL 8B 上验证，并称该结构在 2B–32B 各规模均存在。
  🔗 abs: https://arxiv.org/abs/2611.21600 ｜ pdf: https://arxiv.org/pdf/2611.21600 ｜ 项目页: https://plan.baulab.info/

## 4. agent harness

- **Harness Leverage Across Model Size: A Ladder of Five Local Agent Harnesses from 0.75B to 4.7B**（arXiv:2611.21407，2026-11-16）
  作者：Hao Wang（北京科技大学）, Ting Huang（荣耀终端）
  分类：cs.AI ｜ 🏷 领域标签：agent harness / 评测口径 / 小模型
  一句话摘要：5 个已发布 harness × 18 个产物型任务 × 4 个本地模型（0.75B–4.7B）+ 1 个 35.5B 锚点，用同一确定性 checker 打满 360 格；Mingbird（带 completion gate）在每个规模均值最高，去掉一条 repeat-blocking 规则在 0.75B 就掉 0.411，357 个可用单元中 127 个没有留下声明产物、其中 85 个正常退出 ⇒ 只读 exit code 的判分会给「没写出任何东西」的运行记分。
  🔗 abs: https://arxiv.org/abs/2611.21407 ｜ pdf: https://arxiv.org/pdf/2611.21407
