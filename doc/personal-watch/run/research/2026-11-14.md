## 2. agent harness / 运行时

- **EvoX: Rethinking the Agent Harness as a Runtime Policy**（arXiv:2611.15006，2026-11-11T04:05:54Z）
  作者：Haoyang Zhang · Qumeng Sun · Xiao Zhang · Xiang Liu · Zhidong Fan · Junjie Wang（共 6 位）
  分类：`cs.AI` ｜ 🏷 领域标签：agent harness / 运行时策略 / 工具调用失配 / 结果落地
  一句话摘要：把 harness 视为与模型「Semantic Policy」互补的 **Operational Policy**，用三个机制做确定性运行时控制——**Action Realization**（动作落地）、**Execution Continuity**（流程不中断）、**Outcome Grounding**（完成声明须有证据）；同时提出 **Contrast** 评测框架（显式公平约束 + provider 侧请求核验 + 基于证据的裁定）；在 **5 个基准 / 6 个基座 / 6 个 harness**、**691 个共同 task–model 对**上取得 **56.2%** 最高成功率，比其余 5 个 harness 均值高约 **3.0 个百分点**，在 GLM-5.3（+10.7）与 Kimi K3（+7.9）上优势更大。
  🔗 abs: <https://arxiv.org/abs/2611.15006> ｜ pdf: <https://arxiv.org/pdf/2611.15006>
