  分类：cs.CL（另 cs.LG） ｜ 🏷 领域标签：LLM / 循环深度 / 测试期算力

  作者：Nan Chen · Soledad Villar · Soufiane Hayou
  分类：cs.LG（另 cs.CL） ｜ 🏷 领域标签：后训练 / 学习率迁移 / 精度

## 03:00 时窗补充（A 轨收口 5/5）

- **CO-GRAFT: Attributing Reinforcement Learning Gains in Search Agents via Role-Level Policy Grafting**（arXiv:2611.31185，2026-11-23）
  作者：Ramraj Chandradevan · Sayontan Ghosh · Vinoth Selvendran
  分类：cs.IR ｜ 🏷 领域标签：agent harness / RL 归因
  一句话摘要：把 RL 训练后的搜索 agent 与 RL 前初始化拼成同一条实时检索轨迹，按四种功能角色做 2⁴=16 种干预指派（不改权重、不重训），用 Shapley 值分解 RL 总增益；实测查询生成只占 ≤15%，增益主要由 RL 前答案有效率、检索保留率、模型规模与固定检索预算决定。
  🔗 abs: <https://arxiv.org/abs/2611.31185>

- **Attention Temperature Confounds Zero-Shot Context Extension**（arXiv:2611.31113，2026-11-23）
  作者：Ruben Navasardyan
  分类：cs.LG ｜ 🏷 领域标签：LLM / 长上下文评测口径
  一句话摘要：零样本上下文扩展的「提升」可能只是注意力温度失校准；按模型与长度各校准一个温度后，块稀疏注意力 / attention dropout / ALiBi 的多数优势消失（ALiBi 反落后 RoPE 5%），建议长上下文结果一律在校准温度下报告并检查 normalization gain 是否真的移动。
  🔗 abs: <https://arxiv.org/abs/2611.31113>
