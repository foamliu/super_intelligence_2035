## 4. agent harness

- **Kolpona: An Agentic Framework with Gradient-Free Neuron Programming for RTL Generation**（arXiv:2611.33973，2026-11-25）
  作者：Musa Tur Farazi, Md Nasir Uddin, Soumik Bhattacharjee et al（5 位）
  分类：cs.LG ｜ 🏷 领域标签：EDA / agent / RTL / harness
  一句话摘要：不做梯度微调，用「神经元编程」闭式改写神经元权重并只在全新 testbench 有利时保留；工具型 agent 出候选、无标签选择器按规格与仿真选设计。Qwen3.5-4B 改 16 个神经元把 VerilogEval v2 pass@1 从 31.7% 提到 55.4%、全框架 77.6%；27B 从 73.1% 到 94.9%。
  🔗 abs: https://arxiv.org/abs/2611.33973 ｜ pdf: https://arxiv.org/pdf/2611.33973

- **AgentDRC: Multi-Agent Algorithms for Spatially-Aware Automated DRC Correction**（arXiv:2611.31876，2026-11-24）
  作者：Pengju Liu, Nuo Xu, Winson Chen et al（8 位）
  分类：cs.AR ｜ 🏷 领域标签：EDA / agent / physical design / designflow
  一句话摘要：把迭代式 DRC 纠错写成多智能体算法，重建关键形状的结构化空间关系并用几何 + 语义约束验证；困难违例 pass@1 最高 30.4%、pass@5 55.7%，比最好基线 pass@5 高 13.8 个百分点。
  🔗 abs: https://arxiv.org/abs/2611.31876 ｜ pdf: https://arxiv.org/pdf/2611.31876

- **RoboEvo$^2$: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution**（arXiv:2611.34675，2026-11-25）
  作者：Chenzhi Liu, Jiehong Lin, Wei Huang et al（12 位）
  分类：cs.RO ｜ 🏷 领域标签：agent / harness / self-improvement / posttrain
  一句话摘要：harness 与 policy 递归协同演化：策略失败驱动 coding agent 搜索 Code / Code+ICL / Code+Policy 并沉淀为技能与经验记忆；已验证轨迹用于监督 + 反事实偏好蒸馏。LIBERO-PRO 单机成功率 11.0%→84.1%、混合 30.4%→90.5%。
  🔗 abs: https://arxiv.org/abs/2611.34675 ｜ pdf: https://arxiv.org/pdf/2611.34675

- **How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches**（arXiv:2611.34875，2026-11-25）
  作者：Aakash Goel, Benjamin Steenhoek, Yu Hu
  分类：cs.SE ｜ 🏷 领域标签：agent / code agent / benchmark / harness
  一句话摘要：提出 DRA，把补丁单元追溯到写入步骤并逐个回退重跑测试；18 个前沿模型 7,660 条已解决轨迹显示 agent 补丁更长，但多出的编辑在 SWE-bench 上 61% 是测试、13% 是文档，平均 11% 的代码单元仍不必要且 89% 改变行为。
  🔗 abs: https://arxiv.org/abs/2611.34875 ｜ pdf: https://arxiv.org/pdf/2611.34875
