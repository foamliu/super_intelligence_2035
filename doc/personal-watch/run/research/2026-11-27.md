- **Kolpona: An Agentic Framework with Gradient-Free Neuron Programming for RTL Generation**（arXiv:2611.33973，2026-11-25）
  作者：Musa Tur Farazi, Md Nasir Uddin, Soumik Bhattacharjee et al（5 位）
  分类：cs.LG ｜ 🏷 领域标签：EDA / agent / RTL / harness

  🔗 abs: https://arxiv.org/abs/2611.31876 ｜ pdf: https://arxiv.org/pdf/2611.31876

- **RoboEvo$^2$: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution**（arXiv:2611.34675，2026-11-25）

  一句话摘要：harness 与 policy 递归协同演化：策略失败驱动 coding agent 搜索 Code / Code+ICL / Code+Policy 并沉淀为技能与经验记忆；已验证轨迹用于监督 + 反事实偏好蒸馏。LIBERO-PRO 单机成功率 11.0%→84.1%、混合 30.4%→90.5%。
  🔗 abs: https://arxiv.org/abs/2611.34675 ｜ pdf: https://arxiv.org/pdf/2611.34675

- **How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches**（arXiv:2611.34875，2026-11-25）
