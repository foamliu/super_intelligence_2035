# research/video/SCENES/ — 《论文两分钟》**分镜脚本** · 目录契约

> **谁写**：research agent。**谁读**：supervisor、用户。
> **用途**：**目的 2（科普视频）** —— 每天 **18:00（6PM）** 从**当日 TOP-5 推荐论文**里挑 **TOP-1**，产出**分镜脚本 HTML**（供后续成片）。
> **来源指令**：`../../WATCH_RESEARCH_TASK.md` **第 5 批（2026-10-09，P0）**。

## 1. 命名 / 放什么

| 文件 | 内容 |
|:--|:--|
| `MM_DD.html` | **每天一份分镜脚本**（`MM_DD` = **本地日期**，例：`2026-10-10` → **`10_10.html`**）—— **自包含单文件**（内联 CSS · 🚫 零外链 · 离线双击可开） |
| `index.html` | 按日**倒序**索引，链到各日分镜（**顺手维护**，每次只动 1–2 行） |

> 📌 与既有的 `../scripts/<arXiv_ID>.md`（**md 口播稿**）**并存**：本目录是**分镜脚本（HTML）**，粒度更细（逐镜含画面/字幕/音效）。

## 2. 挑选口径（TOP-1 = 当日 5 篇里最适合做视频的 1 篇）

**= 目的 2「科普」口径（不是「借鉴」口径）**：① 大众能懂（直观画面 / 反直觉结论）② 有传播力（震撼结果 / 热门话题）③ 可讲清（不必搬全篇）④ 有真实来源（arXiv ID + 链接）。
⚠️ 当天 5 篇全是难懂的借鉴类 ⇒ 选**可视化潜力最强**的，并注明。
**脚本里必须写明「为什么选它」。**

## 3. 分镜脚本必备（逐镜 shot）

- **每镜字段**：`镜号 · 时间轴 · 口播文案 · 画面描述（自绘/自生成）· 屏幕文字/字幕 · 音效/BGM · 时长`；
- **固定五段时间轴**：`钩子 0–10s → 问题 10–30s → 方法 30–80s → 结果 80–105s → 意义/展望 105–120s`；
- **口播长度**：中文 **≈350–450 字 ≈ 2 分钟**（语速 180–200 字/分）；
- **必带**：论文**原题**（英文照抄）· 作者/机构（前 3 + et al）· **arXiv abs 链接** · 明标「**论文解读**」· 免责（**非官方 · 非结论**）。

## 4. 红线（🚫 违反即退回）

1. 🚫 **不盗用论文原图** —— 画面**自绘 / 自生成**；
2. 🚫 **不夸大**：说「SOTA / 颠覆 / 突破」**必须指到原文出处**；不编造数据；
3. 🚫 **不为话题性曲解论文**；
4. ✅ 明标「论文解读」+ 给 arXiv 链接；
5. 📦 **大文件不入 git**（单文件 ≥5MB 走网盘，见 `../../WATCH_RESEARCH_TASK.md` §4-9）；
6. ⚠️ **《两分钟论文》是已有知名频道名** → 建议起**自己的栏目名**避免品牌混淆；
7. ✅ 平台发布由**用户本人**执行。

> ℹ️ **V3（真正生成视频）仍待用户确认工具链** —— 本目录只到**脚本/分镜**为止，🚫 不做成片。
