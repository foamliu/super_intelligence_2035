## 问题（10–30s）

**口播**：为什么不用现成的编程题考 AI？因为现在的编程 agent 太会作弊了。题目给一段程序问输出，它可以直接把程序跑一遍，根本不用推理；而且固定题库还容易被训练数据污染。

**分镜提示**：机器人直接点「运行 ▶」得到答案 vs 需要「思考🧠」的对照；右侧标注「题库会被污染、还难更新」。

## 方法（30–80s）

**口播**：作者提出 Codoku。它把程序挖空成带类型的格子，要求填回去后满足全局的静态约束和控制流、动态约束和执行路径。关键点在于：残缺的程序是「不能运行的」，而合法填法在指数级大的空间里又极其稀疏——所以无论是调工具还是暴力枚举，都代替不了真正的程序推理。而且题目能从零合成、按需生成。

## 结果（80–105s）

**口播**：他们用五个前沿模型，通过一个可以用任意工具、但预算固定的 coding agent，做了 300 道题。结果是：小题目就已经难住开源权重模型，大题目连闭源模型也只解出大约一半。
