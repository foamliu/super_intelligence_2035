## 5. 小模型组件 / 因子实验

- **Do Frontier Model Ingredients Add Up? A Replicated Factorial Study of Small Language Models**（arXiv:2611.24540，2026-11-18）
  作者：Biswa Sengupta（**单一作者**；JPMorgan Chase & Co., LLM Suite）
  分类：cs.CL ｜ 🏷 领域标签：小模型 / 因子实验 / MoE / Muon / Gated DeltaNet
  一句话摘要：在同一 8 层 decoder（**51,455,488** 参数、词表 50,304、1,024 token 序列、FineWeb、名义 **300M** token 预算）上比较五个改动（MoE / Muon / Gated DeltaNet 混合 / 额外归一化 / sigmoid 注意力门），**32 次核心训练**、每配置两个种子：MoE、Muon、GDN 增益最大且多数可叠加，额外归一化有帮助，匹配参数预算的注意力门平均增益接近零；全开配置 **3.6792 / 3.6750 nats**，同时 95% 参考边界 **±0.0043 nats**；MoE 臂 **161.3M 总参 / 51.6M 激活** ⇒ 增益同时反映路由与约 3× 总容量；论文另记一次数据泄漏（未来 token 泄漏造成异常低 loss）由奇偶位置置换测试发现（均作者自报）。
  🔗 abs: https://arxiv.org/abs/2611.24540 ｜ pdf: https://arxiv.org/pdf/2611.24540 ｜ 原生 HTML: https://arxiv.org/html/2611.24540v1

## 6. B 轨 · 经典论文（第七十一轮 +4 → 272；第七十轮 +4 → 268）

- **Transformer-XL**（arXiv:1901.02860，2019，**1,881**）—— 段级递归 + 相对位置编码；依赖比 RNN 长 80%、比原版 Transformer 长 450%、评测最多 1,874×；WikiText-103 ppl 18.3（训练注意力 384 / 评测 1600）。
- **Emu3**（arXiv:2409.18869，2024，**1,022**）—— 全离散 token + 单个 8B 自回归 Transformer 同做理解与生成；32 层 / hidden 4,096 / 词表 184,622 / 上下文 131,072。
- **Medusa**（arXiv:2401.10774，2024，**1,028**）—— 多解码头 + tree attention，无需草稿模型；Medusa-1 >2.2× 无损，Medusa-2 2.3–2.8×，抽取类最高 3.62×。
- **Janus**（arXiv:2410.13848，CVPR 2025 pp. 12966–12977，**633**）—— 理解用 SigLIP、生成用离散 tokenizer 的双通路 + 共享主干；1.3B 下 GenEval 61%、MSCOCO-30K FID 8.53。
- **ConvNeXt / A ConvNet for the 2020s**（arXiv:2201.03545，CVPR 2022 pp. 11966–11976，**13,910**）—— 把 ResNet 逐步「现代化」为纯 ConvNet：300 epoch / AdamW 4e-3 / batch 4096 / wd 0.05 / LayerScale 1e-6 / EMA；ConvNeXt-T 在 4.5 GFLOPs 下 82.1%（Swin-T 81.3%），ConvNeXt-XL 384² 87.8%（350M 参数 / 179.0 GFLOPs）。
- **Documenting Large Webtext Corpora (C4)**（arXiv:2104.08758，EMNLP 2021 pp. 1286–1305，**990**）—— 首次系统记录 C4 的来源与内容：365M 域名 / 156B token / 305 GB；来源含专利与美国军方网站，含机器翻译文本与其他基准的评测样例；blocklist 过滤不成比例地删除少数群体相关文本。
- **Grokking**（arXiv:2201.02177，2022，**967**）—— 小算法数据集上泛化可发生在严重过拟合之后：除法 mod 97、50% 数据下，训练精度 10^3 步接近完美而验证精度需约 10^6 步；数据比例 25–30% 附近，少 1% 数据使泛化中位时间增 40–50%；weight decay 最有效。
- **Are Emergent Abilities of Large Language Models a Mirage?**（arXiv:2304.15004，NeurIPS 2023 pp. 55565–55581，**1,116**）—— 「涌现」多由指标选择造成：BIG-Bench 上约 92% 的涌现只在 multiple-choice grade / exact match 这类非线性或不连续指标下出现；换成连续指标或增加统计量后消失，per-token 交叉熵随规模按幂律平滑下降。
