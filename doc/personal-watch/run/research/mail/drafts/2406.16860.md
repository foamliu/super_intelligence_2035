## 主题

Cambrian-1 的视觉塔选择与 SVA token 压缩：三个问题

## 正文

童老师：

您好。我是刘杨，做 LLM agent 与多模态方向的研究，主页 https://foamliu.github.io/。

Cambrian-1 用 20 多个视觉编码器做横向对照，并用 SVA 把 576 个视觉 token 压到 36 个，这对我们选视觉塔是少见的可照抄证据。

三点想请教：
1. 你们的对照里 CLIP 与 DINOv2 的差距在冻结与解冻两种设置下方向不同。若我们只能解冻最后一层、图文对规模约为你们的十分之一，您会优先选哪一类编码器？
2. SVA 从 576 压到 36 时，OCR 与文档类任务的掉点主要出现在哪种版面上？有没有「压到多少 token 就开始掉」的经验阈值？
3. Cambrian-7M 里 OCR 占 27.6%。若目标场景是芯片版图与规格书截图，这个比例该上调还是下调，配比失衡最先伤哪类指标？
