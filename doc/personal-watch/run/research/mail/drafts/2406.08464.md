```
林老师，您好：

我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。

我们在为代码与 EDA agent 找冷启动指令数据的「零人工」起点。Magpie 只喂用户消息之前的模板，让 Llama-3-Instruct 自己生成指令，这条路成本最低；但从 4M 收到 300K 的过滤决定了最终质量，我不想照搬一个看不见的黑箱。

三个问题：
1. 300K 过滤子集里，质量分类器、去重、难度三条各自去掉多少？如果预算只够 50K，哪一条最不能省？
2. 指令与回复都由同一位教师生成（Pro 用 70B、Air 用 8B）。换成「70B 生成指令、8B 生成回复」这类跨教师组合，质量会掉多少？
3. DPO 那组用 k=5、T=0.8 生成 100K 偏好对，并以 ArmORM-Llama3-8B 作奖励模型；若换成人工偏好数据训的奖励模型，AlpacaEval 2 的差距有多大？我们担心自我偏好偏差。

感谢你们把数据与过滤流程一并公开。

祝好，
Yang Liu
```
