我是刘杨，做视觉模型与 agent 评测方向的研究，主页 https://foamliu.github.io/。我们正在给工业缺陷检测搭实时筛查基线，读到你们用一致双分配（一对多 + 一对一）去掉 NMS，正好对上我们「产线节拍里后处理耗时不可控」的痛点。

三个问题：
1. 一对多与一对一两个分支持续协同训练时，监督权重或匹配代价如何平衡？去掉 NMS 后，密集小目标的重复框靠什么压住，AP_small 相比带 NMS 的版本掉多少？
2. rank-guided block design 里的「冗余度」具体用哪个可测指标？换到非 COCO 的工业缺陷数据，block 排序是否需要重排？
3. 你们报的 YOLOv10-S 比 RT-DETR-R18 快 1.8 倍，是在什么输入分辨率与 batch 下测的？能否给出 batch=1 时无 NMS 的延迟分解？

如方便，盼简短指点；答复会直接用于我们的检测基线选型与节拍预算。
