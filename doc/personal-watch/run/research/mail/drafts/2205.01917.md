您好，

我是刘杨，做多模态与 LLM agent 方向的研究，主页 https://foamliu.github.io/。我们在比较「对比与生成同训」和「先训 CLIP 再拼 captioner」两条路线，CoCa 把两者放进一个解码器、并在底部若干层跳掉交叉注意力，正是我们想弄清的形态。

三个问题：
1. 对比损失取的是跳掉交叉注意力那段的输出；n_uni 与 n_multi 的分界在不同规模上按固定层数还是固定比例取？分界下移（多模态层更多）时，检索与 caption 指标各自怎么动？
2. λ_Cap=2.0、λ_Con=1.0 这个 2:1，是否与 batch 65,536、50 万步一起调过？若只保 CLIP 式零样本分类、不追 caption，λ 该往哪边偏？
3. 288×288、patch 18×18 得 256 个 token；分辨率翻倍时，零样本分类、检索、VQA 三类任务的回报差多少？

如方便，盼简短指点；答复会直接用于我们视觉塔与图文对齐目标的取舍。
