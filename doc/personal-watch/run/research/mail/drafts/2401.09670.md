金老师您好：

我是刘杨，做 LLM 推理与 agent 方向的研究，主页 https://foamliu.github.io/。

DistServe 指出 prefill 与 decode 同批共卡会相互干扰、并把两阶段的资源与并行方案绑在一起，这一点正中我们当前的问题：小模型长输出服务里，decode 常被新到的 prefill 抢占，P90 TBT 抖动明显。

两个问题想请教：

1. 7.4× 请求数 / 12.6× 更紧 SLO 是在 90% 达成率下测的。若把达成率提到 99%，收益主要会被 KV 传输开销吃掉，还是被单阶段资源碎片吃掉？二选一即可，并补一句理由。

2. 对 2B 级模型、prompt 多在 512 token 内、输出可达数千 token 的场景，prefill 占比很小；这时拆分的收益是否主要来自「按阶段分别选并行策略」，而不是「消除干扰」？

感谢您把 13B / A100 / input 512 / output 64 的对照与 P90 TTFT、TPOT 分开报得这么清楚。

祝好，
Yang Liu
