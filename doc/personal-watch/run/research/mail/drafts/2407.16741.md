```
王老师，您好：

我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。

我在搭自己的代码 agent 评测外壳时反复读 OpenHands，最看重的一点是您把 runtime、事件流和动作空间都显式定义出来，而不是只报一个 SWE-bench Lite 的 26%。这让我意识到，分数其实是外壳版本的函数。

三个问题：
1. 那 26% 之外的失败，更多来自「改错了位置」还是「环境跑不起来」（依赖缺失、超时）？正文有没有分桶统计？
2. 回放事件流时，如果只保留可观察的 bash / 编辑器动作、丢掉 agent 的内部推理，同一轨迹能复现的成功率会掉多少？
3. 同一模型换 runtime 镜像（比如不同 Python 版本）后，你们会重跑基线吗？差异大概在什么量级？

感谢你们把平台与评测代码整套开源。

祝好，
Yang Liu
```
