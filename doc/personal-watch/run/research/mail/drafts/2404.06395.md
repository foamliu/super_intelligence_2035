```
胡老师您好，

MiniCPM 里最让我停下来的不是 2.4B 超过 7B 模型，而是 WSD 把「训练到哪一步停」变成一个可以复用的决策：stable 阶段随时可续，decay 只花 10% token 就能收敛。

我是刘杨，做 LLM agent 与小模型训练方向的研究，主页 https://foamliu.github.io/。

我们正在 2B 量级上做预训练，token 预算还没最终定，所以 checkpoint 复用对我们很关键。

两个问题：

1. 你们在 0.036B 上得到「decay 用 10% token 足够、2.5% 不够」。到 2.4B / 1.1T token 时，这个 10% 是保持不变，还是随模型变大而变小？请二选一并给一句理由。

2. stable 阶段用的是 4M token batch。如果我们把 2B 的 batch 减半到 2M，decay 的 10% 是按 token 算仍然成立，还是必须按 step 重算？

谢谢你们把 WSD 的中间 checkpoint 行为写清楚，这比只报最终分数有用。

祝好，
Yang Liu
```
