我是刘杨，做 LLM 推理与长上下文方向的研究，主页 https://foamliu.github.io/。MemOnce 只把最后一层少量隐藏状态存成 memory、再按需解码回 KV，这个「只存一次」的取舍很契合我们评估长上下文成本的方式，想请教三个细节。

1. memory sparse attention 的稀疏索引「跨层只算一次」，解码每一步是否复用同一个索引？当关键信息落在上一步未选中的窗口时，召回靠什么兜底、miss 率大概多少？
2. 只缓存最后一层隐藏状态、再由解码器还原各层 KV，相比逐层缓存丢掉了哪些信息？在 needle-in-a-haystack 与下游表征任务上，改存中间层会更好还是更差？
3. Qwen3.5-4B 在 1M 上下文下 memory cache 降 1313×、prefill 延迟只降 6.9×：剩余时间主要花在解码 KV 的 kernel 还是显存带宽？若要继续压延迟，优先改哪一段？
