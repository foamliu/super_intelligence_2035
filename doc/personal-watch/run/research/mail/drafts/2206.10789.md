Subject: Parti：20B 自回归文生图的 tokenizer 与规模边界

Jiahui 老师您好，

我是刘杨，做 LLM agent 与多模态方向的研究，主页 https://foamliu.github.io/。Parti 把文生图还原成 seq2seq、用 ViT-VQGAN 的离散图像 token 当目标序列，这条路线和我们评估「生成塔要不要走自回归」直接相关。

三个问题：

1. ViT-VQGAN 出的 token 序列长度是固定的吗？扩到 20B 时，你们是靠更长的序列还是更大的词表吃到规模收益？我们按 256×256 估算，序列长度一涨，训练成本几乎线性上升。

2. 摘要说质量随规模一致改善；在你们的曲线里，20B 之后是继续改善还是开始饱和？零样本 FID 7.23 与微调 3.22 之间的差距，主要是数据分布还是模型容量造成的？

3. PartiPrompts 的 1600+ 条提示词是怎么写的、怎么避免与训练 caption 撞车？我们想给设计图生成造一套同类基准，担心自己写的提示词把评测变成背题。

这三点会直接影响我们的 tokenizer 与评测设计，谢谢。

祝好，
Yang Liu
