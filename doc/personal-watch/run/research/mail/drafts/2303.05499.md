Subject: Grounding DINO：短语级提示下的三个细节

刘世隆老师您好，

我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。我们把 Grounding DINO 当作版图/封装图开放词表检测的取框基线，COCO 零样本 52.5 AP 与 ODinW 26.1 AP 是对外口径。

三个细节想请教：

1. 特征增强器三档融合（enhanced fusion / bi-attention / deformable）在提示只有单个短语类别名（如 via、pad）时哪档最关键？有无按文本 token 数的消融？

2. 语言引导 query selection 的 `num_queries` 与文本 token 数如何联动？800×800、目标密集偏小时该调 query 数还是改特征层？

3. 子句级表征的注意力掩码，在「提示提到但图中没有」的负样本上会不会压掉小目标框？有失败模式记录吗？

答复可直接改我们的取样阈值与提示写法，谢谢。

祝好，
Yang Liu
