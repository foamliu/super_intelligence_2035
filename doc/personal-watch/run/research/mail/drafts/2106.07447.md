徐老师您好：

我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。我们在给 2B 级主干选视觉编码器的自监督目标，读到 HuBERT 用离线聚类标签做掩码预测，想请教三个工程问题。

一、960 小时 LibriSpeech 上您用 100 个簇、两轮迭代（250k + 400k 步）就够。若把无标注语音换成 60,000 小时 Libri-light，簇数与迭代次数是否要同比放大？判断「标签已经够用」的可测指标是什么？

二、10 分钟标注下 LARGE 已到 4.7% / 7.6%，X-LARGE（1B）再到 4.6% / 6.8%。容量收益在哪个参数量级开始变平？我们据此决定视觉塔是否做到 1B。

三、若预测目标换成视觉 token 的聚类中心，您建议沿用「先聚类、后固定」的两阶段，还是让聚类与编码器联合更新？最该先防的失败模式是哪一个？

感谢您抽空。
