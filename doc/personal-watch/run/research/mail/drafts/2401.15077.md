Subject: EAGLE：窄域上 draft 头要不要重训

张老师您好，

我是刘杨，研究 LLM agent 的推理与解码成本，主页 https://foamliu.github.io/。EAGLE 把自回归搬到倒数第二层特征、再用前移一步的 token 序列消解不确定性，是我们引用成本时的口径（LLaMA2-Chat 70B 上 2.7–3.5× 延迟加速、吞吐翻倍）。

三个问题：

1. 特征层自回归的不确定性，在高温采样与长输出时怎么变？单次草稿 token 数有没有按接受长度实测出来的推荐值？

2. 训练时的 test-time simulation，是否要求 draft 头见过目标模型的输出分布？换到 Verilog/RTL 这类窄域，draft 头大致要重训多少数据才能保住加速比？

3. 2.7–3.5× 是在 batch=1 下测的吗？agent 多为单请求小 batch，加速比会掉多少？

答复能定我们 harness 里是否默认开投机解码。谢谢。

祝好，
Yang Liu
