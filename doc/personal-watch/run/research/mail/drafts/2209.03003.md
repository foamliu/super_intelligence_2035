## 正文

刘老师您好：

我是刘杨，做 LLM agent 与结构化生成方向的研究，主页 https://foamliu.github.io/。您这篇 Rectified Flow 把 π0→π1 的输运写成沿直线路径回归向量场的 ODE，用 rectification 证明凸输运成本不增，单步 Euler 就能出高质量图，正好对上我们在结构约束下压缩采样步数的需求。

三个问题：

1. 「凸输运成本不增」是总体分布层面的结论。在有限样本、有限模型容量下，递归 rectification 到第几次开始不再变直？有没有可在线监控的直度 / 曲率判据？
2. 单步 Euler 在无条件图像上成立；对条件输入（掩码、版图这类硬约束），条件变化剧烈时步数需求怎么定？是否必须以 NFE 与约束满足率两轴同时报？
3. 用于域迁移时若 π0 与 π1 支撑几乎不重叠，rectification 会不会把质量塌到少数模式？你们用什么诊断（覆盖率 / 最近邻 / 似然）判断？

谢谢您的时间。

祝好，
Yang Liu
