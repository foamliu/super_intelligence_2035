## 主题

LongBench 的截断口径与跨模型可比性：三个具体问题

## 正文

白老师：

您好。我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。

我们在给长上下文 agent 定评测口径，LongBench 的 4,750 条样本、6 类任务分层，以及「超长输入从中间截断」的做法，是我们目前最直接的参照。

想请教三点：
1. 中间截断保留首尾各 M/2，会让同一条样本在不同模型上落到不同内容。跨模型比较时这种口径差怎么控制？是否建议改成只保留首段，或按长度分桶分别报告？
2. 中文子集平均 13,386 字的样本上，F1 / ROUGE-L / Edit Sim 与人工判断的偏差有多大？有没有哪类任务您建议直接弃用自动指标？
3. 若把这套思路搬到代码与 EDA 长文档（网表、日志、规格书），您会先改哪一处：任务切分、长度分桶，还是指标？
