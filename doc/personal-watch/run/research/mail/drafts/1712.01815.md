我是刘杨，做 LLM agent 方向的研究，主页 https://foamliu.github.io/。

我们在做 EDA 场景的 agent 评测，其中时序类任务需要一个可离线复跑、结果可核对的参照引擎。读到您这篇 OpenTimer 同时支持 block-based 与 path-based 传播、CPPR 与增量分析，正好对上我们判分时「用哪种传播、要不要开 CPPR」的口径难题。

想请教三点，答复会直接改进我们的判分与题面设计：
1. 同一份 SDC 下，block-based 与 path-based 报出的 slack 与违例路径数通常差多少？差在哪些结构上最明显？
2. CPPR 开启前后，违例路径数量与最差 slack 的变化幅度大概如何？作为判分默认值，您建议开还是关？
3. 增量分析在「只改一处约束」后相对全量重算的加速比是多少？结果在什么条件下会与全量不一致？
