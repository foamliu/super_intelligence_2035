1. TokenGate: Adapting LLMs for Fast and Memory-Efficient Prefill with Learned Token Pruning
   arXiv:2610.26754 ｜ 附件：是（24 页 / 1,074,078 B）
   为何值得读：咬住真正贵的那一段——长上下文的主要开销在 prefill。一个即插即用的小组件为每个 token 学出重要性分数，只把重要 token 送进后续层；用 token-gated attention（受 MoE 启发的门控，用重要性分数重加权 attention logits）绕开 top-K 不可导，从而端到端训练。多种任务上 prefill TTFT 快 1.4–11.3×、峰值显存降 1.5–3.4×且精度不降；相对此前最好的 token 剪枝最多快 6.4×、省 2× 显存；适配量级「与标准 PEFT 相当」，并原生支持混合注意力模型（Qwen3.5）。对口 BaiZe 长上下文 prefill 与 Mamba-2×attention 混合路线。⚠️ 加速比是作者自报、且为 prefill 阶段指标，decode 吞吐未给；需额外训练门控组件（非纯推理期技巧）；数字未复现。

2. Kronecker Delta Rule for Long Context Linear Attention
   arXiv:2610.26834 ｜ 附件：是（53 页 / 838,945 B）
   为何值得读：正打在混合架构的「记忆」部件上。给线性注意力的关联矩阵记忆换了条更新规则：修正目标关联时只沿矩阵空间的单一方向改动记忆，从而比 delta-rule 更少干扰已存信息；作者证明其记忆动力学是收敛到稳态分布的马尔可夫链、记忆矩阵期望范数在整条输入序列上一致有界，因此不需要额外的归一化 / 稳定机制；长上下文基准上与 (Gated) DeltaNet 家族相比「有竞争力、且常常更优」，代码与模型已开源。对口 BaiZe 混合层的状态写回与长序列训练稳定性诊断。⚠️ 摘要只给定性结论（无困惑度 / 长上下文分数）；它是 xLSTM 家族新成员，替换整块架构而非可插拔模块；未覆盖 EDA / 代码 agent 负载；未复现。

3. Same Simulation, Different Evidence: Where Retrieved Tool Output Costs LLM Agents Accuracy
   arXiv:2610.26836 ｜ 附件：是（15 页 / 413,421 B）
   为何值得读：用真实科学工具（USGS 地球化学模拟器 PHREEQC，单份报告可达 846.8k 字符）做 158 道执行可验证选择题：当 harness 把长工具输出存成文件、让 agent 按 section index 检索、而不是整段放进上下文时，GPT-5.1 / GPT-5.2 准确率分别掉 11.3 / 7.9 分，Claude Opus 4.6 / Sonnet 4.6 无可测损失；复跑 11,007 次模拟调用定位到失败不是「没算对」，而是证据替换——agent 跳过权威报告、拿自己更高精度的输出文件作答并舍入到邻近选项；点名权威输出可回升 6.3–7.9 分。对口 ZhuLong 的 MCP 工具输出管理与 harness 评测设计。⚠️ 数字为作者自报，未复现；单一工具单一领域，迁移到 EDA 需自建评测。
