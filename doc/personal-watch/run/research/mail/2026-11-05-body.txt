1) ARLoop: Fully-Open Pre-trained Looped Transformers with Attention Residuals
   arXiv: 2611.05234（cs.CL，2026-11-03，26 页，PDF 已附）
   作者/机构：Yuekun Yao, Yupei Du, Dawei Zhu, Huan Sun（The Ohio State University · Saarland University）
   为何值得读：把 attention residuals 从「层深度」搬到「循环深度」，并发现 looped 模型只需滑动窗口即可 —— 140M R=3 验证 PPL 16.59→16.03、370M 12.28→12.17，收益随循环深度变大（R=1 −0.11 → R=3 −0.53 PPL）；1.2B / 0.5T token / R=3 在 8 个评测全部超过 Huginn-3.5B 并与 Qwen3.5-2B 有竞争力；模型与代码全开放。可借鉴点：若我们在跑共享层 / looped 结构，这是「用参数换计算」里最轻的一处改动（残差聚合方式，QK 结构与数据不动）。

2) LoopVQ: Sub 1-bit KV Cache Quantization for Looped Transformers
   arXiv: 2611.05304（cs.LG，2026-11-03，17 页，PDF 已附）
   作者/机构：Minsoo Cheong, Sungjoo Yoo（Seoul National University）
   为何值得读：looped 模型每循环一次要各存一份 K/V ⇒ KV cache 随循环数线性膨胀。作者沿 loop 轴做通道联合向量量化 + 码本微调，0.5 bit 下 Ouro-1.4B GSM8K 75.82（TaSQ 57.32 / CQ 46.78 / BF16 78.77）、MATH500 69.40（38.80 / 17.80 / 77.20）；SGLang 中 32K 上下文 decode 延迟近乎减半、峰值吞吐 4.3×–6.1×。可借鉴点：page 级 bf16→量化切换 + 跨循环步共享 index，不额外吃内存；先量我们的 KV 占总显存比例再决定是否接。

3) Stabilizing On-Policy Targeted Guidance in Agentic Reinforcement Learning
   arXiv: 2611.05266（cs.LG，2026-11-03，14 页，PDF 已附）
   作者/机构：Kevin Frans, Alexander M. Rush, Sergey Levine, Pieter Abbeel, Ashvin Nair（Cursor Research · UC Berkeley）
   为何值得读：只在「策略失败的轮次」用带评分细则的文本反馈做 on-policy 自蒸馏，再叠逐准则 RL：7 项风格准则 0.00–0.70 → 0.55–0.99，而 coding pass-rate 0.33 持平。可借鉴点：① 只在失败轮注入，避免污染主任务；② 崩溃前兆是熵尖峰，静态小蒸馏权重即可稳住；③ 把 KL 施加到 thinking token 可消除准则间振荡。可先在自有 agentic harness 上挑 1 个可二值判定的准则试跑。

   arXiv: 2611.06840（cs.CV，2026-11-04，43 页，PDF 已附 · 本日科普 TOP-1）
   作者/机构：Liang Yue, Eric A. Vance（University of Colorado Boulder）
   为何值得读：固定物体与起始噪声、一次只改一个变量，测 5 个开源文生图模型的「数字词有效范围」，并请没见过提示词的人盲数 3,088 张生成图。十以内都听话，十以外崩：SD3.5-M 中位数量恒在 4.5–8.5（不管要多少）、FLUX.1-dev 到 30 反而缩到 1–2 个、FLUX.2 [klein] 与 Qwen-Image 勉强跟到 25。只重画比图像八分之一更细的噪声，布局不变而数量挪动 0.69×（≈ 换新数字的 2/3）；把数量以噪点网格画进起始 latent，59% 的图能数对（只写提示词 4%）。科普看点：人人有体验 + 反直觉 + 可现场演示；已做成《论文两分钟》分镜（video/SCENES/11_05.html）。
