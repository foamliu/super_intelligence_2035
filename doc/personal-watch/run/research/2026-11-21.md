  一句话摘要：提出 Skill-FT：用自然语言「技能」抑制教师轨迹里的不良习惯（无依据假设、无效重复、表面验证），再由 LLM agent 组织轨迹分析—技能设计—数据选择—反馈闭环（AutoMaster）；在 Terminal / Search / 软件工程三类任务、4B 与 9B 目标模型上，比「直接用成功教师轨迹做 SFT」平均高 **1.42–8.99 个百分点**，且 SFT 时保留技能说明比去掉更好（六个设置全部成立，作者自报）。

## 2. agent harness / 记忆

- **MemFolder: Structure-Guided Memory Folding for Efficient Agent Memory Management**（arXiv:2611.26427，2026-11-19 v1）
  作者：Xuyang Liu · Chenwen Lu · Junxi Wang（et al.，共 9 位）
  分类：cs.CL ｜ 🏷 领域标签：长期记忆 / 检索成本 / 上下文压缩
  一句话摘要：把「记录条数」与「检索上下文长度」两段成本分开处理：RecordFolder 先按实体与时间链把兼容记录折叠成更少的检索单元，ContextFolder 再把组内原始记录编码成紧凑文本并用可验证反馈修正；在 LoCoMo / PersonaMem / LongMemEval 与两个多模态 M3-Bench 上，Mem0 上以 **50% 更少记录**保留 **99.0%** 原平均性能，比最强基线高 **1.9 个百分点**（作者自报）。
  🔗 abs: https://arxiv.org/abs/2611.26427 ｜ pdf: https://arxiv.org/pdf/2611.26427

- **HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs**（arXiv:2611.26363，2026-11-19 v1）
  作者：Ambroise Borbely · Mathieu Salzmann · Olivier Verscheure
  分类：cs.LG ｜ 🏷 领域标签：稀疏注意力 / RoPE / 预训练 / 解码成本
  一句话摘要：不做 token 稀疏而是做**隐藏维稀疏**：按 token 位置用静态、无参数的规则把 RoPE 的 key/query 拆块，只计算部分点积；从零训练 LLM 时只算约 **1/3 的 query-key 乘积**，效果不低于完整点积（作者称有提升），并给出 FlashAttention-3 的 kernel 实现与解码加速/显存下降。
  🔗 abs: https://arxiv.org/abs/2611.26363 ｜ pdf: https://arxiv.org/pdf/2611.26363 ｜ 💻 https://github.com/ambroise-b/hisa
