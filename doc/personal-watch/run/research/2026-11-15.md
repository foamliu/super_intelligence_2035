- **Negative-Only Policy Optimization for One-Sided Verifiable Rewards**（arXiv:`2611.17287`，2026-11-12）
  作者：Jiacheng Xu, Shuo He, Fuxiang Zhang, Chaojie Wang, Bo An（5 位；机构未从 PDF 核验）
  分类：cs.LG ｜ 🏷 领域标签：RLVR / 部分可验证奖励 / 负例抑制
  一句话摘要：把「只能可靠否证、不能确证」的验证情形定义为 one-sided verifiability，提出 NOPO：把「通过检查」当未标注样本，只用可信负例更新策略（相对参考模型的负例抑制损失 + 按未否证比例缩放的组级适配器），在单元测试 / 约束检查 / LLM 自评三类验证器上提升代码、逻辑、数学任务的 pass@k。
  🔗 abs: <https://arxiv.org/abs/2611.17287>

## 2. 代码 agent / harness（cs.SE）

- **Eliciting and Mitigating Specification Satisficing in Coding Agents**（arXiv:`2611.16289`，2026-11-12）
  作者：Ruixin Wang, Tianyi Zhang（Purdue University，PDF 首页逐字核）
  分类：cs.SE ｜ 🏷 领域标签：coding agent / 自纠正 / 需求偏离 / 评测口径

  🔗 abs: <https://arxiv.org/abs/2611.16289>
