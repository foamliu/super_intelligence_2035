# news/policy/ — **L1 政策信号**（本线核心）· 目录契约

> **谁写**：news agent。**谁读**：supervisor、用户。
> **用途**：**L1 = 用新华社文本预测「政经举措」（什么动作 + 大致时间）** —— 本目录是 L1 的全部产物。

## 1. 放什么（**按下列顺序产出，不得跳步**）

| 顺序 | 文件 | 内容 |
|:--|:--|:--|
| ① | `EDA.md` | **探索性分析**：动作动词/高频词 · 主体词 · 年度/月度分布（**真实计数**）· 标题模式 |
| ② | `TAXONOMY.md` | 动作分类体系 —— **由 ① 归纳**（每个类含**实测样本量** + 2–3 个真实示例 + 边界规则） |
| ③ | `SIGNALS.md` | 先行信号清单（措辞强度 / 词频新词 / 通稿密度 / 版面 / 社论 / 口径变化），每条给**提取方法 + `as-of`** |
| ④ | `EVENTS.csv` + `EVENTS.md` | **事件库**（监督标签）：`日期 · 主体 · 动作类型 · 领域 · 力度 · 依据标题 · 链接` |

| 附 | `extract_events.py` | 事件抽取脚本（**半自动流水线**：规则/正则 → 候选 → LLM 分类 → 抽样校验） |
| 附 | `L2_PREREG.md` | L2 **方法预注册**（窗口/口径/检验/多重比较 —— 先写死再跑） |
| 附 | `INDEX_FILES.md` | 大文件清单（路径/行数/大小/sha256） |

## 2. 命名规范

- 库文件用**固定名**（上表），便于验收对照；
- 大件（`EVENTS.csv` 等 >20 MB）**按年/按类型分片**，并记 `INDEX_FILES.md`。

## 3. 红线（🚫 违反即退回）

1. ⚠️ **硬顺序**：**① 先拿语料 → ② EDA → ③ 由数据归纳类别 → ④ 频率分层由实测得出**。
   🚫 **EDA 未完成前不许产出 `TAXONOMY.md`**；🚫 不许**先验拍脑袋**；🚫 不许为"凑分层"硬切类别。
2. 🚫 **不许编造**：每条事件**必须可核验到原文链接**；事件库须报**抽样人工校验准确率**（抽 ≥100 条）。
3. 🚫 **不许用未来信息**：预警评估必须 **walk-forward**；**必须给可比基线**（随机 / 历史频率）—— **没有基线的"准确率"一律作废**。
4. 🚫 **不许把预测写成事实**：只给**概率 + 时间窗 + 不确定性**；措辞用「**迹象 / 倾向**」，不用「一定会」。
5. ⚖️ **政治中立**：只做**公开报道的描述性与统计性分析**；🚫 **不预测具体政治/军事事件**、不表态、不生成宣传内容。
6. 🔒 **只用公开新闻**；🚫 不采集非公开/涉密信息。
7. ⚠️ **定位**：产出是**研究性观察**，🚫 **不是投资建议**。
8. ❄️ **L3 相关（策略/仓位/择时）一律不许写在这里** —— L3 已冻结。

> 📖 完整规则见 `../WATCH_NEWS_TASK.md` **§0.0.0 / §0.0.1 / §0.0.2 / 第 8 批 N3 / 第 9 批 N4**。
