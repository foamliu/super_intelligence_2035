- **研究发现 coding agent 补丁普遍「多改」：约 11% 代码单元不必要，其中 89% 会改变行为**（research 日报 2026-11-27 引用 · arXiv 2611.34875，2026-11-27）
  摘要：研究者分析 18 个前沿模型在 SWE-bench Verified / DeepSWE 的 7,660 条已解决轨迹（6,728 + 932），发现 agent 补丁比开发者提交更大；平均约 11% 的 agent 代码单元仍属不必要，其中 89% 会改变行为。SWE-bench 上多余编辑中 61% 是测试、13% 是文档；DeepSWE 上 58% 是代码。结论不是「小改动就好」，而是多余编辑本身有相当比例会影响行为、需要审查。
