# news/ — news 线产物根目录 · 目录契约

> **谁写**：news agent。**谁读**：supervisor、用户。
> ⚠️ **本目录混着"三类产出"，口径必须分开** —— 这是最容易出错的地方。

## 1. 三类产出（**计数与口径严格分开**）

| # | 类别 | 位置 | 口径 | 计数 |
|:--|:--|:--|:--|:--|
| **①** | **新闻日报** | 本目录（`2026-10-03.md` 等） | **§0.1：≤72h 真新闻**（时效 + 事件性 + 报道体 + 可核验） | 计入「news 条数」 |
| **②** | **历史语料** | `archive/` | `type: archive`；**只取 标题+日期+来源+链接** | **不计入** news，按源分列 |
| **③** | **分析/信号** | `analysis/`（图表·关联） · `policy/`（L1 政策信号） | 统计/探索性；**相关≠因果** | **不计入** news |

## 2. 本目录固定文件

| 文件 | 用途 |
|:--|:--|
| `<YYYY-MM-DD>.md` | **当日新闻日报**（积累式，同日多轮追加） |
| `SEEN.md` | **去重台账**（主键 = 链接；含非新闻的类型标签，防重复评估） |
| `INDEX.md` | 索引与计数（只计 §0.1 真新闻；非新闻单列） |
| `mcp_web_search_free.py` | **免 key 自建 MCP**（`web_search` / `search_news` / `rss_latest` / **`cn_news`**） |
| `cline_mcp_config.json` | MCP 配置片段 |
| `FETCH_CN_NEWS.md` | `fetch_cn_news()` 用法与自测记录 |
| `API_COMPARISON.html` / `.md` | 免 key API 选型对比（自包含报告） |

## 3. 红线（🚫）

1. 🚫 **不许编造**：每条必带 **标题 + 来源 + 发布日期 + 链接**；无来源不收录。
2. 🚫 **非新闻直接不收**（特稿/观点/博客/论文/论坛帖 ≠ 新闻）；**不许拿"接口 200"当"已采集"**。
3. 🚫 **不许把 ②③ 混进 ① 的计数与摘要**（本目录最容易犯的错）。
4. 🚫 **不抓正文**（历史语料只存 5 字段）。
5. ⚠️ **大文件（`archive/` 分片、index、原始 JSON）**：单文件 >20 MB **不入 git**，记 `INDEX_FILES.md`。
