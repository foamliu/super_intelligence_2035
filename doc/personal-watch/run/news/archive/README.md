# news/archive/ — 历史回溯**语料库**（任务 **N1**）· 目录契约

> **谁写**：news agent。**谁读**：supervisor（巡检）、下游分析（`news/analysis/`、`news/policy/`）。
> **用途**：为三层链的 **L1（政策信号预测）** 提供**长期语料** —— 本目录**不是**"新闻日报"，是**语料**。

## 1. 放什么

| 文件 | 内容 |
|:--|:--|
| `<source>-<年>.jsonl.gz` | 每条**只有 5 个字段**：`{"date":"YYYY-MM-DD","source":"…","channel":"…","title":"…","url":"…"}` |
| `PROGRESS.md` | **进度游标**（源 / 年 / 月 / 日 追到哪）；**可中断可恢复** |
| `INDEX_FILES.md` | 文件清单：`路径 · 行数 · 大小 · sha256` |

## 2. 命名规范

- 文件名 **`<source>-<年>.jsonl.gz`**，`source` ∈ **`xinhua` / `chinanews` / `people` / `cctv`**。
- **主键 = `url`**；跨文件去重。
- 按**年**分片 + **压缩**。

## 3. 红线（🚫 违反即退回）

1. 🚫 **只取 标题 + 日期 + 来源 + 链接** —— **不请求文章详情页、不保存正文**。
2. 🚫 **代理源不许冒充新华社**：`chinanews/people/cctv` **不得标成** `xinhua`；**统计与图表必须按源分列**。
3. ⏱ **同站 ≥2 秒/请求**，单轮请求数受控，**不并发**；失败重试 ≤2 次后跳过并记录。
4. 🚫 **不绕封锁**：403 / WAF **如实记录（贴响应片段）**，**不代理、不伪造 UA**；**试错上限 1–2 轮**。
5. 📦 **体积纪律（2026-10-05 修订 · 红线）**：**单个文件 ≥ 5 MB → 一律不入 git**（**旧口径「单年 >20MB」已作废**），
   **改走百度云盘**（`bypy` / `BaiduPCS-Go`），并在 `INDEX_FILES.md` 登记 **网盘路径 / 文件字节数 / sha256 / 存放位置**。
   🚫 禁止 `git add -f` / 压成 zip 规避；**若网盘不可用 → 宁可不传，也不许塞 git**（见 `WATCH_NEWS_TASK.md` §4-11）。
6. 📝 `PROGRESS.md` 须**如实**写明「**新华网 K 年未通 → 该年由代理源（X/Y/Z）覆盖**」。
7. ⚖️ 只用**公开新闻**；不采集任何非公开/涉密信息。

> 📖 完整规则见 `../WATCH_NEWS_TASK.md` **§0.0.0 / §0.0.2 / 第 7 批 N1 / §9**。
