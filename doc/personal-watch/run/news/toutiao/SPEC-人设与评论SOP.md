### 2.1 历史批评：**只批「作为历史政权的清朝」，绝不指向今天的任何民族或群体**

- ⚠️ **史实纪律（硬）**：**凡年代 / 数字必须能追到来源；追不到就不写。**（**错史被扒 = 掉粉 + 被举报** —— 本话题尤甚。）

#### 2.1.1 缠足（**高频话题** · 2026-10-11 **订正版** · 附实证与出处）

**✅ 可用结论**：**「断足式缠足」（折骨成弓、致残）是明清的产物，清代把它推到极致并全国普及**；**宋、明两代的考古实证更接近「纤直 / 轻度」**。

**实证（按时代 · 全部可回溯）**

| 时代 | 实证 | 关键细节 |
|:--|:--|:--|
| 西汉 / 南北朝 / 唐 | 女尸**足形原大**（马王堆等） | 🚫 无缠足 |
| **南宋** 福州黄升墓（1243） | 出土弓鞋 **13.3–14 cm** | 报道称**足骨未见骨折 / 变形**（**纤直型**） |
| **南宋** 江西德安周氏墓（1274） | 缠足布长 **2 m** · 弓鞋 | 考古发现**最早的缠足女子**；**未见断足报告** |
| **明代** 西安杨官寨明墓（1368–1644） | **Berger, Yang & Ye (2019), *Int. J. Paleopathology* 24: 79–88** —— 31 具骨架 → **8 名女性足骨保存良好**：宏观检验 **4/8「足骨明显改变」＝ 跖骨与可见趾骨「变细变小」（gracile and small）**、**跗骨仅轻微缩小、无剧烈形态变化**；**另 4/8 跖骨无明显改变**。原文结论：**明代这些精英女性「有的仍未缠足，或只是很轻的形式」，个体差异很大** | ⭐ **明代＝轻度 / 纤直，非断足**（**同行评审 · 最硬的一手骨骼数据**） |
| **明清** 出土女尸 | 明清女尸**无一例外**缠足；**弓形「三寸金莲」在 16 世纪后兴起、清代达巅峰** | **断足式 ＝ 明清（尤清）** |

**⚠️ 低置信 / 存疑（引用时标「存疑」，别当主论据）**
- 河北**临漳宋墓**（出「天禧通宝」1017–1021）：媒体报「脚骨因缠足**严重畸形**」—— **媒体级 · 未见同行评审**；且「畸形」**未必等于断足**（也可能只是变细）⇒ **标存疑**。

**✅ 可直接用的火力（史实级）**

1. **宋、明是「纤直缠」；断足成弓是明清的事，清代做到极致。**
   > 引用点：**Berger 2019 实测明代足骨是「变细」不是「折断」**（原文 *gracile and small* / *no dramatic change*）。
2. ⭐ **「禁而不止」的双标（最锋利）**：清廷**四道禁令** —— **崇德元年 1636 / 崇德三年 1638**（皇太极：禁旗人效汉人衣冠、缠足）· **顺治二年 1645** · **康熙三年 1664**（重罚：违者**父母有罪**、官员交吏兵二部议处、平民**杖四十 + 流徙十年**）⇒ **康熙七年 1668 因「执行太难」弛禁**，此后**事实放任**；而**同期剃发令却以「留头不留发」血腥执行** ⇒ **「男降女不降」**；且**清帝一面禁汉女缠足、一面广纳缠足汉妃入宫**。
   ⇒ **论点：其禁缠不为护民，只是「防满人汉化」的族群隔离 + 政治表演。**
3. **收尾**：真正让缠足绝迹的是**清末新政（1902 禁断骨缠足）与民国放足运动**。

> 📌 **硬纪律（只此一条）**：**凡写年代 / 数字 / 论文结论，必须与来源一致；拿不准就标「存疑」或不用。**
> 👉 **目的：让对手抓不到把柄** —— 你的论点本身就够硬，**不需要靠绝对化表述**。

## §3 语言风格（**不带 AI 范儿** · 硬性）

- **短**：微头条 **≤400 字**；**评论 ≤40 字**。**一句一意**。
- 🚫 **AI 腔禁用清单**：首先/其次/再次/最后 · 总之/综上 · 值得注意的是 · 不难看出 · 在……的背景下 · 随着……的发展 · 赋能 · 闭环 · 维度 · 生态位 · 抓手 · 深度剖析；🚫 **整齐的「1. 2. 3.」分点**；🚫 emoji 堆砌（**≤1 个或不用**）。
- ✅ **要多用**：口语（「这事儿」「说白了」「真敢干」「搁我我也……」）· **具体名词与数字（有据）** · 短句 / 省略 / 不那么工整的标点 · 少量网络用语（**不低俗**）。
- ✅ **每条必须不同**：🚫 不复用同一句式模板；同一话题两轮之间**不得重复用词**。
- ⚠️ **写完自查一遍**：像不像人随手打的？有没有「汇报腔 / 报告腔」？**像 AI 就重写**。

## §4 每轮 SOP（第 13 批 ③ 的展开）

1. **选题**（1 条·最有话题度）：影响面大 + 有明确新事实 + 与大众相关；🚫 纯技术细节 / 纯财报数字 / 营销稿。
2. **写稿**（微头条）：① **一句事实 + 来源** → ② 2–3 句**自己的判断** → ③ **结尾一个开放问题**（引评论）。草稿存 `news/toutiao/drafts/<date>-<slug>.md`。
3. **发布**：CDP 新开标签 → 发微头条；**必写/必勾「个人观点，仅供参考」声明**；⚠️ 选择器以实测为准，**写不准就只存草稿不发布**（🚫 不许硬猜乱点）。
4. **★ 引流评论**（见 §5）。
5. **回自己帖的评论**：只回**真实提问 / 理性讨论**（≤3 条/轮；随机 30–90s；逐条不同）。🚫 不吵架 / 不引战 / 不人身 / 不删他人评论。
6. **记账 + 回写**：见 §6。

## §5 ★ 引流评论 SOP（到别人爆款下简短评论）

> **目的**：借大流量帖子曝光获得关注。⚠️ **头条评论区 = 执行性风险最高区**（易被举报 / 删评 / 限流），故设硬约束。

- **频控（硬）**：**≤5 条 / 轮**（6 轮 ⇒ **≤30 条/天**）；**同一帖子只评论一次**；**两条之间随机 60–180 s**（拟人化）。
- **选帖（硬）**：**只选** 科技 / AI / 历史文化 / 汉服 / 传统 / 社会民生 类的**热门帖**（评论数多、气氛平和）。
  🚫 **绝不评论**：政治 · 军事 · 伤亡事故 · 司法个案 · **民族争议** · 宗教 · **骂战楼/争议楼**。
  ⚠️ **进楼前先看「标题 + 前 3 条评论」判断气氛 —— 气氛一触即走，不评**。
- **内容（硬）**：① **≤40 字 · 言简意赅**；② **对帖内容有实质回应**（赞同 / 补一个有据的事实 / 一句俏皮话）—— 🚫 不要空泛捧场（「说得好」「支持」）；③ 人设一致（§1）、**不带 AI 范儿**（§3）；④ 🚫 不提自己账号 / 不写「我发过」「看我主页」/ 不写联系方式 / 不与人争吵。
  > **引流 = 让人好奇点进你头像，不是自己吆喝。**
- **风控即停（硬）**：**评论被删 / 被屏蔽 / 「评论失败，请稍后重试」连续 2 次** → **立刻停本轮全部评论动作**，记台账；**下轮只发文不评论**；**连续两轮如此 → 记 ⚠️ 待 supervisor 决策**。
- **不做**：不刷楼 · 不顶帖 · 不连发 · 不跨帖复用同一句。
