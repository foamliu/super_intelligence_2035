# 折叠屏第八年：第一次，新机的卖点不是那块屏

十一月十五日，余承东发了一条视频，给华为 Mate X 系列过第八个生日。视频最后放了 Mate X8 的外观。

他还补了一句：大折叠已经是千万用户的主力机。

同一天的另一条消息里，他说自己应该是 Mate X 系列的第一位用户。

八年前那批人的想法很朴素：合上是一台普通手机，展开是一块平板。当时很多技术没人做过，只能自己研究。

八年之后，这句话的味道变了。

因为这一次公布新机时，他说的重点不是「折得多平」，而是屏幕、拍照、性能都有新突破。

一块屏从稀奇到不再稀奇，用了八年。这大概是硬件行业最慢的一门功课。

最早买折叠屏的人，买的其实是那个「展开」的动作。后来大家发现，动作会腻，屏幕不会。

所以到了第八年，一款大折叠值不值得买，终于回到了最俗的几件事：拍照糊不糊，电池撑不撑得了一天，重不重。

这也是为什么「主力机」这三个字比「千万用户」更耐读。千万是成绩，主力是位置。

顺带说件有意思的对比。十一月十三日，网上已经流传出他手持紫色新机的画面，大家据此认定是 Mate X8，还说圆形镜头模组回来了。

真到官宣那天，读者拿到的东西只有一段视频、一张外观图，加上「又有新突破」这几个字。

参数的事，还是别人替我们猜的。屏幕多大、什么芯片、相机几百万像素，全出自网上爆料。

对新机来说这不稀奇，对读者来说不算好消息：想知道值不值得换，还得再等一场发布会。

我更好奇的是另一件事。当一款折叠机被称作主力机，它的用户每天要开合多少次？电池能不能撑住一整天的通勤加加班？

这些问题，参数表从来不回答。
