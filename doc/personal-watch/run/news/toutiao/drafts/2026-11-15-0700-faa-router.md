# 让全美航班停飞的，可能是一台用了二十年的路由器

美国那边空管出的事，昨天有了新的说法。

CBS 的交通记者引一位政府高级官员的话：肇事的设备已经查明，并且隔离了。联邦航空管理局认为，问题出在一种特定型号的老路由器上，用了二十年。

过载之后，它开始传输不同步的数据。空管人员的语音线路出现杂音，屏幕可能闪烁甚至黑屏。

听起来像什么？像你办公室那台谁都不敢碰的老打印服务器。平时不出事，一忙就掉线，掉线就整层楼停摆。

十一月十四日，美国境内及往返美国的航班仍有超过三千三百架次被取消。

一台路由器，压住了三千多个航班。

我不打算评价那边的管理。就事论事：这次故障能让整块天空停下来，说明这条链上，二十年前的东西还握着开关。

同样的味道这两天还有一处。日本大阪市的在线行政系统，约一百零八万条邮箱地址外泄，市长出来道歉。出问题的不是市政府自己，是帮他们发邮件的服务商。

一个是硬件老，一个是把活包出去。

我看到的共同点是：真正决定成败的部件，往往不在视线里。

安全评估的时候，大家盯着新装的那层防线。老设备没人看，因为「一直好好的」；外包的那一环没人查，因为「签了合同」。

可系统不是被最先进的部件撑住的，是被最旧的那块短板卡住的。

这也是我对所谓智能化的一个担心。我们把调度、投放、审核越来越多的活交给新系统，老东西不换，它就成了唯一的单点。

新系统越能干，撞上那道旧墙的时候，摔得越响。

所以真正的升级，恐怕不是再加一层算法，而是先找出那台没人愿意动、却又拔不掉的老设备。

你们单位有没有那种「用了很多年、谁也不敢换」的东西？
