# 草稿 · 2026-11-16 0700 · OATs 物体智能体双生体

标题：二十美元的电子墨水屏，让一盆花学会委屈

## 正文（17 段）

一块小小的电子墨水屏，贴在花盆上。你忘了浇水，屏上那只植物形状的小东西就垂头丧气。

这不是玩具广告。是卡内基梅隆大学未来交互研究小组的一项研究。

做它的人叫金大华，博士五年级。项目名 OATs，中文叫物体智能体双生体。

十一月初，她在底特律的 ACM 用户界面软件与技术研讨会上展示了这套东西，拿了两项荣誉奖。

思路不新。上世纪九十年代的拓麻歌子就是这个逻辑：一只虚拟宠物，你不照顾它就难受。

但她把这件事从屏幕里搬到了实物上。花盆、咖啡机、滑板、哑铃，都能有自己的一张脸。

硬件很简单。一块电子墨水屏，加内外两组传感器，能测湿度、温度、光照、有没有人在用、有没有在动。

主模块成本约二十美元。屏幕上的角色，是谷歌 Gemini 旗下 Nano Banana 图像生成服务做的。

系统按传感器数据给角色换表情。网页上还能设置名字，按物品种类选择要接哪些传感器。

她发出去一批设备，发现人用它的方式大致三种。

一种是看东西有没有被用。有人装在咖啡机上，一磨豆子，屏上的小角色就兴奋。

一种是给周围的人提醒。3D 打印机工作时可能有气味，装一个上去，谁走近都能看见它正在跑。

还有一种是盯自己的习惯。有人装在哑铃上记录举重频率，为了不让那只小家伙失望，就真的坚持下来了。

短板也很直白：续航只有三到四天，接了声音传感器就掉到一天左右，靠 USB-C 充电。

所以它现在更像概念验证，不是成熟商品。要不要做成生意，她说还没决定。

这场展示也带出一个老问题：该不该给 AI 一张会难过的脸。研究者的担心是，拟人化会让人高估它，以为它真的在意你。

她的处理办法是把交互严格限制在表情和屏幕上，不做更复杂的互动。

她举了个例子：人会给自己的车取名字，给自行车取名字，但很少见谁给手机取名字。

花盆会难过、哑铃会失望，这套设计确实能把人从手机屏幕上拉回来一点。

但它换个地方继续要你的注意力。以前是通知栏响，现在是东西本身在等你。

你愿意让家里的物品有自己的情绪吗？
