# 2026-10-31 第 185 轮 微头条草稿 · 华为 CGM 三类证

华为终端的连续血糖监测系统拿到三类医疗器械证了，国械注准20263072228，10月30日药监局公示的。三类是最高等级，跟心脏支架一个监管档。（据IT之家）

以前华为的健康功能都是二类证：动态血压、睡眠呼吸暂停、房颤早搏提示。那类东西是“筛查、给趋势”，不能当临床依据。CGM不一样，是连续测组织间液葡萄糖，要拿平均绝对相对误差MARD说话，行业里MARD不超过10%才算高精度。

余承东早就说过要做独立的血糖器械，何刚说研发搞了四年。现在证下来了，产品名、价格、上市时间一个都没公布。

这一步的意义不在传感器，在于责任。二类只需要提醒你，三类就得为读数负责。这么一来，华为跟欧姆龙、雅培那些医疗器械公司就正面撞上了。
