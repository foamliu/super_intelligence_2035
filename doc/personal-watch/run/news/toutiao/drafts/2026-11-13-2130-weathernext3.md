# 十年云图摊开了，天气预报要换算法

天气预报的底子，是过去几十年的云图、雨量、气压记录。这批东西谁能拿到，谁就能训练模型。

十一月十三日，谷歌的 DeepMind 团队把两套数据集对外开放了，用的正是它那个气象模型 WeatherNext 3 的底子。

先看第一套。它把五颗静止气象卫星的云图拼成一张全球图，每小时更新一次，历史存档跨十年以上。

第二套更有意思。它是一套全球降水数据，空间分辨率约十公里，时间分辨率十五分钟，平均延迟约五小时。

谷歌公布的口径是，和全球三万六千多座气象站、三大陆基雷达网做过比对，它在这几个指标上都优于现在常用的同类产品。

报道里还提到，对轻到中度降水的一小时识别，它比常用基线提高了三成以上；越是没有地面雷达的地方，越能显出它的用处。

这套数据以知识共享署名的方式开放，研究者可以下载，也可以接实时数据流。

我的看法很简单：过去十年，算力是门槛。往后十年，门槛可能变成数据。

模型的论文大家都能读，训练用的底料却不是谁都拿得出来。谷歌这次把底料也拿出来，一部分是示好，一部分是标准之争。

谁的数据被更多人用，谁的格式、谁的评测口径，也就慢慢成了行业默认的起点。

对研究天气的人来说，这是好事，省了几年攒数据的功夫。对别的公司来说，压力就来了：自家的数据集，是继续锁着，还是也放出来。

我更关心另一头。数据越开放，拿它做的事情就越难被审计。预报错了，是模型的问题，还是数据本来就缺了那一块？

这个问题，现在还没有人能回答。

你觉得，天气数据该像现在这样公开，还是留一部分不公开？
