语音也分两档卖，微软这次把每分钟压到一分钱

十一月十七日的 Ignite 2026 大会上，微软推了自家第一款语音对语音模型，叫 MAI Realtime 1。发布稿里最显眼的还是价格：基础语音对语音使用费每分钟 0.01 美元，按现汇率大概六分多人民币。

要是模型需要边想边说，价钱另算：每百万输入 token 一美元，每百万输出 token 五美元。还有另一款 MAI-Transcribe-2，负责把医患对话转成文字，微软给的限时价是每小时音频 0.10 美元。

微软说 MAI Realtime 1 能处理打断、快速确认、等对方说完这些自然对话里的细节，嘈杂环境或者几个人同时说话也能听懂。它可以在任务需要更深入思考时调用更强的推理引擎，也能接企业系统完成预订、客服这类操作。这款模型已经兼容 OpenAI 的 Realtime API，方便开发者把现有的语音应用迁过来。

分数和账单，微软一起摆了出来。在 Big Bench Audio 上，它自报 98.9% 的准确率，每小时输入音频成本约 1.35 美元；对照的 GPT-Realtime-2 High 是 96.6%、每小时 4.14 美元，Grok Voice 2.0 是 97.2%、每小时 4.80 美元。

另一半故事在医疗那边。声明的口径是，Dragon Copilot Transcribe 已经百分之百切到 MAI-Transcribe-2，每月处理约一千万次患者就诊，多语言工作流里错误率下降约五成，全美约三分之一的医师在用。在 FLEURS 基准的六十种语言上，微软报的平均词错误率是 5.2%。

这里得说清楚，以上都是微软自己的数字，没有第三方复测。厂商发布会的对照表，挑哪几个基准、怎么取平均，本身就是一道选择题。

我觉得这次值得琢磨的地方，是同一个发布会里出现了两种完全不同的卖法。

前一种是给开发者的：一次对话几十秒到几分钟，用户会嫌它慢，所以速度要快、要能被打断、要便宜，一分钟一分钱这个定价是奔着「常开」去的。后一种是给医院的：没人关心转录花了几毛钱，关心的是这句话有没有写错，尤其是病人用母语或方言说的时候。所以那款模型一口气支持六十种语言，还把说话人区分、词级时间戳、关键词偏置都做进去了。

同一个技术底子，落到两边，一边算的是账单，一边算的是风险。

还有一处变化不太显眼：语音模型开始兼容别人家的 API 了。开发者不用重写代码就能换模型，这对用户是好事，对做模型的公司却是一种压力——接口标准化之后，剩下的比拼就只有价格和质量，讲故事的空间变得很小。

不过录音转录这种事，便宜和好用之间还有个更硬的东西：它进了谁的系统。医生问诊的录音、病人说的话，最后都存在某家公司的服务器上，这块的边界不会因为价格降了一半就变得更清楚。

我更想知道的是接下来几个月的用法：一所医院真的把全部门诊的转写都交给它之后，医生到底是省下了打字的时间，还是多了一道核对转写的活。这个答案，榜单给不了。
