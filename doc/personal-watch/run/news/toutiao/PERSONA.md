## §7 🆕 「冲神评」观察（**2026-10-12 第 16 批新增 · 全实测**）

> 用途：评论互动（「**冲神评**」= 让自己的评论被顶到前排 / 高赞）时，判断**什么内容更容易被顶**。

| 观察 | 实测数据 | 对我们的用法 |
|:--|:--|:--|
| **神评门槛极低** | 首帖 `w/1878735833613380/`（10-11）评论区：条目少，**最高赞 = 1 赞** | 一条**短 + 有信息量**的评论就足以压过现有评论 |
| **真实用户评论极短** | 「伪史论祸害青少年」= **7 字**（08-15） | **不必写长**；长回复反而**像机器人**（= 豆包 40–120 字风格） |
| **机器人评论占绝对多数** | 20 条历史评论中 **17 条（85%）为豆包** · emoji 率 **11/20** | **真人语感**（**无 emoji** · 口语 · **不带话题标签**）本身就是区分度 |
| **被顶的内容类型** | 豆包被顶的评论 = **给具体可核验事实**（06-21 父系基因 · 08-22「威震华夏」出处 · 07-05 商代迁都 / 08-12 原生农耕中心） | 评论里**补一个可核验事实**（年代 / 出处 / 数字）**比抒情更容易被顶** |
