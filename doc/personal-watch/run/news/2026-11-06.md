- **MIT「Astra 改权重」研究被公开质疑：spaCy 作者 Matthew Honnibal 称其「存在严重误导」——论文 8 组实验条件差异极大，只有 1.7 万–17.2 万参数的小模型是「仅看原始权重」，而 Qwen3.5-0.8B 数学能力修复那组实际被授权写 Python 并最多做 50 次前向测试**
  摘要：量子位 11-05 报道。MIT 团队此前宣称 **Astra 仅修改 Qwen3.5-0.8B 的 0.016% 权重**，把数学成绩从 **7.9%** 拉到 **48.1%**；**Matthew Honnibal**（spaCy 作者、Explosion 联合创始人）发文质疑该研究「**存在严重误导**」，以「舞台魔术师一次表演换一种手法、观众却以为是同一项技术」作比。Honnibal 梳理论文 **8 组实验**后指出：在「识别小型网络任务」「修复卡住的赛车模型」等实验中，Astra 确实「只看原始权重」，但这类实验的模型参数只有 **1.7 万–17.2 万**；而最引人注目的 **Qwen 数学修复实验**里，Astra **并未直接读取原始权重**，而是**被授权使用 Python 编程、最多进行 50 次前向测试**，通过观察模型输出再分析修改权重。量子位同时引述 Honnibal 的正面评价：让模型被提示去设计并执行人类 ML 工程师才能做的任务（写代码分析甚至直接改权重），**本身就是巨大进步**，「一两年前的 AI 模型在所有这些任务上都会失败」；真正的问题在于**成果的呈现方式**。
