①结论

核心结论（有效 · 负面）：未发现稳定滞后相关。全网格 23,940 格中，FDR（按频率分族 BH）校正后 q<0.10 = 0 格，stable = 0 格；未校正 p<0.05 = 1217 格（5.08%，与零假设下期望 ≈5% 一致）⇒ 观测与「无稳定信号」一致。
  • 结论 1 · 未发现稳定滞后相关（本批核心）：「新闻在前」方向的日/周/月频滞后相关，在全网格上无一格同时通过 FDR + 样本外同号且赢随机基线 + 分年度符号一致 三道。
  • 结论 2 · 未校正「显著」≈ 随机水平：未校正 p<0.05 = 1217 格（5.08%）—— 属多重比较下的预期量级，不得当作线索。
  • 结论 3 · |系数| top 格仍是探索性：即使某格系数绝对值较大，其 q 均 ≥ 0.10（FDR 未过），且多数样本外方向命中率不赢随机基线 ⇒ 按 PREREG.md §6 非线索（见 §4）。
  • 结论 4 · 块自助稳健性一致：移动块自助（block=21 · B=5000）中，随机「典型格」19/20 格的 95% CI 跨 0 ⇒ 保序列自相关下亦不支持「稳定滞后相关」（BOOTSTRAP.md）。
  • 结论 5 · 分年度不稳：top 格的分年度符号一致年数普遍 < 8/11，未达 stable 门槛（lag_corr.csv stable_match/stable_total 列）。
⚠️ 读法（硬约束）：以上均为样本外预测关联的描述性统计，非因果 · 非投资建议；🚫 无点位预测 / 仓位 / 择时。任何「线索」必须同时过 FDR + 样本外 + 分年度一致三道（PREREG.md §6）。

②方法 / 口径

预注册（先于结果）：news/signal/PREREG.md —— git 首次提交时间早于 LAG_CORR.md；对策空间 / 滞后阶 / 频率 / 信号特征 / 检验与校正 / 样本切分 / 判据均在见结果前写死。🚫 跑后不回改（确需修订须在 PREREG.md §8 记「修订记录」）。
项口径（写死）
X（新闻信号）逐日条数 → log1p(条数) → 滚动 z-score（窗 252 / min 60，只用 ≤t 信息，防前视）
Y（资产价格）对数收益 r_t = ln(P_t/P_{t-1})（🚫 不用价格水平做相关 = 伪相关红线）
滞后 k仅「新闻在前」方向：日频 k=0..+20 · 周频 0..+4 · 月频 0..+3
回归式r_{t+k} = a + b·X_t + c·r_{t-1} + 星期哑变量 + 节假日前后哑变量；b = 关注系数；HAC(Newey–West) SE；CI = b ± 1.96·se
多重比较按频率分族 BH-FDR；q≥0.10 标 exploratory
样本外训练 2016–2022 / 检验 2023–2026：报检验段相关系数 + 方向命中率，对照随机基线（多数向占比）
稳定性分年度符号一致性（≥8/11 年才可能判 stable）
分析窗口⚠️ R3「价格 ∩ 语料」显式截断：只保留「价格 ∩ 语料」共同可用交易日；语料冻结于 2026-09-30 ⇒ 其后交易日 X 恒为 0（无语料 ≠ 无新闻）⇒ 截断。个股上市/可得晚于 2016 者，其缺段保持 NaN / 不参与该段回归
周/月聚合周 = 该周最后一个交易日收盘；月 = 该月最后一个交易日收盘（与日频同源，口径固定）
异常点剔除 |日收益| > 30% 的异常点

⑥局限

  • 语料为代理源 chinanews（非新华社），且只含标题 + 日期（无正文 / 版面）⇒ 结论仅就该源成立；扩展源须按源分列重算。
