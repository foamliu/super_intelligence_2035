## 4. 核心分析：滞后互相关（**全网格一次跑完、全表落盘**）

- **主口径**：`ρ(k) = corr(X_t, r_{t+k})`，只做「**新闻在前**」方向。
  - **日频**：`k = 0 … +20`（交易日）；`k = -20 … -1` **仅作对照/预期检验**，必须**单列并标「预期性」**。
  - **周频**：`k = 0 … +4` 周；**月频**：`k = 0 … +3` 月（低频样本小 ⇒ **必须给 CI**）。
- **检索面**：`信号类别 × 资产 × 频率 × k` 全网格 ⇒ **一次跑完、全表落盘**（🚫 不许只报好看的格）。
- 周/月聚合口径**固定并写明**：**周 = 该周最后一个交易日收盘**；**月 = 该月最后一个交易日收盘**（与日频同源，避免口径打架）。

## 5. 必须处理（**缺一即结论作废**，规格 §2.5）

| # | 问题 | 处置（**写死**） |
|:--|:--|:--|
| ① | 自相关 / 重叠窗 | **HAC（Newey–West）** SE，滞后阶 `L = floor(4·(N/100)^(2/9))`；CI 另给 **block bootstrap**（block = 21 交易日，5000 次）；🚫 不用朴素 t |
| ② | 同期混杂 | 多元回归里控制 `r_{t-1}`、**星期效应**、**节假日前后**哑变量（不做裸相关就下结论） |
| ③ | 反向因果 | 另报 `corr(r_{t-1}, X_t)`（**市场 → 新闻**）作对照；标出「稳市场/救市」类**回应性**新闻（`EXPLORE.md` §3.2 口径） |
| ④ | 多重比较 | **全网格 FDR（Benjamini–Hochberg）**，按**频率分族**；**未校正一律标「探索性」** |
| ⑤ | 样本外 | 切 **训练 2016–2022 / 检验 2023–2026**；报**样本外**系数 / 方向命中率，**并与随机基线（50%）对比**（**赢不过随机 = 不算线索**） |
| ⑥ | 稳定性 | **分年度 / 滚动窗符号一致性**；不一致 ⇒ 标 `unstable` |
| ⑦ | N 与 CI | 每格必给 **N + CI**；**N<30（日频）/ N<8（月频）⇒ 直接写「样本不足」**，不许硬算 |

## 6. 判据（**何谓 `stable`**，写死）

一个 `信号 × 资产 × 频率 × k` 格判为 **`stable`（候选线索）** 当且仅当**同时**满足：
1. **FDR 校正后** `q < 0.10`（否则标 `exploratory`）；
2. **样本外**（2023–2026）系数**与全样本同号**，且方向命中率 **> 50%** 且其 CI 不含 50%；
3. **分年度符号一致** ≥ 8/11 年（2016–2026）；
4. **N** 达标（日频 ≥ 30 / 月频 ≥ 8）。

**不满足任一条 ⇒ 状态 = `unstable`（或 `样本不足`）**，照写。**「未发现稳定滞后相关」= 有效结论**。
