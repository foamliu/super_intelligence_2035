## 1. 方法（与 PREREG 一致）
- X = 逐日 `log1p(条数)` → **滚动 z-score（窗 252 / min60，只用 ≤t 信息）**；Y = **对数收益** `ln(P_t/P_{t-1})`。
- 对齐：交易日历 = A股个股日线并集；信号 X_t = 落在 `(上一交易日, 本交易日]` 的新闻条数。
- 窗口（R3 显式化 · R4/R5 复核）：**只保留「价格 ∩ 语料」共同可用的交易日** —— 语料冻结于其末日，其后交易日的 X 恒为 0（**无语料 ≠ 无新闻**）⇒ 截断；价格上市/可得晚于 2016 的标的，**其缺段保持 NaN / 不参与该段回归**（⚠️ 幸存者偏差见 §4）。
- 回归：`r_{t+k} = a + b·X_t + c·r_{t-1} + 星期哑变量 + 节假日前后哑变量`；`b` = 关注系数；**HAC(Newey–West)** SE；CI = `b ± 1.96·se`。
- k：日频 `0..+20`，周频 `0..+4`，月频 `0..+3`（**仅「新闻在前」方向**）；**全网格一次跑完、全表落盘**（`lag_corr.csv`）。
- 多重比较：**按频率分族 BH-FDR**；`q≥0.10` 标 `exploratory`。
- 样本外：**训练 2016–2022 / 检验 2023–2026**；报检验段相关系数 + 方向命中率，**对照随机基线**（多数向占比）。
- 稳定性：**分年度符号一致性**（≥8 年一致才可能是 `stable`）。
