3音频获取路径（合法 · 会员本人） 覆盖报告点 2

🚫 红线前置：只调研、只记录；不得绕过付费墙。以下每条均标合规性。

路径 A —— 官方下载 / 离线缓存 无官方入口

yanshe / dongfangtime 页面均无下载按钮，且注明禁止下载、10 分钟后自动关闭音频（反爬/防录设计）。不存在「官方一键下载」这种合规捷径。 已实测

路径 B —— 小鹅通 H5 / 小程序内接口 未登录态不可得

音频详情页（实测）：

https://app8ydmwl262114.h5.xet.pomoho.com/p/course/audio/a_6ac22971e4b0694c5c0fa9fd?product_id=p_59e9fbdfbb63e_ttHpBdbE

curl -L 实测：HTTP 302 无限重定向（Maximum (50) redirects followed）→ 必须有登录态（cookie/token）才进入播放。

小鹅通机制（据文档，未逐字段验证）：登录后播放器向后端请求带签名的音频地址（通常 …m4a 或 m3u8），签名有时效 → 会员本人在自己设备上理论上可观察到该地址。🔒 本线不实现、不提供任何"抓签名接口"的代码（=不绕付费墙）。

路径 C —— 播客 / RSS 待验证

本轮未发现该音频的官方播客/RSS 上架（喜马拉雅 / 小宇宙 / Apple Podcasts 未核实到）。「若上架 → 可合法直下」是最优解（公开 RSS 属授权分发）。→ 请用户在自己的订阅 App 搜一次确认（§8 P7）。

4微信登录凭证 覆盖报告点 3

  • 形态：平台是微信内 H5（小鹅通），登录态通常 = 微信 OAuth 后小鹅通下发的会话 cookie / 存储 token（可能含 wx_* 或小鹅通自有 session）。 据文档
  • 有效期：小鹅通会话通常数天 ~ 数十天（各端不同）。 待验证
  • 用户在自己设备上如何导出（合规、需用户操作）：
    • PC 微信：微信内打开 H5 → F12 开发者工具 → Network/Application 查看请求头 Cookie 与 localStorage（仅查自己的登录态）。
    • 手机：需代理抓包（Charles / mitmproxy）— 本线不提供、不推荐（易触红线）。
  • agent 需要用户提供什么（清单）：①（可选）公开 RSS 地址（若有，最合规）；② 若走 H5：用户自行在 PC 微信开发者工具导出的 Cookie / token（用户主动提供，本线不代为获取）；③ 用户明确授权仅个人使用、不二次分发。

⚠️ 即便拿到凭证，内容仍属付费墙内；本线仅在用户「个人使用、不公开传播」授权下处理，且音频绝不入 git（§6）。

5转写方案（本地 ASR 已实测可行） 覆盖报告点 4

5.1 本地 ASR ✅ 实测可行

环境：faster-whisper 1.2.1 + ctranslate2 4.8.2，device=cpu，compute_type=int8，language=zh。本机 2 核 / 3.7 GB / 无 GPU。

model=tiny load=1.2s transcribe30s_audio=0.72s RTF=0.024 peakRSS=258MB segs=0
指标`tiny`（实测）说明
模型加载1.2 s冷启动
30 s 音频转写0.72 s纯音（无语音）→ RTF 偏乐观
RTF（实时率）0.024（≈42× 实时）⚠️ 真实语音经验 RTF ≈ 0.1~0.3（估算）
峰值内存258 MB✅ 远低于 3.7 GB

可复现安装（关键坑已实测填平）：

# ① 装（无需 torch；国内镜像）
python3 -m pip install --user --break-system-packages -i https://pypi.tuna.tsinghua.edu.cn/simple faster-whisper
# ② 下模型：HF 官方被墙 → 用镜像；且新版 huggingface_hub 默认走 Xet 协议（镜像不支持，401）→ 必须禁用
export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_DISABLE_XET=1
# ③ 转写（用 numpy 数组喂入，绕开 av 版本兼容问题）
import os
os.environ["HF_ENDPOINT"]="https://hf-mirror.com"; os.environ["HF_HUB_DISABLE_XET"]="1"
from faster_whisper import WhisperModel
m = WhisperModel("small", device="cpu", compute_type="int8")   # tiny/base/small 备选
segs, info = m.transcribe("audio.wav", language="zh", vad_filter=True)
print("".join(s.text for s in segs))

实测踩坑：

  1. av 19.0.1 与 faster-whisper 1.2.1 不兼容：av.open(..., metadata_errors=…) 对文件路径抛 TypeError → 绕法：传 numpy float32 数组（实测通过），或 pin 旧版 av。
  2. hf Xet 协议：cas-server.xethub.hf.co 401 → 必须 HF_HUB_DISABLE_XET=1（实测）。
  3. ffmpeg：本机无系统 ffmpeg → 免 root 方案 pip install --user imageio-ffmpeg（实测自带静态 ffmpeg 7.0.2），用于视频转音频 / m3u8 拼接。

6合规红线（硬性） 覆盖报告点 5

  1. 仅限会员个人使用；🚫 不得二次分发 / 公开传播音频或全文。
  2. 🚫 不得绕过付费墙（不实现抓签名 / 逆向；须用户在自己账号内获取）。
  3. 🚫 音频一律不入 git：音频远超 5 MB 阈值 → 只留本地 / 网盘，并在 INDEX_FILES.md 登记（网盘路径 / 提取码 / sha256；⚠️ 本机无 bypy → 网盘不可用，届时标「未上云」）。
  4. 文字稿可入 news/；但长篇全文同样受体积红线约束 → 建议分片或仅存摘要 + 指向本地全文。
  5. 🚫 不采集 / 不转写未获授权的内容。
