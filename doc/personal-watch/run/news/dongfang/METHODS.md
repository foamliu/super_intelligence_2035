## 3. 音频获取路径（覆盖报告点 2 · **合法，会员本人**）

> 🚫 **红线前置**：**只调研、只记录；不得绕过付费墙**。以下每条都标「合规性」。

### 3.1 路径 A —— 官方下载 / 离线缓存：**【已实测】无官方下载入口**

- `yanshe.org.cn` 播放页与 `dongfangtime.com` 页面**均无下载按钮**，且注明**禁止下载**、`10 分钟后自动关闭音频`（反爬/防录设计）。
- 结论：**不存在「官方一键下载」这种合规捷径。**

### 3.2 路径 B —— 小鹅通 H5 / 小程序内接口：**【已实测】未登录态拿不到；登录态下由签名接口下发**【据文档】

- 音频详情页（实测）：
  `https://app8ydmwl262114.h5.xet.pomoho.com/p/course/audio/a_6ac22971e4b0694c5c0fa9fd?product_id=p_59e9fbdfbb63e_ttHpBdbE`
- `curl -L` 实测：**HTTP 302 无限重定向**（`Maximum (50) redirects followed`）→ **必须有登录态（cookie/token）才进入播放**。
- 小鹅通机制（【据文档】小鹅通 H5 通用架构，**未在本仓库逐字段验证**）：登录后播放器向其后端请求**带签名的音频地址**（通常为 `…/audio/…m4a` 或 m3u8），**签名有时效**。→ **会员本人在自己设备上，理论上可观察到该地址**（这正是「离线缓存」在底层做的事）。
- 🔒 **本线不实现、不提供任何"抓签名接口"的代码**（= 不绕付费墙）。

### 3.3 路径 C —— 播客 / RSS：**【已实测 · 2026-10-06 P7 核验】→ 未发现公开 RSS**

> 用户拍板选 **(a) 先核验 P7**：由本线在本机逐一核验主流播客/音频平台的**公开 RSS**。**结论：未发现**《衍射+东方时事解读音频》的公开播客/RSS 源 → **「公开 RSS 直下」这条最优合规路径 ❌ 不可用**。

- 平台是**微信内 H5**（小鹅通），登录态通常是：微信 OAuth 后小鹅通下发的 **会话 cookie / 存储 token**（可能含 `wx_*` 或小鹅通自有 `session/token`）。**【据文档】**
- **有效期**：小鹅通会话通常**数天~数十天**（各端不同）→ **【待验证】**（需实测导出后观察）。

## 4. 转写方案（覆盖报告点 4）

### 4.1 本地 ASR —— ✅ **实测可行（本机 2 核 / 3.7 GB / 无 GPU）**

**实测环境**：`faster-whisper 1.2.1` + `ctranslate2 4.8.2`，`device=cpu`，`compute_type=int8`，`language=zh`。

**实测原始输出**（`/tmp/asr_probe2.py`，30 秒音频）：

```text
model=tiny load=1.2s transcribe30s_audio=0.72s RTF=0.024 peakRSS=258MB segs=0
```

| 指标 | `tiny`（实测） | 说明 |
|:--|:--|:--|
| 模型加载 | **1.2 s** | 冷启动 |
| 30 s 音频转写 | **0.72 s** | 纯音（无语音）→ RTF 乐观 |
| **RTF（实时率）** | **0.024**（≈ 42× 实时） | ⚠️ 无声样本偏乐观；**真实语音**（`tiny`）经验 RTF ≈ **0.1~0.3**（**估算**） |
| 峰值内存 | **258 MB** | ✅ 远低于 3.7 GB |

**可复现安装**（**关键坑已实测填平**）：

```bash
# ① 装（无需 torch；国内镜像）
python3 -m pip install --user --break-system-packages -i https://pypi.tuna.tsinghua.edu.cn/simple \
  faster-whisper                      # → faster-whisper 1.2.1 + ctranslate2 4.8.2 + av + onnxruntime …

# ② 下模型：HF 官方被墙 → 用镜像；且新版 huggingface_hub 默认走 Xet 协议（镜像不支持，会 401）→ 必须禁用
export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_DISABLE_XET=1
```

```python
# ③ 转写（用 numpy 数组喂入，绕开 av 版本兼容问题 —— 见下）
import os
os.environ["HF_ENDPOINT"]="https://hf-mirror.com"; os.environ["HF_HUB_DISABLE_XET"]="1"
from faster_whisper import WhisperModel
m = WhisperModel("small", device="cpu", compute_type="int8")   # tiny/base/small 备选
segs, info = m.transcribe("audio.wav", language="zh", vad_filter=True)
print("".join(s.text for s in segs))
```

**实测踩坑（已定位，供复现者参考）**：

1. **`av 19.0.1` 与 `faster-whisper 1.2.1` 不兼容**：`av.open(..., metadata_errors=…)` 抛 `TypeError`（传入**文件路径**时触发）。
   - **绕法**：**直接传 numpy `float32` 数组**给 `transcribe()`（**实测通过**）；或改 pin 旧版 `av`。
2. **`huggingface_hub ≥1.x` 默认 Xet 协议** → `cas-server.xethub.hf.co` **401**；**必须** `HF_HUB_DISABLE_XET=1`（**实测**）。
3. **ffmpeg**：本机**未装系统 ffmpeg**（`ffmpeg: command not found`）；**免 root**方案 = `pip install --user imageio-ffmpeg`（**实测**自带静态 `ffmpeg 7.0.2`，路径 `…/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2`）→ 用于**视频转回放音频 / m3u8 拼接**。

**模型选型建议（2 核 4G，估算）**：

| 模型 | 磁盘 | 内存(估) | 中文质量 | 本机建议 |
|:--|:--|:--|:--|:--|
| `tiny` | ~75 MB | ~260 MB【实测】 | 差（仅粗听） | 仅测速 |
| `base` | ~145 MB | ~350 MB（估） | 一般 | 低配兜底 |
| **`small`** | ~490 MB | ~700 MB（估） | **较好**（推荐） | ✅ 首选 |
| `medium` | ~1.5 GB | ~2.5 GB（估） | 好 | ⚠️ 3.7G 内存吃紧 |

> 🎯 **中文**场景若追求更强，可另选 **FunASR / Paraformer（ModelScope，`modelscope.cn` 实测可达 HTTP 200）** —— **【待验证】**（本轮未实测其本机性能）。
