# news/analysis/ — 数据分析与图表 · 目录契约

> **谁写**：news agent。**谁读**：supervisor、用户。
> **用途**：把 `news/`（日报）与 `news/archive/`（语料）**统计化、可视化**；并承载 **L2 探索性关联分析**。

## 1. 放什么

| 文件 | 内容 |
|:--|:--|
| `XINHUA_2016_2026.html` | **自包含**报告：每年条数 / **每月分布饼图** / **频道占比饼图** / 年度趋势 |
| `xinhua_stats.csv` | 上述图表的**底表**（可核验） |
| `EXPLORE.md` + `explore.csv` | **L2 探索性关联分析**（政策动作 × A股，⚠️ **非因果**）—— 由 `news/policy/` 产出后放这里 |
| `L2_PREREG.md` | L2 **方法预注册**（窗口/口径/检验/多重比较方案 —— **先写死再跑**） |

## 2. 命名规范

- 图表报告：`<主题>_<时间窗>.html`（如 `XINHUA_2016_2026.html`）；
- 底表：同名 `.csv`（**与图一一对应**）；
- 探索性关联：**只能用 `EXPLORE`**（🚫 **不用 `IMPACT`**）。

## 3. 红线（🚫 违反即退回）

1. 🚫 **图表必须由真实数据生成**；**画不出就不画**（不许示意图/编造数据）。
2. 📦 **自包含**：内联 CSS/SVG，**离线可开、无外链**；如用 matplotlib 须把 PNG **内联**（data-URI）。
3. ⚠️ **相关 ≠ 因果**：图表与文字**必须标注**；L2 全文 🚫 **禁用「影响 / 导致 / 利好 / 利空 / 冲击」**，只用「**相关 / 同期 / 滞后 / 共现**」。
4. ✅ **默认只做描述性统计**（分布 / 均值·中位数 / 自助法置信区间 / **N**）；**显著性宣称须多重比较校正**（FDR/Bonferroni），未校正一律标"**探索性**"。
5. ⚠️ **必给 N**：N 小的格子写「**样本不足**」，不许硬算。
6. 🚫 **禁数据窥探**：不许反复换窗口/基准/板块直到"显著"；✅ **允许结论是"没找到稳定关联"**。
7. 🧭 **超能力就写「本线做不了，需人工/专家介入」**（同 N1 兜底原则）。
8. ⚖️ 政治话题**只做公开数据的描述性/统计性分析**；产出是**研究性观察，非投资建议**。
