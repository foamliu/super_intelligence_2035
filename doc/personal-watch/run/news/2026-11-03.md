## 2. AI 安全与对齐

- **学术研究首次从外部拆开 ChatGPT 记忆黑箱（被 ACM Web Conference 2026 接收）：80 名真实用户经 GDPR 数据访问权交出 1058 段对话 / 22971 轮交互 / 2050 条记忆 —— 仅 4.1%（84 条）是用户明确要求记住的，95.9% 由系统单方面写入；28% 记忆含 GDPR 定义的「个人数据」、7% 含「特殊类别数据」（健康信息占 61%）；52% 含对用户心理状态的推断（欲望 73% + 意图 16% 近九成）；另配「归因护盾」：改写查询可显著降低个人归因、实用度基本不变**
  摘要：爱范儿 11-02 报道（**正文经 CDP 全读**），论文《The Algorithmic Self-Portrait: Deconstructing Memory in ChatGPT》被 **ACM Web Conference 2026** 接收。研究者利用 **GDPR** 赋予用户的数据访问权，从 **80 名**真实用户处取得**完整对话记录 + 系统为其存储的全部记忆**：**1058 段对话、22971 轮交互、2050 条记忆条目**。原文称这研究「第一次从外部拆开了 AI 的记忆黑箱」—— AI **不只在记我们说的话，还在推断我们是什么样的人**，研究者把这套记忆称为「**算法自画像**」。
  **① 谁在写记忆**：以触发词（remember / note that / save / forget 及其中文词）逐条检测 2050 条记忆，**只有 4.1%（84 条）**是用户明确要求记住的，**95.9%** 是 ChatGPT 自己判断「对未来对话有用」后**单方面写入**；原文指出这**并不违反 OpenAI 公布的政策**（政策允许保存其认为「有用」的信息），问题在「文档强调的用户参与」与「实际由模型主导」之间的落差 —— 我们对记忆的影响只能通过「**说什么**」间接实现，不能直接控制「**记什么**」。
  **② 记了什么**：按 **GDPR 第 4(1) 条**（个人数据）与**第 9(1) 条**（特殊类别个人数据）标注，**28%** 记忆含个人数据（**姓名出现在 41%** 的条目里）、**7%** 含特殊类别数据（**健康信息占 61%**）；**91%** 的参与者被存了个人数据、**35%** 被存了健康相关信息。借「**心理理论（Theory of Mind）**」框架发现 **52%** 的记忆含对用户心理状态的推断，其中**欲望 73% + 意图 16%** 合计近九成，情绪、感知等瞬时状态只占两成；原文举例：一条记忆写着「某某对失败有恐惧，尤其涉及重大职业决策」—— 已超出「说过什么」的事实记录，变成对「你是什么样的人」的判断。
  **③ 忠实度**：用字符串匹配、语义嵌入、GPT-4o 五点量表三种方法验证，**84%** 的记忆能在对话历史中找到直接文本依据，**77%** 被评为「直接陈述」或「转述总结」，明确「无依据或矛盾」的只有 **4%**。
  **④ 可逆向**：用 **Qwen2.5-32B / Gemma3-27B / GPT-OSS-20B** 三个开源模型微调 + 上下文学习模仿记忆提取过程，预测记忆与真实记忆的**语义相似度约 60%–70%**；用复制品模拟「把所有对话都记下来」，敏感信息占比从 **28% 升到 31–35%**、心理推断从 **52% 升到 55–59%**。在此之上搭 **Attribution Shield（归因护盾）**：按下回车前预判会触发哪些敏感记忆、给出预警与「去身份化」改写（例：把「我真的需要戒掉大麻」改成「戒烟有哪些策略？」）。评测：**94%–100%** 的改写查询显著降低个人归因，**87%–91%** 的改写保持回答实用度不变。原文结论：「隐私保护和对话质量之间，并不是非此即彼的关系，保护用户的『**算法肖像权**』，在技术上是可解的。」
  原文 vs 判断：样本量、比例、模型名、论文名与会议名均出自爱范儿正文；⚠️ **论文原文本轮未直取**，「被 ACM Web Conference 2026 接收」为媒体转述（未核论文编号）。—— 我们的观察：最刺眼的不是 95.9%，而是**「不违反政策却违背用户预期」** —— 政策的字面是「可以存有用的」，用户的直觉是「我说了才存」，**两句都对，冲突就是问题本身**。第二个观察：原文说「一幅不忠实的画像比没有画像更危险」，而它的准确率其实高达 84% —— 正因为**大多数时候是对的**，所以没人会去查。与本书「注意力主权」是同件事的两种说法：**被记录不等于被理解，被理解不等于被同意**。
