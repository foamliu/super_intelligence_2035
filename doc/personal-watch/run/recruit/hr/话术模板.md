# Boss直聘回复话术模板与建议

> 适用岗位：AI+EDA 研究员（DRAM 设计方向）/ 大模型·Agent 算法工程师
> 场景：828 位候选人中，818 人最后一条消息是候选人发的，需要 HR 主动回复

---

## 一、核心原则

### 你真正的对手不是"候选人"，而是"信息噪音"

一个算法候选人每天收到几十条 HR 消息，95% 长这样：

> ❌ "您好，看到您的简历很感兴趣，方便发一份简历吗？"

这种消息的效果 ≈ 0。**你要做的不是"礼貌"，而是 3 秒内让对方觉得「这个人是认真的、这个岗位值得看」。**

### 三个必须

| # | 必须做到 | 为什么 |
|---|---|---|
| 1 | **第一句引用他亲口说过的话** | 证明你不是群发。这一条能把转化率拉开 3~5 倍 |
| 2 | **给岗位的硬卖点**（平台 / 方向 / 薪资 / 团队） | 优秀候选人是双向选择，他凭什么给你简历？ |
| 3 | **把行动成本降到最低**（明确发给谁、怎么发） | 每多一个"然后呢"，就流失一批人 |

### 三个不要

| # | 不要做 | 原因 |
|---|---|---|
| 1 | **第一条消息就发微信号** | Boss 判定"私域引流"，会**降权/屏蔽/限流**，甚至影响账号 |
| 2 | **发长段落**（超过 4 行） | Boss 聊天窗很窄，长文本被折叠，候选人根本不会展开 |
| 3 | **一条消息只问一个问题** | "有论文吗"→"什么学历"→"几年经验"来回 5 轮，人早跑了 |

---

## 二、通用骨架

```
【个性化开场】引用他打招呼里的具体内容（10~20 字）
        ↓
【为什么找他】你的岗位和他的哪个能力对上了
        ↓
【岗位卖点】1~2 个硬信息（平台/方向/薪资）
        ↓
【明确诉求】简历 + 怎么发（附件/邮箱）
```

控制在 **4 行以内**，每行不超过 25 字。

## 三、分场景模板

### 场景 1 ｜ S 级 · 硬门槛全中（缪铭凯）

**对象特征**：微电子博士 + UIUC ECE 硕士 + 一作 DAC/AAAI/IJCAI，AI for EDA 方向
**策略**：**平视、专业、直接**。他有挑公司的资本，用"求"的语气会掉价。要让他感觉"对面懂行"。

```
缪博您好，看到您「AI/LLM for EDA」方向 + 一作 DAC，这正是我们这个岗位的核心画像。

我们做的是 AI + DRAM 设计交叉方向（长鑫存储），团队 [待你确认：是否有学术氛围/鼓励发论文]。

想跟您确认两点：
① 您更倾向正式入职，还是先实习？
② 方便发一份简历吗？我拉通技术负责人跟您聊。

（简历可发 [邮箱] 或直接 Boss 附件）
```

**要点**
- 称呼用「缪博」而不是「您好」——立刻区分于群发
- **主动点出 DAC**，证明你看懂了，这是最能打动科研背景候选人的细节
- 把他"可以长期实习"的信息接住，问清楚诉求（博士投实习岗通常是想转正或还在纠结）
- ⚠️ **「团队是否鼓励发论文」这类卖点我无法确认，不要凭空承诺**，如实填或删掉

---

### 场景 2 ｜ S 级 · 他主动要发简历（顾嘉伟）

**对象特征**：33 岁，Agent 开发 + 体系结构背景，**主动问"可以发一份简历给你吗"**，还精准提问"agent 加速 DRAM 设计"
**策略**：**最短、最快**。他已经递了球，你只需要接住。但**必须正面回答他的问题**。

```
顾老师您好，您的理解非常准 —— 这个岗位 [待你确认：偏 agent 训练 还是 agent 用于 DRAM 设计加速]，正是您说的后者/前者方向。

您的体系结构背景很加分。简历直接发我 Boss 附件就行，或者 [邮箱]。

什么时候方便电话聊 15 分钟？[待你确认：你的可约时段]
```

**要点**
- 他的问题其实是在**验证岗位是不是真·EDA 交叉方向**。含糊回避 = 直接失去他
- 这类"懂行的候选人"是最优质的，回复速度要快（他可能同时在问别家）

---

### 场景 3 ｜ S 级 · 交叉背景但信息薄（罗靖皓 / 孙晨枫 / 汪皓然 / 黄欣琳）

**对象特征**：微电子/集成电路/FPGA 背景 + 有一点点 AI，但没说学历年限论文
**策略**：**先肯定交叉背景，再用"结构化追问"一次问清关键信息**。

```
您好，本科微电子 + 研究生做 LLM，正好是我们最想要的交叉背景。

想确认几个信息，方便您一次回复：
① 目前是硕士在读还是已毕业？学校？
② 有发表论文吗（CCF/EDA 方向优先）？
③ 哪年毕业、能投入的时间？

方便的话发一份简历：[邮箱] 或 Boss 附件
```

**要点**
- ①②③ 用**编号列出来**，对方复制粘贴就能回答，回复率远高于一句一句问
- 结尾**永远给一个具体动作**（发邮箱 or 发附件）

---

### 场景 4 ｜ A 级 · 大模型能力强但无 EDA 背景

**对象特征**：硕/博 + LLM/Agent/Multi-Agent 经验扎实，但完全没提芯片
**策略**：**不要求他已经会 EDA，而要判断他"愿不愿意转方向"**。所以要先把方向讲得**性感**。

```
您好，看到您[具体项目，如"商汤 Browser GUI Agent"]的经历，方向很对口。

我们做的是大模型 × 芯片设计（AI for EDA / DRAM），属于把 LLM 能力用在工业级硬核场景，[待你确认：技术挑战/团队构成]。

想聊两点：
① 您对转做 AI+EDA 方向有兴趣吗？
② 方便发份简历吗：[邮箱] 或 Boss 附件
```

**要点**
- 核心是**试探转方向意愿**。一个有 LLM 硬实力 + 愿意学 EDA 的人，往往比"半吊子 EDA"更有价值
- "工业级硬核场景"是说服算法人转方向的关键话术，但**不要编造具体技术细节**

---

### 场景 5 ｜ 实习生岗专用

```
您好，看您[引用他说的内容]，跟我们实习方向很匹配。

想确认：
① 学校 + 目前研几/博几？
② 一周能到岗几天、能持续多久？
③ 有论文或相关项目产出吗？

简历发我：[邮箱] 或 Boss 附件
```

---

### 场景 6 ｜ 信息极少 / 只想批量初筛

```
您好，[个性化一句]。
方便说下：①学历 ②毕业年份 ③有无相关论文/项目？
合适的话我发您岗位详情。
```

> 这条**故意不直接要简历** —— 信息不清时先要简历，会让对方觉得你不会看简历。
> 先问清 → 判断值不值得 → 再要简历，反而更专业、回复率更高。

## 四、反模式对照表

| ❌ 不要这样写 | ✅ 应该这样写 |
|---|---|
| 您好，方便发一份简历吗？ | 看到您 DAC 一作 + AI for EDA，方便发份简历吗？ |
| 有论文吗 | 方便说下①学历②毕业年份③论文情况吗？ |
| 我们公司待遇很好 | 40-60K × 14-16 薪，博士可放宽经验要求 |
| （直接发微信号） | （等对方回复后再给微信） |
| 一大段 200 字的岗位介绍 | 4 行以内，每行一句话 |

## 五、执行建议（重要）

### 1. 每条消息至少花 10 秒改第一句
Boss 有**反骚扰检测**：短时间内发送高度雷同的内容，会被判定群发 → 消息被折叠、账号被限流。
**第一句必须因人而异**，这是最低成本的规避方式。

### 2. 分批发送，拉长间隔
- 每批 **3~5 人**
- 批间隔 **≥ 30 分钟**（最好隔天）
- 优先发 S 级 8 人，看回复率再决定要不要扩到 A 级

### 3. 优先级顺序
| 优先级 | 对象 | 理由 |
|---|---|---|
| P0 | **缪铭凯** | 唯一硬门槛全中，且是博士（经验可放宽） |
| P0 | **顾嘉伟** | 主动要简历，意愿最强，懂行 |
| P1 | 罗靖皓 / 孙晨枫 / 汪皓然 / 黄欣琳 | 交叉背景，需澄清信息 |
| P2 | 成晨 | 主动自荐且表达清晰，但 EDA 是新方向 |
| P3 | 张浩然 | **先问清楚是本人还是对象求职** |
| P4 | A 级 108 人中挑 | 优先挑有论文/大厂实习的 |

### 4. 准备好你的"标准答案"
候选人回复后大概率会问这几个问题，**提前想好答案**，别临场卡壳：
- 具体做什么？（agent 训练 vs 用 agent 做 DRAM 设计）
- 团队多少人、向谁汇报？
- 能否发论文 / 去会议？
- 工作地点（上海 / 合肥 / 北京）？
- 面试流程几轮？

**这些问题答不好，前面的简历就白要了。**

---

## 六、需要你确认的信息（模板里已标注 `[待你确认]`）

我没有编造任何一句你不确定能兑现的承诺，以下几处请你替换为真实信息：

1. 接收简历的**邮箱地址**
2. 岗位实际内容：**偏 agent 模型训练，还是用 agent 辅助 DRAM 设计？**（顾嘉伟的问题必须答准）
3. 团队是否**鼓励发表论文 / 支持参会**（对缪铭凯这类博士生极关键）
4. 你的**可约电话时段**
5. 是否能接受**在校博士长期实习**、是否有转正通道
