## 岗位定位

面向下一代 DRAM 工艺平台，参与大模型、AI Agent、多模态大模型与 EDA 工具链交叉领域的前沿研究，探索 AI for EDA 在 DRAM 设计全流程中的研究与应用。团队拥有丰富的芯片设计数据资源和计算资源（目前配备 16 张 H100），与 EDA 业务方（如 CAD 部门）深度合作，致力于打造业界领先的芯片智能设计能力。

## 岗位职责

1. **AI+EDA 前沿研究**：参与基于大模型与 Agent 技术的 EDA 工具链智能化研究，探索 Agent 在 DRAM 设计场景中的自动弱点识别、优化方案推荐与设计空间探索方法，协助形成可发表、可验证、可复现的研究成果。
2. **Agent Benchmark 与评测**：参与构建面向 DRAM 设计全流程（架构设计、逻辑综合、物理设计、时序验证等）的 AI Agent 评测基准，协助定义大模型及多模态大模型在设计业务场景中的能力评估标准与自动化测评方法。
3. **DRAM 设计领域 Deep Research**：参与基于大模型与 AI Agent 技术构建面向 DRAM 芯片架构设计、电路设计、物理实现等核心环节的自主化深度研究系统，协助利用 Agent 实现前沿论文自动追踪、技术路线推理、方向预判与假设生成。
4. **MLLM 在 EDA 中的预研与落地**：参与多模态大模型在 DRAM 设计全流程的预研工作，探索 MLLM 在芯片版图识别与理解、设计规则检查（DRC）辅助、电路图语义解析、设计文档智能生成等场景的应用路径，参与从模型选型、数据准备、训练调优到实验验证的研究闭环。
5. **Agent 方法学与理论体系建设**：参与 DRAM 设计全生命周期 Agent 方法学构建，协助定义大模型在架构探索、设计实现、验证签核等场景的标准化研究范式（包括微调策略、评测体系、部署规范）。
6. **前沿技术跟踪与学术转化**：持续跟踪大模型、AI Agent、AI for EDA、多模态融合等前沿技术，对关键学术领域进行系统性梳理，识别可落地的技术方向并推动工程转化，产出高水平论文与专利。与团队一起在 **ICCAD、DAC、DATE、ASP-DAC、NeurIPS、ICLR、ICML、CVPR、ACL** 等顶级会议投稿发表论文。
