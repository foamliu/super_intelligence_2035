## 一、发生了什么

### 08:00–08:10 登录态恢复（承接前一日 3 次风控导致登录态作废）

- **观察**：`www.zhipin.com/web/chat/index` 反复 302 到 `login.zhipin.com`，页面显示「当前登录状态已失效」。
- **根因（实测两条）**：
  1. 用 `domain: '.zhipin.com'` 注入 cookie 串时，**`wt2 / zp_at / bst / wbg` 四个鉴权 cookie 根本没写进去**（其余 11 个正常）；
  2. 浏览器里**残留着 `login.zhipin.com` 的旧标签**，`ctx.pages()[0]` 经常取到它 —— 之前三轮「导航后仍跳登录」其实是在操作那个旧标签。
- **动作 / 结果**：改用 **`{ name, value, url: 'https://www.zhipin.com/' }`** 形式 `addCookies`，再用**全新标签页**打开 `web/chat/index` → **一次成功**（显示「刘先生」+ 完整沟通列表）。
- **时间基准**：本机时钟比 Boss 服务器**慢约 8 小时**（本机 00:05 时 Boss 页面显示 08:05）。
