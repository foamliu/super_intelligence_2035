## 岗位定位

面向大模型与 AI Agent 方向开展算法研究与工程落地：围绕 LLM / MLLM 的建模、训练与评测，以及 Agent 的方法学、工具调用、记忆与多智能体协作，构建可验证、可复现、可上线的算法能力，并推动研究成果向业务场景转化。

> ⚠️ **岗位层级**：本岗为**工程师岗（非资深/专家/总监）**。职责中的「主导/负责」按「**在团队负责人指导下参与并逐步独立承担**」理解；**不要求**候选人已有带团队或主导大型项目经历。

## 岗位职责

1. **大模型算法研究与优化**：参与 LLM / MLLM 的继续预训练、指令微调（SFT）、偏好对齐（RLHF/DPO/GRPO 等）与推理优化，形成可复现的实验结论。
2. **Agent 能力建设**：设计并实现基于 LLM 的 Agent 系统（规划、工具调用、记忆、反思、多智能体协作），解决实际工程问题并建立量化评测。
3. **Agent Benchmark 与评测**：构建面向真实任务的 Agent 评测基准与自动化测评方法，定义能力评估标准，推动评测体系可复用。
4. **RAG 与知识增强**：搭建检索增强生成（RAG）与知识库系统，优化召回、重排、上下文组织与答案可靠性。
5. **多模态方向预研**：参与 MLLM 在文档理解、图表/图像解析、结构化信息抽取等场景的选型、微调与验证。
6. **工程化与落地**：与工程/产品协作完成从模型选型、数据准备、训练调优到上线验证的完整闭环，产出论文、专利或高质量开源。
