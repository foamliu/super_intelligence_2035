# S 级 · 论文录用确认话术（20 人）

> **只问问题。**
> 不带自我介绍、不寒暄、不索要简历、不加"方便吗"。
> **一条消息 = 一个问题**：哪个会议，录用还是在投。
>
> **纪律**：每条独立发送；**每批 ≤2 人，批间隔 ≥60 分钟**。

## 三、他怎么答 → 定到哪一级

| 回答 | 结果 |
|---|---|
| 已录用 + 一作 | **确认 S**（学校只用于区分 A/B/C） |
| 在投 / 在审 / 还没出结果 | 降到 **A / B / C** |
| 是期刊不是会议 | 降到 **A / B / C** |
| 导师一作，我二作 | 降级或淘汰 |
| 不回 / 含糊 | 标红，等简历 |

> 消息只是第一道过滤 —— **最终以简历里的 publication list 为准。**
