# 211 / 985 / 上海 985 院校名单（判据文件）

> 建立：2026-11-11（依据运维指令区 2026-11-11 令 §③「以教育部 211 / 985 官方名单为准」）。
> 用途：全职推荐判「**本科 211 以上**」、实习推荐判「**985 在读 + 学校在上海**」时，**只认本文件的名单**。
> 判据纪律：
> - 名单内 ⇒ 达标；名单外 ⇒ 不达标；**查不到 ⇒ 标「院校待核」，不得当成达标**。
> - **全职看本科**：简历「本科 XX / 硕士 YY」⇒ 判 **XX**。专升本 / 自考 / 独立学院 / 民办 ⇒ **即使硕士 985 也不算本科 211**。
> - **实习看当前在读院校**：同时满足 ① 在读（预计毕业时间未到）② 院校在**上海**且属 **985**。
> - 异地校区：按**校址**判。「哈工大深圳」「北理工珠海」等**校址不在上海** ⇒ 实习不达标；交大 / 复旦 / 同济 / 华师大在沪校区 ⇒ 达标。
