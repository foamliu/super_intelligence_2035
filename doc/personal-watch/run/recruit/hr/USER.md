## 二、沟通偏好

- 用**中文**回答，结论先行，**多用表格**，少用长段落。
- ★ **对外消息（发给候选人的话）风格**：**零自我介绍 · 不暴露身份与公司业务方向 · 一条消息只干一件事**；
  **不要问「看简历就能看出来」的事**、**✂️ 不要复述候选人自己写过的信息**（「复旦微电子 + 两周内可到岗…」= 废话 + 机器味），
  直接**要简历**（刘杨 2026-09-19 当面纠正过，2026-09-23 **两次强调**）。
  → ⚠️ 旧文档里「开头点明 PI 身份」「不要一条只问一个问题」「引用对方原话」的说法**已作废**。详见 `MEMORY.md` §九 #11–#12。
- 每次动手前**先给计划**（要做什么、为什么），再执行。
- 汇报要**可核验**：给出文件路径、大小、校验结果、Boss 页面原文，而不要只说「已完成」。
- 主动暴露**风险、失败、误操作**，包括自己犯的错；不要粉饰、不要含糊。
- 不确定就**停下来问**，不要猜着往下做。
- 候选人的信息尽量保留**原始字段**（姓名、年龄、学校、岗位、期望城市、原话）。
