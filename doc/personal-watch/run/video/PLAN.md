- **`SCENES/`** = 逐镜脚本（`.md`，42 章全，2203 镜）——**是脚本不是图**。
- **`ASSETS/SHOT_SPECS/`** = T2I/I2V Prompt 规格（`.md`）——**27 章有，15 章缺**（缺：15/16/17/20/26/27/28/29/30/31/32/35/38/40/41）。
- **`OUTPUT/<章>/frames/`** = 实际生成的分镜帧图；`OUTPUT/<章>/videos/` = 视频片段。
- **MCP `comfyui-drama` 的 `project_root` = `E:\code\stem_fest`**（非短剧仓）⇒ 相对 `output_dir` 会落到 stem_fest 下；**目标短剧仓必须传绝对路径**（`D:\...\short_drama\OUTPUT\...`）。
- 短剧仓历史路径为 `E:\code\...`，现已迁至 `D:\Users\Administrator\code\...`（所有 EP13 脚本硬编码旧路径，需修）。
- 体积红线：**≥5MB 不入库**（`OUTPUT/` 整体 .gitignore；视频/音频/大图靠 `manifest.json` 间接入库）。
- 角色一致性：人物镜头用 `image_edit_longcat`（定妆照为输入）；非人物镜头用 `z_image_turbo_t2i`；视频首选 `video_minimax_h3_i2v`（16GB 下 megapixels ≤ 0.6）。
- 🚫 **禁用 TTS（2026-10-11 用户令）**：**人物对话全部由 MiniMax H3 随视频一起生成**（写进 prompt 的 `Audio:`）；⛔ `qwen3_tts`/任何 TTS 不用，合成时**不再叠人声**。
- ⚠️ **验收式陈述纪律（2026-10-12 教训）**：写「已产出」前必须核验**路径 + 字节**；`OUTPUT/` 整体 .gitignore，二进制产出**不会**随 git 跨机存活，故「帧/视频已生成」必须落到 `.gitignore` 之外或 `manifest.json` 间接入库，且以落盘核验为准。
