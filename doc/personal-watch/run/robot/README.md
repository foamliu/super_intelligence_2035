## 一句话目标

让手机成为"看得见、听得懂、说得出"的家教入口：拍题 -> 识别 -> 分步引导（**不代写**）-> 语音讲解 -> 错题本/学情画像。

## 四条红线（写在最前面，避免跑偏）

1. **不代写作业**：只给分步引导，最终答案默认不直接给出。
2. **不采集真实学生隐私**：评测一律用自造/公开题；原始照片不出设备（必须上传则脱敏）。
3. **不擅自采购硬件 / 不注册账号 / 不买 API**。
4. **不碰 ComfyUI 与旧视频流水线**（已冻结，`video/` 资产不得删除）。

## 第一轮验收（用户可据此判断进度）

- `P0_设备通路.md` 有**真实命令 + 真实输出**（不是计划）；
- 选定一条技术路线并说明理由与被否路线的原因；
- 最小 demo：给一张题图 -> 输出一段**不含最终答案**的分步引导 + 语音（可先 PC 端 mock）；
- "需要用户做的事" 压成 <=5 条，能一次性照做。
