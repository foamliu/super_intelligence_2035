## 2. 下载方法（本轮实测口径，纠正上一轮错误）

- **不用 curl**：PowerShell 的 `curl` 别名会把进度写 stderr → 被当成 `NativeCommandError`，是上一轮误删好文件的根因。
- **不用代理（172.19.92.25:13128）**：本轮实测代理经 curl 直接 `http=000` 超时；经 `Invoke-WebRequest` 也只有 ~60KB/s。
- **直连更快**：`curl.exe --max-time 12 -o NUL -w` 实测直连 `138944 B/s`（≈136KB/s）且 `http=200`。
- **用 `Invoke-WebRequest -UseBasicParsing` + 直连 + 独立后台进程**（每条 shell 命令有 30s 超时，大文件必须放到 `Start-Process` 独立进程，否则被 30s 杀掉）。

下载脚本：`C:\Android\dl_all.ps1`（platform-tools → cmdline-tools → JDK17 顺序下载，直连）。

```powershell
$ProgressPreference='SilentlyContinue'
Invoke-WebRequest -Uri 'https://dl.google.com/android/repository/platform-tools-latest-windows.zip' -OutFile 'C:\Android\platform-tools.zip' -UseBasicParsing
```

### 6.1 踩坑记录（本轮新增）

1. **30s 命令超时**：交互 shell 单命令 >30s 被杀 → 大任务（gradle/emulator/server）一律 `Start-Process` 后台 + 轮询。
2. **stderr 误报 NativeCommandError**：`adb push`/`adb pull` 进度写 stderr 被 PowerShell 当异常 → 用 `2>&1 | Out-Null` 或 `Out-String` 包裹。
3. **系统代理 `127.0.0.1:7897` 对 Gradle 拉依赖卡死** → 构建前清空 `HTTP_PROXY`/`HTTPS_PROXY`（直连 `dl.google.com`/`maven` 可达）。
4. **`cmd media scan` 报 `Can't find service: media`** → 改用 `am broadcast MEDIA_SCANNER_SCAN_FILE` 让推入的题图进 MediaStore（`content query` 确认 `q2_geometry.png` 在册）。
5. **uiautomator 中文 mojibake** → 解析时用 `[System.IO.File]::ReadAllText(path, UTF8)`。
