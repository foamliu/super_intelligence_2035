## 分步 rubric 示例（q1）

1. 先问：这道题要求的是未知数 x，你打算怎么把含 x 的项和常数分开？
2. 提示：等式两边同时减去 3，得到什么？
3. 学生写：2x = 8
4. 提示：等式两边同时除以 2，得到 x = ?
5. 校验：学生答 x = 4 则通过，进入下一题。
