## 2. 邮件口径（学术请教信）

- **语言**：**默认英文**；🈶 **若作者是中国人 ⇒ 用中文**（判据：**中文姓名** / **中国大陆·港澳台机构** / **主页或论文挂中国机构**；**不确定时按英文**）。**简短礼貌**：英文 **≤200 词** / 中文 **≤300 字**。
- **四段式**：
  1. 一句自我介绍（**《超级智能2035》/ BaiZe-ISEDA2027 & ZhuLong-DAC2027 项目 + 署名**；署名口径同 recruit）。
  2. **为什么读你这篇**（点出与 BaiZe / ZhuLong 的关系）。
  3. **2–3 个具体问题**（**技术细节**，须**能回填研发决策**；逐条写明「答复会改进 BaiZe / ZhuLong 的哪一步」）。
  4. 致谢 + 签名。
- **问题质量（硬）**：🚫 不问摘要里已有的内容；🚫 不问泛泛的「能否分享代码」（除非确需）；须**具体到方法 / 超参 / 失败模式 / 复现细节**。
- **草稿先落盘（入 git，供监督）**：`doc/personal-watch/run/research/mail/drafts/<arXiv_ID>.md`。

---

## 3. 频率上限（硬）

- **每轮（每个 06:00 / 18:00 时窗）≤ 3 封**。
- **同一作者 / 同一论文 ≤ 1 封**；**同一机构 ≤ 2 封/天**。
- 🚫 **不群发 / 不用模板群拷贝**（**一信一作者**，正文须因论文而异）。
- 🚫 **不催**（未回信不发第二封，除非对方回复）。

- 不冒充他人身份 · 不群发 · **不发大附件**（≤5MB）。
