1. **读现状**：`MEMORY_ARCHIVE.md` 顶部 + 已有 `archive/ENDPOINTS.md` / `COUNT_STUDY.md`（**增量推进，不重做**）。

7. **提交**：`git add` 只加本线文件（`MEMORY_ARCHIVE.md` `archive/` `daily-memories-archive/`）→ commit → push。

## 4. 铁律（红线）

1. 🚫 **不许编造**：端点/数字**必须来自真实请求**；**贴 HTTP 码 + 响应片段**。403/WAF **如实记录**，🚫 **不要绕**（不搞代理/伪造 UA 绕过封锁）。
2. 🚫 **不许把抽样估数当精确值**：必须写"抽样 + 样本天数 + 区间"。
3. 🚫 **`200 ≠ 有料`**：拿到 HTML/WAF 页**不等于**可枚举 → **必须验"能解析出条目 + 日期"**。
4. ⏱ **限速**：**同站 ≥2 秒/请求**，单轮请求数受控，**不并发**。
5. 🚫 **不整篇转载**：归档只存 **标题 + 日期 + 来源 + 链接**（+可选摘要 ≤2 句自写）；**不存正文全文**（版权）。
6. 🚫 **不 `git add -A`**；🚫 **不在正文/快照/流水写以 `WAITING:` 开头的行**。
7. ⚠️ **A3 全量抓取前必须经 supervisor 批准**（先算代价：条数 × 限速）。
