## 2. 前提条件

### 2.1 本机环境

- Windows 10/11 自带 OpenSSH（路径：`C:\Windows\System32\OpenSSH\ssh.exe`）
- PowerShell 或 cmd
- Python 3.x + paramiko（仅首次部署密钥时需要）

检查方式：

```powershell
ssh -V
python -c "import paramiko; print('ok')"
```

### 2.2 本机 SSH 密钥

如果还没有密钥，先生成：

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\id_ed25519" -N '""'
```

## 3. 首次部署：将本机公钥部署到各节点

需要在 **每台服务器** 上部署本机的公钥，实现无密码登录。

### 3.1 方法 A：使用 Python 脚本一键部署

```powershell
python -c "
import paramiko, os

key_path = os.path.expanduser('~/.ssh/id_ed25519.pub')
with open(key_path) as f:
    pubkey = f.read().strip()

servers = [
    ('10.251.36.15', 'Cxmt@20260909'),
    ('10.239.2.12',  'Ly3960405#'),
    ('10.239.2.29',  'Ly3960405#'),
]

for host, pwd in servers:
    print(f'>>> {host} ...', end=' ')
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    try:
        client.connect(hostname=host, username='app.e0031982', password=pwd, timeout=15)
        client.exec_command('mkdir -p ~/.ssh && chmod 700 ~/.ssh')
        _, stdout, _ = client.exec_command('cat ~/.ssh/authorized_keys 2>/dev/null')
        if pubkey in stdout.read().decode():
            print('[已存在]')
        else:
            cmd = \"echo '\" + pubkey + \"' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys\"
            client.exec_command(cmd)
            print('[已部署]')
        client.close()
    except Exception as e:
        print(f'[失败] {e}')
"
```

### 3.2 方法 B：逐一手动部署

```powershell

```

## 4. 建立 SSH 隧道

### 4.1 隧道 ①：让 36.15 ⇄ 2.12（经本机中转）

**作用：** 36.15 上执行 `ssh -p 2222 localhost` → 连接到 2.12

```powershell
# 直接命令行方式
ssh -N `
  -o ServerAliveInterval=30 `
  -o ServerAliveCountMax=3 `
  -o StrictHostKeyChecking=accept-new `
  -R 2222:10.239.2.12:22 `       # 36.15:2222 → 本机 → 2.12:22
  -L 172.19.195.133:2224:10.251.36.15:22 `  # 本机:2224 → 36.15:22（可选）
  app.e0031982@10.251.36.15

# 或使用 SSH Config 别名
ssh -N tunnel-251
```

**参数说明：**

| 参数 | 含义 |
|------|------|
| `-R 2222:10.239.2.12:22` | **远程转发**：让 36.15 的 2222 端口映射到 2.12 的 22 端口 |
| `-L 172.19.195.133:2224:10.251.36.15:22` | **本地转发**：让本机 2224 端口映射到 36.15 的 22 端口（可选） |
| `ServerAliveInterval 30` | 每 30 秒发送心跳包防止断开 |
| `ServerAliveCountMax 3` | 连续 3 次心跳无响应则断开 |

### 4.2 隧道 ②：让 2.29 → 36.15（经本机中转）

**作用：** 2.29 上执行 `ssh -p 3333 localhost` → 连接到 36.15

```powershell
# 直接命令行方式
ssh -N `
  -o ServerAliveInterval=30 `
  -o ServerAliveCountMax=3 `
  -o StrictHostKeyChecking=accept-new `
  -R 3333:10.251.36.15:22 `      # 2.29:3333 → 本机 → 36.15:22
  app.e0031982@10.239.2.29

# 或使用 SSH Config 别名
ssh -N tunnel-229
```

### 4.3 核心原理说明

两条隧道都使用 **SSH 远程端口转发（-R）** ：

```
SSH -R [远程端口]:[目标主机]:[目标端口] [SSH服务器]

 远程转发：
 ┌──────────┐    SSH 隧道     ┌──────────┐
 │ 远端服务器 │ ◄────────────── │  本机    │ ◄──── 目标机器
 │ :2222    │                 │          │      :22
 └──────────┘                 └──────────┘
  用户 ssh -p 2222 localhost
```

本机作为 SSH 客户端主动连接各台服务器，服务器通过已建立的 SSH 连接将端口的流量反向转发回来，再由本机转发到最终目标。

## 5. SSH Config（持久化配置）

写入 `~/.ssh/config`，方便用别名启动隧道：

```
# ── 单机快捷登录 ──

Host 10.251.36.15
  HostName 10.251.36.15
  User app.e0031982
  ForwardAgent yes
  IdentityFile ~/.ssh/id_ed25519

Host 10.239.2.29
  HostName 10.239.2.29
  User app.e0031982
  ForwardAgent yes
  IdentityFile ~/.ssh/id_ed25519

Host 10.239.2.12
  HostName 10.239.2.12
  User app.e0031982
  ForwardAgent yes
  IdentityFile ~/.ssh/id_ed25519

# ── 隧道别名 ──

Host tunnel-251
  HostName 10.251.36.15
  User app.e0031982
  IdentityFile ~/.ssh/id_ed25519
  RemoteForward 2222 10.239.2.12:22     # 隧道①：36.15 → 2.12
  LocalForward 172.19.195.133:2224 10.251.36.15:22  # 可选：外部→36.15
  ExitOnForwardFailure yes
  ServerAliveInterval 30
  ServerAliveCountMax 3

Host tunnel-229
  HostName 10.239.2.29
  User app.e0031982
  IdentityFile ~/.ssh/id_ed25519
  RemoteForward 3333 10.251.36.15:22    # 隧道②：2.29 → 36.15
  ExitOnForwardFailure yes
  ServerAliveInterval 30
  ServerAliveCountMax 3
```

配置完成后，只需执行：

```powershell
ssh -N tunnel-251   # 启动 36.15 方向隧道
ssh -N tunnel-229   # 启动 2.29 方向隧道
```

## 7. 自动化与保活

### 7.1 阻止 Windows 睡眠（隧道断开预防）

**方案 A：修改电源设置（管理员）**
```powershell
powercfg /CHANGE standby-timeout-ac 0
powercfg /CHANGE standby-timeout-dc 0
powercfg /CHANGE hibernate-timeout-ac 0
powercfg /CHANGE hibernate-timeout-dc 0
```

**方案 B：Python 保活脚本（推荐，无需管理员）**
```python
# keep-awake.py
import ctypes, time
ES_CONTINUOUS, ES_SYSTEM, ES_DISPLAY = 0x80000000, 0x1, 0x2
ctypes.windll.kernel32.SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM | ES_DISPLAY)
try:
    while True:
        time.sleep(60)
        ctypes.windll.kernel32.SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM | ES_DISPLAY)
except KeyboardInterrupt:
    ctypes.windll.kernel32.SetThreadExecutionState(ES_CONTINUOUS)
```

后台运行：`pythonw keep-awake.py`

### 7.2 开机自启（任务计划程序）

| 设置 | 值 |
|------|-----|
| 触发器 | 启动时，延迟 30 秒 |
| 操作 | `C:\Windows\System32\OpenSSH\ssh.exe`，参数 `-N tunnel-251` |
| 用户 | 当前用户，勾选"用户登录时运行"和"最高权限" |
| 重复 | 每 10 分钟，持续时间无限（失败后恢复） |

### 7.3 快速启动/停止脚本

**start-tunnels.ps1：**

```powershell
$ErrorActionPreference = "SilentlyContinue"

# 清理旧进程
Get-Process -Name ssh -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Sleep -Seconds 1

# 启动隧道①（36.15 → 2.12 + 本地 2224 转发）
$p1 = Start-Process -PassThru -FilePath "C:\Windows\System32\OpenSSH\ssh.exe" -ArgumentList @(
  "-N", "-o", "ServerAliveInterval=30", "-o", "ServerAliveCountMax=3",
  "-o", "StrictHostKeyChecking=accept-new",
  "-R", "2222:10.239.2.12:22",
  "-L", "172.19.195.133:2224:10.251.36.15:22",
  "app.e0031982@10.251.36.15"
)

# 启动隧道②（2.29 → 36.15）
$p2 = Start-Process -PassThru -FilePath "C:\Windows\System32\OpenSSH\ssh.exe" -ArgumentList @(
  "-N", "-o", "ServerAliveInterval=30", "-o", "ServerAliveCountMax=3",
  "-o", "StrictHostKeyChecking=accept-new",
  "-R", "3333:10.251.36.15:22",
  "app.e0031982@10.239.2.29"
)

Write-Host "[$(Get-Date -Format HH:mm:ss)] 隧道已启动:"
Write-Host "  ① 36.15 ⇄ 2.12   PID: $($p1.Id)"
Write-Host "  ② 2.29  → 36.15  PID: $($p2.Id)"
```

**stop-tunnels.ps1：**

```powershell
Get-Process -Name ssh -ErrorAction SilentlyContinue | Stop-Process -Force
Write-Host "所有 SSH 隧道已停止。"
```

## 8. 排障指南

| 问题 | 可能原因 | 解决办法 |
|------|---------|---------|
| `Permission denied` | 公钥未部署或权限不对 | 检查 `~/.ssh/authorized_keys` 权限（应为 `600`），重新部署 |
| `port xxx already in use` | 端口被占用 | 换端口或在服务器上 `fuser -k xxx/tcp` |
| `Connection timed out` | 防火墙或网络不通 | 检查基本连通性：`ping` / `Test-NetConnection` |
| `Remote port forwarding failed` | 远程端口已被占用 | 换一个端口（如 2223 / 3334） |
| 隧道频繁断开 | 无心跳保活 | 添加 `ServerAliveInterval 30` / `ServerAliveCountMax 3` |
| SSH 进程意外退出 | 本机睡眠或网络中断 | 使用保活脚本 + 任务计划自动重启 |

### 检查命令

```powershell
# 检查 SSH 进程
Get-Process -Name ssh

# 检查端口监听
netstat -an | Select-String "2222|2224|3333"

# 检查 36.15 上 2222 端口
ssh 10.251.36.15 "ss -tlnp | grep 2222"

# 检查 2.29 上 3333 端口
ssh 10.239.2.29 "ss -tlnp | grep 3333"
```

## 9. 安全建议

1. **私钥权限**：`~\.ssh\id_ed25519` 保持 `600`，建议添加 passphrase
2. **远程转发绑定**：`-R` 默认只绑定 `127.0.0.1`，不暴露到外网
3. **定期换钥**：每 3~6 个月更换一次 SSH 密钥
4. **审计日志**：`last -10` 查看登录记录
5. **最小权限**：使用应用级账号（`app.e0031982`）而非 root
