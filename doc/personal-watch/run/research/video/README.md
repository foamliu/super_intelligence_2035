# research/video/ — 《两分钟论文》科普视频 · 目录契约

> **谁写**：research agent。**谁读**：supervisor、用户。
> **用途**：**目的 2** —— 找有潜力的论文做**两分钟中文科普视频**，发 **B站 / 抖音**，涨粉（日后收益）。

## 1. 放什么

| 文件 | 内容 |
|:--|:--|
| `SHORTLIST.md` | **选题表**（10–20 条）：`论文 · 一句话看点 · 为什么大众会看 · 预估难度(易/中/难) · 建议平台 · 备注` |
| `scripts/<arXiv_ID>.md` | **两分钟口播稿**（对 TOP-3 选题各一份） |
| （后续）`assets/` · 成片 | 画面/配音/成片 —— **大文件不入 git**（>20 MB 走外部目录并记清单） |

## 2. 命名规范

- 口播稿：`scripts/<arXiv_ID>.md`（如 `scripts/2609.09133.md`）——**与论文 ID 严格对应**；
- 选题表固定名 `SHORTLIST.md`。

## 3. 口播稿规范（**固定结构**）

- **长度**：中文 **350–450 字 ≈ 2 分钟**（语速 180–200 字/分）；
- **结构**：`钩子(0–10s) → 问题(10–30s) → 方法(30–80s) → 结果(80–105s) → 意义/展望(105–120s)`；
- **须含**：论文标题 + 作者/机构 + **arXiv 链接**（口播里提一句"链接放简介"）；
- **须含**：**分镜提示**（每段建议画面）。

## 4. 红线（🚫 违反即退回）

1. 🚫 **不盗用论文原图** —— 画面**自绘/自生成**；引用观点要**标明出处**。
2. 🚫 **不夸大**：说「SOTA / 颠覆 / 突破」**必须有出处**；不编造数据。
3. ✅ **必须标明是"论文解读"**；**必须给 arXiv 链接**。
4. 🚫 **不许为了话题性曲解论文**（筛选口径 = **大众能懂 + 有传播力**，但**不能牺牲准确**）。
5. 📦 **大文件不入 git**；只入 git 的应是**文本（md）与小图**。
6. ⚠️ **《两分钟论文》是已有知名频道名** → 建议**起自己的栏目名**（避免品牌混淆）。
7. ✅ 平台发布由**用户本人**执行（账号/实名/平台规则在用户侧）。
