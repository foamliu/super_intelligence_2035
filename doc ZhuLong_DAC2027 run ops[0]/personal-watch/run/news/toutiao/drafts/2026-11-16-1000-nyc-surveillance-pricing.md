同一杯咖啡，为什么你付的钱比别人多三十块？这事纽约市议会刚刚立了规矩。

十一点十二日，纽约市议会通过一项法案，编号 Introduction 891-A，禁止企业用消费者的个人数据和算法，对相同的商品或服务收不同的价钱。

议会的说法很直接，这叫监控式定价。算法会分析你的购物记录、你在哪、你是什么人，判断你最多愿意掏多少，再按这个数报价。

整个过程都在后台跑。你看到的那个价格，其实是为你看的那一眼定的。

议会公告里举了几个调查案例。一家大型生鲜配送平台做过算法定价实验，部分商品对不同消费者的报价差异最高到了百分之二十三。

还有一家零售商，同一台电视，顾客开进停车场之前标价四百九十九点九九美元，开进去之后就变成五百九十九点九九美元。

更扎心的是另一个说法。一名曾在大型网约车企业工作的行为经济学家披露，应用可能把用户手机电量低当成调价的参考，专挑你着急回家的那一刻。

新规适用于纽约市五个行政区。违规企业每项行为最高罚一千美元，折合六千六百九十元人民币，而且可以按不同消费者分别计算。

也就是说，要真按人头罚下去，那张单子会很长。

法案也没有一刀切。会员奖励、学生优惠、退伍军人优惠、季节性促销、优惠券、买一赠一，这些照旧可以做。

企业也可以根据你主动加入的会员计划、公开披露的优惠资格，给你特定的折扣。

不允许的是另一件事：把这些公开信息和你别的数据混在一起，拼出一个只对你一个人的基准价。

法案还要求企业建立披露程序，让消费者能申请了解，企业定价时到底用了你哪些个人信息。

这条比罚款更硬。罚一千美元对一家平台来说是零头，但被要求说清楚自己用了什么数据，事情就藏不住了。

我的一点看法：过去二十年，定价这件事从看商品变成了看人。

货架上贴的标签是固定的，同一个柜台对所有人都一样，这是零售业最基本的信用。

现在标签还在，但每个人都看到了不一样的那一张。

问题不在于差异化本身。航空公司早就按提前多久订票定不同的价，这是公开规则，你也知道规则。

问题在于，你不知道自己是在什么位置上被定价的。

一个不愿让你看见的算法，本质上是在剥夺你议价的前提。

所以这个法案真正有用的地方，可能不是那一千美元，而是那句「你得说清楚用了什么数据」。

话说回来，罚一千美元确实太轻了。对一家年营收几百亿的公司，这连提醒都算不上。

真正能让企业收敛的，大概是两件事：披露，以及被披露之后的舆论。

还有一个更现实的问题。纽约市做到这一步，别的城市呢。

你在网上买东西，有没有明显感觉过同一样东西，自己看到的价跟别人看到的价不一样？
