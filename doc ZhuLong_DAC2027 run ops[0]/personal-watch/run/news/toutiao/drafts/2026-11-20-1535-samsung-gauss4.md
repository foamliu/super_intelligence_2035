# 三星自己的 AI，可能就快在手机里跑起来了

手机里的 AI，可能正在悄悄换一颗「心脏」。而且这次的心，是三星自己的。

11 月 19 日，科技媒体 SammyGuru 在 One UI 9.5 的第一个 Beta 版里翻到了踪迹：一个叫 Gauss 4 E2B 的模型名字，出现在两个地方。

一个是支撑 AI 智能体功能的 Personal Agent Core，另一个是三星新做的 Memory 应用。

翻出来的不止一个新名字。内部模型列表里还列着 Gauss 3.8 3B、GaussA 26B-A4B，GaussA 30B 的多个历史版本也留着记录。

这说明至少在首尔，三星的模型流水线是一直在转的，不是临时试水。

更值得注意的是 Memory 应用里的一个细节。

它不光列了 Gauss 4 E2B，还会去检查设备上有没有 Gauss 模型的本地文件。

这一条很关键。检查本地文件，意味着它在等一个能装进手机里的版本。

隐藏设置里，这个模型和谷歌的 Gemini Nano、Gemma 被并列放在一起，暗示三星可能正在测试让它直接在手机上运行。

换句话说，Gauss 4 的野心不在云端，在口袋里。

这条路谷歌已经先走了一段。Gemini Nano 就是拿来做端侧小模型的那一个，现在三星把自己家的 Gauss 4 E2B 放到同一个架子上，意思很清楚：端侧这一格，不想一直靠别人。

为什么这事值得说？因为过去两年，手机上的 AI 功能大多是「借来的」。

你把一句话丢给云端，等几百毫秒，答案回来。网络好的时候感觉很快，进了电梯、上了高铁、到了地下室，就变成转圈。

厂商当然知道这件事。所以过去一年，几乎所有旗舰都在讲同一句话：把 AI 搬回设备里。

搬不搬得动，取决于两件事：模型够不够小，芯片够不够省电。

三星手里这两张牌其实都有。它有自家的 Exynos 芯片，也有从手机到家电一整套硬件；现在缺的那张，是一个又小又能干的自研模型。Gauss 4 E2B 这个名字里的 E2B，通常指的就是一个小体量的端侧规格。

如果它真能落到 One UI 上，变化会出现在很细的地方。

比如相册里找一张三年前的截图，不用等联网；比如通话记录整理、通知归纳这些一天要做十几次的小活，可能就在本地跑完；比如飞机上没信号，那些功能也不至于全瘫。

这些都不算惊天动地，但它们决定了一件事：AI 到底是功能表上的一行字，还是你每天真在用的东西。

当然，现在还不能下结论。

代码里出现一个模型名，离用户能用上它，中间隔着测试、适配、功耗评估，还有一整套产品决策。历史上被内部砍掉的模型也不少。

而且三星在端侧上也不是从零起步，它之前的 Gauss 系列已经用在手机的部分功能里，这次更像是版本换代。

真正值得盯的信号有两个：一是 Personal Agent Core 这个组件什么时候出现在正式版系统里；二是有没有机型明确标注「本地运行」。

说白了，判断一款手机 AI 好不好用，别只听发布会说了多少参数，看它断网之后还能做多少事。
