## 正文（段落原文）

1. 通义千问团队今天正式发布 Qwen4-Max，主干参数 2.4 万亿，原生支持视觉理解，上下文窗口 100 万 Token。
2. 值得注意的是，11 月 11 日先行开放的只是一个限时预览版。今天是正式版，接入千问平台，开发者可以通过 Token Plan 或 API 调用。
3. 官方这次给的重点不在「更聪明」，在「更便宜」。同等性能下，Xhigh 和 High 两档推理强度消耗的 token，分别比前代减少约 24% 和 35%。
4. 在 Terminal-Bench 4.0 上，这个降幅到了约 48% 和 49%。
5. 评测数字也摆出来了。Work360 行业基准 52.69 分，前代 Qwen3.8-Max 是 47.74 分。
6. 更直观的是钱：Work360 评测里单个任务的平均费用，从 26.58 元降到 11.16 元，降幅 58%。
7. 这个 Work360 是团队自己搭的评测框架，覆盖 26 个一级领域、182 个二级子领域、721 个三级专业方向。
8. 给自己的模型搭评测集，这事一直有争议。但至少它把「按任务算账」这件事摆到了台面上。
9. 智能体场景里，官方引入了 Live Delivery 机制：先交一个能用的首版，再按反馈一版版扩内容。
10. 插件也开源了，叫 Qwen-Live-Delivery-Plugin。
11. 官方展示的案例跨得很远：Blender 三维建模、Unity 和 Unreal 引擎游戏开发、汽车产线规划与零件加工编程，还有金融投研、法律尽调、危重症临床辅助。
12. 其中最具体的一个：汽车零件加工，单个工件编程的人工投入从约 475 分钟，降到 24 分钟。
13. 这个数字来自厂商的演示案例，本号没有复现，也没有拿到完整评测条件。
14. 换个角度看，19 倍左右的提速，如果有一半能落到真实产线上，就已经很可观了。
15. 但「一半能落地」这个前提，恰恰是最难验证的。
16. 模型越能干，越容易让人把验证这一步省掉。省掉的那一步，往往就是代价所在。
17. 另一个方向也值得留意：Qwen4-Max 是 Qwen4 系列第一款，官方说小尺寸模型将陆续开源，沿用同源技术路线。
18. 大模型负责探路，小模型负责铺开，这条路径今年被反复验证。
19. 对普通用户来说，模型降价最直接的影响不是能力，是你每天能免费问几次。
20. 省钱这件事，最后会变成大家的日常体验。
21. 至于 2.4 万亿参数到底强在哪里，等真实任务上的第三方复测更靠谱。
22. 数据来源：IT之家 11 月 16 日报道，以上性能与费用数字均为通义千问官方公布口径。
