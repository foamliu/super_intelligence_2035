自动驾驶最贵的一段路，被监管先关上了

一台无人驾驶出租车想超过一辆正在疏导交通的警车，这件事最后把整条高速公路的运营资格都停掉了。

加州车辆管理局这次的做法很直接：禁止 Waymo 的无人驾驶出租车在加州高速公路上运营，理由是对公共安全构成迫在眉睫的威胁。这句话在监管文件里属于很重的措辞，一般不会随便用。

它列出来的几件事，都不是撞车。伯灵格姆附近，三辆 Waymo 开进了受限制的施工区域；还有一辆试图超过一列正在疏导交通的公路巡警车辆；此外无人车多次尝试穿过高速公路上的施工区。

回头看时间线，会发现这已经是第三回合了。今年五月，Waymo 自己主动暂停了高速公路服务；六月召回三千八百辆车；七月重新获准上高速。四个月之后，同样的问题又出现了，而且不是同一类误差。

Waymo 的回应挺克制，说安全是一切工作的根基，已经遵守限制，同时把其他运营区域的高速服务也暂时停了，用来评估自己的表现。把范围从一个州扩到所有区域，这个动作说明公司自己也不确定问题边界在哪。

我觉得这里值得说的不是它犯错，而是它犯错的类型。

一个自动驾驶系统在路上要处理两件事：一是看清有什么，二是判断该不该让。前者靠感知，后者靠规则。三辆车开进封闭施工区，是「该不该进」的判断出了问题；想去超一辆亮着灯的警车，则是「谁优先」的判断出了问题。这两件事恰好都不是算力不够、传感器不够的问题，而是它对人写在路面上的那些临时约定理解得不够。

施工区的锥桶、警示灯、巡警的手势，都是临时的、当场的、没有写进地图的规则。人类司机靠眼睛和常识判断，很多情况下甚至不判断，看到穿反光背心的人就先减速。这类知识很难被整齐地做成训练样本，因为它每天都不一样。

这也是为什么监管的刀落得比事故早。真要等到出事再来管，代价就不是暂停运营了。

对行业来说，这一刀的意义不小。无人驾驶最值钱的故事一直是规模化，而规模化的前提是能在各种路况下运营。高速公路是效率最高的一段路，也是规则最不固定的一段路。今天被叫停的是 Waymo，明天要复盘的会是所有打算跑高速的玩家。

我更好奇的其实是另一件事：下一次它重新拿到许可的时候，靠的是补足了多少公里的测试数据，还是学会了一件更朴素的事，看到前面有警灯就慢下来。

你觉得无人车应该先学会守地图上的规则，还是先学会看现场的人？
