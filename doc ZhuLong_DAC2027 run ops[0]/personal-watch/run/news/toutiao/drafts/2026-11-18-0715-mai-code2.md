微软这次发的不是一个更聪明的模型，是一个更便宜的模型。

十一月十八号，Ignite 2026 大会上，微软把自研的编程模型 MAI Code 2 和 MAI Code 2 Flash 一起推了出来，直接上到 GitHub Copilot 里。发布稿里最扎眼的不是跑分，是单价：Code 2 平均单次任务成本 0.309 美元。

这个数字要跟谁比呢。微软自己给的对照是，GPT-6.1 Sol 是 0.761 美元，Claude Opus 5.5 是 6.306 美元。也就是说，Code 2 跑一次活儿，花的是 Opus 5.5 的不到二十分之一。

性能上，微软说在他们公布的四项编程基准的平均结果里，Code 2 拿到 GPT-6.1 Sol 大约 98% 的表现，价格是它的 40%。轻一点的那款 Flash 更狠，百分之五十的促销价下单次任务成本压到 0.052 美元；在 DeepSWE 1.1、Terminal-Bench 2.1 和 SWE Atlas 三项测试里，Flash 的平均通过率是 61.0%，对面的 GPT-6 Luna 是 55.1%，Claude Haiku 5.5 是 53.9%。

这里得说清楚，以上全是微软自报的口径，没有第三方复测。厂商发布会上的对照表，选哪几项基准、怎么取平均，本身就是一道选择题。

但我觉得这篇公告真正值得琢磨的地方，不在数字高低，在于它把「便宜」摆到了台面正中央。

过去两年，模型发布会的主角是能力：参数更大、榜单更高、上下文更长。今年这一轮开始变味了，价格下降的比例被念得比分数还响。有意思的是，同一天前后，另几家也在做同一件事——OpenAI 发了 GPT-6.2 的两款模型，主打降低输出 Token 数；快手的可灵把图像模型做到了原生 8K、单图两千字；微软自家的图像模型 MAI Image 2.7 登顶，强调的也是成本约为对手的五分之一。

这其实是一个很朴素的市场信号：当各家能力咬得差不多的时候，买家开始按账单投票。企业不是不想用最好的模型，是不能在每一行代码上都用最贵的那个。所以微软这次特意把产品切成两档——Code 2 干复杂的活，Flash 干解释代码、定点修改、快速迭代这种高频轻活，Flash 还覆盖 Free 和 Student 用户。

这个切法很像现实里的工程团队：资深的工程师不拿去改拼写错误。模型公司现在在学一件事，怎么让调用方也这么分工。

不过便宜是真的便宜，好用不好用是另一回事。单次任务成本和「一次就把活干对」的概率是两码事，前者可以标价，后者只能累计。一个模型如果便宜四成，但要多跑两遍才成，账就算不平。

所以我更好奇的其实是接下来几个月的真实使用数据：不是发布那天的榜单，是开发者用脚投票之后，Code 2 和 Flash 的分工比例会走到哪一步。

你觉得编程模型的价格还会再掉一个数量级吗？
