何老师您好：

我是刘杨，做 LLM agent 与后训练研究，主页 https://foamliu.github.io/。我们在 2B 级模型上做多轮工具调用 RL，最近被「同一轨迹展开成多行后长失败轨迹被隐式加权」卡住，读到 OMA 很解渴。

想请教三点。第一，Outcome Alignment 与 Mass Alignment 的消融里哪项贡献更大？在 ALFWorld「失败打满 50 轮、成功提前结束」的设置下，我猜结果去重更关键；若把最大轮数从 50 降低，排序会反转吗？

第二，普通 WebShop 你们报告 mixed or reversed，WebShop-SOL 上端点 0.648→0.734、nAUC 0.399→0.511。端点和 nAUC 给出相反信号时该按哪个选？有没有开训前就能判断「展开-结果耦合强度」的诊断量，比如失败与成功轨迹的平均展开行数比？

第三，1.5B / 3B 上增益 7–9 个百分点，降到 0.5B 以下、或 group size 更小（如 4）时还在吗？我们主跑 2B，但消融常在小模型上做，需要知道能否外推。

这三点会落到我们的多轮 RL 记账、阶段评估点与消融设计上。感谢您的时间。

祝好，
Yang Liu
