口径修正（诚实性）：前序 wake#1684 以「post-GRPO 0.8667 = +26.67pp」作为 GRPO 成果头条。经核对，该 +26.67pp 是相对 base 模型(0.60) 的「整条 SFT+RFT+GRPO 链路」增益，并非 GRPO 自身增益。GRPO 的冷启动 adapter 是 RFT2(0.90)，post-GRPO 为 0.867，GRPO 真实增益 = −3.3pp（McNemar b=2 c=1 p=1.0，不显著）。误判成因：smoke 用 init_adapter=null（fresh LoRA from base）跑出 0.60，被误记为「post-SFT/rft2-init 基线」——它其实是 base 模型分数。本报告以真正的冷启动基线(RFT2=0.90)为 GRPO 对照。

3. 预注册判据与诚实结论

判据（用户令 step d）：对比 pre-SFT / post-SFT / post-GRPO 的波形图理解通过率；GRPO 是否相对其冷启动提升通过率。
结论：
  • Stage-1W（SFT→RFT）是增益来源：base 60% → RFT2 90%（+30pp；既有 v2-RFT McNemar b=7 c=0 p=0.0156，预注册显著）。
  • Stage-2W（GRPO）未提升：post-GRPO 86.7% vs 冷启动 RFT2 90% = −3.3pp，McNemar b=2 c=1 p=1.0（不显著）。属负结果，如实记录。
  • 技能层面：duty_cycle 0.8→1.0（改善），但 amplitude_read 0.6→0.2（回归），其余持平，净 27→26。
  • 「+26.67pp」是整条链路 vs base（base→post-GRPO McNemar b=2 c=10 p=0.039，显著），但不能归因于 GRPO。

7. GRPO 训练诊断（为何没有提升）

指标值解读
训练步数 / wall224 logged / 2765s（≈46min，GPU7）500 步目标完成
reward==1.0 的步数189/224（84%）奖励饱和：冷启动已在 0.90，多数 group 全对
loss>0 的步数2/224仅 2 步有梯度；其余 advantage=0→loss=0
reward 均值（首10 / 末10）0.952 / 0.801末段略降（个别难题）
末步 loss 异常-6.927单 group reward=0.125 离群，非趋势
根因：GRPO advantage=(R−mean)/(std+ε)；group 内 4 条 rollout 奖励全同（冷启动已会做→全对→全 1.0）时 std=0→adv=0→loss=0→无梯度。500 步仅 2 步有效更新，且把 amplitude_read 拉差了。即 GRPO 在「冷启动已近天花板」的合成题上几乎无操作。

8. 方法与配置

  • 模型：完整 Qwen3.5-2B MLLM（含视觉塔，不剥离）+ LoRA r=8 α=16 ≈ 5.46M trainable（0.246%）。
  • Stage-1W：SFT2（3 seed）→ RFT2（v2 加强管线 RFT，rft2_adapter_seed11，即 GRPO 冷启动）。
  • Stage-2W GRPO：lr=1e-05 · B=2 G=4 · ppo_epochs=1 · clip=0.2 · max_new_tokens=64 · temp=0.8 top_p=0.95 · seed=20261119 · train_seed=20261114（150 train case，6 技能×25）· GPU7 bf16。
  • 可验证奖励：synth_waveform_qa.reward_for（回归 exp(−rel_err/τ) / 分类二值）。
  • 评测集：合成波形图 held-out n=30（vision/vqa_tool/eval_images/q0..q29.png，eval_seed=20261115）。

9. 改进建议（下一步）

  • 留出头空间：GRPO 从 base 或 SFT（而非已 0.90 的 RFT2）冷启动，让 RL 有可学余量。
  • 奖励分解：连续值奖励拆「区间内 vs 越界」，β>α（research 日报 2026-11-19 建议），减少全对饱和。
  • 更难/长尾训练题：加入噪声、多通道、非整数周期等，提高 group 内奖励方差。
  • 增大多样性：提高 temperature / 增大 group_size，避免 4 条 rollout 全同。
  • 真实 benchmark 复测：把 post-GRPO adapter 装入 :30003 → 重跑 EDA-Eval-DesignFlow-WaveView 子集 V2 臂（真实 EDA 题，非合成）。
