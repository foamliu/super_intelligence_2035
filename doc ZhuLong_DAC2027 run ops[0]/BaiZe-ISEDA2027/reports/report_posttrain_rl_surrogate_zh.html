4. 负结果归因

假设证据是否成立
训练没跑起来（infra/塌缩）grad_norm=1.65、84/200 步 posadv、reward 非 0否（与 R0 不同）
cheat/污染cheat=0/1600 绿否
ppo_epochs=1 使 clip 无效mean_ratio==1.0 为 ppo_epochs=1 结构性 logging artifact，不能作「policy 不动」证据待修（见下一步）
proxy reward 与任务正确性未对齐训练 reward ↑（0.053→0.111）但评测 Pass@1 ↓（3.04→0.48）是（主因）

5. 下一步（预注册）

  1. 修 PPO 配置：ppo_epochs≥2 + 冻结 old_logp（当前单 epoch 使 clip 比率恒为 1，PPO 实质退化为单次 REINFORCE）→ 再跑 200 步。
  2. 换奖励：sandbox-exec 奖励 → 更贴近 benchmark 的可验证奖励（如：生成代码 经 run_code 执行 + check 断言通过 才给分，而非仅「执行成功」）。
  3. 每轮单独测 5-run Pass@1（同 .17 口径 vs step105），预注册判据：Δ>0 且 bootstrap CI 下界>0 才算正向；否则继续诚实负结果。
  4. R2 须另在 zhulong 口径（36.15）重测，与 zhulong 基线 18.99% 比较（.17 口径与 36.15 口径不可比）。
