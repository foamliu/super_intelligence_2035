一句话目标：把 2B 基模在 EDA 脚本任务上的通过率，用 SFT → RL 做显著提升，并出可引用的 5-run mean±std + 配对检验结果。

2.4 管线 bug 排查（5-run 坍塌 RCA）

现象：5-run 中 run2/3/4 报 0.0%，仅 run1 正常。

根因：抽取器只读 code/<task>/ws/pyAether_code/，但模型代码写到无 ws 路径 → 只取到 1/1/0 条 → 0.0%。不是模型 collapse，是管线 ws/no-ws 路径失配。

修复：回补 wrapper（归一化路径）+ 精确 batch↔eval 匹配。回补后干净数字：run2=4.43%、run3=2.53%、run4=3.80%（exec 43/28/35 ≫ 1，证伪 collapse）。

已修复 产物全保留
